# V*: Guided Visual Search as a Core Mechanism in Multimodal LLMs

## What this paper does
Introduces SEAL: a VQA LLM with visual working memory plus V*, an LLM-guided hierarchical search that recursively splits the image into sub-images and uses target/contextual cue heatmaps to prioritise which to explore; introduces V*Bench.

## Goal-by-goal answers
### Goal: What are k and image size in V*Bench, and how is search structured?
191 SA-1B images, average 2246x1582; 115 attribute-recognition questions (one target object) and 76 spatial-relation questions (two objects), so k is 1-2 [full text, Section 4]. Search is hierarchical sub-image splitting guided by heatmaps; V* reduces average search length vs random/sequential BFS/DFS [Section 5.3]. Already an adaptive coarse-to-fine search, not per-region exhaustive querying.
