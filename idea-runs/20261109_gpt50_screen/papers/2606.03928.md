# Value-Aware Stochastic KV Cache Eviction for Reasoning Models (VaSE)

## What this paper does
Training-free decode-time eviction for reasoning models. It finds a small fraction of value vectors with abnormally large Range(v)=max−min; evicting them sends models into repetitive self-reflection loops. VaSE-AttnV reserves N_v slots for the largest-Range values and fills the rest by sampling (not top-k) from SnapKV attention weights; VaSE-DKV resamples CurDKV's Gaussian projection at every eviction step. Periodic eviction with buffer 64 and budget K≈N_avg/4. Evaluated on Qwen3-4B/14B over AIME25, AIME26, HMMT25, GPQA-D, MATH, LCB-v6.

## Goal-by-goal answers
### Goal: What is the link between value magnitude, loops and quantization error?
Evicting large-Range value states causes "endless loops of self-reflection" and ungrammatical text [full text, Section 3.1, Fig. 9]. On GSM8K at K=512 (~4×) Qwen3-4B (full 88.4%): reserving 16→256 value slots raises SnapKV-based accuracy from 73.3% to 80.5%; replacing top-k with sampling raises SnapKV 64.3→70.9 and CurDKV 78.6→87.6 [full text, Section 4.1, Fig. 3]. Range(v) is highly correlated with per-token HQQ value-quantization MSE across bit-widths/groups (e.g., b2g32), because the scale is Range/(2^b−1) [full text, Section 4.3, Fig. 5 right].

### Goal: What protocol and accuracies are reported?
Budget set per task to ≈ full-model mean length/4 (K∈{1024,2048,4096}), SeerAttention-R at matching 25% activation; pass@1 over 16 runs (<100 items) or 8 runs [full text, Section 4.2 Setup]. Qwen3-4B average: VaSE-AttnV 59.09% vs SeerAttention-R 58.81%, R-KV 54.69%, CurDKV 49.78%; Qwen3-14B: 65.81 vs 65.37 vs 60.90 vs 55.70 [full text, Section 4.2, Table 2]. LCB-v6-Medium at 2048 budget: SeerAttention-R only 45.3% vs R-KV 62.6%, VaSE-AttnV 63.5% (gate fails under domain shift) [full text, Section 4.2]. Generation-length or loop-rate tables are not given as main metrics; loops are shown qualitatively.

### Goal: What throughput/memory evidence is given?
Qwen3-14B, one A100-80G, FlashAttention2 without PagedAttention, batch 16, prompt 256: at 16K output and budget 2048, VaSE-DKV 411 vs Full 133 tok/s (3.1×); Full OOMs at 32K output; peak memory ordering VaSE-DKV < VaSE-AttnV < R-KV < Full, ~4× KV compression [full text, Section 5, Fig. 6]. Fixed batch, not memory-saturated serving; no cost-per-correct.
