# AsyncSpade: Efficient Test-Time Scaling with Asynchronous Sparse Decoding

## What this paper does
Training-free, query-aware token-level sparse decoding for long CoT. A separate "cache rank" device predicts the next step's query from a short window of recent queries, using softmax-normalized ridge regression pooled over window sizes. It selects the top KV tokens for step t+1 while the inference rank runs step t, so selection is off the critical path. Evaluated with Qwen3-32B and DeepSeek-R1-0528-Qwen3-8B on AIME24/25, GPQA-Diamond and MATH500 against Quest and TOVA on A100/H100 nodes.

## Goal-by-goal answers
### Goal: How fast do decode-time query/attention patterns drift across steps in long-CoT reasoning (measured)?
They measure the top-k overlap ratio O_{t-d,t} between the selected token sets of queries d steps apart (Qwen3-32B, AIME24, full attention, top 1/8 of the KV, 4 layers). "The most recent 16 tokens consistently maintain high overlap ratios of over 40%" [full text, Section 3.1, Eq 1, Fig 4]. A softmax-weighted linear combination of the previous W=16 queries gives a predicted query whose top-k overlap with the true one is "relatively high", and shifting it one token ahead works as well [Section 3.2, Eqs 2-4, Fig 5]. Only one-step-ahead prediction is used. Nothing is reported for gaps of hundreds of tokens.
### Goal: Does it use the stale/predicted query to compute attention, or only to select?
Only to select. The attention itself still uses the true current query on the selected KV [Section 4.1, Section 4.2]. It claims comparable or better Pass@1 than Quest/TOVA with 2K selected tokens at lower decoding FLOPs [Section 5.2, Fig 9]. TPOT is measured at batch 8 with 32K context [Section 5.3].
