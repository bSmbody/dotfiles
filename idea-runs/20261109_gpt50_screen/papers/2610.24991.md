# Certified Sparse Attention via Perturbed Retrieval

## What this paper does
Training-free decode sparse attention with per-query error certificates. Each pool key gets an Exp(1) perturbation; thresholding the perturbed score yields Poisson PPS (threshold) sampling with probability min(1, w_i/tau) in the attention weight; a Horvitz-Thompson estimate of numerator and denominator is formed, and anytime-valid Chernoff/Bernstein certificates on a geometric grid of thresholds let each head stop at the first level that meets error epsilon. Candidates come from a 4-bit key scan with deterministic score upper bounds, shared across a GQA group. Reads O(eps^-2 log(1/delta)) values independent of context; CPU implementation.

## Goal-by-goal answers
### Goal: How does it sample and estimate, and does it use any variance-reduction / centering on values?
Light keys are sampled independently with probability w_i/tau and get HT weight tau; heavy keys (w_i >= tau) and a recent window are exact: N_hat = N_R + N_B + tau sum_{S cap A} v_i, D_hat similarly, o = N_hat/D_hat [full text, Section 4.1-4.2]. Certificates are centered at c = known-part output so the deviation scales with value spread around c, which cuts keys read 1.8-1.9x [Section 4.3]. No low-dimensional value-moment balancing.

### Goal: What does it read and cost per query?
A 4-bit per-block key scan is read for every pool token (84 bytes/token per query, 16.4% of dense attention bytes, the floor), plus exact 16-bit keys for candidates and values only for sampled keys; the index adds ~40% storage (16% without 8-bit codes) [Section 4.4-4.5]. So it, too, pays an all-keys pass (compressed) and saves mainly on values and exact keys.
