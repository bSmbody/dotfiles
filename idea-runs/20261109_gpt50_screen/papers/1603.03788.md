# A Primer on the Signature Method in Machine Learning

## What this paper does
Tutorial/survey (Chevyrev & Kormilitzin) on path signatures: definition as iterated integrals of a path X:[a,b]->R^d, levels k with d^k terms each, key properties (reparametrization invariance, shuffle product, Chen's identity, log-signature), and ML pipelines that embed data as paths and use truncated signatures as features (e.g., handwritten digits). No video-LLM or memory system.

## Goal-by-goal answers
### Goal: Does it state Chen's identity in the form C6 uses, and what does level k cost?
Yes. Theorem 1.2: S(X)_{a,c} = S(X)_{a,b} ⊗ S(X)_{b,c} componentwise as a sum over splits of the multi-index [full text, Section 1.3, Eq 19]; the inverse-based interval read S[a,b]=S[0,a]^{-1}⊗S[0,b] follows from the group-like structure. The k-th level is the collection of all d^k terms [full text, Section 1.2, around Example 4], so the truncated signature to level n has O(d^n) entries. For a 1-D path the signature depends only on the increment X_b - X_a [Example 5], i.e., the signature encodes how a path moves, not where it sits, unless augmented (time/basepoint channels).
