# MagicPIG: LSH Sampling for Efficient LLM Generation

## What this paper does
(Abstract only, not body-read.) Argues top-k attention is biased when attention is not sparse and instead estimates attention by LSH-based importance sampling with theoretical guarantees; stores hash tables and runs the sampled attention on CPU, giving up to 5x decode throughput on Llama-3.1-8B at 96k.

## Goal-by-goal answers
### Goal: Is sampling-based (unbiased) decode attention prior art independent of SANTA?
Yes: sampling instead of top-k for decode attention, with the sampling distribution supplied by LSH so that keys need not all be scored on GPU [abstract]. It precedes SANTA and shows the key-scoring cost is the part worth avoiding.
