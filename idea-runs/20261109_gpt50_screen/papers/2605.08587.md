# Kaczmarz Linear Attention

## What this paper does
Revisits the per-token online-regression objective behind Gated DeltaNet and derives, from the Kaczmarz projection (minimum-norm state change satisfying S^T k_t = v_t), a key-norm-normalised step beta_t = eta_t / (||k_t||^2 + eps). KLA is a one-scalar modification of GDN that keeps the state, gates and chunkwise algorithm. 0.4B models on 1B tokens; evaluated on perplexity up to 65K, MQAR, S-NIAH, palindrome, stack, throughput.

## Goal-by-goal answers
### Goal: What memory update rule does it use and what determines the write/erase strength per token?
Eq. 1-3 [full text, Section 3.1]: S_t = S~_{t-1} + beta_t k_t e_t^T with residual e_t = v_t - S~_{t-1}^T k_t and S~_{t-1} = alpha_t S_{t-1}. The objective (Section 2) is J_t(S) = 1/2||S^T k_t - v_t||^2 + lambda_t/2 ||S - S~_{t-1}||_F^2: it "fits the current key-value association" while staying close to the decayed memory. With eta_t = 1 the update is an exact projection onto the current pair's constraint (Theorem 1).

### Goal: What does it report as its limitation on recall / memory capacity at long context?
Section 6 Limitations: "KLA improves the local write coefficient but retains the capacity limits of a fixed-size recurrent state." Exactness holds only at eta_t=1, eps=0; GDN slightly beats KLA on the longest palindrome setting, "suggesting that structured reversal may need mechanisms beyond key-norm-normalized residual writes".

### Goal: Does the rule decide what to retain using anything other than recency and the current token?
No: the derivation is explicitly token-local (one constraint per token), and the exact projection fully overwrites the current key direction regardless of what else is stored there.
