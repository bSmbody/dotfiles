# Joint Subspace Sparse Attention for Efficient Long-Context Decoding

## What this paper does
(Abstract only, not body-read.) Learns a shared low-dimensional query-key subspace for token-level top-k selection and provides a gather-free indexed-attention kernel supporting distinct per-KV-head selections under the GQA layout; up to 6.43x decode throughput at 128K on B200 while keeping reasoning accuracy and avoiding generation-length inflation.

## Goal-by-goal answers
### Goal: How do current token-level sparse methods treat the GQA group?
The selection unit is the KV head (one selection shared by its query heads), with a kernel built for that layout [abstract]. This is the deterministic analogue of what C3 wants: one read set per KV group. It also scores keys in a low-dim subspace, i.e. it avoids reading full keys — the part C3 cannot avoid.
