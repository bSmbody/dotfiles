# Fractal KV-Cache Archives: Lossless Symbolic Storage with In-Place Retrieval for Long-Context LLM Inference

## What this paper does
(Light-mode digest, from arXiv biblio/abstract only; body not read.) Given a KV cache already quantized to codebook indices (per-head residual VQ), it serializes the index stream with contractive iterated-map codes into low-dimensional real vectors, giving a lossless archive with O(1) random access / amortized append that is also a substring-search index. GPT-2, 1024-token contexts, 4 sink + 32 recent tokens exact; 36-54x archive compression at 11-15% perplexity cost; keys ~4x more sensitive than values.

## Goal-by-goal answers
### Goal: Is GPT's novelty delta for C2 vs this paper accurate?
Yes as stated: Fractal KV losslessly stores the quantized code stream itself; it does not route raw token literals out of the quantized channel or change the output (copy) interface. But it is not the closest prior to C2; token-selective mixed precision (MiKV, IntactKV, SemKV) and pointer/copy networks are closer. Abstract-level only.
