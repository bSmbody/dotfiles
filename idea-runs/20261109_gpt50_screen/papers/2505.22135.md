# RAD: Redundancy-Aware Distillation for Hybrid Models via Self-Speculative Decoding

## What this paper does
RAD picks which attention layers of a pretrained Transformer (Llama-3.2-3B etc.) to replace with SSM blocks (Mamba, Mamba2, Longhorn). It builds a self-speculative draft by skipping a binary set of attention layers, measures the throughput of self-speculative decoding on 10 PG-19 summarization prompts (2048-token input, 128 generated tokens, greedy), and runs 2000 iterations of Bayesian optimization to find the skip set with the highest throughput. Those layers become SSMs (out_proj copied, in_proj zero-initialized), and only the new SSM parameters are trained by forward-KL (self-)distillation. Reports large GSM8K/CRUX gains over a Llama-70B-distilled baseline.

## Goal-by-goal answers
### Goal: What signal does it use to pick which attention layers to replace, and is it computed on the model's own generations?
Throughput of self-speculative decoding with the selected attention layers skipped in the draft, which implicitly measures token acceptance of the draft's greedy generations against the full model [full text, Section 3.1 / Eq 1]. So the signal is generation-based (the draft generates, the full model verifies), but the draft is the teacher with layers skipped, not the trained hybrid. Selection is done once, before any distillation, over a whole skip configuration (BO over {0,1}^L), not per failure or per position [Section 3.1; Section 4.1 "Redundancy Identification Setup"].

### Goal: How is the number of replaced layers set, and is selection validated against a weaker selection?
The ratio is mostly fixed by hand at 50% of attention layers (8 or 14 layers in ablations); the Limitations say other ratios were not explored [Section 6]. An ablation contrasts the "opt" set with a "worse" set found by minimizing throughput: Longhorn opt vs worse gives GSM8K 63.31 vs 55.5, MMLU 58.27 vs 55.88, Needle 99.7 vs 97.0 [Section 4.2, Table 6]. There is no comparison against other selectors (KL-based or uniform interleave) in that ablation.

### Goal: Does it evaluate long chain-of-thought reasoning or retrieval at long length?
No long-CoT evaluation; reasoning is GSM8K/CRUX-style short generation, plus LongBench and passkey retrieval in the appendix [Section 4.2; Appendix A.1]. Generation length in the selection procedure is 128 tokens [Section 4.1].
