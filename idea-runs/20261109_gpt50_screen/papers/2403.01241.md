# IntactKV: Improving Large Language Model Quantization by Keeping Pivot Tokens Intact

## What this paper does
(Light-mode digest, from arXiv biblio/abstract only; body not read.) Identifies "pivot tokens" (initial tokens absorbing most attention) whose KV must be exact for quantized LLMs, and generates their KV losslessly from the full-precision model; optionally calibrates them as parameters. ACL 2024 Findings.

## Goal-by-goal answers
### Goal: Is "keep a token class's KV exact while the rest is quantized" prior art?
Yes, for a token class chosen by attention role (sinks/pivots). C2's literal-in-high-precision variant would swap the class definition to numbers/identifiers.
