# Combinatorial Group Testing and Sparse Recovery Schemes with Near-Optimal Decoding Time

## What this paper does
Pure coding/algorithms paper: constructs disjunct and list-disjunct test matrices with optimal number of tests and near-optimal (sublinear in n) decoding time, plus error-correcting variants and heavy-hitter / compressed-sensing analogues. No learning, no vision.

## Goal-by-goal answers
### Goal: How many non-adaptive tests does exact identification of k of n need, and does noise matter?
Disjunct matrices (exact recovery) need Omega(k^2 log_k n) rows; random constructions achieve O(k^2 log n). List-disjunct matrices need roughly a factor k fewer rows but only return a small superset, so a second stage is needed [full text, Section 1, "Disjunct Matrices" / "List-Disjunct Matrices"]. Error-correcting constructions exist for false negatives or for false positives, but the authors cannot get fast decoding for both at once [Section 3.3]. So the C7 claim "O(k log n)" for a fixed disjunct design is off by a factor k; O(k log n) is the adaptive / list-disjunct regime.
