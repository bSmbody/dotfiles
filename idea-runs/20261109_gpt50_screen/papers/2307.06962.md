# Copy Is All You Need

## What this paper does
(Light-mode digest, from arXiv biblio/abstract only; body not read.) Formulates text generation as copying contextualized text segments from an indexed collection via vector search instead of choosing tokens from a vocabulary; WikiText-103 quality gains with comparable inference efficiency.

### Goal: Relevance to C2?
Shows copy-as-retrieval output interfaces for LMs; but it needs training the model around the new interface, which is the cost C2's "LoRA-train a copy interface" also incurs.
