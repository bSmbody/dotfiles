# Does Accuracy Equal Evidence? Reasoning Faithfulness under KV Cache Compression

## What this paper does
An evaluation paper (EMNLP 2026 Findings). It introduces fixed-trace replay: a Full-KV run produces <think>r</think>; each compression method then prefills q‖r with its own compressed cache of r (question cache protected) and regenerates only the post-</think> answer and visible rationale. It scores final accuracy, answer–chain consistency (LLM-judge "Reasoning Wrong, Answer Correct", RWAC), and perturbation faithfulness (inject a wrong answer at start/middle/end of the trace). Ten eviction methods plus KIVI-2bit on Qwen3-8B (also R1-Distill-Llama-8B, Qwen3-30B-A3B) over AIME24/25/26, GPQA-D, MedCalc, RULER QA.

## Goal-by-goal answers
### Goal: What protocol and budgets are used, and how do they differ from end-to-end generation?
Main eviction budget 256 retained tokens (chosen to separate methods), ablated 512–8192; 3-seed means; judge validated vs. a human (94.6% agreement, κ=0.89) [full text, Sections 3.1, 4.1]. Fixed-trace replay is explicitly a component-level retention diagnostic, not an end-to-end deployment benchmark; end-to-end AIME26/GPQA checks are added and show the same pattern [full text, Section 2, Table 2].

### Goal: What is the answer–evidence gap and does quantization show it?
Eviction methods often keep the final answer while the visible chain becomes invalid; SnapKV RWAC cases are dominated by "answer-first rationalization" [full text, Section 4.2, Table 6]. Across compressors, accuracy rank and chain-validity rank are negatively Spearman-correlated on AIME/GPQA, so accuracy leaderboards can select evidence-destroying methods [full text, Section 4.3, Table 4]. KIVI-2bit, which keeps token coverage, stays close to Full-KV on all metrics and rarely degrades matched-correct chains [full text, Section 4.2, Table 5].

### Goal: Which retention biases matter and does more cache close the gap?
Attention/head-salience methods (SnapKV, AdaKV, HeadKV) retain late injected conclusion-like claims; prior-retaining methods make early injected answers act as anchors; redundancy methods may evict repeated verification steps that would reject a false claim [full text, Section 4.4]. Larger budgets recover accuracy (near Full-KV on GPQA/MedCalc) but on AIME chain validity remains degraded at all budgets up to 8192 [full text, Section 4.5, Fig. 2].
