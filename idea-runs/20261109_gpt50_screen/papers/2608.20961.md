# TreeWY: Speculative Verification for Gated DeltaNet Hybrids

## What this paper does
Removes per-draft-node recurrent-state snapshots in speculative decoding for GDN hybrids (Qwen3.5 35B/397B). A tree-structured WY transform of the gated delta rule computes every draft node's output with one triangular solve over pseudo-values and reconstructs only the accepted state on commit, storing an N x d_v pseudo-value matrix instead of N full states.

## Goal-by-goal answers
### Goal: How does TreeWY represent a GDN branch/tree, and does it ever combine several branches' states?
Rewrite S_t = alpha_t S_{t-1} + v~_t k_t^T with pseudo-value v~_t = beta_t (v_t - alpha_t S_{t-1} k_t); for a DFS-ordered tree, (I + diag(beta) G) V~ = R with G[t,i] = (g_t/g_i)(k_t^T k_i)[i ancestor of t] solved by one forward substitution [full text, Section 3, Eq 2]. On commit the accepted node's state is S_a = g_a S_0 + sum over ancestors (g_a/g_i) v~_i k_i^T [Eq 3]. Only the single accepted root-to-leaf path is materialised; siblings are discarded, never merged. The scalar-decay ancestor mask is from STree, and extending it to GDN's non-commuting rank-1 correction is the stated contribution [Section 3].
