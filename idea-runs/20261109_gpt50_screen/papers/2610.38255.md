# ParaTTT: Parallelizing Test-Time Training Layers with Deep Memories

## What this paper does
ParaTTT computes the exact tokenwise online-gradient-descent trajectory of a deep (L-layer, used with L=2) MLP fast-weight memory with chunkwise-parallel kernels. Given a guess of the hidden-layer pre-activation gradients ("pseudo-labels"), each hidden layer becomes gated linear attention or a gated delta rule, and the readout becomes an exact Gated DeltaNet on the resulting features. A parallel backward pass then recomputes the gradients, and a damped Picard iteration converges to the exact sequential recurrence (N=2 iterations in practice). Decoding is exact single-step OGD. At 340M and 1.3B it matches or beats Gated DeltaNet and Mamba-2 (released 2026-10-28).

## Goal-by-goal answers
### Goal: How does ParaTTT treat the readout versus the hidden layer of a two-layer memory, and does the hidden layer receive credit from the joint reconstruction error?
The memory is f_W(k) = W^(L) phi with features phi = h^(L-1). Each token takes one gradient step on the joint loss 1/2||f_W(k_t) - v_t||^2 for every layer (Eq 1-2). Conditioned on the pseudo-labels D, the hidden layers are linear recurrences with values -eta delta z (Eq 3-4). "Unlike the hidden layers, the readout needs no trajectory estimate. Once its input features are fixed, its fast weights follow a Gated DeltaNet with keys phi_t" (Step 2). The feature gradient e_t = eta W^T(W phi - v) (Eq 5) is propagated back into the hidden layers (Step 3, Eq 6). So, unlike DeltaTTT, the hidden layer gets credit for the readout's error. The readout itself takes one delta-rule step per token; it is not solved to optimality [full text, Section 3.1-3.2]. Section 3.4 adds centering so that hidden layers get gradient from the first token. The related-work section names MesaNet's optimal regression readout as a possible extension: "Extending its readout to these other updates is a possible direction" [Appendix A, Linear recurrences].

### Goal: Does a more accurate inner trajectory or more inner optimization reliably improve downstream long-context results?
Not reliably. Training with N=5 refinement iterations instead of 2 "improves all four recall tasks ... but raises LAMBADA perplexity from 26.93 to 28.44 and reduces 32K NIAH accuracy from 16.0 to 5.8" [Section 4.1]. Without its sliding-window branch, LaCT's fast-weight-only layer is "essentially context-free" (WikiText-103 perplexity in the hundreds) [Appendix F.2, Table 5]. Block-form TTT-MLP gives "little improvement on recall" [Section 4.1].
