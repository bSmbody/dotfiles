# MLLMs Know Where to Look: Training-free Perception of Small Visual Details with Multimodal LLMs

## What this paper does
Shows MLLM accuracy drops sharply as the answer region shrinks, that this is a perception (not localisation) failure because answer-to-image attention concentrates on the right box even when the answer is wrong, and proposes ViCrop: use relative attention / gradient maps from the same model to pick a crop and append its tokens.

## Goal-by-goal answers
### Goal: Do small targets cause false negatives in a downsampled/large view, and can localisation be done in ~1 pass?
Yes on both: accuracy falls from large to small answer boxes and human cropping restores it [full text, Section 3, Table 1]; attention ratio >1 in most layers regardless of correctness, so the model localises in one (rel-att: two) forward passes [Sections 4-5]. For V* it computes importance maps per <1024 px block and re-attaches them [Section 5, High-Resolution Visual Cropping].
