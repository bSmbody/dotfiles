# Lynx: Progressive Speculative Quantization for accelerating KV Transfer in Long-Context Inference

## What this paper does
Lynx targets prefill-decode disaggregation, where decode waits for the whole KV transfer. It quantizes KV hierarchically (distribution-aware, non-linear for the Laplacian-like centre) into a high-priority Anchor stream (most significant information) and a low-priority Residual stream. Decoding starts as soon as the Anchor arrives and produces speculative draft tokens; once the Residual arrives the KV is refined to full precision and the drafts are verified losslessly in one parallel forward pass, as in speculative decoding.

## Goal-by-goal answers
### Goal: Does it implement "low-bit base resident + residual fetched later" (seed 4)?
Only as a one-shot transfer-latency trick: the residual is always transferred in full and the cache is then refined to full precision for verification and subsequent decoding [full text, Sec 4.2]. There is no selective residual fetch per block, no attention-concentration trigger, and HBM ends up holding full-precision KV, so it does not save decode-time capacity.

### Goal: Accuracy guarantee?
Lossless by construction: drafts generated on the Anchor state are verified against Q_full, accepting the longest valid prefix [Sec 4.3]. Acceptance is reported high enough that relaxed verification is unnecessary [Sec 4.3, Fig 10]. Not evaluated on long CoT.
