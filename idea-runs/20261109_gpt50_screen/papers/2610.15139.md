# When Dynamic Scaling Fails: A Scale-State Feedback Governs Recurrent-State Quantization in Linear-Attention and SSM LLMs

## What this paper does
Training-free, state-only fake-quantization study on GDN (0.8B, 2B) and Mamba-2 (1.3B). Shows a failure frontier in bit-width x decode horizon, identifies a feedback loop between per-token dynamic quantizer scale and the state it is derived from, and compares containment policies (persistent scale, ceilings, resets, group-wise, layer allocation).

## Goal-by-goal answers
### Goal: What happens to recurrent-state compression as decode horizon grows, and what limits current methods?
Per-token dynamic INT4 keeps synthetic recall at H=0 and destroys it by H=1024 [full text, Section 1, Figure 1]. Yoking the scale removes norm explosion but recovers only 1.8 of 5.4 nats; the residual is resolution-dependent [full text, Sections 5, 8, Table 3]. Learned per-layer bit allocation collapses onto protecting the first layers [full text, Section 8]. Short evaluations certify policies long before failures appear (11/30 articles fail by H=2048 with no short-horizon precursor) [full text, Section 9]. The best policy still leaves perplexity 7.8x (0.8B) at H=2048 [full text, Limitations].
