# WeaveTime: Stream from Earlier Frames into Emergent Memory in VideoLLMs

## What this paper does
CVPR 2026. Diagnoses "time-agnosticism" in Video-LLMs for streaming QA. Adds a light finetuning objective (Temporal Reconstruction / Streaming Order Perception) to make representations order-aware, and at inference a Past-Current Dynamic Focus Cache: answer from a short recent window, and only if the answer entropy exceeds a threshold, do coarse-to-fine recall of history (frame-level similarity, then token-level maxSim late interaction, top-K frames).

## Goal-by-goal answers
### Goal: Is GPT's novelty contrast ("WeaveTime trains order and retrieves history") accurate?
Yes. Order comes from a training objective [full text, Section 3.2]; inference is an uncertainty-gated policy (entropy vs threshold delta, Eq 5-6) plus coarse-to-fine retrieval over stored per-frame KV/keys with maxSim scoring (Eq 7-8) [full text, Section 3.3]. It retrieves raw frame tokens, not a closed-form interval summary, so C6's stated difference (order kept algebraically by non-commutative products, O(1) interval read) is a real difference in mechanism. WeaveTime is, however, only one of many streaming-video memory baselines and not the closest one for efficiency (see StreamKV, MuKV).
