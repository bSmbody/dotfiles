# Kalman Linear Attention: Parallel Bayesian Filtering For Efficient Language Modelling and State Tracking

## What this paper does
KLA casts sequence mixing as exact Kalman filtering under an Ornstein-Uhlenbeck dynamics prior with process noise, and token keys and values as noisy evidence. In information form, the per-channel precision update is a Moebius (linear-fractional) map and the mean update is affine, so both compose associatively and run as parallel prefix scans. Tested on MAD synthetics, MQAR, A5 state tracking and stacked language modelling at billion-token scale.

## Goal-by-goal answers
### Goal: Is KLA's covariance dense or diagonal, and how does it achieve temporal parallelism?
Diagonal. "KLA's covariance/precision remains diagonal throughout". The state-expanded N x D matrix comes "solely from state expansion ... and is not a full covariance" [full text, Section 4, Notation and scope]. Parallelism: the per-channel precision recursion lambda_t = (alpha lambda_{t-1} + beta)/(gamma lambda_{t-1} + delta) is a Moebius transform whose 2x2 coefficient matrices compose by matrix product, giving an O(T)-work, O(log T)-depth scan [Theorem 1 / Eq 16-17; Corollary 1.1]. The mean update is affine and is also scanned [Theorem 2]. Limitations: "diagonal, linear time-invariant (LTI) dynamics"; headroom remains "in standalone long-context retrieval" [Section 7]. Cross-key interference (off-diagonal covariance) is therefore not represented.
