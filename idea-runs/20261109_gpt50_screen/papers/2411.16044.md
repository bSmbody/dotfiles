# ZoomEye: Enhancing Multimodal LLMs with Human-Like Zooming Capabilities through Tree-Based Image Exploration

## What this paper does
Training-free tree search over an image quadtree: each node is a sub-patch split into 4 children until encoder resolution; the MLLM ranks nodes by yes/no next-token probabilities of an existence prompt and a "could zooming reveal it" prompt, weighted by depth, and stops when an answering-confidence prompt passes a threshold.

## Goal-by-goal answers
### Goal: Does a hierarchical existence-query search already give logarithmic cost, and how reliable is the existence (OR) answer at coarse views?
Yes: quadtree with depth-dependent priority; search steps decrease as the number of sub-regions per split increases, and accuracy rises with more search steps [full text, Sections 3.2-3.5, 4.4.1, 4.4.3]. The authors add a separate "latent confidence" prompt precisely because at shallow depth the object is too small to be perceived, so the plain existence answer is unreliable on coarse/large views [Section 3.3].
