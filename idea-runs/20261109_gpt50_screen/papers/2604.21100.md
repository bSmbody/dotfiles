# Preconditioned DeltaNet: Curvature-aware Sequence Modeling for Linear Recurrences

## What this paper does
Casts linear attention and the delta rule as first-order solvers of online least squares and adds a key-space preconditioner. With the exact inverse key Gram, preconditioning the query of linear attention (ATQ) and preconditioning the write key of DeltaNet (ATK) both recover the exact least-squares map. In practice it uses a diagonal key-Gram approximation, squashed for stability, which keeps the WY chunkwise kernels. It gives preconditioned DeltaNet, GDN and KDA at 340M and 1B, plus synthetic recall.

## Goal-by-goal answers
### Goal: Does it already give an exact dense second-order (RLS) delta write, and how is it parallelised?
Theorem 3.1 [full text, Section 3.1 / Eq 5]: with P_t = (sum k k^T + lambda I)^{-1} and write key k~_t = P_{t-1} k_t / (1 + k_t^T P_{t-1} k_t), the modified DeltaNet recursion gives S_t = C_t P_t exactly. So "delta write with a write key preconditioned by the dense inverse covariance" is stated here as exact RLS. Section 3.2 / Eq 6 gives the chunkwise WY form *given* per-token P, but says exact Sherman-Morrison updates "cannot be summarized into a chunk-local affine transition, precluding a chunkwise parallel form" [Section 3.2; Appendix C.4]. Appendix C.4 suggests an intra-chunk-sequential, inter-chunk form as future work. The implemented model is therefore diagonal: A_t = alpha A_{t-1} + beta (k ⊙ k), squashed into [1/x, x] [Section 3.3, 3.5 / Eq 7-9]. This setting has no forgetting at all (fixed ridge, plain sum), so the stated obstacle to chunking is the nonlinear inverse recursion, not the forgetting rule.

### Goal: What evidence does it give on the anisotropy of the key Gram in a trained model?
Figure 1 [Section 3.3]: in a pretrained DeltaNet-340M layer, the eigenspectrum of the key Gram correlates with that of its diagonal, and its eigenvectors are "fairly axis-aligned". The authors use this to justify the diagonal approximation. It is an argument that the dense off-diagonal structure is modest in that model.
