# Retrieval-Augmented Perception: High-Resolution Image Perception Meets Visual RAG

## What this paper does
Training-free: scores image crops against the query with a visual retriever, keeps top-K, composes them into one image with a Spatial-Awareness Layout that preserves relative positions, and picks K by Retrieved-Exploration Search using model confidence.

## Goal-by-goal answers
### Goal: How does an MLLM behave when several regions are composed into one input image?
Composing more crops helps cross-instance tasks but hurts fine-grained single-instance perception: larger K raises the composite resolution and increases wrong answers, smaller K is better for single-target tasks [full text, Section 3.3, Figure 2]; layout preserving relative positions matters [Section 3.2, Table 1]. Per-crop relevance is obtained cheaply from a retriever, not from MLLM queries.
