# Efficient Neural Network based Classification and Outlier Detection for Image Moderation using Compressed Sensing and Group Testing

## What this paper does
Extends neural group testing to non-adaptive pooling with a fixed m x n binary pooling matrix: a quantitative pooled network (QMPNN) takes n images, forms pools by entry-wise max over intermediate feature maps (superposed feature map), and outputs the number of positives per pool, decoded with compressed-sensing / group-testing decoders. Applied to image moderation and pooled outlier detection.

## Goal-by-goal answers
### Goal: Does it already implement a fixed disjunct/pooling matrix with algebraic decoding over neural feature superposition?
Yes. Pools are rows of a fixed binary matrix; the superposed feature map is max over IFMs of pool members, processed by the remaining blocks; outputs counts decoded by CS/GT algorithms [full text, Sections 3.1-3.2]. Requires training the pooled network. It handles items = whole images, not regions of one image; with two firearms in one image it still reports one positive image in 97/100 pools [Section 4.1, "Multiple Objectionable Elements"].
