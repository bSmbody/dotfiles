# Provable Quantization with Randomized Hadamard Transform

## What this paper does
Theory paper. Analyzes a data-oblivious vector quantizer: random sign flips, one normalized Hadamard transform, then a dithered Lloyd-style scalar quantizer whose grid is shifted by one uniform random U. Proves the dithered version is unbiased and matches TurboQuant's dense-rotation MSE constant asymptotically, and gives an inner-product quantizer with a residual stage. No experiments.

## Goal-by-goal answers
### Goal: Is shared-offset dithering already analyzed for KV-style rotated quantizers, and what does it buy?
Yes. One random shift U ∈ [0,1] defines grid points h_j = (j+U)/B on the quantile scale, shared by every coordinate of the transformed vector; each bucket reconstructs at its midpoint quantile [full text, Section 2, Definition 2.1]. The dither is known to the decoder (subtractive), so it costs no stored side code. Theorem 1.1: E[x̃] = x and E||x - x̃||² ≤ (π√3/2 + o(1))/4^b, matching TurboQuant [Section 1.1]. Theorem 1.2 bounds inner-product error by ~||y||²/(d 4^b) [Section 1.1]. KV-cache compression is named as an application, but there is no KV experiment [Abstract, Limitations].
