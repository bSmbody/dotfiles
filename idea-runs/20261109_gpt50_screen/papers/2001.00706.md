# Signatory: differentiable computations of the signature and logsignature transforms, on both CPU and GPU

## What this paper does
ICLR 2021 (Kidger & Lyons). GPU/CPU differentiable library for signatures and log-signatures with algorithmic speedups (fused multiply-exponentiate, better log-signature basis), inverted signatures, and tools that exploit the group-like structure: combine adjacent intervals, expanding-interval streams, arbitrary-interval queries, and online updates when new data arrives.

## Goal-by-goal answers
### Goal: Is the O(1) arbitrary-interval signature query via prefix signatures and inverses already known?
Yes, exactly. Section 4.2: precompute Sig(x_1..x_j) and InvertSig(x_1..x_j) for all j in O(L) work, then Sig(x_i..x_j) = InvertSig(x_1..x_i) ⊠ Sig(x_1..x_j), O(1) in L; this improves on O(log L) query with O(L log L) precomputation of Chafai & Lyons 2005 [full text, Section 4.2, Eq 6]. Exposed as the Path class, with an update method for streaming data [Section 5.5]. The authors warn it "may suffer from numerical stability issues when used for large i,j" [Section 4.2]. So C6's interval-read primitive (S[a,b]=S[0,a]^{-1}⊗S[0,b]) is an existing library feature, not a contribution.
