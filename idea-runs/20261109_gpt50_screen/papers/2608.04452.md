# Q-CueGraph: Query-Conditioned Visual Evidence Graphs for Multimodal Reasoning

## What this paper does
Training-free-reader evidence acquisition for frozen MLLMs: for documents it builds an OCR/layout graph, activates anchors from the question, expands to contextual regions and composes the top-K candidates into one observation window; for natural images it uses OWLv2 detections queried with question words. A small gradient-boosted scorer learns candidate answerability. Qwen2.5-VL-7B V*Bench 0.696 -> 0.832 using 19.1% of image area.

## Goal-by-goal answers
### Goal: What does Q-CueGraph do for natural-image search, and at what cost?
One OWLv2 detector pass per question supplies scored candidates; top-K selected and composed into an enclosing window preserving relative positions; empty detection falls back to full image; then one reader pass [full text, Sections 3.3, 3.5]. So localisation cost is one cheap detector pass plus one MLLM pass, not n region queries. It does not use set/pooled tests or codes; GPT's novelty contrast is accurate but Q-CueGraph shows the baseline cost is already ~O(1) MLLM passes.
