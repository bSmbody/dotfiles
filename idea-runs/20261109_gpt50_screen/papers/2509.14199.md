# DIVE with GRT: Dense Video Understanding with Gated Residual Tokenization

## What this paper does
Video LLM tokenization borrowing video-codec key-frame/P-frame coding: per scene, one key frame is fully tokenized and later frames only tokenize patches that changed (SSIM-gated), using the pretrained ViT without extra training; then merges tokens across scenes semantically. Tokenization cost grows sub-linearly with FPS.

## Goal-by-goal answers
### Goal: Is "write only the innovation of a new observation relative to prior ones" already used for visual tokens, and in what form?
Yes, in time: P-frame residual Delta f = M (.) (f_t - f_{t-1}) with binary SSIM mask M; but the gated tokenizer feeds only the *changed patches themselves* (not pixel residuals) to the pretrained ViT, inserting zero placeholders for masked positions [full text, Sec 3.2.1-3.2.2, Eq. 3-6]. So the readable, training-free form of innovation coding is patch gating, not residual-signal encoding. Applied to frames, not to zoom/crop re-looks of one image.
