# Get More with LESS: Synthesizing Recurrence with KV Cache Compression for Efficient LLM Inference

## What this paper does
LESS adds a constant-size low-rank recurrent state to each attention layer of a pretrained Transformer (Llama 2, Falcon). KV pairs evicted by any sparse policy (H2O, Lambda-shaped, top-k) are folded into this state before deletion, and later queries read it through learned kernels alongside the sparse cache. Kernels are small MLPs trained per layer with all model weights frozen, at the sparse policy and sparsity used at test time.

## Goal-by-goal answers
### Goal: What does the side memory learn, with what objective, and is the eviction policy used during training?
Evicted pairs enter H_t = H_{t-1} + sum psi(k)^T v (Eqs 4-6), and attention mixes phi(q)H_t with the exact softmax over cached pairs in one normalized sum (Eq 3) [full text, Section 3.1]. Only phi and psi are trained, per layer independently, to minimize the L2 distance to the original attention layer's output projection, using the masks of "whichever sparse policy we train on" at a given sparsity [Section 3.2 "Inexpensive Training"]. So the backup memory is trained on the eviction policy's own drops, but the objective is layer-local, not end-to-end.

### Goal: What does it report, and where are its limits?
It recovers over 40% of the Rouge-1 drop from H2O on CNN/DailyMail with Falcon 7B, and beats spending the same memory on more KV pairs; extra storage is about 4 KV pairs [Section 1]. Gains grow with sequence length because sparse caches drop a larger fraction [Section 4.4 "Providing Hope for Long Sequences"]. Scope is pure Transformers with summarization/LM evaluation; no hybrid, no reasoning-length decoding.
