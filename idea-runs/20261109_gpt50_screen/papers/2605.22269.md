# MuKV: Multi-Grained KV Cache Compression for Long Streaming Video Question-Answering

## What this paper does
CVPR 2026. For long streaming VideoQA, builds KV caches at three granularities per segment (whole segment, middle frame, patches of the middle frame), compresses them with attention- and frequency-based dual-signal token pruning, and at QA time does semi-hierarchical retrieval: parallel retrieval across granularities with mean-pooled last-layer keys vs the question, then coarse-to-fine rerank; retrieved KV is loaded for decoding.

## Goal-by-goal answers
### Goal: Does existing streaming video memory already offer multi-scale (interval-level) summaries?
Yes, at fixed granularities: segment-, frame- and patch-level KV, with each block summarized by a mean-pooled key for retrieval [full text, Sections 3.2 and 3.4, Eq 5-6]. It keeps real LLM KV (directly consumable by the frozen LLM) rather than an external feature. C6's arbitrary-interval read is more flexible than MuKV's fixed segments, but MuKV shows that the useful payload is KV the LLM can attend to, which a signature is not.
