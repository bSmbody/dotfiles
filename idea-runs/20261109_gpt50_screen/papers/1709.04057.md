# Parallelizing Linear Recurrent Neural Nets Over Sequence Length

## What this paper does
ICLR 2018. Shows that RNNs with linear sequential dependencies h_t = Lambda_t h_{t-1} + x_t can be trained and run in parallel over sequence length with a parallel scan, gives a CUDA kernel (up to 9x speedups) and linear surrogate RNNs (GILR-LSTM).

## Goal-by-goal answers
### Goal: Is a per-segment (transition, write) pair composed associatively already the standard primitive of parallel linear recurrence?
Yes. Algorithm 1 defines the binary operator (Lambda, x) . h = Lambda h + x; each processor reduces its segment to P_i = product of its Lambdas and R_i = its zero-start accumulated input, and a scan over the (P_i, R_i) pairs computes C_i = P_i C_{i-1} + R_i [full text, Section 2, Algorithm 1]. This is exactly a fixed-size, length-independent segment operator composed associatively; chunkwise DeltaNet/GDN kernels specialise it with WY-compressed transitions [2406.06484].
