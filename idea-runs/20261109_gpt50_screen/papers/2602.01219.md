# MiTA Attention: Efficient Fast-Weight Scaling via a Mixture of Top-k Activations [2602.01219]

## What this paper does
Views softmax attention as a two-layer fast-weight MLP of width N (keys = first layer, values = second layer, exp activation). Efficient attention = scaling this fast-weight MLP either by routing (each query uses a subset) or compression (condense to a narrower MLP). MiTA: m landmark queries by average-pooling queries over windows; each landmark gathers its top-k keys/values = a deformable routed expert; landmark values from landmark-to-all cross-attention form one shared compressed expert; each query is routed (s=1) to the expert of its most similar landmark and attends to [landmarks; that expert's k keys] in one FlashAttention-style pass. Cost O(N(m+k)).

## Results
ImageNet DeiT-T 71.1 vs full 72.2; DeiT-S 79.8 vs 79.9; ADE20K drop-in -14..42% FLOPs at -1.2..2.8 mIoU; LRA 58.91 vs 58.19 with 77% less training time. Vision/LRA only; no causal LM evaluation; gather step memory-bound. Reported (36kr) as NeurIPS 2026.
