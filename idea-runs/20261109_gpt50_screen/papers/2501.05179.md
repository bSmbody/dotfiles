# Global Compression Commander (GlobalCom2): Plug-and-Play Inference Acceleration for High-Resolution LVLMs

## What this paper does
AAAI 2026. Training-free token compression for dynamic-cropping HR-LVLMs (LLaVA-NeXT, LLaVA-OV): a global thumbnail plus local crops. Analysis shows thumbnail and crops are complementary and crops vary in information richness. The thumbnail acts as "commander": its [CLS] attention sets a per-crop retention ratio and, interpolated to each crop, is mixed with the crop's own [CLS] attention to pick which crop tokens to keep (TopK). Keeps >90% performance at 90% token compression.

## Goal-by-goal answers
### Goal: Does prior work already remove crop tokens that are redundant given the global view, training-free?
Yes, at the crop-vs-thumbnail level: thumbnail scores s^G guide crop compression; holistic score s_{j,i} = alpha * interp(s^G) + (1-alpha) s^L, then TopK per crop with adaptive ratio r_j [full text, Sec 4.1-4.2, Eq. 5-6]. It selects original crop tokens by importance; it does not compute any orthogonal residual or write residual tokens. Static multi-view input, not interactive zoom re-looks.
