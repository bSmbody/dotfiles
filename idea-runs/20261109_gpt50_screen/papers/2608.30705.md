# VisLens: Single-Pass Interpretable Visual Search for Multimodal LLMs

## What this paper does
Uses a logit lens (plus a small tuned lens on early layers) to decode visual tokens into words, matches them to query target words to build a crop, and appends the crop in the same pass; claims single-forward-pass visual search.

## Goal-by-goal answers
### Goal: What is the current cost frontier for MLLM visual search?
Single pass: on Qwen2.5-VL-7B V*Bench 74.3% at 0.98 s vs Thyme 72.25% at 8.78 s (9x); on LLaVA-OV-7B 4.8-22.2x faster than ZoomEye at matched accuracy, gap growing with resolution [full text, Section 4.3, Table 3]. Related work notes training-free methods (ViCrop, ZoomEye, UG-Search) need several passes per example [Sections 1-2].
