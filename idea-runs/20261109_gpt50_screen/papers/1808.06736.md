# A parallel non-uniform fast Fourier transform library based on an "exponential of semicircle" kernel (FINUFFT)

## What this paper does
FINUFFT is a CPU library computing type 1 (nonuniform to uniform), type 2 and type 3 exponential sums to a user tolerance eps in near-linear time. Type 1 spreads M nonuniform strengths onto an upsampled grid of size n >= sigma*N (sigma about 2) with an ES kernel of width w (w ~ log10(1/eps)+1), runs an n-point FFT, then truncates to N modes and deconvolves. It reports benchmarks on "high-density" tasks where M is comparable to or larger than N.

## Goal-by-goal answers
### Goal: What does the type-1 NUFFT compute, and what is its cost relative to direct summation?
Type 1: f_k = sum_{j=1}^M c_j exp(i k x_j) for integer modes k in [-N/2, N/2), with x_j in [-pi,pi) [full text, Section 1, Eq 1]. Naively O(NM); NUFFT is O(wM) spreading + O(n log n) FFT with n ~ 2N + O(N) deconvolution [full text, Section 3.1.1, Steps 1-3]. So the gain over direct summation exists only when M is large compared with the per-mode FFT cost (~log n): the FFT term is independent of M.
### Goal: Does the paper say when direct summation or dense matrix products beat the NUFFT?
Yes. Remark 2: repeated small problems pay a plan overhead, and there is a regime "small enough that a ZGEMM matrix-matrix multiplication approach wins" [full text, Section 2, Remark 2]. Remark 5: for adversarial type-3 data "a direct summation of (4) is preferable" [full text, Section 3.3, Remark 5]. Benchmarks deliberately use "high density" tasks where M is somewhat larger than N "so the FFT is at most a small fraction of the total time" [full text, Section 6]. The paper is CPU-only; a benchmarked GPU code is listed as future work [full text, Section 7].
### Goal: Is the NUFFT result exact, and how is precision controlled?
It is an approximation to relative tolerance eps set by kernel width and upsampling; error analysis in Section 4 gives near-exponential convergence in w [full text, Section 4.1-4.2]. It also describes "phase winding": consecutive exp(i alpha k q) over a regular k grid differ by a constant phase factor, replacing many cosines by multiplications [full text, Section 3.1.1].
