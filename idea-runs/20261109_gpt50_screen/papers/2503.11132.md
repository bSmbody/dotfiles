# X-EcoMLA: Upcycling Pre-Trained Attention into MLA for Efficient and Extreme KV Compression

## What this paper does
Upcycles pretrained attention (Llama3.2-1B/3B, up to 8B) into MLA via SVD-based initialization of all MLA matrices followed by end-to-end knowledge distillation from a (possibly larger) teacher and DPO. Reaches strong KV compression with lightweight post-training.

## Goal-by-goal answers
### Goal: How does the conversion choose the latent subspace and the retained RoPE dimensions, and what objective does it fit?
W^DQ/W^UQ/W^QR come from SVD of W^Q; W^DKV, W^UK, W^UV from joint SVD of [W^K, W^V]; the shared RoPE key W^KR is initialized as the last d_r columns of the head-averaged key projection [full text, Section 4.1, Eqs 8-12]. Rank is fixed or set by a weight-singular-value energy threshold delta [full text, Section 4.1, Eqs 13-14]. All initialization is weight-space; fidelity is recovered by KL distillation on SFT data [full text, Section 4.2].
### Goal: What does it report about long-context fidelity and limitations?
LongBench is reported only as an appendix: e.g. Llama3.2-1B base average 30.8 vs X-EcoMLA at 53% KV with mixed per-task changes; 3B LCC improves [full text, Appendix A.4.1, Table 8]. No explicit analysis of position-dependent error from the RoPE re-initialization.
