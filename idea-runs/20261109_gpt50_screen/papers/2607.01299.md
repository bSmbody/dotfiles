# HYPIC: Position-Independent Caching for Hybrid-Attention LLM Serving

## What this paper does
A serving system that brings position-independent caching (PIC: reuse of independently prefilled, non-contiguous segments such as RAG chunks) to hybrid models (Qwen3.5 GDN, Ring-linear, etc.). For linear-attention layers it caches, per segment, the tuple (segment-cumulative transition operator T_C, zero-start end state S_{C|0}) and composes any prefix state with cached segments in constant time. For full-attention layers it recomputes a small "seam window" at segment boundaries. It also parallelises cache-miss prefill across instances. TTFT down 3.25x on average, QPS up 1.66x, 1.71-point gap to full recompute.

## Goal-by-goal answers
### Goal: Is HYPIC's cached segment object the same as a C4-style "state patch" (segment transition + write term) for GDN, and how big is it?
Yes. Every linear-attention variant is written S_i = T_i S_{i-1} + u_i; for GDN T_i = g_i (I - beta_i k_i k_i^T) [full text, Section 2.2, Table 1, Eq 2]. HYPIC caches (T_C, S_{C|0}) with T_C = (prod g_t) prod (I - beta_t k_t k_t^T), a dense d_k x d_k matrix (32 KB per head per layer in FP16 at d_k=128), accumulated during first prefill in O(|C| d_k^2), applied in O(d_k^2 d_v) independent of segment length [Section 4.2, Table 3]. For Qwen3.5-35B-A3B the transitions across 30 linear layers are 31.4 MB per segment, the size of one running state [Section 4.2, "System-level memory footprint"]. Construction adds 5.2-6.7% to segment prefill [Section 6.3, Fig 13].
### Goal: What composition law does it use, and does it merge divergent sibling segments or only chain segments sequentially?
Sequential chaining only: S_{S C_1...C_n} = (T_{C_n}...T_{C_1}) S_S + sum_i (T_{C_n}...T_{C_{i+1}}) S_{C_i|0} [Section 4.2, Eq 6], i.e. "rebase" of cached segments onto an arbitrary prefix state. It motivates this by showing naive state addition has structural error (I - T_{C_2}) S_{C_1|0}; for RetNet with gamma=1-2^-5 the normalized error is 1.0 already at 256 tokens [Section 3.1, Eqs 3-5, Table 2]. There is no notion of two branches diverging from a shared ancestor, no merge of siblings and no commutator/conflict signal in the sections read.
### Goal: How exact is the composition in a deep model?
Layer 0 matches full recompute to ~1.6e-15 relative L2 in FP64 [Section 4.2, "Fidelity analysis"]. Across all linear layers (FA layers disabled), state drift vs full recompute is 8.92% relative L2 / 5.11 degrees (Qwen3.5-35B-A3B) because deeper-layer inputs of an isolated segment differ from in-context ones [Section 6.3, Table 4].
