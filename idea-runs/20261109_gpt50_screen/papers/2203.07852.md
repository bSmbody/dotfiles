# Block-Recurrent Transformers

## What this paper does
NeurIPS 2022. A transformer that combines sliding-window attention (window W=512) with a recurrent layer. The layer keeps S=512 state vectors that are updated once per block of W tokens via cross-attention and LSTM-style gates. Tokens in a block cross-attend to the state left by the previous block. Trained from scratch on PG-19, arXiv and GitHub; it remembers information over 60K+ tokens at the cost of about one extra layer.

## Goal-by-goal answers
### Goal: Does an existing architecture give near context at every step but far context only through a block-lagged channel?
Yes, in compressed form. Each token attends locally (its own block and the previous one), and far information arrives only through recurrent states updated at the end of each block. The far summary a token sees therefore lags by up to one block (W tokens) [full text, Section 3, Fig 2; Section 3.1]. It is trained end to end with this lag, and the state is compressed (S vectors), not the exact far KV [Section 3.1].
