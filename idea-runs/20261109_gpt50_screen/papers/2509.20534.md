# Efficient Symbolic Computation via Hash Consing

## What this paper does
(Light-mode digest, from arXiv biblio/abstract only; body not read.) Integrates hash consing into JuliaSymbolics: a global weak-reference hash table canonicalizes structurally identical symbolic subexpressions so each one is stored once, reducing "expression swell". Reports up to 3.2x faster symbolic computation, 2x less memory, faster codegen/compilation. Pure computer-algebra systems work; nothing about neural networks, KV caches or LLM decoding.

## Goal-by-goal answers
### Goal: Does it support C2's claimed mechanism (lossless literal side table addressed from a lossy channel)?
Only loosely. Hash consing is deduplication of identical immutable subexpressions via canonical pointers; C2 is not deduplication (KV of repeated literals differs by context) but a side channel for exact token identity. The source grounds "store canonical symbols once, refer by address", not the transfer condition C2 needs (that a literal's downstream use depends only on its identity). Abstract-level only.
