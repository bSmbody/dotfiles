# AsyncTLS: Efficient Generative LLM Inference with Asynchronous Two-level Sparse Attention

## What this paper does
Hierarchical sparse attention: coarse block filtering, then fine token selection inside the chosen blocks. It is combined with KV offloading that prefetches blocks asynchronously, using the temporal locality of block choices across decode steps. Evaluated on Qwen3 and GLM-4.7-Flash (GQA and MLA) at 48K-96K contexts, with 1.3-4.7x end-to-end throughput.

## Goal-by-goal answers
### Goal: How is the far cache read asynchronously, and is any attention computed with a stale query?
Coarse selection is lagged by one step: M_t = BlockSelect(q_t), while S_t = TokenSelect(q_t, M_{t-1}). Blocks in M_t that are missing are prefetched while attention over S_t runs, and only the set difference crosses PCIe (incremental transmission) [full text, Section 4.2]. Token selection and attention use the fresh query q_t. Only the block set is one step stale, so this is selection with a lag, not a lagged attention output.
