# SANTA++: Sampling Attention through Representative Keys

## What this paper does
Training-free stochastic decode attention that avoids SANTA's full-key scan. Prompt keys are grouped into teams with an actual-key representative; the query scores representatives, forms routing weights n_g exp(q.l_g/sqrt d), samples K teams by Gumbel-top-K, reads all member keys/values of selected teams, and divides each team's unnormalized mass Z_g and value sum U_g by its conditional inclusion probability (importance-sampling correction); o = U_hat/Z_hat. Generated suffix is exact. 16-22% of dense KV reads retain 94-99% of dense scores on LongBench v2 / HELMET RAG (Qwen2.5-7B, 32K); 1.69x attention speedup.

## Goal-by-goal answers
### Goal: What exactly does SANTA++ sample and correct, and does it read all keys?
It samples teams (groups of keys) from routing weights based on one representative key per team, so it does NOT read all keys: "replacing the full-key scan with approximate routing to enable substantially lower KV access" [full text, Section 1]. Selected teams' keys and values are read in full; Z_g and U_g are divided by the conditional inclusion probability c_g; "The two unnormalized sums are unbiased ... Their ratio ... is generally biased" [Section 2.3 / Eq 4]. GQA heads share the partition but select independently; KV is read for the union [Section 2.3].

### Goal: How does it relate to SANTA and other sampling-attention work, and is there any value-moment constraint?
SANTA "samples from the exact post-softmax attention distribution, which requires scoring every cached key"; SANTA++ is its grouped generalization and recovers SANTA when each key is its own team [Section 1, Section 5 "Sampling and importance correction"]. Under the reference counter, "SANTA's full-key scan contributes 50% before sampled value reads" [Section 3]. MagicPIG is cited as the LSH-based self-normalized importance-sampling relative [Section 5]. Weights are pure inverse inclusion probabilities; no value-side moment/balancing constraint or control variate is used [Section 2.3].
