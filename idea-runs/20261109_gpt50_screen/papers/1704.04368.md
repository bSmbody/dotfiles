# Get To The Point: Summarization with Pointer-Generator Networks

## What this paper does
(Light-mode digest, from arXiv biblio/abstract only; body not read.) Pointer-generator: the decoder mixes generation from the vocabulary with copying a source token via its attention distribution (a soft switch p_gen), which improves faithful reproduction of factual details (names, numbers); coverage reduces repetition. CNN/DailyMail summarization.

## Goal-by-goal answers
### Goal: Is "a copy head emits a pointer and the exact token is fetched from the stored id sequence" prior art?
Yes. This is exactly the pointer/copy output interface C2's "copy head reads raw bytes" requires; in a decoder-only LLM the raw token ids of the context are already stored, so the pointer-generator head is the mechanism, applied here to a low-bit-KV model.
