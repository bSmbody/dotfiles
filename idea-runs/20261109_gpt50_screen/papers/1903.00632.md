# Pairwise optimal coupling of multiple random variables

## What this paper does
Generalises the two-variable optimal coupling theorem (P(X!=Y)=d_TV achievable) to arbitrarily many random variables: there is a single coupling of a whole family in which every pair disagrees with probability at most 2d/(1+d), d their TV distance, and this bound is shown optimal in several cases. Two constructions are given (a Poisson-process / shared-randomness one and a discrete one), generalising Broder min-hash and Kleinberg-Tardos style schemes in which each party samples using shared randomness without communication.

## Goal-by-goal answers
### Goal: Does the source support "sample common mass min_h p_h, then per-head residuals" as an optimal multi-head coupling?
Partly. Theorem 1 (two variables, folklore/Doeblin) is the classic common-part coupling [full text, Section 1, Theorem 1]. For many variables the paper's point is that a single coupling cannot make every pair agree with probability 1-d_TV; the achievable pairwise bound is 2d/(1+d) [Theorem 2, Section 2]. GPT's min_h decomposition makes all G heads agree with probability sum_i min_h p_hi (an all-agree common component), which is a valid coupling preserving each marginal but is not what this paper proves optimal; the paper's constructions use shared randomness, no explicit min computation [Section 1 discussion of [2], Section 2]. Marginal-preservation (hence per-head unbiasedness) holds for any coupling.
