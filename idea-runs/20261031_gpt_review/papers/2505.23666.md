# LoLA: Low-Rank Linear Attention With Sparse Caching

## What this paper does
A training-free inference augmentation for linear-attention + sliding-window models (e.g. LoLCATs-distilled Llama). Each head keeps three memories: a local sliding window, a small sparse global cache of "difficult-to-memorize" KV pairs, and the linear-attention state for everything else. Which pairs go to the sparse cache is decided by the self-recall error (SRE), ||m_t(k) - v||, of each pair against the current state, and the sparse cache is re-scored at every update. Pass-key retrieval rises from 0.6% to 97.4% at 4K with a 4.6x smaller cache than Llama-3.1-8B.

## Goal-by-goal answers
### Goal: What criterion decides which KV pairs keep an exact copy, and is it fixed at write time or re-evaluated against the live state?
The criterion is the self-recall error SRE(k, v | H_t, s_t) = ||phi(k)^T H_t / phi(k)^T s_t - v||, i.e. whether the pair's own key still retrieves its own value from the *current* state [full text, Section 3, Eq 10]. At every update interval LoLA scores the pairs leaving the window *and re-scores every pair already in the sparse cache*; the top-lambda errors stay, the rest are written into the state for good. "Re-scoring pairs in the sparse cache is essential since the SRE is dependent on the current hidden state" [Section 3 "Method Overview", Eqs 11-13]. So it is a running, state-aware complementarity rule: keep exactly what the state currently fails to recall, release what it holds. It is reactive; there is no forecast of future interference.

### Goal: Where are the memories placed (same head or across layers), and what does the ablation show about the criterion?
All three memories live in the same head and are read by the same query in one normalized sum (Eq 14), so a released pair is read back through that head's state with the same key space; the paper calls this the "intra-head" design and contrasts it with inter-layer hybrids, which it does not treat [Section 3 Eq 14; Appendix D "Hybrid approaches"]. Ablation on S-NIAH-1 at 512 tokens: SRE 99.0% vs extending the window 29.4%, exp(q^T k) attention score 10.6%, softmax-approximation error 11.4-20.0% [Section 4.4, Table 4]. The authors note that standard importance metrics assume evicted tokens are gone, which does not hold when the "unimportant" tokens are kept in low precision by the state [Section 4.4].
