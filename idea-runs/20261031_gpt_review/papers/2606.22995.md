# Group-Graph Policy Optimization for Long-Horizon Agentic Reinforcement Learning

## What this paper does
G2PO is a group-based RL method for multi-turn LLM agents. It clusters identical observations across the N rollouts of a task into state groups, which form the nodes of a state-transition graph. It estimates each group's value as the plain average of the discounted terminal returns of all visits. It then combines a node-centric advantage (successor values normalized among actions leaving the same group), an edge-centric advantage (the TD difference V(G') - V(G), standardized globally over all steps), and the GRPO episode advantage with a static weight w.

## Goal-by-goal answers
### Goal: How does G2PO pool returns across visits to a shared state, and with what weights?
V(G_k) is the uniform mean of v_j^i = gamma^{T-j+1} R_i over all visits in the group [full text, Section 4.2 Eq 2-3]. Grouping uses exact observation identity [Section 4.1]. The final advantage is A^EP + w(A^NC + A^EC) with one static w [Section 4.3 Eq 8]. No weights are optimized.

### Goal: Does its variance analysis account for covariance from shared trajectories?
Only heuristically. Appendix B.1 assumes independent trajectories, each visiting a group at most once, and gets sigma^2/|G_k|. B.2 writes Var(delta) = Var(V') + Var(V) - 2Cov and asserts Cov >= 0 "since trajectories ... share historical context", then drops the term to get an upper bound [full text, Appendix B.1-B.2]. It does not model the case where one trajectory's return enters many groups and edges.
