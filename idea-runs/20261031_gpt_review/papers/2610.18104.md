# The Effect of Layer Ordering in Hybrid Architectures

## What this paper does
Theory plus small-scale experiments on layer ordering in hybrids of attention (abstracted as windowed functions) and SSMs. Proves that for any layer configuration there is a task on which that configuration is resource-optimal under fixed memory, so the best ordering is task-specific; constructs natural 2-3-layer tasks (segmented retrieval, exact copy, a TST task) where learned hybrids show the predicted separations, and finds in 4-8-layer models that "containing" the dominant sub-architecture predicts performance; probes show attention layers do most associative recall.

## Goal-by-goal answers
### Goal: Does it propose a data-driven method to choose which layers keep full attention in a converted or pretrained LLM?
No. It is an expressivity/learnability analysis on synthetic tasks with small models trained from scratch; it proposes no allocation algorithm for practical LLMs, and the conclusion names predicting effective orderings from task properties before training as future work [full text, Sections 1, 5].

### Goal: What does it imply for allocating full attention in hybrid reasoning models?
The optimal ordering depends on the task's structure [Section 2.1, Theorem 1], and small changes in ordering (T*S* vs S*T*) change associative-recall accuracy sharply, with different peak attention ratios per family [Section 4, Figure 4]. This supports choosing allocation from the target workload (e.g., long-CoT) rather than generic text, but gives no evidence on natural-language reasoning [Section 5].

# The Effect of Layer Ordering in Hybrid Architectures

## What this paper does
A theory-plus-synthetic-task study of where Transformer (T) and SSM (S) layers should sit in a hybrid. It abstracts layers as generalized windowed functions and generalized SSMs under memory/precision budgets and proves that for any layer configuration there is a task on which that configuration beats every other under the same resources. It then trains 2- to 8-layer Transformer/Mamba (and DeltaNet) hybrids on segmented retrieval, exact copy, tensor lookup and associative recall, showing that "containing" the task's optimal sub-architecture (e.g., TS, TST) predicts performance, and that nearly identical orderings differ sharply on associative recall.

## Goal-by-goal answers
### Goal: Does it propose a method to choose layer allocation for a pretrained or converted LLM, or only analysis?
Only analysis. The contribution is an existence theorem (Theorem 1) and separations for small hybrids on synthetic tasks [full text, Section 2, Section 3]. The conclusion says the theory relies on constructed tasks and abstractions, and names extending it to practical layers and natural language as future work [Section 5]. No conversion, distillation or reasoning benchmark.

### Goal: What does it say about task-dependence of the optimal allocation and about layer interactions?
The dominant ordering is task-specific: for each configuration a task exists on which it is resource-optimal [Section 1; Section 2.1, Theorem 1]. Empirically, all 4-layer hybrids containing TS solve segmented retrieval while none without it do (Table 1), and on (2,1)-AR small ordering changes (TTSSSSSS vs TTTSSSSS) change accuracy dramatically, with different peak T:S ratios per family [Section 3.2, Section 4, Figure 4]. This supports the claim that allocation should be chosen against the target task and that layers act jointly (motifs), not independently.
