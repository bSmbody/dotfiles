# Learning to Search Better Than Your Teacher

## What this paper does
Proposes LOLS (Locally Optimal Learning to Search) for structured prediction cast as sequential decisions with irreversible actions. For each decision point it rolls in with the learned policy, tries every action, completes each with a roll-out that follows the reference policy with probability beta and the learned policy otherwise, and trains a cost-sensitive classifier on the resulting cost vectors. It proves a bound combining regret to the reference with regret to the learner's own one-step deviations, so the learned policy can improve on a suboptimal reference. It also shows which roll-in/roll-out choices fail and extends to structured contextual bandits.

## Goal-by-goal answers
### Goal: What are LOLS's roll-in and roll-out rules, and how are costs defined?
Roll-in with the current learned policy for t steps to reach s_t; for each action a in A(s_t), roll out with pi_out = pi_ref with probability beta else pi_hat_i to an end state, and set c(a) = loss(e(a)) - min_a' loss(e(a')); feed (c, features of s_t) to an online cost-sensitive learner [full text, Section 2, Algorithm 1, Eq 2]. The returned policy is the average of the iterates.
### Goal: Why are roll-in with the reference and roll-out with a suboptimal reference bad, and what does LOLS guarantee?
Roll-in with the reference makes the state distribution "unrealistically good", so "the learned policy never learns to correct for previous mistakes" (Theorem 1). Roll-out with a reference that is not optimal or not in the hypothesis class "can make the learner blind to compounding errors" and gives arbitrarily large regret to one-step deviations (Theorem 2) [full text, Section 3.1, Table 1]. With learned roll-in and mixture roll-out ("Good" in Table 1), Theorem 3 bounds beta(J(pi-bar) - J(pi_ref)) + (1-beta) sum_t (J(pi-bar) - min_pi E[Q^{pi-bar}(s, pi)]) <= T delta_N, without any assumption on the reference's quality; beta = 1 is essentially AggreVaTe [Section 3.2, Theorem 3, Corollary 1]. Empirically, with a bad reference, reference roll-out gives loss 1.670 vs 0.316 for learned roll-out on KDDCup cost-sensitive classification [Section 5, table].
### Goal: What does the method assume about the reference and costs?
Only that roll-outs can be executed from any state reached by roll-in and their end loss observed; the reference may be arbitrarily suboptimal [Section 3.2]. Local optimality is defined as no single changed decision improving the loss [Section 3.1].
