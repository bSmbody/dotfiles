# A Hippocampus for Linear Attention: An Exact Memory for What the Recurrent State Forgets

## What this paper does
HOLA attaches a bounded exact KV cache (default w=64) inside every delta-rule linear-attention layer; tokens are kept by the delta-rule committed write magnitude beta*||e|| (prediction residual times write strength), read with a sharpened softmax and added to the state read-out. Trained from scratch at 340M/15B tokens; lowers Wikitext PPL 27.32 to 22.92 and improves RULER NIAH to 32K vs GDN.

## Goal-by-goal answers
### Goal: What criterion does it use to decide what exact memory keeps, relative to what the recurrent state already holds?
Keep "the tokens that are least well represented by the state memory": m_t = ||beta_t k_t e_t^T||_F = beta_t ||e_t||, where e_t is the delta-rule residual; tokens already predicted by the state have small residual and are not stored [full text, Section 3.3, Eqs 5-6]. Ablation: residual alone or write strength alone underperform the product [Section 3.3]. This is an explicitly complementary (state-aware) selection rule.

### Goal: Does it address the KV cache of full-attention layers in an existing hybrid?
No. The cache lives inside each recurrent layer of a model trained from scratch; it contrasts itself with inter-layer hybrids (Jamba, Samba) and with LTE, whose lossless component is recency-based or a separate sparse layer [Section 2, "Hybrid exact memory"].
