# Test-time regression: a unifying framework for designing sequence models with associative memory

## What this paper does
Shows that sequence layers with associative memory can be derived by specifying three choices for a test-time regression problem over past key-value pairs: the relative importance (weights) of each association, the regressor function class, and the optimisation algorithm. Derives linear attention, gated linear attention/SSMs, fast-weight/online-learning layers (DeltaNet, Longhorn, TTT) and softmax attention as special or approximate cases, and analyses MQAR capacity with a single layer plus short convolution.

## Goal-by-goal answers
### Goal: How are the weights (importance) of stored associations chosen in existing update rules?
Vignette 2 [Section 4, Eq. 14-16]: gated linear attention / SSMs are (suboptimal) weighted least squares with "time-decaying weights" gamma_i^(t) = prod_{j>i} gamma_j, i.e. "Each association is down-weighted based on how far it is from the current timestep"; the cheap recurrences arise from approximating K^T Gamma K ≈ I. Vignette 3: fast-weight programmers / online learners are first-order (one-step SGD) solvers of the streaming least-squares problem. The weighting is thus a recency schedule, motivated by "recent tokens are more informative of predicting the next token".

### Goal: What limits recall, and what does a second-order solver buy?
Section 6, "Memory capacity, not sequence length, limits model performance": with d_model = 64, linear attention solves MQAR at P = 64 pairs but not at P = 128 "since it is impossible for 128 keys to be orthogonal"; unweighted RLS, which accounts for the key covariance K^T K, solves it even when P > d_model (Figure 3, stationary task with no forgetting). The conclusion lists more effective, stable and parallelizable test-time optimizers as an open direction.
