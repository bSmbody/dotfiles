# Learning to Attribute with Attention

## What this paper does
AT2 makes ablation-based token attribution cheap. Instead of fitting a surrogate per example (as ContextCite does), it learns one score function across many examples: the score of a source is a learned linear combination, over all layers and heads, of the attention weight that source receives while the target is generated. The coefficients are trained so that the implied linear surrogate predicts the measured effect of random ablations. It is evaluated on context attribution and on thought attribution (attributing a reasoning model's final answer to its own thoughts), and used to prune context on HotpotQA.

## Goal-by-goal answers
### Goal: How does AT2 turn random-ablation labels into a cheap, generalizing predictor, and with what features and mask distribution?
w_theta(X,S,Y)_i = sum_{l,h} theta_{lh} Attn(X,Y,s_i)_{lh}, with attention aggregated over the generated span and the source's tokens [full text, Section 3.2]. theta is fit across a dataset of examples by making <w_theta, v> predict p_LM(Y | Ablate(X,S,v)) for m sampled ablations per example [Section 3.2, Algorithm 1]. Ablation vectors are sampled uniformly: "each source is ablated independently with probability 1/2" [Section 3.2, Implementation details; Appendix A]. Once trained, attribution costs less than one extra forward pass [Section 5].

### Goal: Does it cover reasoning traces and pruning, and what is its scope?
Yes for attribution: "thought attribution" treats the model's generated thoughts as sources for the final response, evaluated on DeepSeek-R1-Qwen-7B [Sections 2.3, 4.2]. Pruning is post-hoc context pruning followed by regeneration on HotpotQA, where it beats per-example surrogates with 32 ablations and average attention [Section 5]. It is not a decode-time eviction policy: no budget, no keep-rate-matched masks, no iterative policy/label loop, Transformers only, no recurrent memory.
