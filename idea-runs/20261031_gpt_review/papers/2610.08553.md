# DeltaTTT: Layerwise Optimization for Nonlinear Recurrent Memory

## What this paper does
Studies test-time-training (TTT) memories with a nonlinear two-layer inner network. It finds serial chunkwise TTT (LaCT-style) underperforms a fixed-base parallel variant whose gradients are all evaluated at the initial state, and that nonlinear memories fit poorly in a single pass. It proposes DeltaTTT: give each linear layer of the two-layer memory its own local reconstruction target (both reconstruct v) and a delta-rule update, so each layer reuses DeltaNet's chunkwise scan with exact tokenwise updates while the readout stays nonlinear. 0.5B models, 92.5B tokens.

## Goal-by-goal answers
### Goal: How do existing TTT methods with nonlinear memory get parallel training, and what does this cost?
Serial chunkwise TTT evaluates each chunk gradient at the memory after previous chunks (S_c = S_{c-1} - eta grad L_c(W_{c-1})); fixed-base parallel TTT evaluates all gradients at W_0 and prefix-sums them [full text, Section 2 / Eq 3-4]. Table 2 summarizes: tokenwise and mini-batch TTT are nonlinear but not efficiently trainable; chunk-TTT (LaCT), E2-TTT and parallel TTT are efficient but evaluate gradients/readout at chunk-start or initial states; only DeltaNet has previous-token gradients, tokenwise state and current-token readout, but it is linear [Section 4.1, Table 2]. Smaller chunks fit better but serial nonlinear TTT then needs more sequential steps with less parallelism, which is why LaCT uses large chunks [Section 3]. Serial TTT got 28.25 single-needle accuracy vs. 37.87 for fixed-base parallel [Table 1].

### Goal: What is the key enabling assumption of DeltaTTT's parallel form, and what are its limits?
"Given the keys and targets, each delta update is affine in the preceding memory state, enabling efficient chunkwise parallel evaluation" [Section 3]. DeltaTTT therefore replaces the joint objective ||B phi(A k) - v||^2 with two local linear regressions ||A k - v||^2 and ||B h - v||^2, with h = phi(A_{t-1} k) in the default "pre" variant [Section 4.1 / Eq 7-12]; the first layer never receives credit from the second layer's error. Limitations: slower and more memory than DeltaNet (1.37x vs 1.42x full-attention throughput, Table 4), only 2-layer MLPs with 1x expansion tested, small scale [Section 5.4, Section 8].
