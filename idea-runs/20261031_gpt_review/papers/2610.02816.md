# Gated Slot Attention-2: Two-Sided Associative Memory Correction in Linear Attention

## What this paper does
GSA-2 combines a key-side correction (a Gated Oja Rule, which uses the value to correct the key stored for it) with GDN-2's value-side delta correction through shared latent slots, and derives a chunkwise algorithm. It reports gains over linear-attention baselines on language modelling, retrieval and long-context tasks.

## Goal-by-goal answers
### Goal: Does GSA-2's extra correction use any read-side (query) signal or record of past reads to decide what is erased or kept?
No. The Oja correction is one gradient step on 1/2||k_t - S^T v_t||^2, giving S_t = (I - beta_t v_t v_t^T) S_{t-1} + beta_t v_t k_t^T [full text, Section 3.1 / Eq 7-8]. OJA2 adds channel-wise decay and decoupled erase/write gates b_t, c_t following GDN-2 [Section 3.1 / Eq 9-10]. All gates come from the current token's projections; queries appear only in the two-stage read [Section 3.2]. It adds a second correction axis, but erasure is still set at write time from the current pair.
