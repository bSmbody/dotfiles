# Continual Learning with Scaled Gradient Projection

## What this paper does
Scaled Gradient Projection (SGP) is a continual-learning method that extends Gradient Projection Memory (GPM). After each task it runs an SVD on each layer's input representations to find the basis of the "core gradient space" that matters for past tasks. It gives each basis direction an importance in [0,1], computed from its singular value relative to the largest one, and accumulates these importances over tasks. New-task gradients are then scaled down along each stored basis by (1 - importance) and are left untouched in the orthogonal complement. On Split CIFAR-100, miniImageNet, CIFAR-100 Superclass and Atari, it beats GPM, TRGP and FS-DGPM at little extra cost.

## Goal-by-goal answers
### Goal: What is the core mechanism: how are the protected subspace and per-direction importance computed, and how are updates scaled?
For each layer, a representation matrix R of input activations is built from n_s samples. Its SVD gives orthonormal bases U, kept up to an energy threshold epsilon_th [full text, Section 3, Eq 1]. Following GPM, these input bases "equivalently span the most important gradient space" for the task. Importance is lambda_i = (alpha+1) sigma_i / (alpha sigma_i + max sigma), which runs from 0 to 1, with 1 for the top singular direction [Eq 2]. The new gradient becomes g - M Lambda M^T g, so it is unchanged orthogonal to M and scaled by (1 - lambda_i) along each basis [Eq 3]. Over tasks, new bases are added from the residual R - M M^T R [Eq 4-5]. Old bases get "surrogate singular values" by projecting the new task's in-span energy onto them [Eq 6-7], and importance accumulates additively, capped at 1 [Eq 10]. Setting alpha -> infinity recovers GPM's hard projection.
### Goal: Why does soft importance scaling beat hard orthogonal projection, and by how much?
Hard projection blocks every direction of the stored space and "hamper[s] the learning capability of the new tasks" [Abstract; Section 1]. Singular values are non-uniform, so most stored directions carry little input energy and can still be updated [Section 3; Figure 3c-d]. SGP gains about 3.5% ACC over GPM on Split CIFAR-100 (76.05%) and about 2.4% on miniImageNet. Forgetting (BWT) rises slightly, to about -1% / -1.5% [Section 4, Results; Table 1]. On CIFAR-100 Superclass it reaches 59.05 vs 57.72 (GPM) [Table 2]. After 20 tasks, only about 37% / 18% of the stored directions are fully frozen [Section 4, Importance Accumulation Dynamics].
### Goal: What assumption does it rely on, and what does it cost?
It relies on the fact that a weight change orthogonal to the span of a layer's past inputs leaves the layer's outputs on those inputs unchanged. The protected object is therefore the input-space subspace that past data actually occupied, and its importance follows how much input energy lies along each direction [Section 3; Section 1]. The cost is one SVD per layer per task. Training time is about 1.05-1.17x GPM and memory about 0.1% above GPM [Section 4; Appendix D, Table 5]. The paper does not consider streaming or per-token updates. Importance is refreshed only at task boundaries.
