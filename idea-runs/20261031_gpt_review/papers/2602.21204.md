# Test-Time Training with KV Binding Is Secretly Linear Attention

## What this paper does
Argues that TTT layers with key-value binding (LaCT, ViTTT, and others) do not behave as test-time memorizers. Better inner-loop fitting hurts, gradient ascent works about as well as descent, and Q can be replaced by K. The paper proves that a broad class of TTT inner loops (including momentum and Muon variants) unrolls into a learned linear-attention operator. This view gives architectural simplifications and fully parallel forms (ICML 2026).

## Goal-by-goal answers
### Goal: Does lowering the inner-loop (KV reconstruction) loss improve downstream performance of TTT models?
No, in their tests. Increasing the number of inner gradient steps at inference "usually yields lower inner-loop loss" in pretrained TTT models, yet "downstream performance degrades consistently as the number of inner-loop steps increases", in both LLMs and novel-view synthesis [full text, Section 4.1, Fig 1]. Their explanation is train-test mismatch: the inner loop "defines a learnable mapping" into effective q/k/v, so changing the inner optimization at inference changes the attention operator the model was trained with [Section 5.2]. The experiment changes the inner optimizer only at inference. It does not test a model trained end-to-end with a better inner solver, so it shows that inner-loss reduction is not a sufficient proxy, not that a better trained-in solver cannot help.
