# PM-KVQ: Progressive Mixed-precision KV Cache Quantization for Long-CoT LLMs

## What this paper does
Post-training KV-cache quantization for long-CoT dense LLMs. Progressive quantization stores KV in 16 bits first and, once the per-block memory budget fills, shrinks existing cache bit-width 16->8->4->2 via an "Equivalent Right Shift"; block-wise bit allocation by first-order Taylor sensitivity solved as an integer program; calibration with positional interpolation to cover long-context RoPE channel distributions.

## Goal-by-goal answers
### Goal: When is rounding/quantization committed or precision changed (timing), and is that schedule fixed or input-adaptive?
Precision is lowered when the memory budget is fully used, computed per transformer block from the maximum context length and the final bit-width Fbit [full text, Section 3.1]. The trigger is memory fill, not content; the shrinking is applied to the existing cache of a block. The per-block Fbit comes from an offline integer program over Taylor sensitivities s_{i,b} (Eqs 4-8) [Section 3.2].
### Goal: How does it treat the attention-layer KV cache versus the recurrent state, and is the byte budget shared between them?
Dense softmax models only; the budget M covers the KV cache of all transformer blocks [Eq 7]. Limitations name MLA and system integration, not hybrids or recurrent states [Appendix E].
