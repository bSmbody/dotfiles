# Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention

## What this paper does
Generalises Gated DeltaNet and Kimi Delta Attention (KDA) by replacing the single scalar delta gate beta_t with a channel-wise key-side erase gate b_t and a value-side write gate w_t: S_t = (I - k_t (b_t ⊙ k_t)^T) D_t S_{t-1} + k_t (w_t ⊙ v_t)^T with channel-wise decay D_t. Derives a chunkwise WY algorithm and gate-aware backward pass. Trained at 1.3B / 100B FineWeb-Edu tokens, compared with Mamba-2, GDN, KDA, Mamba-3 in recurrent and SWA-hybrid settings.

## Goal-by-goal answers
### Goal: What memory update rule does it use and what determines the write/erase strength per token?
Eq. 10 [full text, Section 3.1]. Gates are "independent projections of the token representation", b_t = sigma(W_b x_t), w_t = sigma(W_w x_t) (Eq. 11); decay alpha_t = exp(-exp(a) ⊙ softplus(W_f x_t + delta)) (Eq. 12). All three are functions of the current token x_t only. Section 2.2 explains the division of labour: decay "clears the state uniformly", the delta term "edits a selected association".

### Goal: What does it report as its limitation on recall / memory capacity at long context?
Table 3 [Section 4]: even the best recurrent rule degrades with length: GDN-2 recurrent S-NIAH-2 100.0 (2K) -> 93.0 (4K) -> 39.2 (8K); S-NIAH-3 92.0 (1K) -> 31.8 (4K); MK-NIAH-1 72.6 (1K) -> 51.4 (2K) -> 37.8 (4K). Table 4 real-world retrieval (2K inputs): recurrent GDN-2 averages 29.88 vs Transformer 38.07, FDA 19.98 vs 54.78. The paper attributes remaining NQ/DROP gaps to "formats that also need local evidence aggregation, which SWA supplies" [In-context retrieval on real-world tasks]. No explicit limitations section.

### Goal: Does the rule decide what to retain using anything other than recency and the current token?
No: the ablation (Table 5) shows the erase gate b_t carries most of the gain, but it is still computed from x_t at write time; nothing in the rule depends on what is later queried.
