# QuantMLA: Function-Aligned Dual-Path Quantization for Low-Bit MLA KV Caching

## What this paper does
Models how quantization errors in MLA's two cached tensors (content latent C and decoupled RoPE key K_P) reach the attention output, then learns offline-fusible path-specific transforms: attention-output reconstruction for the content path (capturing its coupled matching and aggregation errors) and positional-QK reconstruction for the RoPE path (with a finite output-distortion bound). Reports joint INT4 caching of both paths, and INT2 content with INT4 RoPE key, across four MLA families, plus a native low-bit MLA kernel.

## Goal-by-goal answers
### Goal: How does a single latent perturbation enter both the score and the value in MLA?
With absorbed weights, S_h = tau(Q_bar_{C,h} C^T + Q_{P,h} K_P^T) and Y = sum_h A_h C B_h, so the latent C feeds matching and aggregation in every head while K_P feeds only matching [full text, Section 2.1, Eq 1]. The exact finite route is Delta Y_C = sum_h (Delta A_{C,h} C B_h + A_h Delta C B_h + Delta A_{C,h} Delta C B_h), i.e. score change, value change and their interaction; Delta Y_P = sum_h Delta A_{P,h} C B_h [full text, Section 2.3, Eq 2-3]. The shared latent acts on all heads at once, and the output sums over heads.
### Goal: Under matched cache error, which path dominates output distortion?
Across six MLA models (DeepSeek-V2-Lite, V3-Base, R1, Kimi-K2, LongCat-Flash-Lite, GLM-4.7-Flash), the RoPE-path response per unit cache NMSE is 1.941x to 6.864x the content path's, with large layer-wise variation [full text, Section 2.2, Fig 2].
### Goal: Does QuantMLA provide a worst-case or runtime certificate?
No runtime certificate. Proposition 2 is a finite output bound for positional-QK perturbation used to justify the training objective; the content path is handled by learned attention-output reconstruction, i.e. average-case [full text, Section 3.2].
