# Rebalancing Reference Frame Dominance to Improve Motion in Image-to-Video Models

## What this paper does
DyMoS (NeurIPS 2026) is a training-free method for image-to-video (I2V) models. Its observation: with the same prompt and first frame, non-reference frames in I2V self-attention put much more attention on the reference frame's key tokens than in the paired T2V model ("reference-frame dominance"). The effect is strongest in the first denoising steps, and it spreads the reference appearance along time and suppresses motion. DyMoS subtracts a scalar γ from the logits of attention from generated frames to reference-frame keys. It does this only in the first λ fraction of steps and only in the text-conditional CFG branch. It raises VBench dynamic degree on Wan2.1/2.2, HunyuanVideo-1.5 and CogVideoX-5B I2V with stable quality.

## Goal-by-goal answers

### Goal: What mechanism does DyMoS blame for static I2V output, is it tied to position, and when does it act?
"Excessive attention to reference-frame key tokens propagates the reference appearance along the temporal axis, thereby weakening frame-to-frame interactions necessary for motion dynamics" [full text, Section 3.2]. The dominance is measured at frame level, as frame-to-frame attention from the I2V model minus the paired T2V model, averaged over the first 10% of steps. It is "most pronounced during the initial denoising stage" [Section 3.1, Fig. 2b]. The intervention is a frame-level logit bias, L̃[i,j] = L[i,j] − γ·φ(f(i))·1[j ∈ ref frame]·1[i ∉ ref frame], applied in every self-attention layer. It is not tied to spatial position or to RoPE [Section 3.3 / Eq 4, 6]. Raising γ raises dynamic degree monotonically with stable video quality, and negative γ makes videos more static [Section 3.2, Fig. 3b]. The modulation is applied only in the early λ fraction of steps (λ = 0.2 on Wan2.2), and only to the text-conditional branch of CFG, so the guided update "steer[s] ... away from reference-frame dominance" [Section 3.3 / Eq 7; Section 4.1].

### Goal: How large are its gains, at what cost, and does it address pure text-to-video or the CFG combination rule?
VBench-I2V dynamic degree (baseline → ALG → DyMoS): Wan2.2-14B 51.7 → 55.3 → 64.8; Wan2.1-14B 48.7 → 52.5 → 54.5; HunyuanVideo-1.5 48.0 → 46.3 → 55.3; CogVideoX-5B 30.9 → 52.0 → 52.9. Video quality and VisionReward are roughly unchanged, and ViCLIP rises slightly [full text, Table 1]. γ and λ are tuned per backbone "to account for differences in attention scale and denoising schedule" [Section 4.1]. The method needs a reference frame, so it does not apply to pure T2V. It does not change the CFG combination rule; it changes the conditional branch's attention, and standard CFG then scales the result [Section 3.3 / Eq 7].
