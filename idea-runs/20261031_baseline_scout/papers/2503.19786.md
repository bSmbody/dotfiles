# Gemma 3 Technical Report

## What this paper does
Technical report of Gemma 3 (1B-27B open-weight multimodal models, 128K context except 1B). Architecture: GQA with QK-norm (replacing Gemma 2 soft-capping), 5 local sliding-window layers per 1 global layer, RoPE base 1M on global and 10k on local layers, positional interpolation to extend global layers from 32K pretraining to 128K, distillation, and quantization-aware training. Includes ablations on local:global ratio and window size against perplexity and KV memory.

## Goal-by-goal answers
### Goal: What local/global structure does Gemma 3 use and how much KV memory does it save?
"5 local layers for every global layer, starting with a local layer" [full text, Section 2]; window 1024 in the 2B ablation architecture (L:G=5:1, sw=1024) [Section 5.2]. With a 32K prefilled cache, "global only" has a 60% memory overhead (KV relative to model), reduced to "less than 15% with 1:3 and sliding windows of 1024" [Section 5.2, Figure 5]. KV memory vs context is plotted for 5:1 sw=1024 vs global-only [Figure 6]; no table of bytes. The global layers' KV still grows linearly.

### Goal: What evidence supports the ratio/window choice and what limitations are stated?
Changing the local:global ratio from 1:1 to 5:1 has "minimal impact on perplexity", and "the sliding window can be reduced significantly without impacting perplexity" [Section 5.2, Figures 3-4]; evidence is perplexity only on 2B text models, not long-generation reasoning or retrieval. Long context: models "generalize to 128K, but rapidly degrade as we continue to scale" [Section 5.3, Figure 7].
