# The Query Knows What to Forget: A Second Erase Direction for Linear Attention

## What this paper does
QED adds a second erase direction to Gated DeltaNet-2. The erase vector b_t ⊙ k_t is augmented by lambda_h P_perp_k(b_t ⊙ q_t), a gated, query-derived component projected orthogonal to the current key. The update can then cancel old-state content that the current query picks up but that a key-directed delta edit cannot reach. 340M models trained on 15B tokens (two seeds, five ablation arms) improve S-NIAH-1 beyond the 2K training length and FDA recall, with no change in validation loss.

## Goal-by-goal answers
### Goal: Does QED use the query to protect or to erase state content, and is the signal per token or accumulated over past reads?
It erases. The read o_t = sum_j (q_t^T k~_j) v~_j contains the target plus interference, and the interference "lives along q_t", so QED adds a direction derived from q_t that lets "the layer remove content selected by what it reads" [full text, Section 3.1 / Eq 5-6]. The exact effect is S^QED = S^GDN2 - lambda_h k_t (S-bar_t^T d_t)^T with d_t = P_perp_k(b_t ⊙ q_t) [Section 3.2 / Eq 11-12]. The signal is the current token's query only. Nothing accumulates over past reads, and retention is not shielded along read directions. The gate exists because without it "the layer would erase on every read and delete content that later reads still need" [Section 3.1].
### Goal: How much does it help, and how robust are the ablations?
S-NIAH-1 improves at every length past the training window in both seeds, by up to 39 points, and the usable context grows from about 8K to 16K. FDA improves by 3.4-3.7 points [Section 1; Section 6]. Only the query-derived direction is consistently supported against a random-direction control. The gate and the key-orthogonal projection are inconclusive across seeds [Section 6].


### Goal: Where exactly does QED's change enter the GDN-2 update, does it move the write address, and what does it cost in the kernel?
GDN-2 is S_t = (I - k_t a_t^T) Diag(exp g_t) S_{t-1} + k_t (w_t ⊙ v_t)^T with erase vector a_t = b_t ⊙ k_t [full text, Section 2 / Eq 4]. The erase vector decides which old content is sampled (S-bar^T a_t) and subtracted; the subtraction and the new write both land at the write address k_t. For any probe x the update changes the read only by (x^T k_t)[w ⊙ v - S-bar^T a_t], so "a key-directed delta edit cannot change the response to any x ⊥ k_t" [Section 3.2 / Eq 9]. QED edits only a_t (adding lambda_h P_perp_k(b ⊙ q)); the write address stays k_t, and projecting the added term orthogonal to k_t "leaves the nontrivial eigenvalue of I - k_t a_t^T unchanged" [Section 3.1 / Eq 6]. "Since QED only edits the erase vector, the QED kernel keeps the structure of the GDN-2 kernel. The extra work is one dot product and one subtraction for each token and head" [Appendix A]. Measured eigenvalues of unprojected variants stayed in [-0.011, 0.985], so training avoided the expansive regime [Section 6]. Strength lambda_h = 0.25 sigmoid(theta_h), initialised near 0.03 [Appendix A / Eq 13].
