# Scaling Linear Attention with Sparse State Expansion

## What this paper does
Reinterprets the linear-attention key as a classifier that assigns each token's information to state rows, and argues that dense writes to all rows cause interference and uniform decay causes forgetting. Proposes a row-sparse update (softmax over top-k key logits) and Sparse State Expansion (SSE): the state is expanded into N partitions sharing QKV weights, a write-read gate picks top-k partitions per token, and only those are updated and read. Trained from scratch / continually trained (GLA-style transitions), with masking and varlen kernels; improves retrieval and reasoning at fixed parameter count.

## Goal-by-goal answers
### Goal: How does SSE decide which state rows/partitions a token writes, and is the decision content- or state-aware?
A gate e_t = softmax(x_t W_e) picks the top-k partitions; inside them softmax(k_t) softly selects rows; unselected partitions are carried unchanged [full text, Section 4.1, Eqs 9-14]. The selection depends only on the current token ("context-only hard-selection"); the authors list a state-aware form e_t = g(t, x_t, S_{t-1}) as future work [full text, Section 6]. A load-balancing auxiliary loss prevents row collapse [full text, Section 3.2].
### Goal: Does SSE reduce stored state memory of an existing pretrained model, or is it a new architecture?
It is a new architecture trained with the routing in place: the state is expanded N-fold, all partitions are stored, and sparsity saves compute (decode updates only selected partitions), not state memory [full text, Sections 4, 4.2]. It is not applied post hoc to dense-write models such as GDN or Mamba; delta-rule (GDN) variants are not yet evaluated [full text, Section 6].
