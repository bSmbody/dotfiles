# Bridging KV-Cache Quantization and Linear Attention: From Theory to Pretrained Weight Migration

## What this paper does
Shows that RAM-Net (product-softmax addresses over a discrete product address space {0..d_p-1}^U, slots holding write mass and value means) bridges per-KV quantization and linear attention. Under a restricted circular-codebook construction, the overlap of soft read/write address distributions locally approximates exp(q.k); because the overlap is separable, history aggregates into per-address slot statistics. Uses this to migrate nine pretrained Transformers (0.3B-7B) into RAM-Net with 500M tokens, recovering 87.1% of teacher gains on commonsense tasks.

## Goal-by-goal answers
### Goal: Does RAM-Net already aggregate history into per-product-address mass and value statistics read by a softmax-like query weight?
Yes. Address space A = {0..d_p-1}^U; Product Softmax gives read r_t(a) and write w_s(a) as products of per-factor softmaxes [full text, Section 3.1]. History aggregates as m_t(a) = sum_s w_s(a) and s_t(a) = write-weighted value mean, with mass-aware readout sum_a r_t(a) m_t(a) s_t(a) / sum_b r_t(b) m_t(b) [Section 3.3, Eq 9; Appendix A.2, Eq 21].

### Goal: What is the hard-assignment limit, and how big is the address space used?
With write concentration beta_w -> infinity, w_s becomes a one-hot on the product code tuple and the readout equals softmax attention over product-quantized keys; each occupied slot's mass and state become the count and mean of its assigned values, which "recovers the per-code aggregation underlying Transformer-VQ" [Appendix A.5, Eq 22-23]. Default configuration d_p=4, U=5 (1024 addresses) with Top-K=32 sparse access [Appendix B.2]. The address table is small enough to store densely; no low-rank / tensor-train compression of the joint address tensor is used or discussed.
