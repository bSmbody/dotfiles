# LeapQuant: Efficient Linear Attention with Accurate Recurrent State Quantization

## What this paper does
Training-free recurrent-state quantization for GDN/KDA hybrids (Qwen, Kimi, GLM families). Per-window quantization holds a low-bit boundary state fixed, buffers p high-precision (alpha, k, u) update tuples, and quantizes the materialized state only once per window via the chunk-form unrolling (Eq 4). Compensator Tokens (a few high-precision rank-one outer products from power iteration) absorb row/column outliers, and the residual is smoothed before quantization. Near FP32 at 8-bit state, 3.4x less state traffic, 1.47x end-to-end speedup.

## Goal-by-goal answers
### Goal: How does it treat the attention-layer KV cache versus the recurrent state, and is the byte budget shared between them?
Only the linear-attention recurrent state is quantized; the full-attention layers of the hybrid are not touched, and the paper notes that "for models that pair linear attention with dense full attention, the gain shrinks slightly as the context grows, since the full attention layers take a growing share of each step" [full text, Appendix D]. Motivation counts state memory under prefix caching with one state per 1,024 cached tokens [full text, Section 1, Figure 1b]. No shared budget with the KV cache.
### Goal: When is rounding/quantization committed or precision changed (timing), and is that schedule fixed or input-adaptive?
Fixed: the state is quantized once per window of p tokens [full text, Section 3.2, Eqs 2-4]; per-window quantization lowers state error at 64K by 100x (BF16) and 39x (INT8) versus per-step. p=16 is a single global constant chosen by ablation: accuracy saturates at 16 and the kernel is fastest there; p=32 gives no gain and slows the kernel [full text, Section 4.4 "Window length"]. Nothing adapts p per head or per input.
