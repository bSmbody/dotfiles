# ThinKV: Thought-Adaptive KV Cache Compression for Efficient Reasoning Models

## What this paper does
Hybrid quantization + eviction for long-output reasoning models. Attention sparsity (calibrated on a few layers) classifies each 128-token CoT segment into Reasoning, Execution or Transition thoughts. Think-Before-Quantize assigns precision by thought type (R/E at NVFP4 4-bit, T at ternary 2-bit, group 16, FP8 scales). Think-Before-Evict progressively shrinks earlier segments (retention 64/32/16/8/4 tokens via K-means on post-RoPE keys) whenever a transition thought appears. A "Continuous Thinking" Triton kernel extends PagedAttention to reuse evicted slots in place, avoiding gather compaction. ICLR 2026 oral.

## Goal-by-goal answers
### Goal: What models, lengths and headline results are reported?
R1-Distill-Llama 8B/70B, R1-Distill-Qwen-14B, GPT-OSS 20B/120B, QwQ-32B, AceReason-Nemotron-14B, MobileLLM-R1; MATH-500, AIME, GSM8K, LiveCodeBench; max generation 32K; pass@1 over 8 samples [full text, Section 6.1]. Versus quantization baselines (k=1024): R1-Qwen-14B AIME 50.00 (BF16 53.33, KIVI-2bit 40.00, PM-KVQ 43.33), LCB 45.84 (47.90/34.56/41.97); QwQ-32B AIME 70.28 (73.33/60.56/67.86) [Section 6.2, Table 1]. With 1024-token budget it reports <3.67% of FullKV memory on AIME/LCB [Section 6.2]. Throughput: 2048 budget on R1-Llama-8B raises max batch 13->290 and throughput 15.8x over FullKV on A100 [Table 3]; in vLLM serving 38% higher req/s and 27% lower latency than R-KV at B=256 [Figure 9].
### Goal: What does it find about quantization-induced generation-length inflation?
"Pure quantization can inflate generation length by up to 5.1x" on R1-Llama-8B; "eviction does not cause an increase in generation length" [Section 6.3, Figure 10(d); Section 2]. TBQ alone (3.5 bits) keeps GPT-OSS-20B LCB accuracy at 77.8 but gives only 1.1x throughput because of the length inflation [Section 6.3, Table 4].
### Goal: What limitations do the authors state, and is code released?
"Not directly applicable to settings dominated by long input contexts" [Appendix F]. Prefill tokens are treated as R type [Section 6.1]. Gather-based compaction of prior eviction methods causes up to 37x TPOT slowdown at large batch [Section 5.1]. Hyperparameters (thought count, refresh 128, retention schedule) are hand-set. No code repository URL is stated in the paper body.
