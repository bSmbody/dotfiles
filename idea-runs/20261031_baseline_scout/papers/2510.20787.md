# Alleviating Forgetfulness of Linear Attention by Hybrid Sparse Attention and Contextualized Learnable Token Eviction

## What this paper does
Builds hybrids trained from scratch (0.4B/1.4B, 4K sequences) that interleave Gated DeltaNet 1:1 with intermediate-cost mixers: native sparse attention (laNSA) or a new learnable token eviction layer (laLTE) combining an attention sink, sliding window and a per-head, per-token retention score from a small CNN over pre-RoPE keys/values of neighboring tokens, trained end-to-end with a straight-through estimator and adaptive sparsity penalty, capped at b=512 retained KVs per head at inference.

## Goal-by-goal answers
### Goal: How does it decide which KV entries an attention layer in a hybrid keeps, and does the decision use the recurrent layers?
Retention r_{j,h} comes from a 3-layer 1D CNN (receptive field 13) on the concatenated key/value of that attention head, applied when a token leaves the window; tokens with r>0.5 enter a capped out-of-window cache, the lowest-score entry is evicted when full [full text, Sections 3.1.1, 3.1.3]. Gradients come from the value-mask surrogate <v, dL/dv> (Eq 6), so the end-to-end LM loss trains it. The score uses only the attention layer's own local KVs; it does not read GDN state signals [Section 3.1.1]. Once dropped, "it is no longer available to any future query" [Section 1].

### Goal: Can it be applied to an existing pretrained hybrid?
It is an architecture trained from scratch with the LTE module (~1% extra params); no conversion of a pretrained model is described [Sections 3.2, 4].
