# Memory Aware Synapses: Learning what (not) to forget

## What this paper does
MAS is a lifelong-learning regularizer. Each parameter gets an importance weight equal to the accumulated sensitivity of the learned function's output to that parameter. The weight is measured on whatever data the model is actually applied to, and no labels are needed. Changes to important parameters are then penalised when later tasks are learned. Because importance can be computed online on test data, the network preserves what it is actually used for and frees the remaining capacity. A local, layer-wise version reduces to a Hebbian co-activation statistic. It is evaluated on 8-task object recognition sequences and on fact learning.

## Goal-by-goal answers
### Goal: What is the core mechanism, and what signal decides what is protected?
Importance is Omega_ij = (1/N) sum_k |g_ij(x_k)|, where g is the gradient of the squared l2 norm of the function output with respect to theta_ij at data point x_k [full text, Section 4.1 / Eq 1-2]. It "can be updated in an online fashion whenever a new data point is fed". Later tasks add a penalty lambda sum Omega_ij (theta_ij - theta*_ij)^2 [Section 4.2 / Eq 3]. For densely sampled regions of the input space, "the function will be preserved". Parameters that do not affect those regions get low importance and remain free for new tasks [Section 4.1]. The paper's stated principle is usage: "Old rarely utilized knowledge can be overwritten ... while important, frequently used knowledge is prevented from being erased" [Abstract]; "Data that appears frequently, will have a bigger contribution" [Section 1].
### Goal: Does usage-based importance measured at deployment protect what is actually used better than importance from the training loss?
Yes, on their adaptation tests. Importance is computed only on one encountered Flower class (Krishna Kamal). After the 8-task sequence, forgetting on that subset is 2%, against 8% on the dataset as a whole. Later tasks also gain capacity, with 84% vs 69% on the last task [Section 5.1, Adaptation Test]. Appendix A repeats this on two random fact subsets [Appendix 0.A / Table 5]. SI computes importance only during training, so it "cannot adapt to a particular subset" [Section 5.2, Adaptation Test].
### Goal: What form does importance take, and is it per parameter or in a subspace?
It is per parameter (diagonal). In the local version, for a layer with input/output activations y, importance is Omega_ij = mean y_i y_j, i.e. a Hebbian co-activation [Section 4.3 / Eq 5-7]. The paper does not use a subspace or matrix-valued (input-covariance) importance, and it does not consider fast-weight or recurrent memories.
