# AsymKV: Enabling 1-Bit Quantization of KV Cache with Layer-Wise Asymmetric Quantization Configurations

## What this paper does
Shows that 2-bit key quantization error is amplified by the query product and softmax far more than value error at equal elementwise MSE, and proposes AsymKV: the first l_k (l_v) layers keep 2-bit keys (values), the rest use 1 bit, on KIVI-style quantization (per-channel K, per-token V, group 32, round-to-nearest). Llama-2-7b/13b on CoQA, TruthfulQA and LongBench.

## Goal-by-goal answers
### Goal: Has K2/V1 (2-bit keys, 1-bit values everywhere) been tried, and how did it fare?
Yes. AsymKV-32/0 on Llama-2-7b (all 32 layers K2, all layers V1) and AsymKV-40/0 on Llama-2-13b are exactly K2/V1 with RTN [full text, Sections 4, 5.1, 5.2.2]. LongBench, Llama-2-7b: TriviaQA 85.27 vs KIVI-2 87.64 vs float 87.72; SAMSum 38.28 vs 41.62 vs 41.69; RepoBench-P 43.35 vs 56.81 vs 59.82; Qasper 8.96 vs 9.73 vs 9.52. Llama-2-13b RepoBench-P 46.92 vs KIVI 53.66 [Table 2]. The reverse K1/V2 collapses (TriviaQA 11.6) [Table 2]. So V1 is far less harmful than K1, but it loses 13.5 points on the retrieval-heavy RepoBench-P; long-context tasks needed more 2-bit layers than short ones [Section 5.2.2].
### Goal: What limitations do the authors state?
Configurations must be found by "exhaustive testing" per model [Section 8]. Only Llama-2, ≤13B, no reasoning or long-generation tasks [Section 5.1].
