### G-C2 verdict
- **Verdict**: `reject(reason=K coupling only recovers RTN-level error; V1 fails exactly where attention is concentrated; K2/V1 already tried)`
- **Evidence**:
  - **The right comparator is RTN / KVarN, and against RTN the K half buys nothing in expectation.** The K theorem only says shared-threshold SR is no worse than *independent* SR, which is a strawman. Per element, SR error variance is f(1-f)Δ² (Δ²/6 on average for uniform fractional parts f), twice RTN's Δ²/12. Softmax is shift-invariant, so what matters is the score-difference error q·(e_i − e_j). For two tokens in one coordinate with independent uniform f_i, f_j:
    - comonotone SR: E[(e_i−e_j)²]/Δ² = E|f_i−f_j| − E(f_i−f_j)² = 1/3 − 1/6 = 1/6;
    - independent SR: 1/3;
    - RTN: also 1/6.

    So the coupling only halves SR's excess and lands back at RTN parity. A reviewer's toy check (2-bit per-channel grid, 128-token block, random rotated keys, 200 trials) agrees: forward KL is RTN 0.172, comonotone SR 0.173, independent SR 0.336. KVarN is 2-bit RTN after Hadamard rotation and dual-axis normalization [2606.03458]. Its fractional parts are close to uniform, so K-coupling should not beat it. The candidate's own kill test ("stop if C2 beats only independent SR but not RTN/KVarN") is therefore predicted to fail for K before any experiment is run.
  - **A better randomized K option already exists and is not cited.** Subtractive dither with one shared random offset U (known to the decoder, so no side code) is unbiased and reaches TurboQuant's dense-rotation MSE constant with a single randomized Hadamard transform [2605.13810, Theorem 1.1, Definition 2.1]. G-C2's shared-U rule is *non-subtractive*: U is not used at reconstruction. So it keeps SR's doubled per-element MSE, which subtractive dithering avoids. Related prior work also covers unbiased 1-bit key estimators (QJL sign sketches [2406.03482, Lemma 3.2]; TurboQuant_prod's QJL residual [2504.19874, Section 3.2]), dithered KV certificates (WitCert Tier B [2607.28699]) and correlated-threshold dither for recurrent caches (Weyl low-discrepancy dither [2609.39185]). Within-token GPTQ-style error compensation of keys at write time, run on a residual buffer of 32-128 tokens, is SQuat [2503.24358, Section 3.3, Proposition 1]. Discrepancy/dependent rounding that preserves linear functionals is DiscQuant for weights, which beats RTN and GPTQ [2501.06417, Sections 3-4]. The G-C2 delta, "dependent rounding moved onto KV grids", is real but narrow: it preserves one fixed functional (the block sum) because the future attention weights are unknown at write time.
  - **V: block-sum preservation helps only where V error was already small, and it fails on concentrated attention.**
    - Under sum-preserving rounding the readout error is roughly σ²Σ_i(a_i − ā_block)². The gain over independent rounding is only the within-block mean component of the attention weights, which is negligible when one token dominates.
    - A toy check (1-bit vs 2-bit per-channel grids, 128 tokens, Gaussian values) gives readout squared error:

      | Attention pattern | V2 RTN | V1 dependent | V1 RTN |
      |---|---|---|---|
      | flat | 0.25 | 0.036 | — |
      | one token at weight 0.9 | 26 | 595 | 372 |

      With one dominant token, V1-dependent is about 23× worse than V2 RTN and also worse than V1 RTN.
    - That pattern is the retrieval-head / once-stated-fact case. Retrieval heads are sparse (<5%), and masking them breaks CoT because "the next step reasoning requires the model to refer to previous information" [2404.15574, Section 4.3]. DuoAttention keeps full KV for exactly these heads [2410.10819].
    - Empirically, K2/V1 under KIVI-style RTN has already been run as AsymKV-32/0 on Llama-2-7b. It loses 13.5 points on retrieval-heavy RepoBench-P (43.35 vs KIVI-2 56.81 vs float 59.82) while staying close on TriviaQA [2410.13212, Table 2]. So "K2/V1" is not new as a configuration, and its failure mode is the one dependent rounding cannot fix.
  - **Byte saving is modest and dominated on the frontier.** KVarN's 2-bit format costs 2.25 bits/element including two FP8 scales and an FP16 zero per 128 [2606.03458, Appendix D]. With the same metadata for V1, K2/V2 = 4.5 and K2/V1 = 3.5 bits per K+V element pair, i.e. −22% of quantized bytes. At 16K, adding a 64-token sink and the ≤128-token BF16 staging window gives 4.82 vs 3.83 bits (−20.5%) (reviewer estimate). With TurboQuant-style boundary layers in BF16 (4 of 36) it is about −12%, i.e. ≤1.26× (typically ~1.13×) more concurrency, and only once memory binds [2606.20474]. Meanwhile:
    - TaSQ already runs ~1.25/1.25-bit KV on long CoT in SGLang (Qwen3-4B-Thinking AIME24 68.9 vs 74.4 BF16; batch 6→84) [2610.03027, Tables 2, Section 6.1]. That is at fewer total bits than K2/V1.
    - R-KV is lossless at a 10-34% token budget [2505.24133].

    K2/V1 thus sits in a narrow band between existing 2.5-bit and 4.5-bit operating points.
  - **The streaming write is feasible, and this is not the objection.** KVarN already quantizes 128-token chunks from a full-precision staging buffer, at 0.18% overhead (1.9 ms per 128 tokens vs 1050 ms to generate them) [2606.03458, Section 4.2]. SQuat does block-wise write-time optimization on a 32/128 buffer [2503.24358]. Pairwise dependent rounding over 128 tokens is ~7 tree rounds, which is cheap. The real engineering cost is a new packed-V1 dequant kernel, since KVarN ships 2-bit only.
  - **Grounding of the mechanism is accurate.** The pairing update with α/β probabilities is standard dependent (pipage) rounding: it preserves marginals and the Δ-weighted sum. The mapping K↔score-shift-invariance and V↔weighted readout is coherent. The claim of "no persistent side code" holds. The contribution type is methodological. The failure is in what the theorems compare against, not in the conceptual mapping.
  - **Salvage, if the orchestrator wants one.** The only regime where the V half wins is diffuse ("streaming") heads, where V1-dependent beat V2-RTN in the toy check. A head-adaptive design (V1 + dependent rounding on diffuse heads, ≥V2 on retrieval heads) would be a different candidate. It would need its own novelty check against head-wise schemes such as DuoAttention [2410.10819] and against TaSQ's 1.25-bit V.
- **Strongest objection in 1 sentence**: Measured against the comparator that matters (RTN/KVarN rather than independent stochastic rounding), the K coupling only recovers RTN's score-difference error. The V coupling cancels error only under diffuse attention and is ~20× worse than V2 when attention concentrates on a once-stated fact, the case AsymKV's K2/V1 already showed failing (−13.5 on RepoBench-P).
