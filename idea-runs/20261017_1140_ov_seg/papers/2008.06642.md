# Group Testing Enables Asymptomatic Screening for COVID-19 Mitigation: Feasibility and Optimal Pool Size Selection with Dilution Effects

## What this paper does
An operations-research study of pooled PCR testing for population screening. It models how pooling dilutes a positive sample's viral load and thereby raises the false-negative rate, derives the expected numbers of tests, false negatives and false positives for linear-array and square-array group testing, chooses the pool size that minimises false negatives under test-capacity and false-positive constraints, and simulates repeated screening of a 100K population.

## Goal-by-goal answers

### Goal: (innovator C2) How does dilution make a pooled test's sensitivity depend on pool size, and how is the pool size chosen?
With n sub-samples of which d are positive, the pooled viral load is the average (1/n)ΣV_i, so the pooled Ct value shifts by about log2 n and the false-negative rate γ(n, d) rises with pool size n and falls with the number of positives d (Eq 4, Fig 2) [full text, Sec 3.4]. Pool size is then chosen by minimising expected false negatives per person subject to a test-capacity and a false-positive constraint, tracing a Pareto frontier over tests used and both error types (Eq 11) [Sec 4.5]. A naive constant-error model is called unrealistic because "the false negative rate is not constant. Rather, it depends on the pool size due to the dilution effect" [Sec 2.3].

### Goal: (innovator C2) Are pooled-test errors independent across pools?
No: "false negatives driven by low viral load are positively correlated across pools", because the same low-load sample is weak in every pool that contains it, whereas false positives from lab contamination are independent across pools [Highlights; Sec 4.3, Thm 4.1]. A sample too weak to be detected is therefore missed systematically, not by chance.
