# ProxyCLIP: Proxy Attention Improves CLIP for Open-Vocabulary Segmentation

## What this paper does
Training-free OVSS that pairs frozen CLIP with a frozen vision foundation model (DINO, DINOv2, SAM, MAE). Shows that VFM feature cosine similarities predict same-label patch pairs far better than any CLIP attention (q-k or self-self). The Proxy Attention Module uses normalised, masked VFM feature similarity as attention over the value embeddings of CLIP's last attention layer, then CLIP's output projection; the CLIP values are bilinearly upsampled to the VFM's token grid. Outperforms prior training-free methods at extra compute.

## Goal-by-goal answers

### Goal: What mechanism does it use to suppress spatial noise in CLIP patch tokens, at which layer(s), and on which quantity (attention weights, value content)?
It swaps the attention weights of CLIP's last block for VFM-derived ones while keeping CLIP's value content: "we expect CLIP's image encoder to provide the semantic base (value embeddings), while the VFMs' image encoder contributes attention scores" [full text, Section 3.2 "Architecture"]. z = Proj(Attn_p · v) with Attn_p = SoftMax(A + M), A = gamma(x x^T - beta·mean(x x^T)) and M masking negative entries [full text, Eqs. 4-8]. v is CLIP's last-layer value embedding (from the penultimate state) and is interpolated to the VFM resolution to use DINO-B/8 [full text, Section 3.2 "Different resolution"]. Normalisation plus masking raises average mIoU from 25.0 to 42.3 [full text, Section 4.3].

### Goal: What does it identify as the source of the noise in CLIP patch tokens?
CLIP's global attention "indiscriminate propagation of information across all image patches" weakens the specificity of local patch representations, and CLIP's local feature correspondence is poor: in a precision-recall test on COCO-Stuff, self-self CLIP attention beats q-k but DINO/SAM feature correspondence "far surpasses" both [full text, Section 3.1, Fig. 1].

### Goal: What limitation or cost does the method carry?
It needs a second backbone, which raises parameters and lowers images-per-second relative to CLIP-only methods [full text, Appendix 0.C, Table 5]. Smaller VFM patch size (8) helps by about 1.0 mIoU [full text, Section 4.3 "Impact of the patch size"]. The class evidence still comes entirely from CLIP's penultimate-state values; the VFM only decides how they are averaged.
