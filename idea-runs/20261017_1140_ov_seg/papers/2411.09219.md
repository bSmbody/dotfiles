# Harnessing Vision Foundation Models for High-Performance, Training-Free Open Vocabulary Segmentation

## What this paper does
Trident combines CLIP, DINO and SAM training-free. Instead of segmenting each sliding-window crop and splicing the results, it splices CLIP/DINO crop features into one map and aggregates them with a global affinity built from SAM's high-resolution encoder (attention weights masked by feature cosine). The coarse argmax map is then turned into per-class point, box and mask prompts for SAM's decoder to refine boundaries. It reports SOTA training-free mIoU on eight benchmarks at the cost of running SAM at 1024 px.

## Goal-by-goal answers

### Goal: (axis: small objects and stuff classes) What mechanism does it use that affects small or thin objects, and at what resolution/scale is the class decision made?
Trident (CLIP + DINO + SAM) uses "splice-then-segment": CLIP/DINO features of 336×336 sub-windows are spliced into one map, then aggregated globally with an affinity from SAM's encoder run at 1024 px (Eq 3-5: SAM last-layer attention W kept only where SAM-feature cosine C ≥ ε) [full text, Sec 3.3, 4.4]. Class decision = argmax of cosine between aggregated CLIP features and text (Eq 3). Fine detail comes from "SAM refinement" [Sec 3.4]: for each class k the argmax map gives a binary map B_k, decomposed into connected regions; each region yields a point (argmax of confidence), a box, and a scaled mask prompt (α=0.005) to SAM's decoder, run per class (Eq 6-7). A class that wins no pixel in the coarse argmax therefore gets no prompt and cannot be recovered by refinement.

### Goal: (axis: small objects and stuff classes) What mechanism does it use for stuff classes / large regions / many-class benchmarks, and what global context or class-competition handling does it apply?
Global context is supplied by the SAM-derived image-wide affinity, which "extends the receptive field ... to the entire source image" [Sec 3.3]. SAM-feature cosine alone captures low-level similarity (a frog's eye correlates with snail centres, not the whole frog), so attention weights are used instead [Sec 3.3]. No text-side or vocabulary handling.

### Goal: (axis: small objects and stuff classes) What does it report as its limitation or failure on small objects or stuff classes, and which knobs are set per dataset?
Segment-then-splice degrades with resolution (ProxyCLIP VOC20 79.7→73.4 from 336→576) because sub-windows lose object-level receptive field [Sec 3.2, Table 1/7]. Trident without refinement is roughly flat on stuff-heavy sets when resolution grows (Stuff 27.6→27.5, ADE 20.6→20.9 from 448→576) [Table 7]. SAM refinement gains are smallest on Stuff (+0.7: 27.6→28.3) and ADE (+1.0: 20.9→21.9) vs VOC21 (+2.6) and Cityscapes (+2.5) [Table 5]. Input resolution is set per dataset (336 for VOC20 up to 688 for Cityscapes) [Sec 4.1]. SAM-CLIP (trained) still beats it on COCO-Stuff (31.5 vs 28.3) [Sec 4.2]. SAM adds large memory/time cost [Sec 4.4].
