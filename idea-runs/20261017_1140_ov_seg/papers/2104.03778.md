# Progressive Semantic Segmentation

## What this paper does
MagNet (CVPR 2021) segments ultra-high-resolution images (Cityscapes, DeepGlobe, Gleason) under a memory limit by looking at the image at several magnification levels, from coarse to fine. Each stage splits the image into smaller patches, resizes each patch to the segmenter's fixed input size, and segments it. A refinement module then updates the cumulative map only at selected uncertain locations. MagNet-Fast processes only the most uncertain patches at each scale. Both the segmentation backbone and the refinement module are trained with labels.

## Goal-by-goal answers

### Goal: (reviewer C1) How does MagNet choose which locations to re-process at a finer magnification, and what supervision does that need?
Scales run from the full image down to the segmenter's input size: on Cityscapes, patches of 2048×1024, 1024×512, 512×256 and 256×128, each fed at 256×128 [full text, Sec 3.1, Sec 4.2]. At each stage the segmentation module gives a scale-specific map O, and a small network combines O with the cumulative map Y into R. Per-pixel confidence is the gap between the two highest class probabilities, and uncertainty is one minus that confidence. The k locations to update are ranked by Q = F(Y_u ⊙ (1 − R_u)) with median blurring F, i.e. where the cumulative map is uncertain and the new scale is confident [Sec 3.2]. MagNet-Fast processes only the patches with the highest uncertainty Y_u at each scale [Sec 3.3]. Selection is therefore margin-based (top-1 minus top-2) uncertainty. The segmenter and the refinement module are trained with cross-entropy on labelled data, the refinement module for 50 epochs [Sec 4.1].

### Goal: (reviewer C1) How does it relate itself to PointRend and boundary refinement for tiny objects, and why does it need intermediate scales?
The paper says boundary-refinement methods "failed to recover tiny objects". It describes PointRend as refining uncertain points with only local context, and as needing training for each backbone [Sec 2, Table 1]. Its stated advantage is keeping the coarse map's overall structure while adding detail stage by stage, which uses global context and fine detail together [Sec 3, Sec 3.3]. Table 3 reports that intermediate scale levels are essential on Cityscapes [Sec 4.2.1].
