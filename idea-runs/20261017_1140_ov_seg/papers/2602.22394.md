# Vision Transformers Need More Than Registers

## What this paper does
LaSt-ViT (CVPR 2026). Defines a Patch Score (patch-CLS similarity) and a Point-in-Box (PiB) metric and finds that ViTs under label, text (CLIP) and self-supervision give higher patch scores to background than to foreground, unlike ConvNets. Attributes the artifacts to "lazy aggregation": with coarse image-level supervision and global attention, the ViT encodes global semantics through background patches early in training. Registers remove high-norm tokens but not this bias. Fix (requires pre-training): the CLS token aggregates, per channel, the top-K patches most stable under channel-wise low-pass filtering. Large zero-shot OVSS gains for CLIP retrained with it.

## Goal-by-goal answers

### Goal: What does it identify as the root cause of noisy ViT/CLIP patch tokens, and is it the high-norm (sink) tokens?
No. Root cause is lazy aggregation: the CLS token learns early in training to aggregate background tokens that correlate with the image label, so image-level semantics are "short-circuited" through background regions; global attention lets background tokens absorb diffused foreground semantics [full text, Section 1; Sections 4.2-4.4]. Evidence: masking the top 50-70% highest-score patches does not hurt ImageNet accuracy [Section 4.2, Fig. 2]; window attention raises PiB (50.1 -> 59.8 for ViT-S) [Table 2]. "High-norm is merely a manifestation of the lazy behavior in later stages. Simply moving the high-norm tokens ... to the register tokens does not fully address the underlying deficiencies" [Section 2].

### Goal: How do registers affect patch-level artifacts in CLIP?
Table 1: OpenCLIP-ViT has high-norm tokens and PiB 39.8; with registers high norms disappear but PiB is 37.6, versus 53.9 for OpenCLIP-ResNet; caption: "Register reduces high-norm tokens but high-norm is not the root cause of artifacts" [full text, Section 1, Table 1].

### Goal: What mechanism does it propose and can it be applied to a frozen pretrained CLIP?
LaSt-ViT replaces CLS aggregation with a frequency-aware selective pooling: channel-wise stability scores compare each patch channel with its low-pass (1-D FFT over channels) version, and for each channel the top-K stable patches are averaged into the CLS query [full text, Section 5.1, Eqs. 4-8]. It is a pre-training change ("tackles the problem directly during pretraining, avoiding ... test-time interventions") [full text, Section 2]; CLIP models are retrained with it, e.g. CLIP ViT-B/16 VOC zero-shot 49.0 -> 75.0 [full text, Section 6.4]. It is not a training-free method for a frozen model.
