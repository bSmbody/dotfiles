# ResCLIP: Residual Attention for Training-free Dense Vision-language Inference

## What this paper does
Training-free plug-in for self-self-attention CLIP OVSS methods (SCLIP, ClearCLIP, NACLIP). Observes that q-k (cross-correlation) attention in CLIP's non-final layers shows class-specific localisation, unlike the last layer. Residual Cross-correlation Self-attention (RCS) averages q-k attention over a range of intermediate layers and blends it with the last layer's self-correlation attention; Semantic Feedback Refinement (SFR) uses an initial segmentation map to raise attention to same-class, nearby patches. Both modify the final block's attention.

## Goal-by-goal answers

### Goal: What mechanism does it use to suppress spatial noise in CLIP patch tokens, at which layer(s), and on which quantity?
Attention weights of the last block only. A_c = mean of q-k attention over intermediate layers s..e; A_rcs = (1 - lambda_rcs) A_s + lambda_rcs A_c with A_s the self-correlation attention of SCLIP/NACLIP-style methods [full text, Section 3.2.1, Eqs. 5-6]. SFR builds a score from the initial segmentation map with a distance decay and Gaussian smoothing, mixed as S_r = (1 - lambda_sfr) S_s + lambda_sfr S^ ; final A = (1 - lambda_rcs) softmax(S_r) + lambda_rcs A_c [full text, Section 3.2.2, Eqs. 11-13]. Best lambda_rcs = 0.5, lambda_sfr = 0.7 [full text, Section 4.3]. Value vectors stay the last block's.

### Goal: What does it identify as the source of the noise in CLIP patch tokens?
The last layer's attention is spatially invariant, while intermediate layers' cross-correlation attention still carries class-specific localisation; self-correlation attention "enforces the self-similar features response and lacks the capacity to capture the cross-feature dynamics" [full text, Section 1; Section 3.2].

### Goal: How large are its gains as a plug-in?
On NACLIP with ViT-B/16 on VOC20, RCS alone raises mIoU 79.7 -> 85.5, SFR alone +1.8, both 86.0 [full text, Section 4.3, Table 3]; the introduction reports 1.7 to 13.1 mIoU gains over the three host methods [full text, Section 1]. All gains come from re-weighting the same value content.
