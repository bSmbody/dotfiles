# AdaCount: Training-Free Similarity-Guided Spatial and Feature Adaptation for Zero-Shot Object Counting

## What this paper does
AdaCount (2026-07, technical report) is a training-free zero-shot counter built on frozen SAM 3 for one text concept at a time. A first SAM 3 pass yields high-confidence instances; their masked-average-pooled encoder features form prototypes, whose cosine similarity to the feature map highlights look-alike regions. The image is then warped with a separable, similarity-driven rectilinear warp that gives those regions more pixels, re-encoded in a second SAM 3 pass, its encoder features are boosted by the warped similarity, and predictions are mapped back. It lowers MAE against vanilla SAM 3 on six counting benchmarks (e.g. −17% on FSC-147, −43% on CARPK) at about 2.5× SAM 3's runtime.

## Goal-by-goal answers

### Goal: (innovator C3) How does it decide where SAM 3 gets more resolution, per concept or for all concepts, and how many extra passes does it pay?
The signal is per concept: prototypes come from the first pass's confident instances of the queried concept, and the similarity map is their averaged cosine response [full text, Sec 3.1–3.2, Eq 3–7]. The map is sharpened, smoothed and turned into row and column CDFs that define one invertible warp of a fixed-size canvas; nothing is cropped, and the whole image stays in view [Sec 3.3, Eq 8–11]. The warped image gets one more SAM 3 pass, with features scaled by (1 + α·centred similarity) [Sec 3.3, Eq 12–13]. Cost is a fixed two passes per concept (about 750 ms against 300 ms for SAM 3) [Sec 4.3, Table 6]. For dense labelling over C classes this would be one warped pass per class; the paper only counts single concepts.

### Goal: (innovator C3) Does it distinguish instances already found from those still missed, and what are its stated failure modes?
No. The found instances are the prototypes, so the warp enlarges them together with every look-alike, and the second pass's predictions replace the first in the warped space; nothing is removed, masked or tested for being unexplained [Sec 3.1–3.3]. Its stated limitation is that it "relies on high-confidence detections from the initial SAM3 inference pass"; when SAM 3 detects no instance of a concept, the adaptations "become ineffective" [Sec 4.3, Limitations]. It describes concurrent SAM3Count as density-triggered adaptive tiling, one SAM 3 pass per tile with recursive refinement in crowded scenes, whose independent upsampled tiles lose context (overcounting on microscopy) and whose cost scales with the tile count (about 8 minutes for one dense image) [Sec 1, Sec 2, Sec 4.2–4.3, Table 6].
