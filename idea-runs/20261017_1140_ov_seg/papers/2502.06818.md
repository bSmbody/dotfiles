# Rethinking the Global Knowledge of CLIP in Training-Free Open-Vocabulary Semantic Segmentation

## What this paper does
GCLIP (TMM 2026) argues that self-self attention methods discard CLIP's useful global context. It detects the block where "global tokens" (patches all others attend to, behaving like [CLS]) emerge and averages those blocks' query-key attention with the last-block query-query attention (Attention Map Fusion), and it renormalises FFN output channels with abnormally large weight norms so value embeddings become more semantically discriminative (Channel Suppression). CLIP-only, evaluated on VOC, Context, ADE20K, Cityscapes and COCO-Stuff.

## Goal-by-goal answers

### Goal: (axis: small objects and stuff classes) What mechanism does it use that affects small or thin objects, and at what resolution/scale is the class decision made?
GCLIP modifies only CLIP's last block. Attention Map Fusion (AMF) averages the Query-Key attention maps of the first block where "global tokens" emerge (detected automatically, Eq 2-3) and the next one (l=1) with the final-block Query-Query attention: A_f = (A_g^qk + A_{g+1}^qk + A_f^qq)/(l+2) (Eq 4) [full text, Sec III-B]. Channel Suppression renormalises FFN output channels whose weight norm exceeds 1.5× the mean (Eq 6-10) [Sec III-C]. The fusion weight is identical for every patch; there is no scale- or size-dependent treatment, and decisions are per patch.

### Goal: (axis: small objects and stuff classes) What mechanism does it use for stuff classes / large regions / many-class benchmarks, and what global context or class-competition handling does it apply?
Its premise is that self-self attention methods (ClearCLIP, SCLIP) weaken global context, "which is known to be useful for distinguishing confusing categories" [Sec II, III-A]; global tokens' attention pattern matches the [CLS] token, so AMF injects image-level properties into every patch [Sec III-B]. Reported gains are largest on Cityscapes (+3.7 over ClearCLIP) and ADE20K (+1.8) [Sec IV-B].

### Goal: (axis: small objects and stuff classes) What does it report as its limitation or failure on small objects or stuff classes, and which knobs are set per dataset?
No small-object analysis or limitation section on scale; qualitative failures discussed are class confusions (cow vs horse) in ClearCLIP that global context fixes [Sec IV-C]. The global-local mix (l, equal averaging) is a fixed design choice, not adapted per region.
