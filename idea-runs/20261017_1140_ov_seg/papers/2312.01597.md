# SCLIP: Rethinking Self-Attention for Dense Vision-Language Inference

## What this paper does
Training-free CLIP OVSS. Observes that CLIP's last-layer attention maps are nearly identical for different source points (spatially invariant features) even though CLIP recognises which objects are present. Replaces the self-attention of the last block with Correlative Self-Attention (CSA): Softmax(X W_q W_q^T X^T) + Softmax(X W_k W_k^T X^T), reusing pretrained weights, so each token attends to itself and to tokens similar to it. Rest of the encoder unchanged; no post-processing. Reports 38.0 average mIoU over eight benchmarks with ViT-B/16.

## Goal-by-goal answers

### Goal: What mechanism does it use to suppress spatial noise in CLIP patch tokens, at which layer(s), and on which quantity (attention weights, value content, whole pathways)?
Only the attention weights of the last transformer block, which it treats as a "decoding layer" [full text, Section 3.3]. The q-k attention is replaced by CSA = Softmax(X W_q W_q^T X^T / tau) + Softmax(X W_k W_k^T X^T / tau) [full text, Eq. 3]. The diagonal is maximal (self-attention to the own position), and other tokens are weighted by projected cosine similarity [full text, Section 3.2]. The value vectors and all earlier layers are untouched. The paper reports CSA is insensitive to the projection matrix: random or hand-set W_r work too [full text, Section 3.2], which shows the mechanism is a generic similarity-weighted smoothing of the existing value content.

### Goal: What does it identify as the source of the noise in CLIP patch tokens?
A spatial misalignment created by self-attention: CLIP "is able to roughly recognize what objects appear in the image yet wrongly localizes them" (e.g. predicts water for flamingos), and last-layer attention maps from different source points look alike, i.e. CLIP learns spatially invariant features because pretraining represents the image by a single vector [full text, Section 1, Fig. 2; Section 3.1].

### Goal: Which alternative localisation strategies did it test and how did they fare?
Attention sharpening (temperature) gives no gain in most cases; local window attention (size 3) roughly matches MaskCLIP; borrowing early-layer attention maps for the last layer gives 26.8 mIoU on Context59 and 16.8 on COCO-Stuff, better than MaskCLIP but far below CSA [full text, Section 4.3, Table 3]. All alternatives again only modify the final-layer attention weights.
