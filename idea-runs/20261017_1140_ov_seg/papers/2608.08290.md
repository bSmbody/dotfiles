# Test-Time Prototype Adaptation for Open-Vocabulary Semantic Segmentation

## What this paper does
TPA is an output-level, transductive plug-in. From a pool of unlabeled deployment images it collects "anchor" pixels where the host OVSS model is argmax-consistent and above probability 2/C, sums their frozen DINO features into one prototype per class, and at test time fuses a centred cosine score against these prototypes with the host's log-probabilities. It composes with five hosts (attention redesign and VFM injection), three CLIP backbones and eight benchmarks.

## Goal-by-goal answers

### Goal: (axis: small objects and stuff classes) What mechanism does it use that affects small or thin objects, and at what resolution/scale is the class decision made?
TPA is an output-level plug-in. On a pool of unlabeled deployment images, a pixel is a class-c anchor if the host's argmax is c and p(c) > τ = 2/C (Eq 3); classes with fewer than K_min=5 anchors get no prototype [full text, Sec 3.2, App. D]. Anchors' frozen DINO features are summed across images into one unit-norm prototype per class (Eq 4-5). At test time a centred cosine score against the prototypes is fused with log p (β=(1−α)λ, α=0.5, λ=5; Eq 6-8) [Sec 3.3]. Anchors come only from where the host already predicts the class confidently, and the auxiliary score lives on the DINO patch grid.

### Goal: (axis: small objects and stuff classes) What mechanism does it use for stuff classes / large regions / many-class benchmarks, and what global context or class-competition handling does it apply?
One global prototype per class shared across all images; class competition is resolved by adding prototype similarity to the host logits. Gains concentrate on classes with low baseline IoU, and rare classes still gain on average [App. C].

### Goal: (axis: small objects and stuff classes) What does it report as its limitation or failure on small objects or stuff classes, and which knobs are set per dataset?
Failure modes: too few anchors for low-frequency classes (prototype reflects a specific pose), and pool/test distribution shift; regressions at ambiguous boundaries or out-of-distribution textures [App. D, E]. No explicit small-object analysis.
