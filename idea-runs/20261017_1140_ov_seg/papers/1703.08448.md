# Object Region Mining with Adversarial Erasing: A Simple Classification to Semantic Segmentation Approach

## What this paper does
Adversarial Erasing (AE; Wei et al., CVPR 2017 oral) builds pseudo-masks for weakly supervised semantic segmentation from image-level labels. A classification network trained on the images localises the most discriminative region of each labelled class with CAM; that region is erased (filled with the training-set mean pixel), and a classification network is re-trained on the erased images, which forces it to find another discriminative region of the same class. The regions mined over three steps are merged, combined with saliency-based background, and used to train a segmentation network, with an online "prohibitive segmentation learning" term. It reports 55.0 / 55.7 mIoU on VOC 2012 val / test.

## Goal-by-goal answers

### Goal: (reviewer C3) What is erased, and what tells the method that more object regions remain after erasing?
At step t, for every image-level label c, pixels whose CAM value exceeds δ are added to the mined set and erased from the image, I_{t+1} = I_t \ F_t, by replacing them with the mean training pixel [full text, Sec 3.1, Alg 1]. The signal that more of the class remains is the classifier itself: "the discriminative regions have been removed and no longer contribute to the classification prediction", so the network "is naturally driven to discover new object discriminative regions for maintaining its classification accuracy level" [Sec 3.1]. Erasing one instance can reveal other instances: for "cow", the right-most instance is mined first and "by erasing this instance, another two instances on the left side are then discovered" [Sec 4.3.1, Fig 6]. Iteration stops when the classifier "cannot well converge" on the erased images, read from the converged training loss (≈0.05, 0.08, 0.1 for steps 1–3, ≈0.15 after more) [Sec 3.1, Sec 4.3.1, Fig 5a].

### Goal: (reviewer C3) Is the second look done by the same frozen classifier or a retrained one, and what happens when too much is erased?
Retrained: each step trains a new classification network M_t on the erased training images (Alg 1, line 4) [Sec 3.1]; nothing is shown for a frozen classifier queried on erased inputs. Over-erasing is the stated failure: "In the case where most object regions are removed from the training images, the classification network has to rely on some contextual regions to recognize the categories. These regions are true negative ones" [Sec 4.3.1, Fig 5b]. Merging a fourth step lowers mIoU by 2.1, so only the first three steps are used [Sec 4.3.1, Table 3]. So once the class's own evidence is gone, a classifier asked "is the class still here?" answers from context rather than saying no.
