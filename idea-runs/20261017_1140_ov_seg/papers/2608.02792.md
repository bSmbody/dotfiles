# PixelUp: Zero-Shot Semantic Feature Upsampling for Fine-Grained Vision Tasks

## What this paper does
PixelUp is a feature upsampler that, once trained self-supervised, works zero-shot across vision foundation models. A high-resolution query built from a light pixel encoder and frozen DINOv3 ConvNeXt multi-scale features (coarse-to-fine cross-attention chain) attends to a local low-resolution neighbourhood and returns a weighted average of the target model's frozen low-resolution features. Evaluated on linear probing, depth, unsupervised segmentation and a training-free open-vocabulary pipeline (RADSeg).

## Goal-by-goal answers

### Goal: (axis: small objects and stuff classes) What mechanism does it use that affects small or thin objects, and at what resolution/scale is the class decision made?
PixelUp is a VFM-agnostic feature upsampler trained once self-supervised (MSE to the teacher's features of a higher-resolution view) [full text, Sec 3.2]. A high-resolution query (from a pixel encoder fused with frozen DINOv3 ConvNeXt-S pyramid features through a cross-attention chain) attends to a compact low-resolution neighbourhood, and the output is V_HR^p = (1/Z(p)) Σ_{q∈N_LR(p)} exp(⟨Q_HR^p, K_LR^q⟩/√d) V_LR^q (Eq 1-2) [Sec 3.1] — a convex combination of neighbouring low-resolution token features. It can sharpen where a class boundary falls but cannot create class evidence that no neighbouring LR token carries.

### Goal: (axis: small objects and stuff classes) What mechanism does it use for stuff classes / large regions / many-class benchmarks, and what global context or class-competition handling does it apply?
No class- or context-side mechanism; values remain the frozen VFM's [Sec 3.1].

### Goal: (axis: small objects and stuff classes) What does it report as its limitation or failure on small objects or stuff classes, and which knobs are set per dataset?
In the RADSeg training-free OVSS pipeline it reaches 53.29 average mIoU, +1.33 over NAF, with the largest gains on thin-structure benchmarks Cityscapes (+3.29) and KITTI (+2.67), but it is −0.39 on ADE20K vs NAF [Sec 5.3, Table 4] — upsampling helps thin-structure boundaries but not the many-class/stuff benchmark.
