# Sparse Attention for Dense Open-Vocabulary Prediction in CLIP

## What this paper does
Training-free study (July 2026) that replaces the row-wise softmax in the final self-attention layer(s) of frozen CLIP with alpha-entmax, which zeroes low-scoring entries via a data-dependent threshold. Applied to standard q-k and to self-correlation (q-q, k-k, v-v) attention, evaluated on VOC, Context, ADE20K and FG-OVD with ViT-B/16 and ViT-L/14. Main finding: the gain from sparsification is proportional to how diffuse the baseline attention is; best at mild sparsity on the last 1-2 layers.

## Goal-by-goal answers

### Goal: What mechanism does it use to suppress spatial noise in CLIP patch tokens, at which layer(s), and on which quantity?
It changes only the normaliser of attention weights in the last layer(s): softmax -> alpha-entmax, so low-relevance tokens get exactly zero weight [full text, Section 1; Section 3.1]. A depth sweep shows the optimum is mild sparsity on the last 1-2 layers; stronger alpha "begins zeroing out relevant attention mass" [full text, Section 5.3, Fig. 5]. Entmax beats a matched-support random mask and temperature sharpening [full text, Section 5.4, Table 3]. Dropping the residual of the final block "increases it sharply", showing "the residual significantly impedes localization by adding back the global features" [full text, Section 5.5, Table 4].

### Goal: What does it identify as the source of the noise in CLIP patch tokens?
The contrastive objective concentrates representational variance on coarse object/scene directions; "fine-grained, spatially localized features are still encoded, but they lie along low-variance directions" obscured by the dominant coarse signal; softmax then forces each patch update to be a global mixture with a long tail of irrelevant tokens [full text, Section 1].

### Goal: What limitation does it report?
The benefit shrinks when the underlying attention is already concentrated (e.g. on self-correlation distributions), and is largest for diffuse attention, higher resolution and larger backbones [full text, Section 1 contributions; Section 7]. It addresses which tokens are mixed, not the content of the tokens being mixed.
