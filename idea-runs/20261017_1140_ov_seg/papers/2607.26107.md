# TraceCLIP: Recovering Local Semantics from Patch-to-CLS Contributions

## What this paper does
Training-free CLIP OVSS (July 2026 preprint). Decomposes the CLS attention update of a block into per-patch, per-head terms and projects them into CLIP's joint space: C_i = sum_h W_proj(A_0i^h W_OV^h LN(x_i)). Diagnostics on COCO show these patch-to-CLS contribution features classify regions and point to targets better than final patch states. TraceCLIP turns contribution-based text responses into a semantic-geodesic topology gate that calibrates the last layer's query-query affinity, then reconstructs dense features from last-layer values. No external backbone; reports +1.3 to +4.5 average mIoU over prior training-free methods on eight benchmarks.

## Goal-by-goal answers

### Goal: What mechanism does it use to suppress spatial noise in CLIP patch tokens, at which layer(s), and on which quantity?
It reads class evidence from the final block: C_i^(-1) is the last block's value of patch i weighted by the CLS attention and projected [full text, "Patch-to-CLS Contribution Decomposition", Eqs. 1-2]. Preliminary labels/confidences from C T^T form a semantic-geodesic gate that suppresses propagation across semantic boundaries in the q-q affinity; dense features are then reconstructed by propagating last-layer values [full text, "TraceCLIP" sections]. Ablation: direct V^(-1) readout 26.3 avg mIoU; q-q affinity on it 37.5; full method 39.8 [full text, "Component ablation"]. So the content is still the last block's value vectors; the novelty is in the gate on the mixing weights.

### Goal: Where in the last block is local semantic evidence lost?
Late-block component analysis (COCO, ViT-B/16): the attention output raises Region Acc from 5.2% (block input) to 35.7%, but adding the residual drops it to 15.1% (ViT-L/14: 37.9% -> 9.9%); MLP output and a mean-MLP replacement show the drop is not caused mainly by the MLP: "local semantics become less directly accessible when the attention update is mixed with the residual patch states" [full text, "Late-block component analysis", Table 2].

### Goal: Can contributions from earlier blocks be read out directly as dense text-aligned features?
Only weakly. Dense readout average mIoU: final patch states 11.9; C^(-3) 16.5; C^(-2) 20.4; C^(-1) 25.6 [full text, "Dense readout analysis", Table 4(a)]. Readout quality falls the further from the end the block is, so the method relies on the last block's contribution and on last-layer affinity propagation.
