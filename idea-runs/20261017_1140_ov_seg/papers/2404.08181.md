# Pay Attention to Your Neighbours: Training-Free Open-Vocabulary Semantic Segmentation

## What this paper does
NACLIP, a training-free CLIP OVSS method. In the last encoder block it replaces q-k attention logits with key-key similarity plus an image-independent 2-D Gaussian window centred on each patch (sigma = 5 patches), and it removes the last block's FFN and its skip connection ("Reduced architecture"), so the last block outputs SA~(LN(Z^(L-1))). Motivation: ViT positional information is injected only at the input and the final block is specialised for the CLS embedding. No auxiliary models, no validation-set tuning.

## Goal-by-goal answers

### Goal: What mechanism does it use to suppress spatial noise in CLIP patch tokens, at which layer(s), and on which quantity (attention weights, value content, whole pathways)?
Last block only. Attention becomes softmax(k k^T / sqrt(d) + omega((i,j); sigma)) v, where omega is a discretised isotropic Gaussian added to the logits so that each patch attends to its own value vector and to its spatial neighbours [full text, Section 4.1, Eq. 13; Section 4.2, Eq. 15]. The FFN and the residual of the final block are removed, the residual because it "puts greater importance on the output of the previous encoder block" [full text, Section 4.3, Eq. 16]. Value vectors come unchanged from the penultimate state; only mixing weights and pathways change. Sigma is fixed to 5 by a heuristic on how many neighbours get their logit raised above a threshold [full text, Appendix A].

### Goal: What does it identify as the source of the noise in CLIP patch tokens?
(1) Weak locality: 1-D positional embeddings are added only at the first block, so patch position is not enforced deeper in the network; (2) the final encoder block "disrupts spatial information" because CLIP is trained to emphasise the CLS embedding while patch outputs are never optimised [full text, Section 3.2].

### Goal: What limitation does it report on extracting segmentation-relevant information from CLIP?
In the Limitations paragraph the authors report that attempts to extract segmentation-useful information from the CLS token "were unsuccessful, having almost no effect on performance", attributing this to the divergence between CLIP's pretraining and dense prediction, and leave the use of the global token open [full text, Section 6, Limitations]. They also note that re-injecting positional embeddings at all layers is not possible training-free because it shifts each layer's input distribution [full text, Section 3.2].
