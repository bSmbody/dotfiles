# OV-Stitcher: A Global Context-Aware Framework for Training-Free Open-Vocabulary Semantic Segmentation

## What this paper does
OV-Stitcher (on top of CorrCLIP) stitches the last-block Q/K/V of all sliding-window crops into one full-image token set and runs a single global attention, so features stay consistent across crop borders. Because stronger coherence spreads a wrong label over larger regions, it augments text prompts with ~15 LLM-generated class-biased visual descriptions per class. Main results use CorrCLIP's SAM2-mask majority-vote post-processing. Reports 48.7→50.7 average mIoU on eight benchmarks and better robustness to input resolution.

## Goal-by-goal answers

### Goal: (axis: small objects and stuff classes) What mechanism does it use that affects small or thin objects, and at what resolution/scale is the class decision made?
OV-Stitcher (built on CorrCLIP) computes Q, K, V of the final CLIP block independently per crop, then stitches them into a single full-image token set and runs one global attention softmax(QK^T/τ)V, with VFM (DINO) affinity transferred into CLIP value space [full text, Sec 3.3, Eq 6-8]. Crops 336 (224 for Cityscapes), stride 112, shorter side 448 (560 City) [Sec 4.1]. Decisions are per patch; the main table uses CorrCLIP's post-processing that assigns each SAM2 mask "the most frequent raw logit prediction within that mask" [Table 1 caption, Sec 4.2] — a majority vote that cannot keep a minority class inside a mask. Smaller VFM patch size (ViT-S/8, B/8) consistently beats larger patch sizes [App. D].

### Goal: (axis: small objects and stuff classes) What mechanism does it use for stuff classes / large regions / many-class benchmarks, and what global context or class-competition handling does it apply?
Global stitched attention gives every token the full-image receptive field. Because "enhanced consistency propagates the error over a larger region, amplifying the misclassification", it adds Class-Biased Prompts: ~15 LLM-generated, image-independent visual descriptions per class (e.g. "a large asphalt road without pedestrians") averaged with ImageNet templates [Sec 3.4, App. E].

### Goal: (axis: small objects and stuff classes) What does it report as its limitation or failure on small objects or stuff classes, and which knobs are set per dataset?
Ablation (Table 2): StitchAttn+CBP vs baseline: Stuff 30.7→31.8 (+1.1), ADE 23.7→24.7 (+1.0), City 44.6→48.1 (+3.5), V21 72.2→75.7. Fig 9: "higher feature coherence can cause larger regions to be assigned to the wrong class"; CBP is the remedy [App. E]. Crop size/stride differ per dataset [Sec 4.1]. No explicit small-object analysis.
