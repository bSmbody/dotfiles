# Perceptual Anchoring: Prototype-Guided Text Calibration for Training-free Open-Vocabulary Semantic Segmentation

## What this paper does
PTC is a plug-in that pulls each class's text embedding toward an image-specific visual prototype. Candidate tokens are those initially predicted as the class; the highest-margin ones (top-1 minus top-2 score), with a count set by a minimum K_min and a proportional ratio, are margin-weighted into a prototype. Classes with too little evidence are skipped, and calibration strength grows with the evidence count up to a cap. Improves SCLIP, ClearCLIP, NACLIP, ResCLIP, ProxyCLIP and CorrCLIP by 0.8-2.2 average mIoU on eight benchmarks.

## Goal-by-goal answers

### Goal: (axis: small objects and stuff classes) What mechanism does it use that affects small or thin objects, and at what resolution/scale is the class decision made?
PTC is a plug-in that recalibrates each class text embedding toward an image-specific visual prototype [full text, Sec 3.2]. Candidate tokens for class c are those whose initial argmax is c (Ω_c, N_c=|Ω_c|, Eq 4); the K_c = min(N_c, max(K_min, ⌊ρN_c⌋)) highest-margin tokens (margin = top-1 minus top-2 score) form a margin-weighted prototype (Eq 5-8). Classes with N_c < K_min are excluded from calibration; calibration strength μ_c grows logarithmically with evidence count up to μ (Eq 9-11). Evidence is gathered from 224×224 crops (stride 112), final inference uses 336 windows [Sec 4.1]. A class absorbed by its surroundings in the initial argmax has N_c≈0 and is therefore never calibrated.

### Goal: (axis: small objects and stuff classes) What mechanism does it use for stuff classes / large regions / many-class benchmarks, and what global context or class-competition handling does it apply?
One calibrated text embedding per class per image; the calibration is global for the class (the same t_c^cal at every location) [Eq 11]. The hybrid evidence count gives large classes (stuff) more evidence tokens [Sec 3.2.2].

### Goal: (axis: small objects and stuff classes) What does it report as its limitation or failure on small objects or stuff classes, and which knobs are set per dataset?
K_min and μ are dataset-specific: VOC21 best at K_min=100, μ=0.3; Cityscapes at K_min=2, μ=0.35 because "an excessively large K_min prevents categories represented by small or elongated regions from satisfying the minimum evidence requirement"; ADE at K_min=10, μ=0.15 [Sec 4.3.2]. Fixed-count evidence yields limited gains on Cityscapes, ADE20K and COCO-Stuff where "object scales vary more substantially" [Sec 4.3.1]. Final gains over ProxyCLIP: VOC21 +5.9, City +1.9, ADE +0.7, Stuff +1.0 [Table 3]. Qualitatively it recovers some small objects missed by ProxyCLIP [Sec 4.2].
