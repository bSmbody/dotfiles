# Detect Anything in Real Time: From Single-Prompt Segmentation to Multi-Class Detection (DART)

## What this paper does
DART (2026-03) is a training-free acceleration of SAM 3 for multi-class detection. It exploits that SAM 3's backbone is prompt-independent: the backbone runs once per image and its FPN features are shared across all class prompts, the encoder-decoder is batched across classes along the batch axis, the mask head is removed for detection-only use, and both stages are exported as TensorRT FP16 engines. It reaches 55.8 AP on COCO val2017 at 15.8 FPS (4 classes, 1008 px) on one RTX 4080, and analyses the cost structure and the resolution-accuracy trade-off.

## Goal-by-goal answers

### Goal: (reviewer R1, C3) How is SAM 3's cost split between the shared backbone and the per-prompt fusion encoder and decoder, and how does the per-prompt part scale with the number of classes?
The backbone (ViT-H-class, 439M parameters, 32 blocks, windowed/global attention, 2D RoPE) is 78% of a single-class pass (87 of 112 ms on an RTX 4080) [full text, Sec 3.1]. Backbone sharing makes its cost O(1) in the class count, and batched multi-class decoding is valid because "text conditioning enters exclusively through cross-attention, which operates independently across the batch dimension" [Sec 3.2]. With TensorRT at 1008 px the backbone is a constant 53.2 ms, while the encoder-decoder grows roughly linearly: 7.9 ms (1 class), 11.4 (2), 19.2 (4), 34.7 (8) [Sec 4.3, Table 2]. So beyond about 12-14 classes the per-prompt fusion/decoder cost exceeds the backbone; "view passes" alone undercount cost when many prompts are tested per view.

### Goal: (reviewer R1, C3) What does it report about input resolution and small objects for SAM 3?
Reducing input from 1008 to 644 px lowers COCO AP from 55.8 to 39.1, "driven almost entirely by small-object recall (APS: 40.3 -> 12.4)", while APL only falls 70.7 -> 65.4 [Sec 4.4, Table 3]. Resolution is the dominant quality lever for SAM 3's small objects. It does not test tiling, crops or zoom.
