# plan — Training-free open-vocabulary semantic segmentation from frozen foundation models

**Goal**: ONE focused, sharp, well-grounded methodological intuition for this problem that a simulated CVPR 2027 panel rates at ≥ 5/10 acceptance odds, executable within the Constraints in problem.md.

**Active direction**: Axis `small objects and stuff classes in training-free open-vocabulary segmentation`, Gap 1 — fine detail is recovered only by redistributing the class evidence of a single CLIP pass on the patch grid; no stage re-queries the VLM where, and at the scale at which, evidence is ambiguous, so structures that never win a token are unrecoverable.
**Status**: `survived`

## Candidate axes
- A1 `spatially noisy CLIP patch tokens for dense prediction` — done: 1 gap (dense global component written into normal tokens' content in intermediate layers; all fixes act on last-block mixing or sparse outliers)
- A2 `small objects and stuff classes in training-free open-vocabulary segmentation` — done: 2 gaps (no uncertainty-triggered evidence re-acquisition; context extent is a global knob, not a per-location decision)

## History
- `forming` at turn 0: run created; spawning gap_finders on the first two axes in parallel.
- `drilling` at turn 1: both axes mapped (3 gaps). Chose A2/Gap 1 (evidence re-acquisition): it matches the problem's concrete failure (poles/signs absorbed), has a crisp new metric (recovery rate of small segments that win no patch), and is a plug-in that composes with every existing method, which gives broad tables at low compute. A1/Gap (intermediate-layer global component) kept as fallback; A2/Gap 2 (per-location context extent) as second fallback. Spawning innovator → C1.
- `under_review` at turn 2: innovator wrote C1 (new) — Distilled Sensing [1001.5311] for sparse weak signals: after the first CLIP pass, discard only (location, class) hypotheses at that class's own background level, then re-encode surviving locations at progressively finer zoom against only their surviving classes; a thin structure only has to survive elimination, not win a patch. Spawning reviewer on C1.
- `drilling` at turn 3: reviewer → C1 `revise(focus=mapping)`. Objection: in DS the cost unit is per component, but here a re-encoded crop measures all classes at a location, and with 18–149 competitors surviving each stage w.p. ½ almost no location retires, so C1 collapses into uniform progressive zoom + class pruning (close to MagNet [2104.03778], CaR [2312.07661], ActiveSAM [2606.16996]); "finest look wins" ignores zoom's context loss. Field-level risk: ActiveSAM with frozen SAM 3 is training-free at 66.0 avg mIoU vs 34–51 on Cityscapes for the CLIP pipelines C1 plugs into. Revise cycle 1: spawning innovator → C2 BUILD_ON C1; if the revision cannot justify itself in the SAM 3 era, this lane is a reject candidate.
- `under_review` at turn 4: innovator wrote C2 (improves C1) — each crop is a pooled test (adaptive group testing [2106.12193], dilution as in pooled PCR [2008.06642]): ask the frozen model's crop-level recognition (SAM 3 presence head or CLIP crop score) whether a concept it recognises is missing from the label map; "no" retires the crop and all its locations, "yes" splits/zooms until confirmed or rejected; fusion lets the coarsest valid view decide, a zoom may only add its parent's flagged concept on segments it fully contains (SNIP [1711.08189], [2610.09313]). Main instantiation on SAM 3 pipelines (ActiveSAM, SegEarth-OV3), CLIP second. Spawning reviewer on C2.
- `drilling` at turn 5: reviewer → C2 `revise(focus=mapping)` (revise cycle 2). Objection: the pooled test is not an OR over defectives — one correctly labelled pole in a crop makes the class "explained" and retires every missed pole, so the root test is negative exactly where the gap lives; SAM 3 presence admits ~94% of small components at image level and adds no localisation. Fusion rule ("coarsest valid view decides") judged well grounded. Missing: ZoomEye [2411.16044] positioning; baselines (aspect-preserving uniform tiling, tiling + same fusion, presence-ranked search without the residual gate). Clear fix offered (residual presence test with labelled segments masked out, CaR-style [2312.07661]). Last revise cycle (3): spawning innovator → C3 BUILD_ON C2.
- `under_review` at turn 6: innovator wrote C3 (improves C2) — residual pooled test: before asking the frozen model "is this concept in this crop?", drop the ViT tokens of the segments the current map already gives that concept (Hwang's group testing removes a found defective before re-testing), so "yes" means ≥1 unexplained instance; only "yes" crops split/zoom; coarsest-valid-view fusion, so C3 only adds wholly missed segments. Positioned vs ZoomEye, ActiveSAM, AdaCount, ViCrop-Det, AutoFocus; three matched baselines named. Spawning reviewer on C3 (final cycle).
- `survived` at turn 7: reviewer → C3 `survive` (mapping now a real OR over defectives). Carried forward: go/no-go pilot (AUROC of residual presence vs "crop holds an unlabelled instance", against unmasked presence, <1 GPU-day); state which concepts are tested per crop and frame the claim as accuracy at matched compute, not k·log2(n/k) efficiency; re-detection guard/removal rule that keeps missed instances touching found ones; cite Adversarial Erasing [1703.08448] and ROI-Gated SAHI [2608.23923]; lead with recovery rate and small-segment recall. Spawning report_writer on C3.
- `survived` at turn 8: report_writer wrote report.json (C3, residual pooled tests gating zoom on frozen SAM 3 over ActiveSAM; 29 cited ids, check_run passes). Spawning the simulated CVPR panel on report.json.
- panel at turn 9: R1/R2/R3 = 3/3/3 (p_core 0.55/0.40/0.40). AC: odds 1.8/10, p_core 0.45, risk-adjusted 1.0/10. Decisive: no committed gain on a standard metric; residual trigger only compared to unmasked presence (missing free alternatives: score map outside labelled area, sub-threshold SAM 3 detections, decode-and-diff in the zoom); only Cityscapes has native resolution for zoom; dense misses make most views positive; 2-token write rule cannot write distant thin poles. AC ceiling with all 8 fixes ≈ 3.8–4.0/10, so this lineage cannot reach the 5/10 goal by revision alone.
