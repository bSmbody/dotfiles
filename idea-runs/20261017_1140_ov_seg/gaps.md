
## Axis: small objects and stuff classes in training-free open-vocabulary segmentation

### What has been done
- **Widening context across sliding windows (motivated mainly by stuff and large regions split across crops).** GLA-CLIP [2603.23030] lets each window's DINO queries attend to keys/values from all windows, replaces queries by proxy anchors (iterated means of tokens with cosine > 0.6), and rescales attention per query by w_i = 1 + λ2/|P_i|, using the count of similar tokens as an object-size proxy, plus a mask threshold u that depends only on the number of windows. OV-Stitcher [2604.08110] stitches all crops' last-block Q/K/V into one global attention and adds LLM "class-biased" prompts because stronger coherence spreads wrong labels over larger regions. Trident [2411.09219] splices crop features and aggregates them with a SAM-encoder affinity over the whole image. LPOSS [2503.19777] runs label propagation over the patches of all windows jointly. SCI-CLIP [2608.05627] blends cross-window key-value retrieval with a fixed weight λ_kv.
- **CLIP-internal global context.** GCLIP [2502.06818] averages the attention of the blocks where global tokens emerge into every patch's last-block attention, with one fixed weight. SegEarth-OV [2410.01768] subtracts 0.3 × [CLS] from all patches, because [CLS] encodes the image's dominant class and contaminates other patches.
- **Recovering small and thin structures after patch-level prediction.** The surveyed methods do this in several ways:
  - Feature upsampling that outputs a kernel- or attention-weighted average of neighbouring low-resolution tokens: SimFeatUp's JBU in [2410.01768] and PixelUp [2608.02792, Eq 1].
  - Pixel-level label propagation initialised from upsampled patch predictions: LPOSS+ [2503.19777].
  - A confidence-weighted, text-gated Laplacian solved on a grid whose size is set per dataset: PEARL [2603.21528].
  - A random walk that diffuses CLIP label probabilities over a fixed global/local affinity mix β: NERVE [2511.08248].
  - SAM decoder refinement prompted by connected components of the coarse argmax: Trident [2411.09219].
  - Majority vote of raw logits inside SAM2 masks: OV-Stitcher/CorrCLIP [2604.08110].
- **Regions first, then labels.** LaVG [2408.04961] finds masks with iterative Normalized cut on DINO features, then labels each mask with its averaged SCLIP feature. SCI-CLIP [2608.05627] allows token interaction only within mask-generator regions (merged by DBSCAN), adds a Gaussian locality prior, and corrects labels with a segment-level reference memory.
- **Class-side handling of many-class and stuff confusion.**
  - FreeCP [2508.00557] drops classes whose CAM changes too much under affinity refinement, using dataset-specific IoU thresholds. It then re-encodes a 112×112 crop with CLIP to resolve groups of overlapping, mutually ambiguous classes.
  - PTC [2608.03991] calibrates each class's text embedding toward a prototype built from the highest-margin tokens among those whose argmax is that class. Classes with fewer than K_min tokens are skipped.
  - TPA [2608.08290] builds one DINO prototype per class from anchors that are argmax-consistent and above 2/C confidence, pooled across unlabeled images.
  - OV-Stitcher [2604.08110] uses static, image-independent LLM prompts.
- **Quantitative signals in the read digests.**
  - *Patch resolution limits small structures:* an oracle that downsamples ground truth to patch resolution caps mIoU at 73.6 on Cityscapes and 80.6 on ADE20K [2503.19777]. Pixel-level LP adds only +0.8 mIoU [2503.19777].
  - *Refinement and upsampling barely help stuff-heavy sets:* Trident's SAM refinement adds +0.7 on COCO-Stuff and +1.0 on ADE20K, against +2.6 on VOC21 [2411.09219]. Raising its input resolution from 448 to 576 leaves Stuff/ADE flat (27.6→27.5 and 20.6→20.9) [2411.09219]. PixelUp gains +3.29 on Cityscapes but −0.39 on ADE20K [2608.02792].
  - *Many-class failure is class competition, not masks:* restricting the vocabulary to ground-truth classes lifts ADE20K 15.6→37.5 and COCO-Stuff 22.1→42.5 [2508.00557], while ground-truth masks lift COCO-Stuff only 23.2→27.6 [2408.04961].
  - *Scale settings are tuned per dataset:* PEARL's best grid is 224 for Cityscapes, about 80 for VOC and 64 for ADE20K [2603.21528]. PTC's best K_min is 100 for VOC, 2 for Cityscapes and 10 for ADE20K [2608.03991].

### Open gaps on this axis
- **Gap:** In training-free OVSS on scenes with thin or sub-patch structures (Cityscapes poles, signs and lights; small ADE20K objects), prior methods recover fine detail only by redistributing the class evidence of a single CLIP pass per fixed-size window on the 14–16 px patch grid (convex-combination upsampling, label propagation or Laplacian solves anchored to that prediction, SAM prompts or mask majority votes seeded by its argmax), but this assumes every class at a location already wins some patch-level evidence, so a structure whose evidence never wins a token cannot be recovered, because no stage queries the vision-language model again where, and at the scale at which, the evidence is ambiguous.
- **Near-miss methods and coverage:**
  - [2503.19777] LPOSS+: pixel-level LP whose objective has a fidelity term to the initial prediction and "refines predictions for all nodes which are already labeled". It gains +0.8 mIoU against +1.8 Boundary IoU, i.e. it mostly sharpens the boundaries of classes that already won patches.
  - [2603.21528] PEARL: its data trust ρ_i = (max p)²(1+u) gives the least trust to low-peak (mixed) nodes, and its grid size is a per-dataset knob that the authors themselves flag ("adaptive grids").
  - [2608.02792] PixelUp: each upsampled feature is a softmax-weighted average of neighbouring low-resolution values (Eq 1).
  - [2411.09219] Trident: SAM is prompted only from connected components of each class's argmax map, so a class absent from the argmax gets no prompt.
  - [2608.03991] PTC: evidence comes only from argmax-candidate tokens, and classes with N_c < K_min are skipped. Cityscapes needs K_min = 2 because small or elongated classes fail the evidence requirement.
  - [2508.00557] FreeCP: the only read method that re-encodes a crop with CLIP. It does so only for ambiguity groups among classes that survived an image-level redundancy test, which the paper says misidentifies small classes, and it assigns one label to the whole crop.
  - [2604.08110] OV-Stitcher's SAM2-mask majority vote removes minority labels inside a mask.
  - Coverage: these are several mechanistically different near misses that share the same deficiency. The queries "training-free open-vocabulary segmentation small objects", "…high resolution", "zoom-in open-vocabulary segmentation", "open-vocabulary segmentation adaptive resolution crops", "training-free segmentation CLIP multi-scale inference small", "feature upsampling open-vocabulary segmentation" and "open-vocabulary semantic segmentation uncertainty refinement training-free" (including a `--since 2025-01-01` recency pass) returned no training-free method that re-encodes regions selectively, triggered by local uncertainty.
- **Methodological deficiency:** This is a missing mechanism (evidence re-acquisition) combined with a representation limitation. The class-evidence field is fixed after a single CLIP pass at one window scale, and every later operator interpolates or smooths that field conditioned on its argmax: LPOSS's fidelity term [2503.19777], PixelUp's Eq 1 [2608.02792], PEARL's confidence-weighted data term [2603.21528] and Trident's argmax-derived prompts [2411.09219]. These operators can only move the boundaries of classes that already won patches. The one re-encoding path, in FreeCP [2508.00557], is gated by whether a class survives image-wide, not by local uncertainty. Raising the input resolution uniformly is no substitute, because it shrinks each window's context and hurts recognition: ProxyCLIP VOC20 drops 79.7→73.4 from 336 to 576 px [2411.09219], and LaVG notes that whole-image recognition fixes part-whole ambiguity but lowers small-resolution accuracy [2408.04961].
- **Why it matters:** This is exactly the failure in the problem statement, where poles and signs are absorbed into road or building. On Cityscapes, patch quantization alone costs about 26 mIoU in the oracle [2503.19777]. Closing the gap would show whether frozen CLIP can recognise small structures when queried at the right place and scale. That would separate a sampling bottleneck from a recognition bottleneck. It would also give a component that composes with the existing context and refinement methods instead of replacing them.
- **Evidence route:**
  - On Cityscapes (pole, traffic sign, traffic light, person, rider) and ADE20K, report per-class IoU and recall binned by ground-truth segment area relative to one patch.
  - Report a "recovery rate": the fraction of small ground-truth segments whose class wins no patch in the coarse prediction but is correct in the final map. Redistribution-only refiners (LPOSS+, PEARL, PixelUp, Trident refinement) can raise this only incidentally.
  - Compare at matched compute against uniform input upscaling and against FreeCP's crop re-encoding, and confirm that stuff-class IoU does not regress.
- **Gap:** To resolve part-whole ambiguity of textureless stuff (sky vs cloud, road vs sidewalk, stuff split across crops), prior methods inject image-level context with one image-wide or dataset-wide setting (a global/local mix β, a fixed attention-fusion weight, a uniform [CLS] subtraction, a fixed cross-window blend or Gaussian locality weight, a per-dataset refinement grid, unrestricted stitched attention) or with a per-query size proxy (the number of tokens with feature similarity above a threshold), but this assumes the right context extent is a property of the dataset or of similarity counts rather than of whether the local evidence is already decisive, so the setting that lets stuff aggregate long-range evidence also lets the dominant class's context overwrite adjacent small objects, and the reverse.
- **Near-miss methods and coverage:**
  - [2603.23030] GLA-CLIP is the closest. It scales attention per query by w_i = 1 + λ2/|P_i|, and |P_i| does correlate with class size on Cityscapes (Fig 5). Yet "λ2 has minimal impact on performance", while the effective masking strength u depends only on the window count. The shared setting reaches 44.0 against 44.3 with dataset-specific tuning.
  - [2608.05627] SCI-CLIP: its Gaussian locality prior improves C60 and VOC20 but degrades Cityscapes and VOC21, "overly restrictive when long-range evidence is needed". Its cross-window blend λ_kv is fixed, and its late-fusion weights are set per dataset.
  - [2603.21528] PEARL: the best grid is 224 for Cityscapes ("prevents oversmoothing of thin structures") but 64 for ADE20K.
  - [2511.08248] NERVE: one β mixes global and local affinity for the whole image, and attention heads are weighted by entropy averaged over all tokens.
  - [2410.01768] SegEarth-OV: the [CLS] token, which encodes the largest region, contaminates other patches, and it is removed with a uniform λ = 0.3.
  - [2502.06818] GCLIP: the same fused global-token attention is applied to every patch.
  - [2604.08110] OV-Stitcher: global coherence "amplif[ies] the misclassification" over larger regions, and the fix is on the text side.
  - [2408.04961] LaVG states the trade-off outright: whole-image recognition fixes stuff part-whole ambiguity but lowers small-resolution accuracy.
  - [2508.00557] FreeCP and [2608.03991] PTC encode the same trade-off as dataset-level thresholds. FreeCP uses a low threshold on ADE20K and COCO-Stuff "to retain small or rare regions". PTC sets K_min to 100 on VOC, 2 on Cityscapes and 10 on ADE20K.
- **Methodological deficiency:** This is a wrong inductive bias combined with an algorithmic limitation: context extent is a global hyperparameter, or a function of how many tokens look alike, rather than a per-location decision driven by how decisive the local class evidence already is. Three findings show it:
  - The global-local trade-off reappears as opposite optima per dataset: PEARL's grid is 224 on Cityscapes versus 64 on ADE20K [2603.21528], and PTC's K_min is 2 on Cityscapes versus 100 on VOC [2608.03991].
  - Locality priors help some benchmarks and hurt others [2608.05627].
  - The one per-query, size-adaptive term in GLA-CLIP barely changes results [2603.23030].
- **Why it matters:** Stuff-heavy many-class benchmarks (ADE20K, COCO-Stuff) and thin-structure benchmarks (Cityscapes) pull these knobs in opposite directions, so the best current numbers depend on per-dataset settings. That contradicts the open-vocabulary premise of an arbitrary image and class list with no labels to tune on. A per-location rule for context extent would let one configuration serve both regimes. It would also test whether the stuff-versus-small trade-off is intrinsic to frozen features or an artifact of global mixing.
- **Evidence route:**
  - Sweep the global knob of strong baselines (NERVE's β, PEARL's grid size, SCI-CLIP's Gaussian weight, GLA-CLIP's λ1). This traces a Pareto frontier between small and thin-class IoU (Cityscapes pole, sign and light; small ADE20K classes) and stuff-class IoU (the COCO-Stuff and ADE20K stuff subsets).
  - A method that closes the gap should sit beyond this frontier with one setting shared across all eight benchmarks.
  - Its per-location context extent should track ground-truth segment size and the stuff/thing type.
