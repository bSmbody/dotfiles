# Learning by Cheating

## What this paper does
Chen et al. (CoRL 2019) split vision-based driving into two imitation stages. A privileged agent sees the ground-truth bird's-eye map and traffic state and imitates expert trajectories. A vision-only sensorimotor agent then imitates the privileged agent, first offline and then on-policy with DAgger, querying the privileged agent as an oracle at every state the student reaches, and across all command branches at once. The result reached 100% on the original CARLA benchmark and +18 points on NoCrash dense traffic.

## Goal-by-goal answers
### Goal: Can a privileged simulator agent serve as a free on-policy oracle for a non-privileged student, and how is it used?
Yes: the privileged agent "can be queried from any state of the environment, not only states that were visited in the original trajectories", enabling "automatic DAgger-like training in which supervision from the privileged agent is gathered adaptively via online rollouts of the sensorimotor agent" [full text, Sec 1]. The student is trained on-policy "using the privileged agent as an oracle that provides adaptive on-demand supervision in any state reached by the sensorimotor student" [Sec 2, Sec 3]. Ablation: on-policy trajectories and white-box (all-branch) supervision each substantially improve results and together reach 100% [Sec 4, Table 1]. Privileged information is used only in training; the deployed student uses only the camera [Sec 1].
