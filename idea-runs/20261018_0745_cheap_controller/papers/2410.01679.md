# VinePPO: Refining Credit Assignment in RL Training of LLMs

## What this paper does
VinePPO replaces PPO's learned value network with Monte Carlo value estimates for LLM reasoning: because a language environment can be reset to any intermediate state by re-feeding the partial context, it samples K auxiliary continuations from each reasoning step, averages their returns to estimate the step's value, and uses value differences between consecutive steps as per-step advantages. On MATH and GSM8K it beats PPO, GRPO, RLOO and RestEM, reaching PPO's peak in fewer steps and less wall-clock time, and the authors show PPO's value network barely beats chance at ranking candidate steps.

## Goal-by-goal answers
### Goal: What is the core credit-assignment mechanism, and what property of the environment does it rely on?
"Language-based environments allow us to reset directly to any intermediate state simply by re-feeding the partial context, enabling efficient MC rollouts" [full text, Sec 1]. For each state s_t it samples K continuations and uses their mean return as V(s_t) [Sec 4, Eq 5]; advantage is r + V(s_{t+1}) - V(s_t) [Eq 6], an unbiased policy-gradient estimate for any K>=1 [Sec 4]. Auxiliary rollouts are used only for value estimation [Sec 4]. Most steps carry near-zero advantage; only a few critical steps change the success probability [Sec 1, Fig 1].
### Goal: How much sampling does it need, and what does it cost?
Small K already works (K=1, 3, 9 ablated; higher K better and more compute-efficient) [Sec 6.4]. Each iteration is 2-5x slower than PPO, but it reaches PPO's peak with 1.5-3.0x less wall-clock time [Sec 6.2]. States are grouped by reasoning step to trade granularity for compute [Sec 4].
### Goal: Why do learned critics fail where MC estimates succeed?
PPO's value network is highly biased, misclassifying bad states as good, and is near chance at identifying the best of five candidate next steps, while MC estimates identify it with high accuracy [Sec 7]. Critic error grows later in the trajectory, where states are less like training data [Sec 7].
