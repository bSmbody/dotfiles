# Causal Agent Replay: Counterfactual Attribution for LLM-Agent Failures

## What this paper does
CAR attributes an LLM agent's failure to a step by intervention. It models a run as a structural causal model, applies a do() operation at step k (resample, force an action, replace an observation, edit context, swap the policy from k on), and runs the agent forward K times to estimate the shift in the outcome distribution with confidence intervals. A contrastive single-step estimator with a "point-of-commitment" rule localizes the causal step, and a Monte Carlo Shapley estimator splits credit between interacting steps. Validation is on synthetic SCMs with planted ground truth; no agent is trained from the attributions.

## Goal-by-goal answers
### Goal: How does CAR intervene on a step and re-execute — does it share or fix noise between the factual and intervened runs?
It holds steps [0,k) at their factual actions, applies the intervention at k and "run[s] forward K times", so an intervention "yields a distribution over outcomes, not a single path" [full text, Sec 2, Sec 4]. Faithful replay of the prefix uses record-replay; a fixed-seed local model replays exactly [Sec 3]. Forward runs use fresh draws: there is no coupling across branches, and the authors state that "isolating a step's direct effect calls for common random numbers across branches, which is hard across divergent LLM contexts and is left as a refinement" [Sec 7].
### Goal: What confound does stochastic run-forward create for localizing the culpable step, and how is it resolved?
"Resampling step k also re-rolls every downstream stochastic step", so an early irrelevant step shows an effect because it re-rolls the pivotal step downstream: "magnitude alone cannot localize the cause" [Sec 4]. Their rule: the causal locus is "the latest step whose effect's confidence interval still excludes zero — the last point at which re-deciding still rescues the run" [Sec 4]. Single-step effects also over-count when two steps fail only jointly, which Shapley fixes [Sec 4, Sec 5].
### Goal: Does it use the attribution to train or distil an agent?
No. It is a debugging/attribution tool with an interactive report; demonstrations use mocked reproducible tools and synthetic SCMs [Sec 5, Sec 7].
