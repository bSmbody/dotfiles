# Variational Linear Attention: Stable Associative Memory for Long-Context Transformers

## What this paper does
Reframes the memory update as online regularised least squares with an adaptive penalty matrix A_t maintained by Sherman-Morrison rank-1 updates (an RLS-style rule), and normalises key and write direction so the recurrence Jacobian has spectral norm exactly 1. Tests on copy and MQAR with small models (d_h = 32), comparing to linear attention, DeltaNet and softmax.

## Goal-by-goal answers
### Goal: What memory update rule does it use and what determines the write/erase strength per token?
Eq. 9-10 [full text, Section 3.3]: z_t = A_{t-1} u_t, A_t = A_{t-1} - z_t z_t^T / delta_t; e_t = v_t - S_{t-1} k^_t, alpha^_t = A_t k^_t / ||A_t k^_t||, S_t = S_{t-1} + e_t alpha^_t^T. The d_h x d_h matrix A_t "routes new writes orthogonally" to earlier key directions [Section 6.4].

### Goal: What does the interference-aware update cost, and is it parallelisable?
Section 3.4: the S_t recurrence admits a parallel scan but "The A_t loop has a data-dependent denominator delta_t that prevents direct parallelism"; all T steps are fused into a sequential Triton kernel. Section 3.5 / Section 8: same O(T d_h^2) asymptotics but ~5x constant factor ("roughly 3x the wall-clock cost of standard linear attention"); crosses below softmax latency only at ~43K tokens (abstract).

### Goal: What does it report as its limitation on recall / memory capacity at long context?
Section 6.4: perfect MQAR up to n_pairs < d_h = 32 is "mathematically expected" (Proposition 3), "not that VLA solves arbitrarily large recall". Section 6.6 overload: "All models degrade past n = d_h"; VLA degrades more gradually "because A_t preferentially overwrites recently written directions"; Table 4: MQAR accuracy 0.990 at n=16 vs 0.044 at n=48 (1.5x capacity). DeltaNet's scalar gate "decays older associations before the query section arrives" [Section 6.5].
