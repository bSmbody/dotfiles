# TriAxialKV: Toward Extreme Low-Precision KV-Cache Quantization for Agentic Inference Tasks

## What this paper does
Mixed-precision (INT2/INT4) KV quantization for agentic workloads, implemented in SGLang. Each prefill token gets a tag from temporal (current / turn−1 / turn−2 / older) × modal (text / image) × semantic role (inst, user, assistant, reasoning in <think>, tool_call, obs, delim), all read from the chat template. Per-tag attention-output-MSE sensitivity D_k(b) is calibrated offline; a greedy allocator picks INT2 or INT4 per tag under an average-bit budget. Fused Triton flash-decoding kernels handle bit-homogeneous splits from a shared INT2/INT4 memory pool.

## Goal-by-goal answers
### Goal: What is allocated, and how are generated (decode) tokens treated?
Unit = tag class (role/recency/modality), b_k ∈ {2,4}, minimizing first-order attention-output MSE L̂(b) = Σ_k D_k(b_k) [full text, Sec 3.1.1-3.1.2, Eqs 1-2; App A greedy]. Calibration hooks fire on prefill only [Sec 3.1.4]. Every token generated during decode goes to the INT4 pool [Sec 3.2.3 "Decode", Fig 4]; INT2 keys are per-channel (G=32) with leftover residual tokens on the INT4 per-token path instead of a BF16 residual buffer [Sec 3.2.1]. So decode-time CoT is not mixed-precision: it is uniform INT4.
### Goal: What accuracy and baselines?
Baselines SGLang BF16, SGLang FP4 KV, KIVI. BFCL Memory (Qwen3-14B/32B/235B, Falcon3-10B): mixed within 1.1 pt of BF16; SGLang FP4 unstable (−7.11 on Qwen3-14B, +4.22 on Falcon) [Sec 4.2, Table 2]. OSWorld (Qwen3-VL-8B/32B-Thinking, InternVL3.5-38B): within 1.8 pt [Table 3]. Axis ablation: removing semantic or temporal axis hurts [Table 4]. No math/long-CoT benchmarks.
### Goal: Serving efficiency?
OSWorld replay (avg prefill 11K, decode 300): 1.26× (Qwen3-VL-8B, B200), 1.32× (32B, B200), 1.52× (32B, H100) BF16 throughput at max concurrency; 3.4–4.0× more in-flight requests; abstract claims 4.5× KV capacity [Sec 4.3, Fig 5]. Gains largest on lower-bandwidth H100.
