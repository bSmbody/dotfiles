# Error Certificates for KV-Cache Eviction via Randomized Design

## What this paper does
Argues that deterministic top-k eviction cannot know its own error on the current query (proved unidentifiable), and replaces the deterministic tail with Poisson sampling at known inclusion probabilities. With the probabilities stored, a Hájek-corrected attention output and a survey-sampling variance estimator give a per-step error certificate from the retained set alone, used to gate recomputation. Evaluated on long assistant conversations, LongBench and several model families.

## Goal-by-goal answers
### Goal: Can a practical KV eviction policy itself be randomized with independent per-entry keep probabilities, and how is that set up?
Yes. A certainty set (score top slice, four sinks, 32 recent tokens, pi_i = 1) is kept; the remaining tail gets independent Bernoulli retention with pi_i = clip(m * score_i / sum_j score_j, eps, 1), where m is the expected tail budget and eps = 1e-6 a floor [full text, Section 3.3, Eq 2]. The retained output is the Hájek estimator, implemented by adding log(1/pi_i) to the retained logit [Eq 3]. Validity rests only on the design being known (Assumption 1) and bounded weights (Assumption 2); a bad score only widens the certificate [Section 3.3, Theorem 2]. The paper uses the design for attention-output error certification, not to label or train an eviction score; it states "randomization buys attribution, not prediction" [Abstract, Section 6.4].
