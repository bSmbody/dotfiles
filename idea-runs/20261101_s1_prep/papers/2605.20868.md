# Runtime-Certified Bounded-Error Quantized Attention

## What this paper does
A tiered KV cache for runtime-certified quantized attention: INT8 keys and INT4 values on GPU, FP16 originals retained in CPU RAM for deterministic fallback. A two-term decomposition gives per-head, per-step bounds on attention-distribution distortion from key quantization and on value reconstruction error; these drive adaptive FP16 promotion of high-mass blocks and a four-rung fallback ladder that can recover exact dense attention. Evaluated on Llama-3.1-8B up to 128K on PG-19, NIAH and RULER.

## Goal-by-goal answers
### Goal: How are key and value errors bounded, and are they treated jointly?
Separately. Theorem 4.1: value error <= eta (max per-token reconstruction error), blockwise sum_b rho_b eta_b; Theorem 4.3: key error <= 2 V_max TV(a, a') [full text, Sections 4.1-4.3]. The paper says the value bound "is tight ... when all per-token compression errors are perfectly aligned", while in practice errors are near-random so actual error is much smaller [full text, Section 4.2]. No score-value coupling is modeled.
### Goal: How does the bound drive reading of full-precision originals?
Blocks are sorted by INT8-estimated mass and the top K* covering tau_cov = 0.995 are paged in as FP16 keys; values are promoted when rho_b eta_b exceeds v_tol; a ranking-consistency check triggers per-head all-FP16 recomputation; the last rung recomputes a whole layer in FP16 [full text, Sections 3.3-3.4]. So bound-driven fetching of originals from a CPU-resident FP16 copy already exists.
