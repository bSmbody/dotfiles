# SPECTRA: Pushing the KV Cache Beyond the 2-Bit Cliff via Spectral Transform Coding

## What this paper does
SPECTRA is a training-free transform codec. It factorizes each K/V projection with a G-weighted SVD (G is the activation second moment; the whitened weight is G^{1/2}W), caches an energy-ordered rank-r latent instead of K/V, and allocates per-group bit-widths by reverse water-filling, which gives zero bits (rank truncation) to low-variance tail groups. The paper's motivation is that importance is concentrated only in the decorrelated basis and that non-uniform allocation helps most below 2 bits. All quality results reconstruct K/V on the fly and then attend (Mode A, RoPE-exact). A latent-space attention mode (Mode B) is left as future work. It also includes a closed-form W_O "healing" step (App. C).

## Goal-by-goal answers
### Goal: Headline compression and quality numbers?
LongBench on Llama-3.1-8B: dense 53.24; at about 8x compression TurboQuant falls to 47.11 and RotateKV to 45.97; SPECTRA scores 54.00 at 7.7x, 51.89 at 8.84x and 48.8 at 11x. Near-lossless at 3.5x (53.56). Single-needle NIAH stays lossless to 12x (Section 4.2, Tables 1-2, App. G.2).
### Goal: Does it evaluate long chain-of-thought decoding?
No. Only Llama-3.1-8B, Qwen2.5-7B and Mistral with LongBench/NIAH (Section 4.1). No AIME, no generated-length analysis. Its cliff argument is about prefill/context caches.
### Goal: System implications?
Mode A reconstructs K/V per step, which adds compute. The memory and throughput claims rest on cache size (Section 3.3, App. E). There is no comparison against an FP8/FP4 serving baseline in the main text.
