# Fathom: Per-Query Read Depth for Sparse Decoding over Offloaded KV Caches

## What this paper does
Fathom targets top-k sparse decoding when the KV cache and its scan index live in host memory (agent sessions up to 1M tokens). It stores a 4-bit uniform symmetric K copy channel-major as bit planes (fp16 scale per 64-token block), so the first t planes are exactly a t-bit quantizer. Per query group, it reverse-water-fills read depth t_j over channels with importance g_j = sum_h (q_j^(h))^2 Var(k_j), then gathers contiguous plane runs over PCIe into HBM and scans to pick top-k rows, which are then fetched exactly. Compared against Loki, Double Sparsity, SparQ, thumbnails, landmarks.

## Goal-by-goal answers
### Goal: Does Fathom fetch residual bit planes from CPU for exact attention reading (seed 4 overlap)?
Partly. Bit planes live in host memory and the query chooses how many planes per channel to pull over PCIe [full text, Sec 3.2-3.6]. But the read planes are used only for the top-k ranking scan of keys; the selected k rows are then read in full precision ("row term" in Eq 1). Values are not bit-planed, and depth is decided per channel by query energy, not per block by attention concentration. 1.37x faster at 256k and 1.67x at 1M tokens in GPU time vs 136-bit scans [Sec 1 Contributions].

### Goal: Under what regime does it win, and what is not measured?
Wins only when the index is in a slower tier: "With the scan index resident in HBM the method is not faster", because the scan is arithmetic-bound there [Sec 8, Sec 9]. End-to-end task success is not measured; quality is attention-output error, RULER-style synthetic tasks, and step agreement on 40-60 coding-agent sessions; offload tables are batch 1 [Sec 8]. No long-CoT reasoning benchmarks.

### Goal: Any per-layer/per-head allocation finding relevant to static vs online allocation?
A per-layer greedy budget calibrated offline halves error on Qwen3 at mean 48 bits at 16k, but is worse on Qwen2.5-7B and Llama-3.1-8B (up to 1.7x and 2.1x) and a plan calibrated at 16k is worse at 32k than the flat budget [Sec 3.4] -- evidence that offline layer plans transfer poorly across context length. Basis rule: raw channels for QK-norm models (Qwen3), KLT basis otherwise [Sec 3.5].
