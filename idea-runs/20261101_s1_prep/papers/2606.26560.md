# Erase-then-Delta Attention: Decoupling Erase and Write Addresses in Delta-Rule Linear Attention

## What this paper does
Argues that in GDN/KDA/GDN-2 the active correction is anchored to the current write key, so stale content at another address can only be removed by passive decay. EDA inserts an independently addressed rank-one erase before the delta write: S_t = (I - beta_t k_t k_t^T)(I - gamma_t e_t e_t^T) D_t S_{t-1} + beta_t k_t v_t^T, with e_t a learned L2-normalised erase address. Pretrains dense 2.5B and MoE 25B-A2.8B models, midtrains at 32K, evaluates RULER 4K-128K and probes memory states.

## Goal-by-goal answers
### Goal: What memory update rule does it use and what determines the write/erase strength per token?
Eq. 8 [full text, Section 3.3]; the erase step is a gradient step on L^erase = 1/2||S^T e_t||^2 (Eq. 10-11). Per Figure 1, query, key, value, erase gate gamma, delta gate beta, decay alpha and erase address e are all projected from the input token (e via a rank-16 low-rank projection) [Section 3.3, Appendix A].

### Goal: What does it report as its limitation on recall / memory capacity at long context?
RULER on midtrained MoE checkpoints [Section 4.4, Table 3]: GDN / KDA / EDA reach 82.15 / 79.66 / 81.52 at 32K, 67.62 / 72.00 / 71.90 at 64K and 45.16 / 42.70 / 44.22 at 128K; EDA's gain is in the 4K-16K regime and it "remains close" to baselines beyond. Limitations [Section 6]: "Introducing the independent erase step reduces raw write-key recall, so the erase path should be understood as a conditional cleanup mechanism rather than a uniform improvement to memory fidelity"; a raw write-key recall probe shows KDA better than EDA [Section 4.5]. Probes "do not directly trace individual erase events to specific downstream prediction improvements".

### Goal: Does the rule decide what to retain using anything other than recency and the current token?
No. Erase address and strength are chosen at write time from the current token; the probe (Figure 2a) shows erase is used most when decay is weak (alpha >= 0.9: 69.1% of contraction share), i.e. it substitutes for decay, but whether erased content was later needed is not modelled, and erasure lowers recall of older writes.
