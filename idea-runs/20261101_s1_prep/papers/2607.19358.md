# LISA: Linear-Indexed Sparse Attention for Efficient Long-Context Reasoning

## What this paper does
Converts a frozen DeepSeek-distilled Qwen reasoning model into a plug-in attention replacement. A linear-attention branch provides long-range memory, and a Lightning-Indexer-style selector picks M tokens for a sparse softmax branch; a learned gate fuses the two. Stage 1 distills linear attention plus a sliding window from the frozen teacher's full attention. Stage 2 replaces the window with the indexer, trained by per-head KL to the teacher attention. It reports a 23.9% latency cut at 16K and a +4.2-point average gain over nine math and code reasoning benchmarks for LISA-1.5B.

## Goal-by-goal answers
### Goal: How is the indexer trained given the hard top-M selection, and does it get a signal on tokens it did not select (dense teacher, exploration, or neither)?
The top-M argmax blocks gradients, so the indexer is trained only by a KL loss. Each indexer head fits the renormalized sum of four teacher heads, and the softmax runs over all keys in the causal triangle, so this is a dense, full-support teacher [full text, Section 3.2 Stage 2 / Eq 2]. In addition, a "candidate-set dropout" takes the top ceil(1.25M) positions and uniformly subsamples M of them early in training, shrinking the pool toward M later. The authors state that this regularizes the selected set and "does not restore gradients through the hard top-M gate" [Section 3.2 Stage 2]. So it randomizes among near-top candidates for robustness. It does not sample far off-support with logged propensities, and the off-support signal comes from the dense teacher.
