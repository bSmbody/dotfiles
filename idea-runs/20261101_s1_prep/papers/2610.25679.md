# LOOP: Recovery-Aligned Iterative Layer Pruning via On-Policy Distillation

## What this paper does
LOOP prunes whole Transformer layers from Qwen3 models (1.7B, 4B-Instruct, 8B; Llama-3.1-8B in the appendix) one layer per "shot", running short on-policy distillation (reverse KL to a frozen copy of the original model, teacher conditioned on the ground-truth answer) after each removal. The layer to remove next is scored from the recovery run itself: Block Influence computed along the student's own on-policy trajectories, fused with the squared gradient of the OPD loss with respect to a per-layer gate. Evaluated on DAPO-Math held-out, MATH-500, AMC, AIME and SciKnowEval at 15-25% pruning ratios.

## Goal-by-goal answers
### Goal: Does LOOP interleave architecture selection with on-policy distillation, using on-policy trajectories as the selection signal, and how close is that to choosing hybrid full-attention layers?
Yes for the loop structure: each shot removes one layer, runs b_k OPD updates, and reuses those on-policy trajectories and gate gradients to rank the remaining layers for the next shot [full text, Section 4.2, Eqs 13-16]. The scores are aggregate per-layer statistics (BI over all tokens of student rollouts, Eq 4; squared OPD-loss gate gradient, Eq 9), fused by min-max normalization with lambda = 0.5 [Section 4.1, Eqs 11-12; Appendix C]. It is depth pruning (removing layers), not attention-to-linear allocation, and it does not localize failures to positions or test per-failure layer restoration. The target size K is set by hand (15/20/25%) [Section 5.1].

### Goal: How much of LOOP's gain comes from iterating (select, retrain, re-select) versus from the better on-policy importance score?
On Qwen3-4B-Instruct at 20% pruning, one-shot BI gives 23.58% mean accuracy; iterating alone gives 30.69%; adding recovery sensitivity in one-shot gives 26.74%; both give 32.68% [full text, Section 5.3, Table 4]. So iteration carries about 7 pp and the better score about 2 pp on top. The fusion weight matters: lambda in {0.8, 0.5, 0.2, 0} spans 36.4-45.1% mean at 15% pruning [Table 5]. Baselines (one-shot + SFT, KD, OPD) share the same total update budget [Section 5.1 Baselines].
