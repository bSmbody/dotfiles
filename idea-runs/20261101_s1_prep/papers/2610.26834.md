# Kronecker Delta Rule for Long Context Linear Attention

## What this paper does
Introduces KronLSTM, an xLSTM-family linear-attention model whose matrix memory is updated by the Kronecker Delta Rule: instead of correcting the d_v-dimensional residual S k_t - v_t, it corrects the scalar association strength v_t^T S k_t toward a target c_t along the single matrix direction v_t k_t^T, aiming at minimally invasive revision with less interference. Proves Markov-chain steady state and bounded memory norm; compares with (Gated) DeltaNet family on LM, retrieval, long-context and state tracking.

## Goal-by-goal answers
### Goal: What memory update rule does it use and what determines the write/erase strength per token?
Eq. 3 [full text, Section 2.1]: S_{t+1} = S_t - beta_t (v_t^T S_t k_t) v_t k_t^T + beta_t c_t v_t k_t^T, i.e. an erase term and a write term. "the direction v_t k_t^T of the correction is determined by the input pair alone without utilizing the memory content"; with c~_t = c_t / beta_t, beta_t sets erasure and c_t sets writing, "both quantities computed from the input as gates" (Section 2.2). In vectorised form it is the delta rule (I - beta_t a_t a_t^T) s_t + beta_t c_t a_t on a_t = k_t ⊗ v_t (Property ii), so it is still a one-step, current-pair update.

### Goal: Does the rule decide what to retain using anything other than recency and the current token?
No; retention strength is set by input gates at write time. Its interference reduction comes from restricting the update to one rank-one matrix direction, not from estimating interference with other stored pairs.
