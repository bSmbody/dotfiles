# The KV Cache Is the New Memory Wall

## What this paper does
A systematization-of-knowledge paper. It derives exact KV footprint and decode-step FLOP/byte accounting, arithmetic intensity as a function of context length and batch, crossover context lengths where KV traffic overtakes weight traffic, and a five-domain taxonomy (precision reduction, eviction, paging, prefix sharing, tiering). It builds a comparison matrix that strictly separates derived bounds from within-paper reported quality deltas, using Llama-3-70B at 128K on B200/H100 under four workloads (W1/W2 batch lever, W3 prefix sharing, W4 cross-session reuse).

## Goal-by-goal answers
### Goal: What does it say about where KV compression speeds up decode and how results should be compared?
The same 2-bit quantization gives a derived 1.25× at W1 but 4.82× at W2: the regime, not the algorithm, decides speedup [full text, Section 4.2, Table 7]. Three regimes in the (sequence length, batch) plane: weight-bound (KV compression buys little), KV-bound (byte reduction converts ~1:1), and beyond single-device capacity (tiering needed) [full text, Section 5.1]. Paging changes feasibility (batch) not per-step bytes; tiering is for reuse across steps, never reads within a step (PCIe ~125× below B200 HBM) [full text, Section 4.5]. The speedup columns are idealized (perfect kernels, no dequant overhead) [full text, Section 4.1].

### Goal: Which evaluation gaps does it identify?
Variance and confidence intervals essentially unreported; quality metrics fragmented (perplexity, NIAH, LongBench, downstream) with position sensitivity rarely measured; cost columns incomplete (TTFT and decode rate rarely together, no tuning/format-conversion costs or power); workloads synthetic or undisclosed [full text, Section 5.4]. Kernel gap: fused dequant is required, QServe-style fallbacks cost 20–90% runtime; eviction produces ragged per-head sets that break dense kernels [full text, Section 5.2]. Reasoning-length inflation is not part of its analysis (quality deltas are taken from the original KIVI/KVQuant/eviction papers).
