# KVTuner: Sensitivity-Aware Layer-Wise Mixed-Precision KV Cache Quantization for Efficient and Nearly Lossless LLM Inference

## What this paper does
Searches offline for a layer-wise (key-bits, value-bits) precision pair per layer under a memory constraint, using multi-objective optimization over a pruned search space (intra-layer Pareto pruning of precision pairs, inter-layer clustering by attention-output error) and end-to-end accuracy on a calibration set that includes math reasoning; configurations are applied statically online. Reports nearly lossless 3.25-bit mixed precision for Llama-3.1-8B-Instruct and 4.0-bit for Qwen2.5-7B-Instruct on math reasoning.

## Goal-by-goal answers
### Goal: Does it allocate KV bytes non-uniformly across layers by sensitivity, and how is the allocation searched?
Yes. Problem: min over P in S^L of (average equivalent bits, accuracy loss) subject to memory and accuracy constraints [full text, Section 5.1, Eq 4]. Candidate pairs {2,4,8}x{2,4,8}; intra-layer pruning keeps Pareto-efficient pairs by relative attention-output error; inter-layer clustering cuts 5^32 to about 5^6 configurations; calibration uses math reasoning and dequantized KV in prefill to amplify error accumulation [Section 5.3]. Layer sensitivity is reported to be an inherent, prompt-stable model property, with error accumulating over layers and generation steps [Section 4.5]. No layer gets zero bits, and it is for dense Transformers only.
