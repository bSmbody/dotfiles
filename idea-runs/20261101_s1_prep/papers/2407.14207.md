# Longhorn: State Space Models are Amortized Online Learners

## What this paper does
Treats SSM recurrences as solvers of online learning problems. It derives Longhorn from an implicit (proximal) online-regression objective whose closed-form solution gives a delta-rule-like update with a key-derived forget gate. A diagonal approximation is used for parallel scans. Longhorn replaces Mamba's SSM block and reports better sample efficiency and length extrapolation.

## Goal-by-goal answers
### Goal: Is a proximal closed-form least-squares update of a linear memory toward new key-value data (stay close to old state, fit new pair) already an established memory update rule?
Yes, for a linear memory and a single token. The update is S_t = argmin_S ||S - S_{t-1}||_F^2 + ||S k_t - x_t||^2_{diag(beta_t)} (Eq 5), framed as online convex programming trading off "stability" and "plasticity" (Eq 4). Its closed form, S_t = (I - eps k k^T) S_{t-1} + eps k x^T with eps = beta/(1 + beta k^T k), "coincides with the implicit online learning method" (Theorem 3.1, Eq 6) [full text, Section 3.1-3.2]. In practice the k k^T transition is replaced by a diagonal approximation for parallel scans (Eq 7). Longhorn has no nonlinear feature layer and no chunk-level multi-token solve.
