# DPS: Dual-Mode Precision LLM Serving with Semi-Unified Memory

## What this paper does
DPS is a vLLM-based serving system that makes WEIGHT precision load-adaptive: a NestedFP model stores an FP8 base plus a residual; under KV-cache pressure the server switches to FP8-only "fast mode" and repurposes the residual-weight memory region for KV blocks (Semi-Unified Memory), restoring FP16 weights from CPU when pressure falls. Evaluated on Phi-3.5-MoE, Qwen3-30B-A3B, GLM-4.7-Flash under bursty Gamma arrivals, measuring SLO attainment and effective pass@1.

## Goal-by-goal answers
### Goal: Is there prior work on serving-time, load- or request-dependent precision switching (seed 2)?
Yes, for weights: precision switching is triggered by global KV-cache pressure (allocation states Free/Backed/Avail/Full/Stale), not per request or per difficulty [full text, Sec IV-D]. KV precision itself is not changed. Motivation: bursty load means static FP8 "incur[s] a permanent cost for an intermittent problem" [Sec III-A]. Throughput gain 2.1-3.3x sustained, effective pass@1 improved [abstract].

### Goal: Accuracy cost of the low-precision mode?
Fast mode within about +/-0.5 pp of full mode on offline benchmarks; static FP8 drops Phi-3.5-MoE by 2.88 pp on average (IFEval 64.88 -> 42.70) [Sec V-B1]. No long-CoT reasoning or difficulty analysis; the decision variable is system load only.
