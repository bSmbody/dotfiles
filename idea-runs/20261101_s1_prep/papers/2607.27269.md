# Beyond KV Reconstruction: Functional Reconstruction for MLA Draft Models in Speculative Decoding

## What this paper does
Shows direct MHA/GQA->MLA conversion (TransMLA, MHA2MLA) hurts speculative-decoding acceptance, and proposes "functional reconstruction": a converter-agnostic per-layer refinement that trains the converted query/KV projections to match the original block's post-W_O attention output on calibration hidden states. Evaluated over 192 configurations with Llama/Qwen drafts up to 8B.

## Goal-by-goal answers
### Goal: Which error terms does MHA->MLA conversion introduce, and does any objective target the attention function?
For an exact map, rank([W^K,nope; W^V]) <= r is required, otherwise a residual is unavoidable [full text, Preliminary, Eqs 5-7]. The logit error decomposes into retained-key reconstruction error q^T R_tj dk, a positional-path error q^T (I - R_tj) k^drop that depends on the relative-position rotation R_tj, and query-perturbation terms [full text, RoPE Handling, Eq 8]. Their E2E loss is masked MSE between converted and original post-W_O outputs per layer, which covers both RoPE and low-rank errors [full text, Method, Eq 11].
### Goal: What does it report as its limitation?
Only 128-token generation and 200-prompt tasks; "long-context workloads are needed". It recovers only part of the lost acceptance, and "the current layer-local objective cannot fully overcome fixed-rank information loss"; "stronger sequence-level reconstruction" is needed [full text, Limitations].
