# Frontier-model "brains" are slow: acting correctly while the brain is still thinking

## Problem definition
A robot manipulation system uses a frontier VLM (e.g. GPT-6 Astra) as its high-level "brain" (planning, sub-task selection, target specification, recovery) and a fast local executor (an open VLA such as π0.5, scripted controllers or code tools) as its "arm". Each brain call takes seconds; the executor acts at 5–50 Hz. Given the observation stream, the executor's committed actions and the brain's delayed outputs, make the system act correctly despite the brain's latency — so that the brain's decisions are made about, and applied to, the world as it will be when they arrive, and the executor does not idle or act on stale decisions — without retraining the frontier model. Input: observations, committed action chunks, brain outputs with latency Δ. Output: executed actions. Evaluation: task success and wall-clock time as a function of brain latency, on manipulation tasks run in real time (no environment pausing while the brain thinks), including tasks with moving objects or moving targets.

## Challenge
Current frontier-brain robot systems are evaluated in simulators that pause while the model thinks, or on static tasks, so brain latency never shows up as a failure. In real time it does: the brain reasons over an image that is seconds old, its spatial targets ("grasp here", "move 5 cm left") refer to a robot pose and an object pose that have since changed, and the executor either waits (idle time) or keeps executing an old decision. Low-level VLA work hides millisecond-scale inference latency with asynchronous chunking, but that does not address a high-level decision that arrives seconds late and refers to a past state. Classical delay compensation (Smith predictors, predictive displays in teleoperation) assumes a known plant and a continuous command stream, not a discrete, semantically specified decision from a black-box model. Concrete failure: a box moves on a conveyor at 5 cm/s; the brain sees it, reasons for 4 s, and outputs "grasp the box at (x, y)"; by then the box is 20 cm further on and the grasp hits the belt. On a static table the same latency makes a relative command ("move 5 cm left of the gripper") land 5 cm off, because the arm kept moving during the call.

## Constraints
- **Venue and deadline**: CVPR 2027 main track (embodied / robot learning track). Paper deadline 2026-11-16 AoE; today is 2026-10-25, so every experiment must finish by about 2026-11-09 (about two weeks). If the panel judges this infeasible, it should say so and score the paper conditional on execution.
- **Compute**: at most 2–4 consumer GPUs with 24 GB each (RTX 3090 / 4090), shared cluster, single-GPU jobs; the whole paper ≤ 40 GPU-days. Open VLAs that fit: π0 / π0.5 (~3B), SmolVLA (~0.5B), OpenVLA-OFT (7B, inference or LoRA), GR00T-class (~3B); open VLMs up to ~8B for inference or LoRA. No large-scale VLA pre-training.
- **Frontier-model access**: API access to one frontier model (e.g. GPT-6 Astra) as a teacher, reference controller or occasional helper; total API spend for the paper must stay modest (assume about US$1,000; the per-call cost must be measured, not assumed). The point of the work is to need the frontier model less, not more.
- **Robots and data**: no robot hardware is assumed. Evaluation in public simulation benchmarks (e.g. LIBERO, SimplerEnv, CALVIN, RoboCasa, ManiSkill, BEHAVIOR/Habitat-style embodied agent suites) with public checkpoints and datasets.
- **Team**: a small group experienced with diffusion transformers and RL post-training; new to robotics, so engineering risk counts against an idea.
- **Literature**: no cutoff — search up to today. arXiv work from the last 12 months counts as prior or concurrent work; frontier-model-as-controller work from Sept–Oct 2026 is the immediate context; classical robotics and control literature (execution monitoring, behavior trees, time-delay teleoperation and predictive displays, Smith predictors, model-predictive latency compensation) counts as prior work too.
- **Significance bar**: a simulated CVPR panel will judge the result. Thin deltas over 2026 work and directional-only predictions have been rejected before; prefer a contribution that gives a new capability or a decisive cost/performance change, with a committed effect size on a standard benchmark.
