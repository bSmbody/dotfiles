# REFLECT: Summarizing Robot Experiences for Failure Explanation and Correction

## What this paper does
REFLECT (CoRL 2023) converts multisensory robot logs (RGB-D, audio, robot state) into a hierarchical summary (task-informed scene graphs, event-based keyframes, subgoal-end observations), then uses an LLM for progressive failure explanation (subgoal verification, then execution or planning analysis) and a correction planner that generates a new plan from the final state. Evaluated on the RoboFail dataset (sim and real).

## Goal-by-goal answers
### Goal: Does the brain pre-specify monitors and local recoveries that fire without re-calling the brain?
No. Failure detection is post hoc: the LLM verifies each subgoal from the subgoal-based summary ("Is the subgoal satisfied?") and explains failures from the event-based summary [full text, Sec. 3.2]; correction is an LLM-generated plan "starting from the final state of the original task execution" [Sec. 3.3]. Every detection and correction is a brain call after the episode/failure.

### Goal: Does it measure latency, and what limitation does it report?
No latency measurement. Limitations: the framework "assumes the rest of the environment will remain static throughout the robot task execution" and is "less effective for handling low-level control failures" [Sec. 5, Limitations].
