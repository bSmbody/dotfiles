# Realtime-VLA FLASH: Speculative Inference Framework for Diffusion-based VLAs

## What this paper does
Speculative inference for flow-matching VLAs. A lightweight draft model proposes a continuous action chunk. The main model's Action Expert checks it in parallel at a few flow-matching timesteps, by interpolating the draft with noise and testing whether the reconstructed endpoints agree. The robot runs the longest consistent prefix and falls back to full inference on failure or near gripper switches. LIBERO: 58.0 ms full rounds become speculative rounds as fast as 7.8 ms (3.04x lower average latency). Real conveyor sorting works up to 15 m/min.

## Goal-by-goal answers
### Goal: Does "speculative" here mean guessing a slow high-level decision and executing physical motion on that guess before it is confirmed?
Partly, but only at the action-chunk level of one VLA. The draft chunk runs once the main model's Action Expert has verified it, and on a failed check the system falls back to the full path [full text, Abstract, Sec 1, Sec 3.3–3.5]. Verification happens before execution, so no unverified physical action is taken. The latencies are tens of milliseconds, and there is no semantic target choice or candidate set. No overlap with C3's mechanism, which hedges over a seconds-late black-box brain's target choice.
