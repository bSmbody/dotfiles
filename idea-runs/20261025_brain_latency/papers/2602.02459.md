# TIC-VLA: A Think-in-Control Vision-Language-Action Model for Robot Navigation in Dynamic Environments

## What this paper does
A dual-system navigation VLA in which a fine-tuned InternVL3-1B reasons asynchronously over delayed frames while a fast action policy runs every control step, conditioned on the current image and state, the cached last-layer VLM KV features from time t−Δt, and explicit latency metadata (Δt and accumulated ego-motion offset). Trained with synthetic delays Δt∼U[0,10] s in imitation learning and then PPO with injected delays; evaluated on a new dynamic-pedestrian simulator (DynaNav) and a real robot.

## Goal-by-goal answers
### Goal: Does the system measure, ignore or compensate the brain's latency, and does the environment pause while the model thinks?
It compensates it explicitly and does not pause: the action policy "never blocks on VLM inference" [full text, Sec 3.2]; effective latency Δt = t_infer + t_elapse is a first-class input. The VLM forward rate is 0.5 Hz with reasoning vs 4 Hz without [Sec 4.4, Table 4].

### Goal: What mechanism predicts the future state or reconciles a stale high-level decision with the current state, and what does it assume?
Reconciliation is learned inside the low-level policy: "semantic features describe a past state of the world, while the control policy is responsible for reinterpreting them in the current frame" [Sec 3.2, Eq 1]. The reasoning outputs (waypoints) are anchored to t−Δt. There is no forward prediction for the reasoner — the VLM still reasons over the stale frame. Assumptions: (i) white-box access to VLM KV-cache features and a fine-tuned VLM [Sec 3.3]; (ii) compensation metadata covers only ego-motion (Δx, Δy, Δθ), not motion of other agents or objects; (iii) the policy is trained end-to-end with the delay distribution. Removing the ego-motion offset drops SR 47.06→41.18 [Table 6].

### Goal: What limitation does it report?
Navigation only: "extending beyond navigation to domains such as robotic manipulation remains future work" [Sec 5]; limited real-world scale and runtime optimization.

# TIC-VLA: A Think-in-Control Vision-Language-Action Model for Robot Navigation in Dynamic Environments

## What this paper does
Dual-system navigation VLA in which a slow VLM (InternVL3-1B, fine-tuned on GPT-5-annotated reasoning traces and waypoints) runs asynchronously over time-lagged frames, and a fast transformer action expert conditions on the VLM's cached last-layer KV features plus explicit latency metadata (Δt, and the ego-motion offset Δp accumulated since the reasoning started). The action expert is trained by imitation with synthetic delays sampled uniformly in [0,10] s and then RL-fine-tuned (PPO) in an Isaac-Sim crowd-navigation suite (DynaNav) with stochastic delay injection. ICML 2026.

## Goal-by-goal answers

### Goal: What mechanism maps a delayed high-level decision/observation onto the current state?
The VLM output R_{t-Δt} (scene understanding, critical objects, intent, and future waypoints) is explicitly anchored at the inference-start time t-Δt [full text, Section 3.2]. The action policy π(S_{t-Δt}, x_t, s_t, Δt, Δp_t) receives the stale semantic hidden state plus the ego-motion offset (Δx, Δy, Δθ) since generation, and is *learned* to "reinterpret them in the current frame" [Section 3.2, Eq. 1]. Removing the ego-motion offset drops SR 47.06 -> 41.18 [Section 4.4, Table 6]. Only the robot's own motion is supplied as an explicit correction; motion of other agents/objects during the delay is left to the learned policy reading the current image.

### Goal: What does the method assume about the slow decision-maker (trainable, white-box features, output type, delay scale)?
The slow model is white-box and fine-tuned: the interface is the VLM's last-layer KV cache, not its text; the VLM is SFT'd on GPT-5-generated traces, and the action expert is trained jointly against those features [Sections 3.2-3.3]. GPT-5 is used only offline as an annotator. Delays up to 10 s are covered in training. The output consumed downstream is a continuous latent, so the method does not address a black-box model whose only output is discrete text/coordinates.

### Goal: What does it report as a limitation relevant to this axis?
Authors list runtime efficiency, limited real-world scale, and that "extending beyond navigation to domains such as robotic manipulation remains future work" [Section 5, Limitations]. Test-time reasoning runs at 0.5 Hz vs 4 Hz without reasoning [Section 4.4, Table 4].
