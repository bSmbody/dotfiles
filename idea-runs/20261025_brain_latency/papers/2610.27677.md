# CovNav: Conformal Prediction-Guided Adaptive Inference for Object Goal Navigation

## What this paper does
Training-free ObjectNav. A local Qwen3-8B in fast mode answers yes/no "is the goal likely near this landmark?". Its temperature-scaled Yes/No logits go through conformal prediction. Only queries whose prediction set is not a singleton are escalated to slow thinking mode of the same model. A GPT-5-precomputed object-relation matrix covers common pairs. Gibson/HM3D plus a TurtleBot 4. Slow mode is triggered on 12.4% of queries and recovers most of the always-slow gain (62.8% vs 64.2% SR) at 0.68 s instead of 2.4-3.4 s average latency.

## Goal-by-goal answers
### Goal: Does it hedge physical action during the slow reasoner's call, or only gate whether to call it?
Only gating. The prediction-set size decides fast vs slow inference [full text, Sec III-D3]. Nothing in the paper says what the robot does while slow mode runs, and no motion hedges across the possible slow answers. The slow model is the same 8B model with thinking enabled, not a frontier brain.

### Goal: What does it show about calibrated small-model confidence as a switch to a slow reasoner?
Temperature scaling followed by conformal prediction gives a set-size switch with a coverage guarantee [Eqs 1-3]. Fast-only reaches 51.5% SR and slow-only 64.2% on HM3D v1, at a slow-only latency of 3.40 s [Sec IV-C1]. CovNav reaches 62.8% at 0.72 s [Sec IV-C1, IV-D]. This is the confidence-gated cascade design: call the slow model only when the fast model is unsure.
