# RAPAC-DP: Response-Aligned Pending-Action Compensation for Diffusion Policies under Delayed Execution

## What this paper does
For cloud-hosted diffusion/flow policies with request-to-response delay d, the local controller executes queued pending actions while waiting; RAPAC-DP conditions the cloud policy on that pending-action sequence (encoder + LoRA adapters on a frozen base policy) and trains it to output the chunk aligned with the response time t+d, built from delay-free demos by shifting the target window. RoboMimic and Kinetix.

## Goal-by-goal answers

### Goal: What mechanism maps a delayed high-level decision/observation onto the current state?
Action-buffer conditioning (the learned analogue of a Smith predictor / delayed-MDP augmentation): A_tar = [a_{t+d}..a_{t+d+H-1}] predicted from o_t and the encoded pending actions P_{t,d} = [a_t..a_{t+d-1}] [full text, Sections III-C, IV-A/B, Eqs. 6-8].

### Goal: What does the method assume about the slow decision-maker (trainable, white-box features, output type, delay scale)?
The delayed model must accept an extra conditioning input and be LoRA-trained; d is "known and fixed within each evaluation setting"; outputs are continuous action sequences [Sections III-C, IV-C, IV-D].

### Goal: What does it report as a limitation relevant to this axis?
Fixed known delay is a stated assumption [Section III-C]; the pending-action trick presumes the committed actions fully describe what changes during the delay, i.e., no exogenous object motion beyond what the policy learns from o_t.


### Goal: What do the authors themselves list as limitations?
Simulation only, "known discrete delays that remain fixed within each evaluation setting"; train-time pending actions come from expert trajectories while deployment uses policy-generated queue contents; variable latency, delay estimation and real robots are future work [full text, Section VI]. (The note in the previous answer about exogenous object motion is this run's inference from the formulation, not an author statement.)
