# RAVEL: Asynchronous Rolling Inference for Flow-Based Vision-Language-Action Models

## What this paper does
Rolling asynchronous inference for flow VLAs: near-term actions execute after one denoising step from a rolling buffer; VLM encoding is decoupled so the action expert uses the latest context with its temporal offset; a Fast Observation Pathway injects current images/proprioception via gated cross-attention. Evaluated on synchronous LIBERO/RoboTwin, a non-paused Dynamic Object Manipulation benchmark, and real table-tennis / ball grasping.

## Goal-by-goal answers
### Goal: What latency does it address, and does it involve a high-level (frontier/VLM planner) brain?
VLA backbone and denoising latency (sub-second). Its dynamic benchmark is non-paused: "the simulator continues to advance during policy inference. Objects may move or change direction before the predicted actions are executed" [full text, Sec 4.2]. No high-level frontier brain.

### Goal: What mechanism predicts the future state or reconciles a stale decision with the current state, and what does it assume?
Reconciliation by freshness rather than prediction: stale VLM context c_{t_o} with offset δ_p is combined with current observations z_{t_a}=F(o_{t_a}, s_{t_a}) [Sec 3.2, Eq 4]. Requires streaming-aligned training and architecture-specific action-expert changes; "the subsequent delay between action prediction and physical execution remains" [Sec 5].


### Goal: Is the DOM benchmark runnable by a third party on consumer GPUs, and in which mode?
Yes. RAVEL evaluates on "the Dynamic Object Manipulation (DOM) benchmark introduced with DynamicVLA", in a mode where "the simulator continues to advance during policy inference", initializing all methods "from the released DynamicVLA checkpoint" [full text, Sec 4.2]. It runs DOM locally on an RTX 4090, measuring 370.7 ms median DynamicVLA latency vs 226 ms reported on an A6000 [Appendix A.2, Table 5]. So DOM's simulator, task specs and a checkpoint are public and run on the hardware class in this problem's constraints; latencies involved remain sub-second.
