# Set-of-Mark Prompting Unleashes Extraordinary Visual Grounding in GPT-4V

## What this paper does
SoM partitions an image into regions with off-the-shelf segmenters (SEEM, SAM, Semantic-SAM, MaskDINO), overlays a unique alphanumeric mark (plus optional mask/box) on each region, and prompts a black-box LMM with the marked image, so the model can answer with mark IDs that map back to exact regions. Zero-shot GPT-4V+SoM beats specialist models on referring segmentation, phrase grounding and DAVIS video object segmentation.

## Goal-by-goal answers
### Goal: How do marks let a black-box LMM refer to regions, and what properties must marks have?
Marks augment only the input image, T^o = F(SoM(I), T^i), leaving the model untouched [full text, Sec 2.1, Eq 2]. The two required properties are that regions are semantically meaningful and that marks are "interpretable and speakable" so the model can name them in its text output; each mark is unique so the region–mark map is a lookup [Sec 2.1, 2.3]. Only GPT-4V showed this emergent ability among the LMMs tried [Sec 2.1]. On DAVIS, GPT-4V given the first and current marked frames reaches 78.8 J&F [Sec 4.2, Video Object Segmentation].

### Goal: What do mark placement ablations say about marks drawn away from the object's pixels?
Marks are placed by a distance transform inside each mask; for very small regions "we move the marks off the region slightly" and GPT-4V "can still build a decent association" [Sec 2.3]. But centered marks can be misattributed to an overlapping or nearby region (a backpack mark chosen for "the person") [Sec 4.4]. Adding boxes to numbers+masks improves grounding significantly; ground-truth masks add 14.5 mIoU on RefCOCOg [Sec 4.3]. So marks need not sit exactly on pixels, but displaced or overlapping marks raise association errors.
