# Acting While Understanding: Asynchronous Semantic-Action Decoupling for Real-Time Vision-Language-Action Models

## What this paper does
Splits an existing VLA (UniVLA, π0.5) along its internal semantic-action interface: a low-frequency understanding module refreshes a reusable semantic condition z (last-layer hidden state or full KV cache), while the high-frequency action head runs every step on the latest cached z, the current robot state and a window of recently executed actions. The action head is trained with stale conditions z_{t-Δ}, Δ sampled up to one action chunk (~1 s). Evaluated on LIBERO and SO100 real robots.

## Goal-by-goal answers

### Goal: What mechanism maps a delayed high-level decision/observation onto the current state?
At each control step the action module computes Â_t = G(z_{τk}, s_t, h_t), where h_t = recent executed actions; the stale semantic condition is compensated by current proprioception plus action history, and by training on deliberately misaligned (z_{t-Δ}, A_t) pairs [full text, Sections 3.3-3.4, Eqs. 2-4]. No forward prediction of the scene is made.

### Goal: What does the method assume about the slow decision-maker (trainable, white-box features, output type, delay scale)?
It requires a white-box VLA with a reusable intermediate tensor before action generation; authors state applicability "remains tied to the internal interface form of the base VLA" [Section 5]. Staleness during training spans only up to one chunk, about 1 s [Section 3.4].

### Goal: What does it report as a limitation relevant to this axis?
On LIBERO-Long naive cache reuse drops 92.0 -> 85.2, full method recovers 91.2 [Section 4.4, Table 4]. Authors state the action module "may still be limited when semantic cache age becomes too large or when the environment changes significantly", that the fixed refresh schedule can let stale semantics mislead the controller, and that fast dynamic manipulation is not validated [Section 5].
