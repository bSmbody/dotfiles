# FutureRTC: Real-Time Robot Execution with Anticipatory-Conditioned Action Chunking

## What this paper does
A plug-and-play adapter for asynchronous flow-matching VLAs that forecasts the execution-time state (forward integration of committed actions plus a learned residual) and execution-time visual latent (motion-aware feature warping plus gated synthesis), trained with a policy-consistency loss; the untouched policy then generates a chunk aligned to execution time.

## Goal-by-goal answers
### Goal: What latency does it address, and does it involve a high-level (frontier/VLM planner) brain?
Low-level chunk inference delay d in control steps (sweeps d=5–20) [full text, Sec Experiments]. No high-level brain.

### Goal: What mechanism predicts the future state or reconciles a stale decision with the current state, and what does it assume?
State: s̃_{t+K} = s_{t+K−d} ⊕ Σ a_i plus an MLP residual [Sec State Correction Module, Eq 3–4]. Observation: stale VLA-encoder latent warped by a flow field predicted from committed-action features, plus a synthesis branch [Eq 5–7]. Assumes the robot is the main source of scene change: the module "may struggle in highly dynamic scenes dominated by independent external agents", and "more extreme inference delays" are future work [Limitations]. Requires the VLA's encoder latent space.
