# Active Sensing and Deferred-Decision Trajectory Optimization for Robust Target Identification

## What this paper does
AS-DDTO (IEEE L-CSS 2026) extends DDTO for a mobile sensor that must identify which of N candidate targets is true while keeping all plausible candidates reachable. It adds to DDTO's deferral (trunk-coincidence) objective a belief-weighted, distance-based active-sensing surrogate, updates a Bayesian posterior (Gaussian sensing) or a conformal candidate set, prunes implausible candidates, and commits to the MAP branch at the forced decision time. MICP reformulation; guarantees on recursive feasibility, posterior concentration, conformal coverage. Quadrotor sims with 4 static candidates, 100 runs.

## Goal-by-goal answers
### Goal: Does AS-DDTO weight branches/motion by a belief over which candidate is the target, and are candidates static or moving?
Partly. Eq 7a: deferral objective plus w * sum_k rho^{k-1} sum_j pi_0(j) phi(d(x_k^r, z^j)), so the shared trunk is biased "toward likely candidates before branching" with belief weights; candidates with belief below tau = 0.2 are pruned from the retained set [full text, Sec III-B, V]. The weighting serves information gain (sensor proximity), not success probability at a reveal time. Candidates are fixed locations z^j (randomized in [-30,30]^2, z = 0) [Sec V]. Identity information arrives gradually from the robot's own distance-dependent queries; there is no slow external decision-maker or latency distribution. Prior is uniform in experiments [Sec II].
