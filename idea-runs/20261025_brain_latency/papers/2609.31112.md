# DualManip: Agentic Dynamic Manipulation via Dual-Path Semantic Reasoning and Geometric Adaptation

## What this paper does
A dual-path manipulation agent: a VLM semantic path decomposes the task, grounds interaction regions (SAM 3, Sofar), generates spatial constraints and optimizes a target pose; a geometric path keeps dense correspondences between a pre-scanned object template and live RGB-D point clouds so the task-relevant grasp contacts are transferred to the current geometry (138.7 ms per update vs 6.376 s for GPT replanning). An interaction module checks feasibility and falls back to semantic replanning. Real-robot only (KUKA iiwa), static / single-change / continuous-dynamic settings.

## Goal-by-goal answers
### Goal: Does the system measure, ignore or compensate the brain's latency?
It measures adaptation latency (Table III: CLEA-GPT 6.376 s, CLEA-Qwen3.5-2B 4.329 s, DualManip 138.7 ms) and avoids re-calling the VLM when "scene changes alter object geometry without invalidating task intent" [full text, Sec III-A, IV-E]. CLEA-style replanning "cannot keep pace with continuously evolving geometry due to the latency of repeated high-level reasoning" (0% under continuous change) [Sec IV-D].

### Goal: What mechanism reconciles a stale high-level decision with the current state, and what does it assume?
The semantic decision is expressed as grasp contacts anchored on an object template; the geometric path re-expresses those contacts in the current observation via shape-adaptive Sinkhorn correspondence plus predicted rigid transform and deformation [Sec III-C, Eq 4]; feasibility (reachability, collision) is checked before execution and failures trigger replanning [Sec III-D]. This is object-anchored reconciliation, but it is reactive (tracks the current state, no prediction of where the object will be), the scene changes studied occur during execution after the semantic path, and it needs a pre-constructed 3D template and object-specific correspondence training [Sec V, Limitations].

### Goal: What limitation does it report on dynamic tasks?
Continuous-dynamic success 53.3% mean; relies on templates and object-specific training, limiting zero-shot generalization [Sec V].
