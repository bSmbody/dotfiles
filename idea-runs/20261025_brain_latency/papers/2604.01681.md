# Bridging Large-Model Reasoning and Real-Time Control via Agentic Fast-Slow Planning

## What this paper does
Autonomous-driving hierarchy: an on-vehicle VLM converts images to an ego-centric topology graph, a cloud LLM (deepseek-v3 via API) emits symbolic directive sequences (left/right/keep, drive plan/style), a Semantic-Guided A* turns directives into a path with soft semantic costs (Correct/Delay/Wrong/Overact), an agentic module tunes planner hyperparameters, and a switching MPC tracks local or cloud references. CARLA.

## Goal-by-goal answers

### Goal: What mechanism maps a delayed high-level decision/observation onto the current state?
No explicit latency compensation. Robustness comes from (a) issuing a whole directive sequence and (b) embedding it as soft costs in A* so the planner can deviate ("allowing recovery from directive errors or local conflicts") [full text, Section V-A]; the MPC switches between a local reference and the cloud reference via z_t [Section V-C, Eq. 5].

### Goal: What does the method assume about the slow decision-maker (trainable, white-box features, output type, delay scale)?
Black-box API LLM producing discrete symbolic directives; measured average latency 4.13 s for the LLM vs 10.24 s for the VLM [Section VI-A2]. The CARLA experiments compare reference trajectories at a fixed 4.2 m/s; the text does not state that LLM latency is injected into the closed loop [Section VI-C].

### Goal: What does it report as a limitation relevant to this axis?
Future work: adaptive edge-cloud collaboration and verification of symbolic directives [Section VII]. The directive alphabet is ego-relative and temporally unanchored (no record of which state a "left" referred to).
