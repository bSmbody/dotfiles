# Think Fast: Real-Time Kinodynamic Belief-Space Planning for Projectile Interception

## What this paper does
A belief-space interception planner for a 6-DOF ABB arm blocking thrown balls. An offline action tree of jerk-limited motion primitives in state-time space encodes reachability to many goal states from one origin. An adaptive Kalman filter maintains a Gaussian belief over the intercept point and crossing time. Online, a QMDP value is the expected probability of interception under the current belief. It is propagated back through the tree every update, and the arm takes the successor of maximal value, so it can switch goals seamlessly. Hardware: 74% blocking success over 50 throws vs 63% for moving to the most likely goal.

## Goal-by-goal answers
### Goal: Does it hedge physical motion over several possible goals before the target is known, and how much does hedging beat committing to the most likely goal?
Yes, for uncertainty over *one* target's future state (not identity). V(n,b) = E_{o~b}[R(n,o) + max_a V(n',b)], with R = 1 if the shield covers the intercept before the crossing time. The arm follows argmax V, and moves to the most probable goal when the tree runs out [full text, Sec V-C]. Against "moves ... as fast as possible to the current most likely goal configuration at each belief update", it reaches 74% vs 63% on hardware. The main failure is "insufficient execution time ... the end effector was too far away" [Sec VI–VII]. The authors say the planner "is able to hedge against a distribution of future observations, making it more robust than the naive approach which commits immediately" [Sec VII]. There is no semantic decision-maker and no latency of a decision.
