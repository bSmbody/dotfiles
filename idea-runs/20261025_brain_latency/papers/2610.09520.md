# Not All Uncertainty Matters: Simulation-in-the-Loop Fast-Slow Reasoning for Decision-Critical Autonomous Driving System

## What this paper does
SIGMA decides when an onboard driving stack should call a slow cloud VLM. It samples plausible scene realizations under semantic and geometric perception uncertainty, runs the local MPC on each, and estimates the expected planning gain (EPG) of resolving the uncertainty. Cloud calls are made only when EPG is high and the predicted response returns before a decision deadline; the returned guidance is validity-checked on arrival and otherwise the local reference is kept. CARLA, static and dynamic obstacles.

## Goal-by-goal answers
### Goal: Does the slow VLM answer contingently over enumerated future scene realizations, or give one decision that is checked on arrival?
One decision. The cloud model reasons over a structured description of the current scene and outputs a single maneuver gamma in {keep, left, right}, converted to a reference trajectory [full text, Sec VI-A, Eq 22]. Scene realizations are enumerated only on the onboard side, to compute EPG for the invocation decision [Sec V]. On arrival, the guidance is used only if it returned before the deadline and is "consistent with the current ego state ... and yields a feasible MPC problem", else the planner falls back to the local reference [Sec VI-B, Eqs 27-28]. No contingent answer, no arrival-time forecast shown to the VLM.
