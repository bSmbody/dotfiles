# CoBind: Stage-Aware Compositional Binding for Training-Free Text-to-Image Generation

## What this paper does
CoBind parses a prompt into an entity–attribute–relation graph and guides the latent with three time-windowed objectives on U-Net cross-attention: early layout, mid binding, and late relaxation. Early on, coarse-layer attention maps drive entity completeness (top-K mean), entity separation (Dice) and relation losses (centroid margins for left/above, distance for near/far, mass ratio for inside). Mid-stage, an attribute-entity contrastive binding acts on mid-resolution maps; satisfied constraints are down-weighted. Experiments use SD1.5, SD2.1 and SDXL on T2I-CompBench++ and GenEval. Caveat: parts of the results discussion are worded conditionally ("If CoBind produces the largest gains...") and the introduction says exact improvements "will be added", so its numbers are not relied on here.

## Goal-by-goal answers
### Goal: How does it schedule and represent relation constraints?
Each graph node v gets a spatial map: the head-mean cross-attention averaged over v's tokens. Layout maps come from low-resolution layers and binding maps from mid-resolution layers [full text, Section 2.3, Eq 10-13]. Layout and binding weights are sigmoid windows over progress p_t = 1 - t/T with boundaries rho_1 < rho_2 [full text, Section 2.4, Eq 14-17]. Relations act on each entity's normalised layout map: the soft centroid mu_e (Eq 21-22) with hinge margins for left/above (Eq 23-24), centroid distance for near/far (Eq 25-26), and attention-mass containment for inside (Eq 27) [full text, Section 2.6]. The rationale is that "spatial relations must be established before the global layout becomes fixed" [full text, Section 1].

### Goal: Does it handle counts or multiple instances of the same noun?
No. "Counting is not a primary design target ... the method does not include an explicit one-to-one instance-assignment mechanism" [full text, Section 3.2.1]. In the failure cases, when several instances of one category (or similar entities) are requested, "entity-attention maps may merge during the early stage. The current method operates on semantic entity nodes and lacks explicit instance slots" [full text, Section 3.11]. The conclusion repeats that multi-instance attention "may become entangled because the current representation does not maintain explicit instance-level identities", and proposes "explicit instance slots" as future work for counting [full text, Section 4].

### Goal: Which backbones; reliability of reported results?
SD1.5 is the main backbone, with SD2.1 and SDXL for generality. Layer sets are chosen per U-Net resolution [full text, Section 3.1.2]. There is no MM-DiT experiment. The paper's own conditional wording in the results discussion and the "will be added" note mean its reported numbers should be treated as provisional [full text, Section 1, 3.2.1].
