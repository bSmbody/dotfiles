# Delta-K: Boosting Multi-Instance Generation via Cross-Attention Augmentation

## What this paper does
Training-free fix for concept omission. A quarter-step preview image is generated, and a VLM (Qwen3-VL) lists missing concepts. Delta-K = K_input(P) - K_input(P_mask), where missing concepts are replaced by [MASK]; it is injected into the attention keys during the first 10 steps with a strength alpha_t optimised online so that the missing concepts' attention matches the baseline attention of present concepts. Evaluated on SDXL and SD3.5-Medium (FLUX in the appendix) on T2I-CompBench, GenEval and ConceptMix.

## Goal-by-goal answers

### Goal: What mechanism does it use against attribute leakage or object omission, and which part of MM-DiT joint attention (image-to-text, text-to-image, text-to-text, image-to-image quadrant, or token states) does it read or modify?
Attention' = softmax(Q (K + alpha_t Delta-K)^T / sqrt(d_k)) V (Eq 4-5), applied in all DiT blocks during the early window [full text, Section 3, Section 4.1]. alpha_t is adjusted per step so the missing concepts' attention approaches A_target, the mean attention of present concepts in the baseline pass (Eq 6) [full text, Section 4.2]. It shifts the key inputs at text-token positions.

### Goal: Does it account for text tokens being rewritten by image tokens across MM-DiT blocks, or does it treat text tokens as fixed keys or apply a uniform text-side transform?
It works on the text-key side, and alpha_t adapts to the current attention state. But Delta-K itself is fixed from the preview pass, and the controller matches only attention magnitude of missing concepts; there is no binding or leakage term. Its analysis finds missing concepts have weak and spatially irregular responses (high CV), predictable early (AUC about 0.78 at step 2 on SD3.5) [full text, Section 1, Section 3].

### Goal: What limitation, failure case, quality or runtime cost, or external dependency (layout, LLM/VLM, fine-tuning) does it report on this axis?
Requires an extra preview pass and a VLM call [full text, Section 4.1]. Limitations: concept-level only, with the roles of individual layers unexplored [full text, Section 6]. VLM errors are claimed to be fail-safe (false negatives revert to baseline) [full text, Section 5.3]. Aesthetic quality comparable [full text, Section 5.2].
