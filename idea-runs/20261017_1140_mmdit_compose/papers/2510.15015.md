# DeLeaker: Dynamic Inference-Time Reweighting For Semantic Leakage Mitigation in Text-to-Image Models

## What this paper does
Training-free, optimisation-free method against semantic leakage (unintended transfer of features between visually similar entities) in DiT text-to-image models, mainly FLUX.1-dev, also SANA. It thresholds pre-softmax image-query-to-entity-text scores to get one mask per entity, aggregated over early blocks and steps with spatial and temporal smoothing. Inside the masks it sets cross-entity image-to-text scores to minus infinity, suppresses very high cross-entity image-to-image scores, and multiplies each entity's image-to-own-text scores by alpha = 1.2. Introduces the SLIM dataset (1,130 human-verified leakage samples) and a VLM-based comparative evaluation.

## Goal-by-goal answers

### Goal: What mechanism does it use against leakage, and which part of MM-DiT joint attention (which query rows / quadrants) does it read or modify?
Masks: E_i^img = image tokens whose score to entity i's text tokens exceeds mu_i + beta_1 sigma_i (beta_1 = 0.9), aggregated from early blocks/steps, then morphological closing/opening and temporal averaging [full text, Section 2.1, Eq 1; Appendix C.1]. Edits (Eq 11): (1) minus infinity on image-to-image scores between entity regions that exceed mu_ij + beta_2 sigma_ij (beta_2 = 2); (2) minus infinity on image-to-text scores from entity i's image tokens to entity j's text tokens; (3) alpha times image-to-own-text scores [full text, Section 2.2, Appendix C.2, Eq 11]. In every case of Eq 11 the query is an image token, so only the image-query rows are modified; the text-query rows (what text tokens absorb from image tokens) are left as in the base model, although the Fig 2 caption describes strengthening as "from each entity's text tokens to its own image tokens" [full text, Fig 2, Appendix C.2]. Interventions run between block 57 and 741 of 1,140 (20 steps x 57 blocks) [full text, Table 6].

### Goal: Does it control what text tokens absorb (text-query rows), and what happens when text-text interactions are suppressed?
It does not edit text-query rows. In the ablation, adding cross-entity text-text suppression ("With Text-Text (-)") degrades leakage mitigation by 9% to 20%, and the authors conclude that leakage "is primarily due to cross-modal misalignment" rather than within-modality interaction [full text, Section 7, Table 2]. The strongest component is image-to-own-text strengthening (removing it drops major improvement to 0.54 of the full method); cross-entity image-to-text suppression alone reaches 0.54 [full text, Section 7, Table 2]. Masks are accurate at the first step and, in leakage cases, "begin to blend by a middle step" [full text, Appendix B.1, Fig 5].

### Goal: What limitation, failure case, scope (models, prompt types), or dependency does it report?
Scope is FLUX.1-dev and SANA; no SD3/SD3.5 [full text, Section 5]. It targets similarity-driven semantic leakage and explicitly separates this from explicit attribute binding ("a red cow and a white parrot") [full text, Appendix A.1, Table 4]. Masks are hard thresholds fixed from early steps: "it cannot create a new mask for an entity if one was not formed in the early stages", so it handles missing entities poorly in three-animal prompts [full text, Appendix E.2]. The image-image component gave inconsistent results and artifacts on SANA and was dropped there [full text, Appendix C.1]; alpha = 2.0 introduces artifacts [full text, Appendix B.1, Fig 7]. Coefficients were set by qualitative review of a few samples [full text, Section 2.2].
