# D2D: Detector-to-Differentiable Critic for Improved Numeracy in Text-to-Image Generation

## What this paper does
D2D makes non-differentiable open-vocabulary detectors (OWLv2, YOLO variants) usable as count critics. Detector logits pass through a steep sigmoid with threshold tau_z and are scaled by the logit to give a soft count. Its gradient tunes a small 3-layer MLP (Latent Modifier Network) that rewrites the initial noise as x_T' = 0.2 x_T + 0.8 M_phi(x_T), with a ReNO-style norm regulariser. Experiments use only one-step distilled generators (SDXL-Turbo, SD-Turbo, PixArt-DMD). It corrects about 40% of under- and over-generations and beats Make It Count, Counting Guidance and TokenOpt on CoCoCount and D2D-Small/Multi/Large.

## Goal-by-goal answers
### Goal: What mechanism converts a detector into a count critic and how is the gradient applied?
The differentiable count is f = sum_i sigmoid(beta (z_i - tau_z)). L_D2D multiplies each sigmoid by (z_i - tau_z) for over-generation, or by (tau_z - z_i) for under-generation, so the gradient stays useful away from the threshold [full text, Section 3.1, Eq 1-2]. The gradient flows from detector logits through the decoded image and the frozen generator into the LMN weights, which define the initial noise. A per-model pre-alignment and a ~0.2 s per-sample calibration keep the LMN output near-Gaussian [full text, Section 3.2, 3.3, Eq 3-5]. The authors place the problem "within the initial noise optimization framework" because of structural priors in the initial latent [full text, Section 1].

### Goal: Which generator types is it restricted to and why?
The problem statement assumes "a pre-trained, one-step T2I model G_theta" [full text, Section 3], and all base models are one-step distillations (SDXL-Turbo, SD-Turbo, PixArt-DMD) [full text, Section 4.1]. The gradient needs a full generator pass from x_T to pixels, so each tuning iteration backpropagates through the whole sampler. That is cheap only for one step. Runtime is 11–21 s per image, against 28–100 s for multi-step counting baselines [full text, Section 4.3].

### Goal: What limitations does it state regarding placement/relations?
"D2D is not a layout-control approach and so is limited in more fine-grained control (e.g., object placement)." High-density scenes remain hard [full text, Section 5]. Multi-class prompts are handled by correcting each box's largest class logit [full text, Section 3.1; Appendix E], with no spatial-relation term.
