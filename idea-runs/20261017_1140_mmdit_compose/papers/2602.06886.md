# Prompt Reinjection: Alleviating Prompt Forgetting in Multimodal Diffusion Transformers for Text-to-Image Generation

## What this paper does
Shows "prompt forgetting" in the MM-DiT text branch: CKNNA to the input space declines with depth, tokens collapse into a concentrated PCA region, and probes for token category (noun, adjective, relation, numeral) decline monotonically (relation tokens worst) on SD3, SD3.5 and FLUX. The cause is argued to be that only visual tokens are supervised. The training-free fix reinjects shallow-layer text features into every deeper block after LayerNorm anchoring and an orthogonal Procrustes rotation (calibrated once on COCO-5K), with a shared weight w. Gains on GenEval, DPG and T2I-CompBench++ for SD3, SD3.5, FLUX and Qwen-Image.

## Goal-by-goal answers

### Goal: What mechanism does it use against attribute leakage or object omission, and which part of MM-DiT joint attention (image-to-text, text-to-image, text-to-text, image-to-image quadrant, or token states) does it read or modify?
T_added = LN(T_tgt) + w LN(T_ori) R, then restored to target statistics (Eq 8-11), applied to all text-token states in layers after the origin layer [full text, Section 5.2]. It modifies text-token hidden states, not attention weights.

### Goal: Does it account for text tokens being rewritten by image tokens across MM-DiT blocks, or does it treat text tokens as fixed keys or apply a uniform text-side transform?
It is built on the text-token dynamics: text tokens "are updated only indirectly via their influence on visual reconstruction through joint attention" [full text, Section 1], and "the majority of tokens progressively collapse into a highly concentrated region ... token features become less spread out and potentially less separable" [full text, Section 4.1]. But the fix is uniform: one w for all tokens and layers, reinjecting the whole prompt; there is no per-phrase isolation or control over which image content each token absorbs.

### Goal: What limitation, failure case, quality or runtime cost, or external dependency (layout, LLM/VLM, fine-tuning) does it report on this axis?
Limitation: cross-depth mismatch means "we can not reliably use large reinjection weights", and w and origin layer need manual selection per model [full text, Appendix A]. On FLUX GenEval, overall 0.6613 to 0.6986 and colour attribution 0.4575 to 0.5275, vs TACA 0.6793 / 0.4600 [full text, Appendix F, Table 14]. Preference metrics are maintained [full text, Section 6.2]. No layout, LLM or training.
