# Make It Count: Text-to-Image Generation with an Accurate Number of Objects

## What this paper does
CountGen (SDXL) runs the base sampler to t=500, builds an instance layout by Otsu-thresholding the object cross-attention and DBSCAN-clustering self-attention features of one decoder layer (up_52), then corrects the count with ReLayout: over-generation removes the smallest clusters, under-generation calls a U-Net trained on ~10K self-generated (k, k+1) mask pairs that adds one instance per pass. The image is then regenerated from the start, guided by a weighted-BCE cross-attention layout loss (t in [1000,500]) plus self-attention masking (t in [1000,900]). Single object class per prompt, counts up to 10; human-judged accuracy rises from 26% to 54%.

## Goal-by-goal answers
### Goal: What mechanism does it use to read and correct object count, and at what point of the trajectory?
Reading: instance identity is not visible in most layers; only self-attention features of SDXL decoder layer l^up_52 at t=500 (halfway through a 1000-step schedule) separate instances in PCA [full text, Section 3.1]. A foreground mask comes from Otsu on aggregated object cross-attention; foreground self-attention features are DBSCAN-clustered into instance masks [full text, Section 3.1]. Correction: ReLayout removes the smallest instances (over-generation) or iteratively adds one instance with a trained U-Net (Dice + overlap losses, 9-in/10-out channels, up to 10 objects) [full text, Section 3.2, 3.2.1]. Generation then restarts and is steered by a pixel-weighted BCE between cross-attention and the corrected mask (t in [1000,500], all U-Net layers) and by masking background-to-foreground self-attention (t in [1000,900], decoder layers) [full text, Section 3.3; Appendix B.1]. So the count is read at mid-trajectory and enforced by a second full pass.

### Goal: What does it report as its limitations, and what method assumption restricts it to its setting?
Stated limitations: the optimization sometimes puts several instances inside one layout mask; backgrounds become plain; scope is one object type per prompt and at most 10 instances [full text, Section 7]. Cost: ~36 s per image on an A100 80GB vs ~8 s for SDXL [full text, Appendix A]. The method is tied to a specific U-Net layer (l^up_52) and a timestep (t=500) found by inspection, and the under-generation step is a trained network, so it is not strictly training-free [full text, Section 3.1, 3.2.1].

### Goal: Does it handle spatial relations or multiple object categories?
No. Experiments and ReLayout training use single-class templates ("a photo of six cats"); the conclusion lists spatial constraints only as future use of the lessons [full text, Section 7, 8]. ReLayout preserves the existing composition when adding instances but has no relational objective [full text, Section 3.2].
