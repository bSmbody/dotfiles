# Rare Text Semantics Were Always There in Your Diffusion Transformer

## What this paper does
NeurIPS 2025 (ToRA). Finds that scaling up the variance of MM-DiT text-token embeddings before joint-attention blocks makes rare semantics emerge (higher local isotropy). ToRA runs PCA on the text tokens per block and timestep, scales the top-k singular values (elbow point) by sigma > 1 (Token Spacing), and rotates the residual subspace toward a conditional-minus-unconditional semantic vector (Residual Alignment). Training-free; tested on SD3 and FLUX on RareBench, T2I-CompBench and GenEval, plus video and editing.

## Goal-by-goal answers

### Goal: What mechanism does it use against attribute leakage or object omission, and which part of MM-DiT joint attention (image-to-text, text-to-image, text-to-text, image-to-image quadrant, or token states) does it read or modify?
Token Spacing: e = U Sigma V^T; lambda_i <- sigma lambda_i for i <= k; e_hat = U Sigma_tilde V^T (Eq 2) [full text, Section 4.1]. Residual Alignment: Givens rotation aligning v_{k+1} with the projected semantic vector (Eq 3) [full text, Section 4.2]. It modifies all text-token states entering each joint-attention block.

### Goal: Does it account for text tokens being rewritten by image tokens across MM-DiT blocks, or does it treat text tokens as fixed keys or apply a uniform text-side transform?
It acknowledges that joint attention updates text tokens [full text, Abstract, Appendix B]. But the transform is prompt-global: scaling the principal singular values multiplies every token's principal-subspace coordinates by the same sigma, so every pairwise distance in that subspace grows by the same factor (a consequence of Eq 2). Relative proximity, e.g. attribute to its own noun vs to another noun, is unchanged; the method has no notion of which tokens belong together.

### Goal: What limitation, failure case, quality or runtime cost, or external dependency (layout, LLM/VLM, fine-tuning) does it report on this axis?
"Variance scale-up may inadvertently amplify embedding directions unrelated to meaningful semantics", hence Residual Alignment [full text, Section 1, Section 3.4]. Limitations: not tested on long prompts; no theory [full text, Appendix G.1]. Targets rare concepts, not multi-object leakage. No external modules.
