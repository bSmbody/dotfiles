# ATHENA: Adaptive Test-Time Steering for Improving Count Fidelity in Diffusion Models

## What this paper does
ATHENA is a training-free, model-agnostic count-fidelity method evaluated on SDXL, SD3.5-Large and FLUX.1-dev. The steering operation is eps_t + gamma(eps_t - eps_hat_t), renormalised, where eps_hat_t comes from a control prompt. Static uses a count-free control prompt; Feedback and Adaptive use a prompt containing the observed count. Feedback and Adaptive run unsteered to t_est=20, decode x0-hat, and count with GroundingDINO. On a mismatch they restart from the same noise and steer only the first steps (t_steer=5 on FLUX/SD3.5). Adaptive doubles or halves gamma once depending on whether the error direction flipped. On SD3.5-L, ATHENA-dataset accuracy rises from 38.9% to 56.1%.

## Goal-by-goal answers
### Goal: How does it estimate the count and when?
"At early sampling steps, object structure is insufficiently formed and decoded images are too noisy for reliable automated count estimation", so it decodes x0-hat at a fixed intermediate step t_est [full text, Section 4.2, Fig. 2]. The estimator is GroundingDINO [full text, Section 5.1]. t_est=20 on FLUX.1-dev and SD3.5-L, and 30 on SDXL [full text, Appendix C, Table 4]. The paper also states that "early stochastic decisions in the sampling trajectory largely determine object multiplicity and spatial layout", which is why correction is applied at the start of a restarted trajectory [full text, Section 1].

### Goal: What correction mechanism does it apply and is it spatially localized?
The correction is a prompt-difference drift, eps_tilde = eps_t + gamma(eps_t - eps_hat_t), rescaled to ||eps_t||. eps_hat_t uses the original prompt with the count removed (Static) or replaced by the observed count (Feedback/Adaptive) [full text, Section 4.3.1, 4.3.2]. Feedback and Adaptive restart from the same initial noise and steer from T down to t_steer, then run unmodified. Adaptive runs at most two steered trajectories and doubles or halves gamma once [full text, Section 4.3.3]. The drift is a global field over the whole latent: nothing in it encodes where an instance should be added or removed, and gamma must be tuned to avoid overshoot that "flip[s] the error direction" [full text, Section 4.3.3].

### Goal: What are its accuracy/cost on SD3.5-Large and FLUX, and its scope (categories, relations)?
ATHENA dataset: SD3.5-L goes from 38.9% (43.8 s) to 56.1% (70.4 s), and FLUX from 39.4% (45.5 s) to 53.6% (72.5 s). On CoCoCount with FLUX, Static (73.3%) beats Adaptive (70.2%) (Table 2) [full text, Section 5.2]. The setup is one target count k "for a particular object category" [full text, Section 4.1]. Relational phrases in the ATHENA dataset ("lined up along a sidewalk") are context only, not controlled [full text, Section 5.1, Table 1]. Failures come from "inaccurate intermediate detection in especially challenging scenes" [full text, Section 5.3].
