# Images Talk Back: Guiding MMDiTs by Suppressing Image-to-Text Feedback

## What this paper does
Studies the image-to-text (I2T) message in MM-DiT joint attention, i.e. what text queries read from image keys/values (B_{i->t} = A_{i->t} V_i in the text-stream output). Message transplantation between same-prompt success/failure pairs on SD3.5M and FLUX shows that I2T feedback carries, and preserves, the objects and attributes already in the evolving image, including errors. Suppressing it helps and amplifying it hurts. Semantic Feedback Guidance (SFG) guides away from an auxiliary branch with amplified I2T feedback and weakened T2I conditioning during the first 20% of steps (about 1.2x NFE). iSFG applies the suppression in place at zero extra NFE. Evaluated on SD3M, SD3.5M and FLUX (GenEval, T2I-CompBench++, HPSv2.1, ImageReward) and HunyuanVideo.

## Goal-by-goal answers

### Goal: Which part of MM-DiT joint attention does it modify, and is the control per token / per phrase or uniform?
It modifies the I2T message in the text-query rows: O_t = A_{t->t} V_t + B_{i->t}, scaled after softmax so that "joint normalization" and the logits are preserved [full text, Section 2.1, Eq 1]. SFG-X uses (1-u) B_{i->t} in the auxiliary branch; iSFG uses (1+gamma) B_{i->t} with gamma < 0 in the conditional forward, plus (1+gamma_S) on the T2I message [full text, Section 2.3, Eq 3, Eq 5]. The scaling is uniform: "text queries use the original text values and image values scaled by 0.80" in every joint block, for all text tokens and all image tokens [full text, Appendix D.1]. No phrase structure, parser, mask or layout is used. The text stream is reset from E(p) at each denoiser call, so text-side edits do not persist across timesteps [full text, Section 2.1].

### Goal: What evidence does it give that the I2T path matters for compositional errors, and when?
Transplanting a successful trajectory's I2T messages into a failed one rescues failures; norm-matched random messages "rarely change the outcome", and failed-donor transplants rescue only 19.0% [full text, Section 2.2; Appendix F.1, Table 21]. Steps 1-8 of 40 recover about two-thirds of the full-schedule rescues, and late transplants rarely matter [full text, Section 2.2, Fig 5]. On SD3.5M all twelve suppression settings beat base GenEval 0.3481 and all twelve amplification settings fall below it [full text, Section 3.3, Fig 6]. Omission probes: with SFG-X, 72.0% of failures are rescued but 16.7% of successes are disrupted [full text, Appendix G].

### Goal: What gains and costs does it report, especially on attribute binding, counting and position?
iSFG over CFG at zero extra NFE: SD3.5M GenEval 0.6890 to 0.7047, counting 0.6458 to 0.6813, position 0.2150 to 0.2367, colour attribution 0.5767 to 0.5950, HPSv2.1 +1.33. FLUX: GenEval 0.6661 to 0.6868, colour attribution 0.5233 to 0.5417 [full text, Section 3.1, Table 3]. CFG+SFG on FLUX: GenEval 0.7479, colour attribution 0.5933, counting 0.8167 [full text, Section 3.1, Table 2]. Most of the gain comes from the I2T control (SFG-X) rather than the T2I term [full text, Section 3.3, Fig 7a]. Longer windows do not help [full text, Section 3.3, Fig 7b].
