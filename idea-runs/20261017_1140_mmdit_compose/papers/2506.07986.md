# Rethinking Cross-Modal Interaction in Multimodal Diffusion Transformers

## What this paper does
ICCV 2025 (TACA). Identifies two MM-DiT attention issues: visual-to-text attention is suppressed because visual tokens vastly outnumber text tokens in the joint softmax, and QK weighting ignores the timestep. Temperature-Adjusted Cross-modal Attention multiplies the visual-to-text logits by gamma_0 (about 1.2) for early timesteps (t >= t_thresh). Because this alone creates artifacts, the authors add LoRA fine-tuning. Evaluated on FLUX.1-dev and SD3.5-Medium on T2I-CompBench.

## Goal-by-goal answers

### Goal: What mechanism does it use against attribute leakage or object omission, and which part of MM-DiT joint attention (image-to-text, text-to-image, text-to-text, image-to-image quadrant, or token states) does it read or modify?
P_vis-txt(i,j) uses gamma s^vt_ij / tau against unscaled visual-visual logits (Eq 10), with gamma(t) = gamma_0 for t >= t_thresh and 1 otherwise (Eq 11) [full text, Section 3.3]. Only the image-query x text-key block of QK^T (Eq 6) is rescaled, by the same factor for every text token [full text, Section 3.1-3.3].

### Goal: Does it account for text tokens being rewritten by image tokens across MM-DiT blocks, or does it treat text tokens as fixed keys or apply a uniform text-side transform?
Token- and binding-agnostic: one gamma boosts all text tokens equally, with no routing of which image region attends which noun phrase. The text-query rows (text-to-image, text-to-text) are not changed, and the update of text tokens by image tokens is not discussed [full text, Section 3.2-3.3].

### Goal: What limitation, failure case, quality or runtime cost, or external dependency (layout, LLM/VLM, fine-tuning) does it report on this axis?
Training-free TACA causes "artifacts such as distorted object boundaries or inconsistent textures" (floating bowl), so LoRA is used [full text, Section 3.3, Section 4.3, Fig 8]. Over-amplification trades attributes: gamma_0 = 1.3 raises shape/spatial but lowers colour from 0.839 (gamma_0 = 1.2) to 0.787 [full text, Table 4]. Stated limitation: it "lacks the ability to adaptively select an appropriate scaling factor based on the actual degree of text alignment" [full text, Section 5]. FLUX colour 0.7678 to 0.7843 with LoRA r = 64 [full text, Table 1].
