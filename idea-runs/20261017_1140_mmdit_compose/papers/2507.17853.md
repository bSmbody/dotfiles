# Detail++: Training-Free Detail Enhancer for T2I Diffusion Models

## What this paper does
Training-free Progressive Detail Injection. An LLM or spaCy splits a prompt into sub-prompts: a base without modifiers, then one added modifier each. Parallel branches share the first branch's self-attention maps for the first S steps to fix the layout. Attribute deltas are injected into subject regions through binary masks from thresholded cross-attention (Accumulative Latent Modification). A Centroid Alignment plus entropy loss sharpens subject maps by test-time latent updates. It extends to MM-DiT (SD3, FLUX) by using the image-to-image and image-text blocks of the joint attention map, and is evaluated on T2I-CompBench and a style benchmark.

## Goal-by-goal answers

### Goal: What mechanism does it use against attribute leakage or object omission, and which part of MM-DiT joint attention (image-to-text, text-to-image, text-to-text, image-to-image quadrant, or token states) does it read or modify?
Masks B_i from min-max-normalised, thresholded subject maps (Eq 3); latent merge z_{i+1} = z_i + B_i (z_hat_{i+1} - z_i) (Eq 4) [full text, Section 4.2]. Centroid alignment and entropy losses, with latent gradient steps (Eq 6-9) [full text, Section 4.3]. On MM-DiT the joint map is split into four blocks; the image-to-image block is shared across branches for layout and the text-image block gives subject masks (Eq 10-12) [full text, Section 4.4].

### Goal: Does it account for text tokens being rewritten by image tokens across MM-DiT blocks, or does it treat text tokens as fixed keys or apply a uniform text-side transform?
Each branch runs its own sub-prompt, so each branch's text tokens evolve with that branch's image. Leakage is avoided by spatially masking latent deltas between branches, not by controlling text-token updates within one forward pass. The cost is n branches [full text, Section 4.4-4.5].

### Goal: What limitation, failure case, quality or runtime cost, or external dependency (layout, LLM/VLM, fine-tuning) does it report on this axis?
It "relies heavily on the quality and accuracy of the initial self-attention maps"; if the early layout is wrong, injection cannot fix it [full text, Section 7.1]. Needs LLM prompt decomposition and subject identification [full text, Section 4.2]. Multi-branch memory and time are reduced with self-attention propagation and a branch scheduler [full text, Section 4.5].
