# Text Embedding is Not All You Need: Attention Control for Text-to-Image Semantic Alignment with Text Self-Attention Maps

## What this paper does
U-Net-era (SD v1.5) analysis and method (T-SAM). Cosine similarity between text embeddings (cross-attention keys) correlates strongly with the similarity of their cross-attention maps. Text embeddings do not separate syntactically bound pairs (attribute, own object) from unbound pairs, whereas the text encoder's self-attention maps do. Method: test-time latent optimisation so that the cross-attention-map similarity matrix matches the (powered) text-encoder self-attention matrix. Evaluated on TIFA and Attend-and-Excite prompt sets.

## Goal-by-goal answers

### Goal: What mechanism does it use against attribute leakage or object omission, and which part of MM-DiT joint attention (image-to-text, text-to-image, text-to-text, image-to-image quadrant, or token states) does it read or modify?
Loss L(z_t) = sum rho_i |T_ij^gamma - S_ij(z_t)| between the text-encoder self-attention matrix T and the normalised cosine-similarity matrix S of cross-attention maps, with latent updates at a few steps (Eq 14-15) [full text, Section 4.2]. Finding 1: "similar text embeddings can result in overlapping cross-attention maps", and the correlation persists to the final steps (Fig 5) [full text, Section 4.1]. Overlap of unbound object maps goes with missing objects, overlap of bound attribute-object maps with correct binding (Fig 4) [full text, Section 4.1].

### Goal: Does it account for text tokens being rewritten by image tokens across MM-DiT blocks, or does it treat text tokens as fixed keys or apply a uniform text-side transform?
It assumes static text keys from a frozen text encoder; the target matrix comes from the encoder's own self-attention. There is no text stream inside the denoiser [full text, Section 3, Section 4].

### Goal: What limitation, failure case, quality or runtime cost, or external dependency (layout, LLM/VLM, fine-tuning) does it report on this axis?
Experiments only on Stable Diffusion (U-Net); no MM-DiT backbone [full text, Section 5]. It is self-contained (no parser) but needs latent gradients.
