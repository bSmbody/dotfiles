# What's "up" with vision-language models? Investigating their struggle with spatial reasoning

## What this paper does
Builds three controlled benchmarks (What'sUp, COCO-spatial, GQA-spatial) in which captions differ only by a spatial preposition (left/right/on/under/in front/behind), evaluates 18 vision-language models zero-shot, studies LAION-2B to explain failures, and tests remedies (caption-prior renormalisation, prompt changes, fine-tuning, hard negatives).

## Goal-by-goal answers
### Goal: How well do contrastive image-text models resolve which object stands in which spatial relation, when objects are fixed and only the relation changes?
Poorly, near chance. CLIP ViT-L/14 scores 26.1 on What'sUp (4-way, chance 25), 49.5 on COCO-spatial and 47.3 on GQA-spatial (2-way, chance 50); CLIP ViT-B/32 41.8 average; the best model (XVLM fine-tuned on COCO, with box-level supervision) reaches 60.4 average [full text, Sec. 2.3, Table 1]. Scaling model size does not help, and contrastive vs generative objectives make no difference; pair and set accuracies are very poor and some models predict the same 1–2 prepositions for all inputs [full text, Sec. 2.3].

### Goal: Why, and does more data or hard-negative fine-tuning fix it?
Prepositions occur in <0.2% of LAION-2B captions, are ambiguous, and are rarely needed to satisfy the contrastive objective within a batch [full text, Sec. 3]. Fine-tuning on 300k spatial pairs helps in-distribution (+14.6) but drops What'sUp by 4.3; with programmatic preposition-swapped hard negatives CLIP cannot even fit the training set (loss ~5.0 vs 0.01), narrowing to the two captions but not choosing between them; the authors conclude an inductive bias or denser supervision is needed [full text, Sec. 4.3, Sec. 6]. SigLIP-family models are not evaluated.
