# Learning to Refer from Estimated Listener Gaze

## What this paper does
Fine-tunes Molmo-7B-D as a referring-expression speaker by RL against a listener model (Molmo-REC-Gaze) that, given an image and a (partial) referring expression, predicts a word-aligned human gaze scanpath. Rewards are derived from where the estimated fixations land relative to the target box (token- and sequence-level), not only from whether the final guess is right. Compared with speakers trained against outcome-only REC listeners, gaze-trained speakers become far more concise (15.4 → 4.0 words) and, with human listeners, more successful than the base model (75.2 → 80.0%).

## Goal-by-goal answers
### Goal: What listener signal is used as the learning signal, and how is it turned into a reward?
The listener π^G maps (image, expression prefix x_{1:t}, previous fixations) to the next fixation g_t, so each word gets a fixation [full text, Sec. 2]. Four rewards convert (image, box, expression, scanpath) to per-token rewards: SeqLPHit (final fixation in box), SeqAnyHit (any fixation in box), BeforeFirstHit (reward only tokens up to the first fixation in the box, plus EOS on success) and Shaping (potential-based shaping on the distance of each fixation to the box, relative to a random initial fixation outside the box) [full text, Sec. 5]. Optimised with REINFORCE plus a KL penalty to the initial policy and an entropy bonus [full text, Sec. 5, gradient equation]. Training uses 38,131 COCO val images with sampled boxes; no human is in the loop during training [full text, Sec. 5].

### Goal: How does learning from the listener's comprehension process compare with learning from communicative outcome alone?
Outcome-only REC listeners give the largest accuracy gains (up to +10.8 points with humans) but at the cost of references up to 24.4 words; gaze-based listeners give up to +4.8 points with 4.0-word references, closer to humans, and shorter human identification times [full text, Sec. 7]. A control listener that predicts only the final gaze point behaves like REC-Success, so the brevity comes from the process signal, not from the gaze model's training data [full text, App. C.3.1]. The authors' conclusion: learning from observations of "the process of reference comprehension, rather than the outcome of a reference game alone" yields more pragmatically optimal speakers [full text, Sec. 1, 7]. Gaze-Shaping is the only machine speaker whose strategy mix is mostly spatial, like humans [full text, Sec. 7, Fig. 4].

### Goal: What failure modes or safeguards does the method report?
Without the KL penalty, validation reward rises but entropy collapses and references shrink to 1–2 tokens, i.e. reward hacking of the listener model; the KL penalty (β=0.02) is required for all speakers [full text, App. C.1]. Shorter gaze-trained references are more often ambiguous: an accuracy–efficiency trade-off [full text, Sec. 7, App. D.2]. REC-Shaping does well with the machine listener but worse with humans, showing a speaker can exploit a model listener's quirks [full text, Sec. 7].
