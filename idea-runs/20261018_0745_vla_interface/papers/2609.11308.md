# 2AM: Grounding Agent-Side Memory as Guidance for Steerable Action Models in Long-Horizon Manipulation

## What this paper does
A multimodal Agent (Qwen3.8-27B) holds all task memory. It issues per-chunk commands made of sub-task language plus optional normalised 2D grasp_target, place_target and move_target points, to an episodically stateless RGB Action Model (Qwen3-VL-4B + flow-matching expert, 16-step chunks). The Action Model is trained from demonstrations with hint labels recovered from privileged annotations. Training uses structured non-empty hint dropout, Gaussian coordinate noise and future-window sampling for move hints. Evaluated on LIBERO-Mem.

## Goal-by-goal answers
### Goal: What non-language representation is used and how is it injected into the VLA?
Coordinates in [0,1000]², passed as part of the command c_k = (ℓ_k, q_grasp, q_place, q_move); missing fields are omitted [full text, Sec. 2.3, Eq. 3]. Each field has its own validity interval (grasp before acquisition, place across transport, move 10–20 steps ahead) [Table 1, Eq. 5].
### Goal: How much VLA training does reading the cue require, and what happens without it?
The Action Model is trained to read the hints: dropout, noise and jitter are training-time mechanisms [Sec. 3.1–3.2]. With the same Agent and Action Model, language-only steering gives 7.25 strict, 19.42 relaxed and 53.72 completion; adding hints raises them by +4.58, +43.58 and +22.57 [Sec. 4.2]. Against an aligned π0 reproduction, completion goes 70.79 → 76.29 and relaxed success 37.42 → 63.00, while strict success is comparable (11.83 vs 12.25) [Sec. 4.2].
### Goal: What limitation or failure mode does it report for cue adherence or OOD generalization?
Dropout and noise make the Action Model tolerate omitted or imprecise hints, "but they cannot correct a subtask or object binding that already encodes the wrong high-level intention" [Sec. 4.2, Fig. 3]. A 2D interface cannot expose hidden geometry, force or motion history. Results come from one simulated benchmark, and per-hint contributions are not isolated [Sec. 6].
