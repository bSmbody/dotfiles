# Adapting Generalist Robot Policies with Semantic Reinforcement Learning (SARL)

## What this paper does
Treats a frozen VLA's language prompt as a "semantic action" and runs online RL in the induced semantic MDP: a VLM proposes a candidate set of commands from the current image and task (cached to the first N∈{32,64,100} proposals), and a semantic Q-function trained by TD backups selects which command to issue at each step via softmax over Q. Applied to π0.5 fine-tuned on LIBERO-90 (evaluated on LIBERO-10) and Bridge (4 real WidowX long-horizon tasks), it lifts success from ~0% to ~80% in 60–100 online episodes per task, beating DSRL, residual RL and an in-context-learning VLM controller.

## Goal-by-goal answers
### Goal: What mechanism maps the controller/user instruction to phrasing the frozen VLA executes, and at what granularity (per episode / per sub-task / per step)?
Per step: ℓ_t ~ softmax(Q_sem(s_t, ·)) over the VLM-proposed candidate set; Q is learned with TD on (s, ℓ, r, s') [full text, Sec. 4.2, Alg. 1]. This both decomposes the task and picks phrasings, e.g. spatial commands ("move right") instead of naming an OOD object ("hammer") [full text, Sec. 4.1, 5.4].

### Goal: What signal tells the method whether a phrasing is executable, and what does acquiring it cost?
Environment task reward from online interaction, learned per task: 60–100 online episodes per task, with 3 seeded demonstrations per real task [full text, Sec. 5.1–5.2]. The authors state VLMs "fundamentally lack grounding for which commands are actually effective… highly dependent on the deployment setting, the VLA's training data, and other factors the VLM does not have access to" [full text, Sec. 4.2]; the ICL VLM baseline picks plausible but non-executable commands (naming "hammer" makes the VLA grasp a spoon; verb "drop" releases early) [full text, Sec. 5.4].

### Goal: What limitation does it report regarding state/context-dependence or cases where no phrasing works?
Limitations: speed (VLM in the loop) and the prerequisite that the VLA produce diverse behaviours under diverse instructions; whether the learned Q-function generalizes without the VLM is open [full text, Sec. 6]. Four LIBERO-10 tasks remain unsolved by any method [full text, Fig. 4]. Q is learned per task through interaction, so it does not transfer to unseen tasks (also noted by [2610.10526] related work).
