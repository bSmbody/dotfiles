# RDD: Retrieval-Based Demonstration Decomposer for Planner Alignment in Long-Horizon Tasks

## What this paper does
For hierarchical VLAs (VLM planner + visuomotor policy), builds the planner's fine-tuning set by segmenting target-task demonstrations into sub-task intervals that are visually similar to intervals in the low-level policy's own training set. Formulated as optimal partitioning solved by dynamic programming over an interval-similarity score computed from frozen visual-encoder features retrieved against a database of training-set sub-tasks. Evaluated with RACER (RVT policy + LLaVA-8B planner) on RLBench and real-world tasks, outperforming the heuristic decomposer UVD.

## Goal-by-goal answers
### Goal: What mechanism maps the controller/user instruction to phrasing the frozen VLA executes, and at what granularity (per episode / per sub-task / per step)?
Alignment acts on sub-task boundaries only: partitions are chosen so each interval's visual features match training-set intervals [full text, Sec. 3.1–3.3]. The sub-task text attached to each interval is produced separately by f_lang — "labeled manually or generated by a powerful language model" — here Gemini-1.5-flash [full text, Sec. 3.1 line on f_lang; Sec. 4 setup]. So phrasing is not aligned to the policy's language distribution; only temporal granularity is.

### Goal: What signal tells the method whether a phrasing is executable, and what does acquiring it cost?
No executability signal from the policy itself: the proxy is visual similarity in single-frame encoder feature space to the policy's training data; training-free, needs access to the policy's training set [full text, Sec. 3.3, Sec. 5]. Encoders without language integration (VC-1, VIP) perform worst [full text, Sec. 4.1].

### Goal: What limitation does it report regarding state/context-dependence or cases where no phrasing works?
RDD "is agnostic to the 'optimality' of the skills" and depends on the training set being clean; similarity is single-frame [full text, Sec. 5]. It assumes the low-level policy's training data is available, and does not use any rollout feedback from the policy.
