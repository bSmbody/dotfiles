# The Human–VLA Communication Gap: What Humans Leave Implicit and What Policies Cannot Recover

## What this paper does
Diagnostic study (π0.5, π0-FAST, Cosmos3-Edge on DROID-style tasks) separating an information gap (task semantics, grounding, event structure left unresolved by natural human specifications) from a residual execution gap (a fully specified task still depends on how commands are organized and from which robot state they are invoked). Builds a taxonomy of human specifications, mines command templates from each policy's robot-training language to render "policy-facing realizations" (action–object–destination commands), and executes controlled variants of the same tasks.

## Goal-by-goal answers
### Goal: What mechanism maps the controller/user instruction to phrasing the frozen VLA executes, and at what granularity (per episode / per sub-task / per step)?
Policy-facing realization: each grounded event (A,O,D) is instantiated in a template mined from the policy's fine-tuning language, giving an atomic command sequence for compound tasks [full text, Sec. III-C]. Used as a fixed reference for measurement, not learned or adapted per policy behaviour.

### Goal: What signal tells the method whether a phrasing is executable, and what does acquiring it cost?
None beyond training-set template frequency (a language prior); success and partial progress are measured by rollouts for analysis only [full text, Sec. III-C, III-D].

### Goal: What limitation does it report regarding state/context-dependence or cases where no phrasing works?
Even with fully resolved atomic commands, (i) issuing events sequentially beats one compound prompt for all three policies (π0-FAST 8.2%→19.5%), and (ii) invocation state matters: later commands start from arm configurations produced by earlier actions, far from training states; resetting to home before each event improves all policies (+11.8 for π0.5, +5.8 for Cosmos3-Edge) [full text, Sec. IV-D, IV-E]. Grounding-dependent references (attribute/spatial) are comparatively cheap, while missing semantics and undecomposed events are the most expensive terms; "no evaluated architecture recovers implicit event structure reliably" [full text, Sec. IV-E].
