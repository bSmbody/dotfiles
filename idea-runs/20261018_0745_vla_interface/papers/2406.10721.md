# RoboPoint: A Vision-Language Model for Spatial Affordance Prediction for Robotics

## What this paper does
Instruction-tunes a 13B LLaVA-style VLM on procedurally generated simulation data (plus VQA and LVIS) to output image points that satisfy a language-specified spatial relation (object reference and free-space reference), then uses the points with depth and a motion planner for manipulation and navigation.

## Goal-by-goal answers
### Goal: Can a pointing VLM resolve relational references among similar-looking objects into an image location, and how does it compare with general VLMs?
On RoboRefIt (cluttered scenes "with similar-looking objects that can only be distinguished by relational references"), RoboPoint puts 49.8% of predicted points inside the target mask vs 24.1 (Qwen-VL), 19.9 (LLaVA-NeXT-34B), 21.3 (SpaceLLaVA) and 15.3 (GPT-4o); on Where2Place free space 46.8 vs 29.1 for GPT-4o, and it keeps its lead on relation types unseen in fine-tuning (44.5 vs 27.1) [full text, Sec. 5.1, Table 2]. Removing the synthetic reference data drops Where2Place from 46.8 to 13.2 [full text, Table 4]. So referent resolution to a point is a separable, trainable skill, but absolute accuracy is moderate.

### Goal: What does it cost, and what are its limits?
Synthetic data only (no real robot data), fine-tuning projector and LLM of a 13B model [full text, Sec. 3]. Real-robot success depends "critically on the alignment between the point predictions and the language" (+39.5 points over GPT-4V on 7 tasks) [full text, Sec. 5.2]. It gives no confidence estimates and the number of output points is not controllable [full text, Sec. 6 Limitation].
