# VLA Grounder: Language-Conditioning Space Optimization for Black-Box VLA Models

## What this paper does
Inserts a language-conditioning policy q_φ (Qwen3.5-9B with LoRA) between the human instruction and a frozen black-box VLA (π0, OpenVLA). Given the initial image and instruction it emits one short "VLA-grounded" command (object colour/shape, spatial position, simplified target) that is held fixed for the whole rollout. q_φ is trained with GRPO on sparse task-completion reward, with a failure-derived command-space prior that biases exploration toward grounding-relevant variations instead of shallow paraphrases. Evaluated on VL-Think and RL4VLA (MultiPlate, MultiCarrot, Pepper); transfers across π0/OpenVLA checkpoints and to MolmoAct2 on a real SO-101.

## Goal-by-goal answers
### Goal: What mechanism maps the controller/user instruction to phrasing the frozen VLA executes, and at what granularity (per episode / per sub-task / per step)?
q_φ(ũ | o_0, u) is "invoked once at the beginning of the episode, outputs a single command, and keeps it fixed for the full rollout" [full text, Sec. 4.1, Eq. 2]; at inference one command, no reward query [full text, Sec. 4.4]. Learned rewrites: replace symbolic target labels with spatial/visual aliases; rewrite brittle source-object names into colour and shape descriptions [full text, RQ5].

### Goal: What signal tells the method whether a phrasing is executable, and what does acquiring it cost?
Only scalar episode return from rollouts of the frozen VLA, compared within a GRPO group of G commands [full text, Sec. 4.3, Eq. 3, App. E]. Cost: 76,800 rollouts / 83 h on 2×H100 for π0, 12,800 rollouts / 80 h for OpenVLA [full text, App. F Table 12]. Sec. 4.5 notes group-based RL gets no signal if samples differ only in grammar (language aliasing), hence the structured prior. Untrained structured prior "does not reliably identify which command aliases the frozen action policy will execute" [full text, RQ2].

### Goal: What limitation does it report regarding state/context-dependence or cases where no phrasing works?
Gains are largest when the instruction is visually under-specified; "limited on tasks where language is not the only bottleneck: clutter, distractors, wrong object grounding, severe visual misperception, missing low-level manipulation skill, or long-horizon reasoning demands" [full text, Sec. 6.2]. RL4VLA improvements are "more modest" because of multi-object distractors and execution errors [full text, RQ1–RQ2]. No multi-step or sub-task sequencing is studied.
