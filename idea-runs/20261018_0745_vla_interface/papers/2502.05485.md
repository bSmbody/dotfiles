# HAMSTER: Hierarchical Action Models For Open-World Robot Manipulation

## What this paper does
Fine-tunes VILA-1.5-13B on off-domain data (770k RoboPoint points, 320k RLBench paths, 55k Bridge/DROID paths, VQA co-training) to predict a coarse 2D end-effector path with gripper open/close flags, simplified by Ramer–Douglas–Peucker. The path is drawn on the image (colour gradient, gripper circles) or concatenated as extra channels. 3D low-level policies (RVT-2, 3D-DA) trained on small in-domain data with oracle projected paths consume it. The VLM is called once per episode.

## Goal-by-goal answers
### Goal: What non-language representation is used and how is it injected into the VLA?
A 2D path p=[(x_t, y_t, gripper_t)] overlaid on all observation images, or concatenated as channels [full text, Sec. 4.2].
### Goal: How much VLA training does reading the cue require, and what happens without it?
The low-level policy is trained from scratch with path-conditioned imitation on task-specific data, using oracle paths from proprioception projection [Sec. 4.2]. No pretrained VLA is reused as the low-level policy. OpenVLA appears only as a baseline [App. C.2].
### Goal: What limitation or failure mode does it report for cue adherence or OOD generalization?
"The low-level action model is not explicitly constrained to strictly follow the predicted trajectory … it may deviate, interacting with the wrong object." 72% of RVT-2 failures are trajectory-adherence failures, against 10% for 3D-DA [App. E.1–E.2]. Paths are generated once at the start and cannot adapt to scene changes [App. E.1]. The 2D path is a "bandwidth limited" interface that cannot carry force or rotation [Sec. 6].
