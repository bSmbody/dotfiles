## 一、现在大家怎么调用 Astra：四种方式

### 1. 每一步都问 Astra，让它直接给动作

做法：每一轮把图像和状态发给 Astra，它返回末端位姿（或位姿增量）加夹爪指令，执行完再问下一轮。

| 工作 | 调用设计 | 结果 / 成本 |
|---|---|---|
| RoboDojo LLM-as-policy [2609.24170] | `move_eef` / `give_up` 两个工具，每回合最多 100 次调用，中等推理强度 | 42 个任务 22.5%，超过 40 个公开策略；GPT-5.5 只有 0.9%；精度、动态、双臂任务很差 |
| RoboMME [2610.17350] | 整个回合放在**一条连续对话**里：目标、任务视频、每 3 帧取 1 帧，再加它自己之前的回答 | 92.1%；每回合 9.5 次调用、每次 18.3 s、$0.39；末次请求中位 148 张图、16.5k token |
| GPT-GEAR [2610.28259] | Observe / Reference / Act / Status / Finish 五个工具，输出有界的位姿增量，同步执行 | RoboDojo 26.9%，RoboTwin 76.0%；每回合 8–28 分钟，是 VLA 的 9–10 倍以上；真机零样本 40%，给 1 个示范后 80% |
| LIBERO-10 [2610.30051] | `move_to` / `done` / `give_up`，3 档推理强度，1,800 回合，花了 $4,936 | Astra 高强度 44%；Astra 每回合 $7–8；1,400 次失败中有 287 次错误地调用了 `done`；实际移动距离只有指令的 64–72% |
| 真机 9 模型对比 [2610.25287] | `move_to` / `done` / `give_up`，每回合 40 步动作预算 | 性能约 54 天翻一倍；Astra 每个子任务 $4.51、1.1 分钟；Gemini Flash 每个子任务只要 $0.38，但要 4.18 分钟 |
| Agent2Act / RoboColiseum [2610.27865] | Astra 先提多个候选目标，harness 做 IK 可行性检查，再回传“指令与实际的偏差” | 去掉偏差反馈：成功率 90%→80%，耗时翻倍；去掉历史：100%→50% |
| MotorMind† [2609.38078] | 只给 VLM 一个中层动作接口，加异步监控和后台记忆 | LIBERO-PRO 66.7%；真机 xArm6 95% |

### 2. 让 Astra 写代码或工具，一次调用执行多步

| 工作 | 做法 | 结果 |
|---|---|---|
| PyRUA-Lean [2610.01939] | Astra 写 Python cell，组合机器人原语（包括冻结的 VLA），在 cell 内部检查并重试，只返回它要看的图和状态 | 成功率 63.1%→71.7%；调用次数 17.0→8.7；输入 token 少 65%；解出一题花 $0.74–1.63；RoboDojo 51.6% |
| URAI† [2609.39018] | 一个编程 agent 写工具，另一个执行 agent 调用工具；每次工具调用在本地跑完一整段动作 | 5 个 RoboDojo 任务 18%→53%。事先写好的程序只有 24%，每次工具调用后都让 agent 做决定则有 56%，说明**调用之间的决策不能省** |
| HexaShell† [2610.23479] | 一条命令行；失败后由优化 agent 读完整记录、写带测试的工具；运行时只用 RGB、相机标定和关节状态 | RoboDojo 官方评测 46.9%，进度分 53.2 |
| AGP† [2609.12541] / RAX† [2610.22496] | agent 写程序并按物理结果修改；RAX 靠在线探索把成功的决策序列编译成程序 | AGP 真机 8 个配置中 7 个 ≥ 80%；RAX 平均比基线高 37.4% |

## 二、调用层面目前的问题

1. **慢和贵，而且评测把它藏起来了。**
   - 单次调用 18 秒；每回合从几分钟到几小时；长程任务每回合 1M–9M token。
   - 约 98% 的 token 是缓存命中的输入（历史和图像），所以输出不是成本大头，输入上下文才是。
   - 几乎所有仿真评测在 Astra 思考时暂停世界，这一点我们第三轮已经验证过。
   - 现有的降本办法只有两种：少调用（写代码、门控），或者换成更便宜的模型。

2. **Astra 判断不准“我做成了没有”。**
   - RoboMME 上 63 次失败里有 25 次是过早宣布完成；LIBERO-10 上有 287 次错误的 `done`。
   - 它会把“手指合上了”当成已经接触，把画面里“杯柄和挂钩重叠”当成已经挂上；知道没做完，却说不出是哪个条件没满足，于是修正不收敛。
   - agent 自己写的校验器错了 91%。
   - harness 消融里收益最大的单个组件，正是一个“评估执行结果”的反馈子 agent（+9.16 个百分点）。

3. **“说到”和“做到”之间有偏差。** 实际移动距离只有指令的 64–72%；去掉偏差反馈后，成功率掉 10 个点、耗时翻倍。

4. **结果对 harness、推理强度、预算极其敏感，改进很难归因。**
   - 推理强度的效果不单调：Opus 5 从中强度到高强度，12%→6%。
   - 10 倍预算让成功率约翻 3 倍。
   - harness 的单个组件就能带来 10–50 个点的差别，但多数结论每种条件只跑一次、每组 10 个样本。

5. **长程跨阶段干扰成了主要残余失败。** Astra 局部执行已经有 94.1%，困难长程任务却只有 22%；失败主要来自“这一步做对了，却挡住或破坏了后面的步骤”。

6. **经验复用有天花板和代价。**
   - 弱模型自己积累不出有用的经验，只能用强模型的。
   - 强模型被技能库限制时反而变差（92%→61%）。
   - 积累经验后，每回合反而更贵（+41%）。

7. **“何时调用”的门控只看“小模型是不是要失败了”，不估计“这次调用能帮多少”。** 调用时机选对了，现有的干预通道（例如改写指令）也不一定能把调用变成成功。这个方向我们第二轮已经做过，很拥挤。

8. **精度、动态、双臂这些硬伤**，靠调用方式基本绕不过去，需要补感知（K1、SpatialHarness）或交给低层控制。

## 三、我们具体可以做的方向

| 方向 | 解决的问题 | 做法要点 | 算力 / 花费 | 判断 |
|---|---|---|---|---|
| **D1 主动校验：在 Astra 宣布“完成”之前，自己去取证** | 2（也部分解决 3） | 每当 Astra 要调用 `done` 或进入下一步时，校验模块先判断这个物理条件现在能不能看出来；看不出来就选一个取证动作（换视角、腕部相机、试抬一下、读夹爪或力传感器），并有停止规则。可以只在关键步骤调用，同时控制总成本 | 低：仿真 + API | **首推**：问题最清楚，证据最多，模型变强也不会消失（证据不在画面里就是看不到）。要和 interactive perception 讲清楚区别 |
| **D2 条件级的“完成定义”** | 2 | 每一步先从指令推出必须满足的物理条件（夹爪张开、物体被支撑、插入深度……），逐条校验并返回证据，让 Astra 只修没满足的那一条 | 低 | 可以和 D1 合成一篇：先定义要验什么，再决定去取什么证据 |
| **D3 小模型 RL 时的逐轮归因（分担 Astra 的调用）** | 1、6 | 小模型规划器做 RL 时，在每一轮的边界读档重放，把“决策好坏”和“执行器运气”分开，得到逐轮的优势估计 | 中：4–9B 模型加 LoRA | 契合 RL 后训练经验，也不违反服务条款；要和 VinePPO 讲清区别 |
| **D4 调用前预判跨阶段后果** | 5 | 在提交抓取位姿或放置位置之前，估计“从这个结果出发，后面的步骤还能不能完成”；用仿真分支得到真实的跨阶段归因 | 中 | 问题会随模型变强而更突出；要防被拆回 TAMP 的几何回溯 |
| **D5 harness 改进的可信评测** | 4 | 把成功率建模成预算的函数，加入 run 级随机效应，按美元成本分配回合；用公开日志（例如 LIBERO-10 的 1,800 个回合）重新检验现有结论 | 极低 | 稳，但更像评测、统计类工作 |
| D6 每次调用前做逐动作的安全判断 | 安全 | 根据当前画面和下一个动作重新判断伤害，而不是只在开头问一次 | 低 | 便宜、时效强，适合 ACL / EMNLP |
| 不建议：调用门控、延迟补偿、纯换便宜模型 | 1、7 | — | — | 第二、三轮已经验证：拥挤，或者会被拆回经典方法；降本也会被模型降价追上（成本约 23 天减半） |

**建议**：如果主攻“Astra 调用改进”，优先选 **D1，可以和 D2 合并**。理由：

- 它直接作用在 Astra 的调用循环上，针对的是失败里最大的一类（过早宣布完成）；
- harness 消融已经说明“评估执行结果”是收益最大的组件；
- 算力低；
- 实验平台现成：LIBERO-10 的 Inspect Robots harness 和 RoboMME 的代码都公开。

如果想用上 RL 经验，D3 是第二选择。
