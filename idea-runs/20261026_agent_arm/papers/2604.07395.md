# A Physical Agentic Loop for Language-Guided Grasping with Execution-State Monitoring

## What this paper does
Wraps an unmodified learned grasp-and-lift primitive in an agentic loop: an event-based interface plus a Watchdog that turns noisy gripper telemetry into discrete outcome labels {SUCCESS, EMPTY, SLIP, WEAK, STALL, TIMEOUT}, which a bounded deterministic decision policy maps to FINALIZE / RETRY-RESELECT / WAIT_CLARIFY. A small local LLM (TinyLlama-1.1B) parses commands. Real-robot evaluation, 180 final-system trials.

## Goal-by-goal answers
### Goal: How does it verify grasp success and what does a verdict trigger?
Outcome grounding is posed as "physical state abstraction" from execution evidence [full text, Sec III-C, Table I]; Watchdog uses "contact-aware fusion and temporal stabilization": a settle window where effort/closure cues stay consistent, and "micro-lift evidence is used to reject contact-only false positives" [Sec IV-E]. SUCCESS→FINALIZE if semantic check agrees; EMPTY→one retry; SLIP/WEAK/STALL/TIMEOUT→terminal by default [Sec III-D].

### Goal: What limitations does it state?
Watchdog "emphasizes robust separation between empty and non-empty grasps"; label-specific recovery is future work; "feasibility reasoning beyond presence/category constraints remains limited"; the label set covers a single grasp-and-lift primitive [Sec V].
