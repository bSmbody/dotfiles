# Ro-SLM: Onboard Small Language Models for Robot Task Planning and Operation Code Generation

## What this paper does
ACL 2026. Distills LLM knowledge into an onboard SLM (Llama-3.1-8B) for UAV/ground-vehicle task planning and code generation: an LLM synthesizes instructions, corrective LLM code generation (with human correction for tasks of 5+ steps) produces ground-truth code, instructions are augmented, then the SLM gets LoRA SFT and GRPO with an LLM judging whether generated code implies the same robot actions as the ground truth.

## Goal-by-goal answers
### Goal: How is the small planner trained, and does it depend on a stronger model's outputs?
Fully: ground-truth code comes from LLM generation plus human correction [full text, Sec 3.3]; RL reward is an LLM that compares the SLM's code with ground truth for same robot actions [Sec 3.6]. No environment execution reward is used.

### Goal: What limitations are reported?
Task-specific synthesis hard to transfer; ~16GB memory; human involvement needed for complex ground truth; "single-pass generation at inference time ... limits the model's ability to correct intermediate reasoning errors" [Limitations]. Ground-vehicle SR 75% vs 87.5% for the LLM method [Table 4].
