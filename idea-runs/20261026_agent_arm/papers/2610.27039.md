# Embodied Playground: A Long-Horizon Agentic Robotics Benchmark for Physical, Strategic, and Spatial Reasoning

## What this paper does
A benchmark of 410 simulated robotic task environments (launcher aiming, Hanoi, pocket/Rubik's cube, Kongming lock, bookshelf, ManiSkill household) for foundation-model agents that write and run control code through a public SDK (`describe`/`observe`/`step`/`finish`). Defines access levels L0–L3, four prescribed trial conditions per task, per-episode physical and wall-time budgets, and an independent evaluator checking goal, rule compliance and physical validity. Evaluates Codex with GPT-6-Astra (high) and Opus-5.5-extra on EP-100 (400 task–condition pairs) with Pass@1/Pass@2 and audits all failures.

## Goal-by-goal answers
### Goal: Under what protocol is the agent evaluated (paused world, privileged state, trials)?
"Observation reads leave physical time unchanged" [full text, Sec 3.1]; "Observation and tool reads leave simulated time unchanged"; actions advance simulation at the native control rate; dynamics tasks impose event deadlines of 5–20 s of simulated time [Sec 5.3]. So model deliberation consumes no simulated time even in dynamics tasks. L3 "privileged observations" expose "object poses, velocities, geometry, or contacts" [Sec 5.1]; the reported Astra run uses "L3 privileged observations" [Sec 6.1]. Four independently initialized episodes per task group; Pass@2 scored on the first two valid attempts; 69 infrastructure incidents excluded [Sec 5.2, 6.1].

### Goal: What does the audit say the scores measure?
Incomplete rule or threshold disclosure affects 574 of 645 scored failures (88.99%), e.g. launcher joint-speed margins, forbidden-contact thresholds; "the failure distribution cannot be interpreted solely as a measure of agent reasoning or control deficiencies" [Sec 6.3]. Mean time per successful attempt ~6.25 min; provider token usage unavailable, so token-per-success not reported; "controlled access-level, controller, and feedback ablations are needed to separate agent capabilities from evaluation artifacts" [Sec 6.3].
