# FORCA: A Force-Aware Coding Agent for Contact-Rich Robot Manipulation

## What this paper does
FORCA is a coding agent (Claude Fable 5) that writes Python task programs with access to wrist force/torque, RGB-D and a predefined skill codebase (SAM 3, GraspGen, PyRoKi). Programs run on a UR5e without querying the model and contain agent-written force-dependent logic (contact probing, stop conditions, 100 Hz force regulation). Between rollouts the agent inspects force records with visual outcomes, diagnoses failures and revises the code. Five real-robot contact-rich tasks; compared against a vision-only variant of the same agent.

## Goal-by-goal answers
### Goal: How does it use force/torque to decide whether a contact step succeeded?
Contact conditions are task-specific predicates the agent writes into the program (e.g. "when an approach should stop", pause forward motion "when contact is insufficient and resume it once contact is restored") and they run in-loop without the foundation model [full text, Sec III-A, III-B]. In the door-handle case a "sharp rise in resistance marks the end stop"; a later revision "adds an angle condition for accepting an end stop and a force-drop condition before pulling" [Sec IV-D].

### Goal: Who decides the overall task succeeded, and how is the program's verification developed?
Iteration: up to 20 real rollouts / 4 h per run; "Revision stops when the agent declares the program converged"; then the frozen program is run over repeated trials and "Human involvement is limited to execution authorization, scene operations, and final acceptance assessment" [Sec III-C, IV-A]. So the step-level checks are hand-tuned per task by trial-and-error on the real robot, and final success is human-judged.

### Goal: What limitations does it report?
Each iteration takes minutes, mostly agent reasoning, and relies on real rollouts; wrist wrench "do[es] not directly reveal where contact occurs"; for longer sequences or tighter force constraints the agent "may struggle to diagnose failures and revise the program" [Sec V].
