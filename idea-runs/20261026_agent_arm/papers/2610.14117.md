# Make pi0.5 Learn to Call Astra for Reliable Robot Manipulation

## What this paper does
A lightweight CALL head on frozen pi0.5 features predicts when help is needed; a temporal trigger hands control to GPT-6 Astra, which issues end-effector correction chunks or returns control. On LIBERO it reaches 97.5% vs 95.5% for pi0.5, with Astra executing 5.49% of steps.

## Goal-by-goal answers
### Goal: Where do the frontier model's tokens go when it is called selectively?
Total 2,985,877 input vs 190,360 output tokens (35,648 reasoning); 2,346,403 input tokens are cache reuse; per test episode 15,881 tokens overall, 48,444 on LIBERO-10 vs 1,986 on Object [full text, Sec 3.5, Table 7]. Inputs carry images, state, policy proposals, history and the tool interface [Sec 3.5].

### Goal: What does selective frontier consultation cost in throughput?
Pure pi0.5 8.25 env steps/s overall vs 2.58 across all hybrid episodes "due to the latency of Astra consultation and recovery"; LIBERO-10 8.84 vs 1.93 [Sec 3.6, Table 8]. The environment does not advance while Astra reasons (step-driven LIBERO) [Sec 2.3-2.4].
