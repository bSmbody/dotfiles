# LIBERO-Agent: Evaluating General-Purpose Agents for Direct Embodied Manipulation

## What this paper does
An agent-native benchmark built on 200 LIBERO-style tasks where general-purpose agents (GPT-6 Astra, Sol, Claude Opus, Fable, Qwen, DeepSeek, Kimi) choose which observations to inspect, process them with their own tools, and issue native action commands. A 30-task primary suite separates perception, short-horizon and long-horizon (easy / hard by cross-stage difficulty) manipulation. Astra leads (Performance Score 45.0/100). A stage-level diagnosis of the five hard long-horizon tasks (20 stages) separates local execution failures from cross-stage interference.

## Goal-by-goal answers
### Goal: How does the agent handle an action that succeeds locally but makes a later stage fail, and what do the failure analyses show?
The agents have no explicit mechanism; they act natively from observations [full text, Sec 3.1]. Long-horizon stable stage completion: Astra 50.0% easy / 22.0% hard; others <=16.7% easy, 0% hard [Sec 4.2]. In the stage diagnosis, "Cross-stage Interference occurs when actions in one stage disturb, occlude, or undo a physical state established by another stage"; excluding these, Astra's local execution success is 94.1% and local execution is only 23.5% of its reached-stage failures (61.1-83.3% for weaker agents) [Sec 5.1]. Astra's residual failures: "a reasonable placement can occlude or block a later interaction, while a subsequent motion can disturb an object or mechanism whose state was already correct", plus correct operations realized with invalid geometry (tube inserted in wrong orientation) [Sec 5.3, Fig 4].
### Goal: What limitation / open problem does it state for composition?
"stronger local manipulation alone is not sufficient for reliable long-horizon control"; the conclusion names "anticipation of downstream consequences and preservation of previously achieved states as key remaining challenges" [Sec 5.3, Sec 6]. The stage annotation is manual on 5 tasks.
