# Are Frontier VLM Agents Ready to Be Robot Generalists? An Empirical Study with the Embodied Agent Arena

## What this paper does
Embodied Agent Arena: 1,000 cases from 32 established sources plus GeoProbe (168 cases), spanning Geometry, Spatial Reasoning, Affordance, Task Planning and Manipulation; ten VLM agents (GPT-6 Astra, Sol, Claude Fable 5.1, Opus 5.5, Gemini, Qwen, DeepSeek) are run through a minimal harness that leaves decisions to the model via each source's native interfaces. Reports domain scores with run SD and fine-grained diagnostics (scale vs shape errors, subgoal attrition, stopping misjudgments, self-review regressions, token/round/time accounting).

## Goal-by-goal answers
### Goal: Under what protocol are agents evaluated (repetitions, success judge, privileged/native helpers)?
Five runs per repeated metric (Fable three); the last three table columns, including Manipulation task SR, use one run [full text, Table 2]. Termination is distinct from success: the evaluator checks environment state "independently of the agent's declaration" [Sec 3.2]. Manipulation uses "protocol-specific scene/state observations and native grounding helpers": RoboTwin provides "actor localization, pose inspection, planning probes"; CLIPort/VIMA expose "instance inspection and pick-and-place actions"; RoboCasa "fixture and contact localization" [App B.1, Table A4]. Traces show agents reading simulator predicates such as `is_grasped=false` [Sec 4.3]. So manipulation scores are measured with source-specific privileged helpers that differ per source.

### Goal: What does the agent get wrong about task completion and resources?
Agents "stop before the required physical state holds": Gemini 4 and DeepSeek issue `sit`, declare themselves seated and stop; both fail the private verifier [Sec 4.3]. CALVIN: five models reach goal 1 in 7–8/10 episodes but goal 3 in 0–7; only 9/18 episodes reaching four goals finish the fifth [Sec 4.3]. Self-review fixes some answers but flips correct ones (Qwen-27B: fixes 1, breaks 2) [Sec 4.4]. 98.23–99.46% of tokens are prompt tokens; the binding budget differs per episode (rounds vs a 640k-token ceiling vs wall time), so "progress per decision, token expenditure, and elapsed time must therefore be assessed separately against the resource that actually ends the attempt" [Sec 4.4].

### Goal: Does the protocol address real time or sim-to-real?
No: all cases are simulator or fixed-input; time is an accounting quantity only [Sec 3.3, 4.4].
