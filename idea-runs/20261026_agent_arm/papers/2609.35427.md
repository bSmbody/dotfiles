# LLMs are General Asynchronous Agents

## What this paper does
AsyncLLM: an async/await framework in which users (or agents) define concurrent LLM inference coroutines that share composable memory states (CacheBlocks of attention KV caches and Gated DeltaNet recurrent states), batched automatically on GPU. Shows Qwen 3.x models operating asynchronously without task-specific training on streaming video understanding, ViZDoom game agents and system monitoring.

## Goal-by-goal answers
### Goal: What mechanism lets the agent act while it thinks, and what access does it require?
Coroutines (e.g. a background "thinker" and a fast "writer"/action subroutine) read and write shared KV-cache blocks so one stream can act on another's partial thoughts in real time [full text, Sec 3, Fig 2; Sec 3.2]. In ViZDoom, a background thinker sets the course of action and "a faster action subroutine converts it into frame-by-frame actions with an early-exit probe" [Sec 4.3]. This needs direct control of the model's KV/recurrent state, i.e. open weights run locally (Qwen3.6-35B-A3B) [Sec 4.3, Fig 4]; for proprietary models the paper only suggests asynchronous APIs or self-written harnesses as future options [Sec 5].

### Goal: Is it evaluated on robot manipulation, and how does latency enter the evaluation?
No robot manipulation; embodied use is mentioned only as motivation. In ViZDoom the x-axis is "mean delay (forward passes) from observation to taking an action", so latency is measured in forward passes on controlled hardware [Fig 4]. Results show AsyncLLM reacts faster than a sequential agent while preserving reasoning gains, but are "basic capability, not state-of-the-art" [Sec 4.3].
