# Frontier LLMs Enter the World of Robotics: RoboColiseum evaluation with the Agent2Act harness

## What this paper does
Integrates GPT-6 Astra, GPT-6.1 Sol, Claude Opus 5.5 and Gemini 4 Argon into the RoboColiseum benchmark (Instruction Following, Spatial Reasoning, General Manipulation, Robustness tracks) through a shared harness, Agent2Act: the model proposes objectives, candidate EEF targets, gripper commands and an expected outcome; the harness checks kinematic feasibility, executes the best admissible candidate over a bounded horizon, and returns RGB, measured state, optional noisy-depth queries and requested-vs-observed deviation feedback. Reports a leaderboard (Opus leads overall, Astra leads IF and Robustness) and a component ablation showing harness design changes success, planning cost and runtime.

## Goal-by-goal answers
### Goal: Under what protocol is the agent evaluated (episodes, seeds, reasoning effort, success judge)?
"Each model is evaluated once per case", same samples and one fixed random seed, shared harness [full text, Sec III-A]. Astra, Sol, Opus use high reasoning effort; Argon uses medium because high was "too slow ... for large-scale batch evaluation", so "comparisons involving Argon therefore reflect differences in both the model and its reasoning setting" [Sec III-A]. Benchmark-native substep scores decide outcomes, independent of the model's completion judgment [Sec II-D]. Actions "execute over a bounded horizon before a new observation returns control to the model" [Sec II-C] — a turn-based loop.

### Goal: How much do harness components change outcomes and cost, and how reliable is that comparison?
All ablations use Astra (high), ten IF tasks, "each task or layout is run once per condition" [Sec IV-A]. Removing execution-deviation feedback: success 90%→80%, planning decisions 16.7→35.6, mean time 32.50→58.26 min; removing gripper geometry: 90%→70%, time +110%; soft IK: 10/10 vs 9/10 but decisions +180.8%; joint control instead of EEF: 8/10, time −39.6%; removing history on 4 block-in-box layouts: 100%→50%, time 64.65→131.81 min [Sec IV-B]. With n=10 single runs, each 10-point success change is one task. Mean episode runtimes are tens of minutes [Sec IV-B].

### Goal: What privileged or extra information does the harness supply?
Camera calibration, robot/gripper geometry, measured poses, noisy simulated depth (not ground truth); no authored task-specific guidance in the benchmark runs [Sec II-B, Table II].
