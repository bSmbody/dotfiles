# Cracking Mobile Manipulation: From Failure Diagnosis to Agentic Robot System

## What this paper does
Starts from a subtask VLA with 80% success on RoboCasa365 atomic tasks whose hierarchical agentic baseline (Kimi K3 planner, adapted from Harness VLA) reaches 19% on the 20 composite mobile-manipulation tasks. It attributes each of the 81 failed episodes to the earliest unrecovered error (planning 21.0%, navigation/base positioning 25.9%, local manipulation 53.1%), then adds failure-targeted interventions around the frozen VLA: a demonstration-derived skill card, retrieval-based visual memory, an accessibility check with base adjustment, and bounded end-effector adjustment. Success rises to 47% (49% held-out), 14% -> 37% on BEHAVIOR-1K, 5/20 -> 13/20 on a real robot.

## Goal-by-goal answers
### Goal: How does the method detect or handle an action that succeeds locally but makes a later stage fail, and is the dependency anticipated before commitment or only found after failure?
The diagnosed handoff problem is navigation reaching the right workspace but a base pose from which the next manipulation is infeasible ("a critical handoff problem between navigation and manipulation") [full text, Sec 4.3, Finding 2]. The fix is a hand-built check for the immediate next stage only: check_stance segments the target (Grounding DINO + SAM), back-projects depth, and classifies the stance as reachable / marginal / out of reach by distance thresholds "estimated from successful training trajectories and fixed before evaluation"; it "does not validate the joint limits, inverse kinematics, or full-body collisions" [Sec 5.3]. Finding 1 notes that "an early action can alter the scene and invalidate subsequent decisions", handled by visual memory retrieval, not by predicting consequences [Sec 4.3, 5.2].
### Goal: How does it attribute a downstream failure to a cause, and is the attribution validated causally?
Offline only: Codex candidate labels checked by humans, using simulator state; an error counts as recovered if the subtask completes within the next three replans, otherwise the earliest unresolved error is the primary failure (kappa 0.86 on 30 episodes) [Sec 4.2, App C]. The earliest-unresolved rule attributes to the stage where an error became visible, not to an upstream choice that set it up. The attribution guides human design of interventions; the online agent does not attribute.
### Goal: What does it do when a failure-causing state is irreversible, and what limitation does it report?
After the interventions the remaining failures are "incorrect object placement, object drops during transport, and collision-induced scene disruption", which "occur at a later stage of execution and are not fully addressed by the current geometric corrections"; the paper calls this "a moving failure frontier" [Sec 6.2].
