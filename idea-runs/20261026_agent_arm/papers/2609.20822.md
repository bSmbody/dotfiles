# SafeHarness: Coding Agents with Harness for Safe Robot Control

## What this paper does
Coding-agent robot control (a language model writes and runs the controller) under an explicit obstacle constraint on SafeLIBERO. SafeHarness adds obstacle-aware route planning (routes planned and verified before the arm moves, replanned when infeasible) and obstacle-aware contact execution, implemented as stateless tools that hold the obstacle box outside the conversation. +13.7 task success and +23.0 collision-avoidance points over prior SOTA; +31.2 / +57.5 over the same agent without harness.

## Goal-by-goal answers
### Goal: Why does a prompt-stated constraint fail for an agent acting over a long episode, and how is it fixed?
An episode is a single conversation of hundreds of steps; by the time the arm approaches the obstacle the context holds tens of thousands of tokens and the constraint stated at the start is exposed to long-context recall/adherence decay — "a stronger backbone does not remove this exposure" [full text, Sec 3.4, Sec 4.3]. The fix enforces the constraint in tools wherever a motion is decided rather than "requested once at the outset" [Sec 3.4, Sec 5].

### Goal: What does it assume about the hazard?
The hazard is a known geometric obstacle given as a box to the tools; the method does not identify which objects are hazardous or infer semantic consequences [Sec 3.2–3.3].
