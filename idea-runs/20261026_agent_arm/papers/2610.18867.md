# EmbodiedEvo: Self-Evolving Coding Agent For Physical Intelligence

## What this paper does
A coding agent (GPT-6 Astra etc.) controls a robot through a programmatic interface of primitives and composed programs on RoboDojo-Sim. In a per-task Playground scene it explores and distills feedback into reusable code Skills and natural-language Lessons (applicability conditions, failure modes, recovery guidance), which are frozen and given to fresh agents on unseen scenes. Reaches 37.82% success (vs 22.48% published Astra) and transfers Astra's experience to weaker models.

## Goal-by-goal answers
### Goal: How does the method handle preconditions and failures across successive stages of a long-horizon task, and what limitation remains?
Astra's zero-shot failures include "Action decisions lack explicit precondition checks" (starting to manipulate before a demonstration finished) and routines that reach poses without securing the object [full text, Sec 3.3]. The remedy is per-task Lessons recording "applicability conditions, observed failure modes, and guidance for diagnosis and recovery", acquired on one Playground scene per task and frozen [Sec 3.4]. Long-Horizon SR stays at 23.50%, below Simate-beta's 43.42%; "completing some stages can leave the overall task unfinished" and "maintaining successful manipulation across a sequence" is a continuing bottleneck [Sec 4.2]. The paper notes the paired runs "do not isolate one artifact's causal effect" [Sec 4.3].

# EmbodiedEvo: Self-Evolving Coding Agent For Physical Intelligence

## What this paper does
A coding agent controls a RoboDojo-Sim robot through a programmatic interface. In a Playground (one scene per task, resets allowed) it explores and writes executable Skills (parameterized procedures) and diagnostic Lessons (preconditions, failure modes, recovery); these are frozen and given read-only to fresh agents on unseen scenes, with no weight updates. Astra/xhigh reaches 37.82% SR on the full set (published Astra 22.48%); paired dev-set SR 8.50% -> 30.17%. Astra's experience also raises weaker API models (Sol, Luna).

## Goal-by-goal answers
### Goal: Can a weaker model acquire its own experience, or only apply experience a stronger model acquired?
Mostly only apply. Relative to no experience, Astra/xhigh's harness raises SR by 18.72 points for Astra/medium, 8.86 for Sol/xhigh and 5.50 for Luna/xhigh; "Sol reaches 12.03% SR versus 2.50% with its own harness; Luna reaches 5.50% versus zero" [full text, Sec 4.4, Table 6]. Authors: "These gains separate the ability to acquire useful experience from the ability to apply it: a weaker executor can use procedures and conditions that its own exploration failed to establish" [Sec 4.4]. The "weaker" executors are closed GPT-5.6 variants, not small open models.

### Goal: What does an episode cost and does experience reuse reduce cost?
Per Test episode (Astra/xhigh, dev scenes, including failures): no experience $4.058, Skills/Lessons $5.732 (+41.3%), Raw History $12.203 [Sec 4.6, Table 8]. Total usage ~3.96-4.46M tokens per episode; cache reads are 82.6-97.6% of input [Sec 4.5, App E]. So experience raises success but also raises per-episode cost; structured experience is cheaper than raw history mainly on the input side.

### Goal: Where do frontier coding agents spend their budget and what remains hard?
Trajectory analysis: agents "spend interaction and inference budgets establishing effective operations and identifying their preconditions" [Abstract, Sec 3.3]; e.g., Astra first retains a ring at action 367, one third of its 1,100-action budget [Sec 3.3]. Precision full-set SR only 13.25%; future work suggests "Reinforcement learning could further improve exploration and recovery" [Sec 5].
