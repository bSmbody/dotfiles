# 选定的 scope：前沿模型机器人 agent 的“物理完成校验”（2026-10-31）

## 一句话

让 agent 在宣布“这一步做完了”之前，知道该验证哪些物理条件；并在现有画面看不出来时，自己去取证：换视角、看腕部相机、试抬一下、读夹爪或力传感器。

## 为什么选它

1. **问题最大、证据最多。**
   - RoboMME：Astra 的 63 次失败里，25 次是过早宣布完成 [2610.17350]。
   - LIBERO-10：287 次在没做完时调用了 `done` [2610.30051]。
   - HexaShell：30% 的失败是“自称完成，但检查器不认” [2610.23479]。
   - SenseNova：harness 消融里，“评估执行结果”这个组件收益最大，+9.16 个点 [2610.22471]。
2. **模型变强也不会消失。** 证据不在画面里时，换更强的模型也看不到。接触类任务上，VLM 裁判的平衡准确率不超过 0.60 [2609.03611]。悬停在杯沿下方的 160 个失败中，有 148 个被判成成功 [2610.24801]。
3. **已有很强的先验，说明“取证”有用。**
   - 加一个固定的第二视角，下游成功率从 75.6% 提到 94.0%；而在同样的证据上调严阈值，反而掉到 71% [2610.24801]。
   - SpatialHarness 渲染虚拟视角，成功率从 18% 提到 83% [2610.12457]。
4. **低算力，平台现成。** 仿真器的谓词可以直接当真值；LIBERO-10 的 Inspect Robots harness、RoboMME、HexaShell 都开源。
5. **能分阶段出成果。** 第一阶段单独就能成文，所以失败风险被分摊了。

## 和最新工作的区别（10/20–10/27 查新）

| 工作 | 它做了什么 | 和我们的区别 |
|---|---|---|
| RoboJev [2610.33718] | 开源 27B 被动裁判，SO-101 同分布上平衡准确率 95.2% | 只判断给定的帧，不会主动取证 |
| RoboDuo [2610.34108] | 用代码检查任务是否完成，失败后交给原子 VLA 补完剩下的步骤 | 检查也是被动的，只有一个整体结论 |
| EventSync [2610.27917] | 事件监视器结合末端轨迹判断子目标是否完成 | 针对特定事件，不推导条件，也不主动取证 |
| Execution Logs Sway Judges [2610.34151] | 日志里写一句“任务完成”就能骗过 VLM 裁判 | 是一个负面结果，正好支持“需要独立证据” |
| EmbodiedLab [2610.35385] | 为了获取知识而行动（科学实验） | 目标是发现规律，不是校验步骤是否成功 |
| AGM [2608.29537]、Watchdog | 抓取后试抬一下 | 写死在“抓取”这一个动作上 |

**结论**：被动裁判这条线越来越挤；“按条件主动取证、带停止规则、能用于任意步骤”目前还没有人做。但这个窗口期大概只有几个月，要尽快占位。

## 三阶段计划（4–6 个月）

### 阶段 1（第 1–6 周）：诊断基准，**单独可发表**

- 在 LIBERO / RoboCasa / ManiSkill 里用脚本扰动，构造接近成败边界的状态：杯沿下悬停、只插进一半、闭合但没有接触、松手时差一点没落到支撑面上、推的时候夹爪闭着、抽屉没关严。
- 用仿真器谓词当真值，并标注“这个事实从哪些视角或动作看得出来”。
- 测试对象：Astra 等前沿模型的自我判断、VLM 裁判（RoboJev、Qwen-VL）、奖励模型。
- 产出：一份失败分类，以及“给定视角下可判定 / 不可判定”的定量分析。

### 阶段 2（第 6–14 周）：主动、按条件的校验子 agent

- 先从指令推出这一步必须满足的物理条件。
- 逐条判断“现有证据够不够”。
- 不够就选一个取证动作，直到能下结论或预算用完（停止规则）。
- 把它接到开源 harness 上，比较端到端成功率、过早完成率、无效重试和成本。

### 阶段 3（第 14–20 周）：用 RL 训练小模型做取证策略

- 奖励直接来自仿真真值，不使用前沿模型的输出，所以不违反服务条款，也正好用上组里的 RL 经验。
- 目标是让一个 4–8B 的开源校验器，达到或超过前沿模型做校验的效果。

### 可选：SO-101 真机做小规模验证

## 第 2–3 周的 go / no-go

在阶段 1 的小样本（约 200 个边界状态，API 花费约 $50–100）上测两件事：

1. 被动裁判在“标准视角下不可判定”的样本上的准确率；
2. 一个 oracle，从 3–4 个预设取证动作里挑最好的一个，能把准确率提高多少。

判定标准：

- **继续**：被动裁判在不可判定样本上 ≤ 70%，而且 oracle 取证能提高 ≥ 15 个点。
- **转向**：如果被动裁判已经 ≥ 90%，说明瓶颈不在证据，转到备选方向 D3（小模型 RL 的逐轮归因）。

## 主要风险

- **interactive perception / next-best-view 是近亲**：要讲清楚，我们针对的是 agent 的步骤成败校验，带条件推导、停止规则和对 harness 端到端的影响。
- **取证动作可能扰动场景**（试抬会把东西碰歪）：要把“取证代价”纳入决策，并单独测量。
- **竞争很快**：阶段 1 尽早挂 arXiv 占位。
