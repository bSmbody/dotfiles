# Risk-Averse Inference-Time Diffusion Model Alignment with Finite-Sample Guarantees (CVaR-SVDD)

## What this paper does
The paper replaces the expected-cost objective of KL-regularised inference-time alignment with a convex combination of expected cost and CVaR of the terminal cost. Via the CVaR threshold representation it shows the optimal reverse transitions are those of a risk-neutral problem with a risk-adjusted hinge cost, reducing alignment to a one-dimensional threshold search (ternary search with quadratic regularisation). Value functions for the adjusted cost are learned by regression on paired (x_t, x_0) samples, with finite-sample and end-to-end TV guarantees. On synthetic heavy-tailed data and SD1.5 (compressibility, aesthetic) CVaR-SVDD improves tail reward over SVDD.

## Goal-by-goal answers
### Goal: Does the method use a distributional functional of the final reward given x_t (beyond its mean), and in which direction?
Yes, but risk-averse: the terminal cost becomes c_{lambda,eta}(x0)=(1-lambda)c + lambda(eta + (c-eta)^+/(1-beta)), which up-weights the WORST tail of outcomes [full text, Section 3, Eq 5-7], and the value is V_{t,eta}=-alpha log E_{q_{0|t}}[exp(-c_{lambda,eta}/alpha)|x_t] [Theorem 1, Eq 8]. The motivation is safety-style tail control (unstable molecules, collisions) [Section 1], not finding the best of several candidates.

### Goal: What intermediate reward/value estimator does it use, and how is it computed?
A learned regressor on pairs (x_t^i, x_0^i) ~ q_t(x_t) q_{0|t}(x_0|x_t) of the transformed target Y_eta(x0) [full text, Section 5.2, Theorem 3]; images use a "learned hinge-type value function" inside SVDD [Section 6.2]. The threshold eta is optimised per setting from terminal samples [Section 4].

### Goal: What limitation bears on intermediate reward estimation for pruning/resampling?
Guarantees assume exact tilted-transition sampling and realisable linear value classes [Section 5]; image experiments are small (one cat prompt; SD1.5; compressibility and aesthetic) and compare only to SVDD [Section 6.2, Table 2]. The framework does not address pruning schedules or best-of-K selection.
