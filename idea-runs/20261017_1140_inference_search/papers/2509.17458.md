# CARINOX: Inference-time Scaling with Category-Aware Reward-based Initial Noise Optimization and Exploration

## What this paper does
CARINOX combines best-of-N exploration over initial noises with per-seed gradient-based initial-noise optimisation (ReNO-style) on one-step models (SD-Turbo, SDXL-Turbo, PixArt-alpha DMD) for compositional T2I alignment. The objective is a composite reward (HPS + ImageReward + DA Score + VQAScore) chosen offline by a Spearman-correlation study against human judgements on T2I-CompBench++, plus a chi-distribution norm-likelihood regulariser on the noise. It reports ~19% gains on T2I-CompBench++ and HRS.

## Goal-by-goal answers
### Goal: How are multiple verifiers selected and aggregated during search?
Rewards are chosen offline by counting how often each of 12 metrics ranks top-3 in Spearman correlation with human labels per compositional category, giving the fixed set {HPS, ImageReward, DA Score, VQAScore} [full text, Section 4.2]. The composite objective is a sum with "fixed weights ... set to 1 for all rewards"; final best-of-N selection uses the same composite [full text, Section 4.1.1 Eq around line 162-172; Eq 10]. An ablation with category-aware correlation weights, which needs the benchmark's ground-truth category labels per prompt, changes the mean only marginally (e.g., 0.5542 -> 0.5595 on SD-Turbo; 0.5554 -> 0.5539 on SDXL-Turbo) [full text, Appendix F, Table 9].

### Goal: What mechanism limits drift / reward hacking, and what does it report about individual rewards?
Only a noise-space regulariser: maximise the chi^d log-likelihood of ||eps||, K(eps)=(d-1)log||eps|| - ||eps||^2/2, with gamma=0.01, plus gradient clipping "to prevent reward dominance" [full text, Section 4.1.1 "Regularization for Latent Space Consistency", Eq 8-9; Section 7]. Related-work text acknowledges that reward-based noise methods "remain sensitive to reward design (risk of reward hacking)" [full text, Section 2.1]. Individually, each reward helps different categories (DA Score colour/shape, HPS numeracy/2D spatial, VQAScore lagging) and no single reward suffices [full text, Section 6.2]. Evaluation reuses T2I-CompBench++ metrics whose family overlaps with the optimised scorers (VQA-style), so held-out separation is limited [full text, Section 5.3].


### Goal: How is held-out quality evaluated (correction to the last sentence of the previous answer)?
Correction: the full text does not show the T2I-CompBench++ evaluators coinciding with the optimised scorers; T2I-CompBench++ "evaluates eight compositional categories using specialized evaluators for each dimension" [full text, Section 5.3], and there is a 200-prompt human study on a 0-3 scale (SD-Turbo mean 0.46 -> 0.75; SDXL-Turbo 0.62 -> 0.79) [full text, Section 5.2, Table 1]. What does hold is that the reward set was chosen by its correlation with T2I-CompBench++ human annotations [full text, Section 4.2], so the choice of verifiers is tuned offline on the same benchmark family, with weights fixed before search.


### Goal: How large is the effect of the adaptive (category-aware) weighting across all backbones?
Mean T2I-CompBench++ score with uniform vs category-aware weights: SD-Turbo 0.5542 -> 0.5595, SDXL-Turbo 0.5554 -> 0.5539, PixArt-alpha DMD 0.5560 -> 0.5582, i.e. changes of at most 0.0053; the weights require the benchmark's ground-truth category label per prompt [full text, Appendix F, Table 9].
