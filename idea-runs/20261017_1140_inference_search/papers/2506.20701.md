# Diffusion Tree Sampling: Scalable inference-time alignment of diffusion models (DTS / DTS*)

## What this paper does
DTS casts inference-time alignment as tree search over the denoising chain: full rollouts to t=0 are scored by the terminal reward and propagated back through the tree with a soft (log-sum-exp) value backup, so value estimates at noisy nodes improve as more rollouts accumulate. DTS samples children by Boltzmann weights on soft values (asymptotically exact for the tilted target); DTS* greedily selects max soft value with UCT exploration and progressive widening to search for a single high-reward sample. It matches best-of-N reward with up to 5x less compute on text-to-image and 10x on class-conditional FID.

## Goal-by-goal answers
### Goal: What intermediate reward/value estimator does it use for partial trajectories, and why?
It replaces the common chain of approximations — Jensen (soft value ≈ expected reward) then Tweedie (expected reward ≈ r(x̂0)) [full text, Section 3.1, Eq 7-8] — with tree-backed-up terminal rewards. In a 2D mixture-of-Gaussians study, Tweedie predictions "devolve into random predictions" near T, so "value estimates used for guidance are essentially random at higher-noise levels" [Section 3.1, Fig 3]. Against 1000-rollout ground-truth soft values, both one-step Tweedie and a single DDIM rollout show high bias and variance that grow with t, while DTS reduces both by aggregating rollouts [Section 4.4 "Bias-variance analysis", Fig 6].

### Goal: How are estimates turned into selection decisions, and what limitation bears on pruning/resampling?
DTS*: argmax of soft value plus a UCT bonus c_uct*sqrt(log N(parent)/N(child)) — a visit-count bonus, not an estimate of reward spread [Section 4.3, Eq 9]. Accurate values require many full rollouts per tree; control flow is sequential and less parallelisable than SMC [Section 6 "Compute cost"]; learning a value network for a fixed reward is left to future work [Section 6]. VASR reports DTS ~66x slower at matched NFE on CIFAR-10 (see [2604.06779] digest).
