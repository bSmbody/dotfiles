# Deep Reinforcement Learning with Double Q-learning

## What this paper does
Van Hasselt, Guez and Silver show that taking a max over value estimates that contain errors of any source (noise, function approximation, non-stationarity) yields systematically over-optimistic values, that this happens in all 49 Atari games for DQN, and that it degrades the learned policy. Their fix, Double DQN, keeps the argmax under the online network but evaluates the chosen action with a second set of weights (the target network), i.e. it decouples action selection from action evaluation. This removes most of the overestimation and yields better policies, with essentially no extra compute.

## Goal-by-goal answers
### Goal: Why does taking a max over noisy value estimates produce overestimation, and how does it scale with the number of options?
"The max operator ... uses the same values both to select and to evaluate an action. This makes it more likely to select overestimated values" [full text, Section "Double Q-learning"]. Theorem 1: if all true action values are equal and the estimates are unbiased on the whole with mean squared error C>0 over m actions, then max_a Q_t(s,a) >= V*(s) + sqrt(C/(m-1)), with no independence assumption on the errors; the Double Q-learning estimate has a lower bound of zero on its absolute error [full text, Section "Overoptimism due to estimation errors", Theorem 1]. With independent standard-normal errors, Q-learning's bias "increase[s] with the number of actions, while Double Q-learning is unbiased" [Fig 1]; with errors uniform in [-1,1] the overoptimism is (m-1)/(m+1). Overestimation also arises deterministically from flexible function approximation fitted to exact samples [Fig 2].

### Goal: What exactly does decoupling selection from evaluation do, and what assumption must hold for it to remove the bias?
The target becomes Q(S', argmax_a Q(S',a; theta); theta'): selection still uses theta, but the selected action is "fairly evaluate[d]" by a second estimator theta' [full text, Eq 4]. In the analysis the second estimator's errors are generated "identically and independently" [Fig 1 caption]; in Fig 2 the second estimator is fit on different samples. Double DQN uses the target network, which is "not fully decoupled" but "provides a natural candidate for the second value function" and gets "most of the benefit" at minimal cost [full text, Section "Double DQN"]. So the requirement is that the evaluating estimator's errors be (largely) uncorrelated with the errors that drove the selection; full independence is not needed for most of the gain.

### Goal: Does removing the overestimation improve true performance, not just the estimate?
Yes. DQN's value estimates end "much higher than the true values", and on Asterix and Wizard of Wor rising value estimates "coincide with decreasing scores"; Double DQN's estimates are close to the true returns and "the blue straight line is often higher than the orange", i.e. better policies, not only more accurate values [full text, Section "Results on overoptimism", Fig 3]. The authors stress that this is "overoptimism in the face of apparent certainty", distinct from optimism-for-exploration bonuses [Section "Overoptimism due to estimation errors"].
