# Inference-Time Reward Hacking in Large Language Models

## What this paper does
The paper formalises inference-time reward hacking for Best-of-n (BoN), Soft Best-of-n (SBoN) and a new Best-of-Poisson (BoP): as the selection-strength parameter theta (n, inverse temperature lambda, Poisson rate mu) increases, proxy reward and KL from the reference rise, but true reward can peak and then fall. Under monotone-likelihood-ratio conditions the true-reward curve is unimodal, so there is a single hacking threshold. HedgeTune finds that threshold by 1-D root finding on a residual that needs calibration pairs of proxy and true rewards. Experiments are on LLMs (PPE verifiable benchmarks; Pythia proxy RMs trained on AlpacaRM gold labels).

## Goal-by-goal answers
### Goal: What mechanism does it use to mitigate inference-time reward hacking?
"Hedging": choose the selection-strength parameter theta at the hacking threshold theta† where d/dtheta E[r_true] = 0, i.e. stop optimising the proxy where marginal true benefit vanishes [full text, Section 4, Theorem 3, Eq 5-7]. Proxy scores are mapped to per-prompt empirical quantiles u, so the method works on ranks of the proxy [full text, Section 2, Assumption 1; Algorithm 4 Step 1]. Theorem 1 shows f(theta)=E[r_true] is monotone or has a single interior extremum for TP2/MLR families, which covers BoN and BoP [full text, Section 2, Theorem 1 / Corollary 1].

### Goal: What does HedgeTune require, and is the hedge adapted per prompt or per sample?
It requires "black-box access to the true reward to perform a one-time calibration of the parameter theta", stated as the main limitation; suggested sources are verifiable rewards, an LLM judge, or a stronger reward model [full text, Section 4, paragraph after Algorithm 4]. The residual is averaged over prompts and a single theta* is returned ("average residual R_bar(theta*)=0") [full text, Algorithm 4 Step 4]. So the hedge is one global scalar on the selection strength; it does not use any per-sample signal of where the proxy is unreliable. In the human-preference setup without gold access, "a favorable operating point can still be found using traditional hyperparameter search" [full text, Section 5.2].

### Goal: Does it apply to diffusion/image search?
No. All experiments are LLM text (MMLU Pro, MATH, GPQA with InternLM-2/Llama-3/Skywork RMs; Pythia-1.4B with Pythia-44m proxies) [full text, Section 5.1-5.2]. The analysis treats generations as discrete sequences [full text, Section 2 Notation].
