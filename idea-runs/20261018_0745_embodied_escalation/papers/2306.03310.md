# LIBERO: Benchmarking Knowledge Transfer for Lifelong Robot Learning

## What this paper does
LIBERO is a procedurally generated manipulation benchmark built on robosuite. Each task has a language instruction, a PDDL/BDDL initial-state distribution and a goal written as a conjunction of predicates. It provides four suites (Spatial, Object, Goal, LIBERO-100) and studies lifelong-learning algorithms and architectures.

## Goal-by-goal answers
### Goal: How are task goals specified, and could they be enumerated as a finite subgoal set?
"We specify the task goal using a conjunction of predicates", with unary predicates such as Open(X) and TurnOff(X), binary relations such as On(A, B) and In(A, B), and termination "when all predicates are verified true" [full text, Section 4.1]. The scene file lists every object and fixture region, e.g. a goal of (And (Open wooden_cabinet_1_top_region) (In akita_black_bowl_1 wooden_cabinet_1_top_region)) [Appendix C.2]. So the goal atoms of a task, and the object × region relations a scene admits, form a finite set the simulator can check at every step.

### Goal: How do LIBERO-90 and LIBERO-Long relate?
"We split LIBERO-100 into 90 short-horizon tasks (LIBERO-90) and 10 long-horizon tasks (LIBERO-Long). LIBERO-90 serves as the data source for pretraining … and LIBERO-Long for downstream evaluation" [Section 4.2]. Both are drawn from the same 100-task procedural pool, so short single-step instructions and the long tasks share scenes and predicate vocabulary.
