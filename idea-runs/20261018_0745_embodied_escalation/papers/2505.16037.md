# Causal LLM Routing: End-to-End Regret Minimization from Observational Data

## What this paper does
Learns an LLM router from observational data in which each query was answered by only one model, instead of full-feedback data where every model answers every query. Counterfactual utilities (accuracy minus λ·cost) are imputed with a doubly robust estimator, and the routing policy is trained end-to-end to minimise decision regret through two surrogate losses (a classification upper bound and a softmax-weighted regret). An interval-conditioned architecture handles a range of cost preferences. Evaluated on public routing benchmarks with BERT and LLaMA embeddings.

## Goal-by-goal answers
### Goal: Does the router learn a treatment effect / counterfactual benefit of the expensive model from partial-feedback data, and with which estimator?
Yes. Routing is framed in potential outcomes with SUTVA, ignorability and support assumptions, and the potential utility of each model is estimated with the Dudík et al. doubly robust estimator (outcome model plus propensity correction); meta-learners such as Künzel et al.'s are named as admissible alternatives [full text, Section 2.3, Eq 11, Remark 1]. The router is then trained to minimise regret rather than outcome MSE [Section 2.2]. Ignoring treatment bias degrades routing [Section 2.3].

### Goal: What setting does it cover — single-shot or sequential, and is there a free control arm?
Single-shot: the router "select[s] a single LLM for each query" [Section 1]; agentic multi-call workflows are mentioned only as motivation [Section 1]. There is no within-episode timing decision, no notion of an unrecoverable state, and no simulator that gives the cheap model's outcome for free at any state; both arms come from logged deployments.
