# RoboAware: Learning to Coordinate Embodied Skills from Counterfactual Outcomes

## What this paper does
RoboAware puts a learned coordinator on top of a frozen coding agent (Claude Code / Cursor with Claude Opus 4.8, or Codex with GPT-5.5) that writes robot code against a fixed API library. At each of five semantic stages the coordinator picks a policy family, modular APIs or an end-to-end VLA block. It is trained from State-Locked Counterfactual Branching (SCB): restore the same simulator state, have the coding agent generate and execute a block for each admissible family, roll out the suffix, and fit a Qwen3.5-0.8B Q-model with Bellman targets. It reports 77.0% over 100 tasks, including 73.8% on LIBERO-Pro clusters.

## Goal-by-goal answers
### Goal: What does SCB branch over, who generates each branch, and how many branches does training use?
SCB restores a snapshot ξ_i (simulator state plus privileged masks, object poses and reward evaluator), and for each admissible family c "samples a_i^c ~ π_code(·|x_i, c)" and executes it; "reevaluating an existing family edge repeats restoration, code generation, and execution with a fresh code sample" [full text, Section 2.2.2]. Suffixes are also completed by the coding agent. UCB tree search runs K=20 completed suffix simulations per root (budgets 5–50 ablated) on 80 LIBERO-Pro, 4 RoboSuite and 16 RoboTwin training tasks, seed 0 only [Section 2.2.2, Eq 1-2; Appendix A.2]. So every training branch calls the billed frontier coding model, often several times.

### Goal: Does it use a cheap surrogate for the billed model or count the training cost of helper calls?
No. Branch outcomes come from the real coding agent in every branch; privileged simulator signals are used only for rewards (perception and pose scores) [Section 2.2.2, Eq 3]. Budgets are per-block API-call, control-step and 30 s wall-clock limits for sandboxed code [Appendix C.6]; no count of training-time LLM calls, tokens or dollars is reported as a cost of the method. The budget K is a simulation budget, and its ablation shows UCB uses a limited branching budget better than uniform allocation [Section 3, Takeaway 4].

### Goal: What does the coordinator decide at deployment — whether to call an expensive model?
No. It chooses which family (modular vs end-to-end) the coding agent should write next; the frontier coding agent is called at every stage regardless [Sections 2.2.3, Appendix C.5]. The learned value is family-conditioned (helper-conditioned in that sense), not a call/no-call trigger.
