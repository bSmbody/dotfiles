# LIBERO-Plus: In-depth Robustness Analysis of Vision-Language-Action Models

## What this paper does
LIBERO-Plus perturbs LIBERO along seven dimensions: layout, camera, robot initial state, language, light, background and sensor noise. It evaluates OpenVLA, OpenVLA-OFT, π0, π0-FAST, Nora, WorldVLA, UniVLA and RIPT-VLA, probes whether the models use language and vision, and releases a perturbed benchmark and a training set.

## Goal-by-goal answers
### Goal: Do LIBERO-trained VLAs actually follow the language instruction, e.g. a changed target?
Largely not. With a blank instruction, OpenVLA-OFT's success on the object suite "remained largely unchanged, with significant degradation observed only on the long suite" [full text, Section 4.1]. When the target object in instruction and goal is replaced by another object in the same scene, "the model's success rate dropped nearly to zero" (Finding 7). The model "still tended to execute the original target action" (Finding 8) [Section 4.2, Appendix E]. So a suite-trained VLA can behave as a vision-action model that ignores a new subgoal string, except where the training data force language use (the long suite).

### Goal: What language perturbations does it define?
LLM rewrites in three subcategories [Appendix A.6]. R1 Distraction makes the instruction longer and conversational with irrelevant cues. R2 Common Sense replaces object descriptions with commonsense descriptions. R3 Reasoning Chain changes the reasoning complexity of multi-step instructions. These are instruction-side perturbations whose correct decomposition requires semantic reasoning.
