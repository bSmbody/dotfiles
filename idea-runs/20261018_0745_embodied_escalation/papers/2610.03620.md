# UniIntervene++: An Adaptive Intervention Agent for Efficient Real-World Reinforcement Learning

## What this paper does
UniIntervene++ adds a high-level intervention scheduler to HIL-SERL online RL on a real robot. At each option boundary the scheduler chooses among the evolving RL policy, a trajectory-correction controller toward a demonstration point, and a task-structured CodePolicy, as options in a semi-MDP. A Double-DQN learns option values from scheduler rewards that subtract per-call costs, an adaptive probe periodically forces unassisted RL windows to track competence, and assisted experience feeds back into RL. Five real-world tasks; human intervention ratio drops to 0.77%.

## Goal-by-goal answers
### Goal: What target does the help trigger learn — the cheap agent's failure risk or the value of the expert's help — and how is it supervised?
Helper-conditioned option values: Q_ψ(x_n, ω) over ω ∈ {RL, trajectory correction, CodePolicy} trained with the SMDP Double-DQN target y_n = R_n^sched + γ^{k_n} Q_target(x_{n+1}, ω*), where R_n^sched is discounted task reward minus c_TC, c_CP call costs and a duration cost [full text, Section III-B, Eqs 3-6]. The greedy rule picks the option with the highest value, so the call decision compares assisted against unassisted continuation values, not a failure probability.

### Goal: How many expert interventions does training consume, and is the expert cheap?
The assisting controllers are local, unbilled controllers (a TCP feedback controller and a CodePolicy of motion/gripper primitives) [Section III-A], learned online with epsilon-greedy exploration over every option boundary [Section III-B]. There is no budget on assisted calls during learning; the costs c_TC and c_CP are reward penalties, and the probe deliberately spends unassisted windows [Section III-C].
