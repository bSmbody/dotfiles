# Grounding DINO: Marrying DINO with Grounded Pre-Training for Open-Set Object Detection

## What this paper does
Grounding DINO extends the DETR-style detector DINO to open-set detection driven by text. Image features (Swin-T or Swin-L) and BERT text features are fused in three places: a feature enhancer with image-to-text and text-to-image cross-attention, language-guided query selection, and a cross-modality decoder. Sub-sentence text features stop unrelated category names from attending to each other. Pre-trained on detection, grounding and caption data, it detects arbitrary categories or referring expressions given as text, with no training on the target dataset.

## Goal-by-goal answers
### Goal: How does it detect an arbitrary named object category (e.g. "gauge dial", "clock face") without category-specific training?
The text prompt (category names or a referring phrase, up to 256 tokens) is encoded by BERT and fused with image features in the neck, query initialisation and decoder; boxes are classified by contrastive similarity to the prompt tokens [full text, Sec 1, Sec 3.1-3.4, Sec 4.1]. It is evaluated "fully zero-shot", e.g. 52.5 AP on COCO without any COCO training data [full text, Sec 1, Sec 4.2].

### Goal: How well does it transfer zero-shot to diverse real-world domains, and how large is it?
On ODinW (35+ real-world datasets) the Swin-L model sets a zero-shot record of 26.1 mean AP, and the Swin-T model has a higher median AP than GLIPv2-T (11.9 vs 8.9), i.e. more consistent across domains [full text, Sec 4.2 ODinW]. Grounding DINO T has 172M parameters [full text, Sec 4.2, Tab 20]. Zero-shot AP in niche domains is far below full-shot AP, so domain detection is not guaranteed.

### Goal: What limitations does the paper state?
It cannot produce segmentation masks, its training data is smaller than the largest GLIP's, and it "will produce false positive results in some cases" (hallucinated boxes) [full text, Sec 5 Limitations]. Existing open-set detectors, it notes, "do not work well for REC data without fine-tuning" [full text, Sec 5].
