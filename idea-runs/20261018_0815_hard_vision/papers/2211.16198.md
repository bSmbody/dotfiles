# SuS-X: Training-Free Name-Only Transfer of Vision-Language Models

## What this paper does
Training-free "name-only" transfer for CLIP: given only category names, build a labelled support set (SuS) by generating images with Stable Diffusion (with GPT-3 CuPL prompts) or retrieving from LAION-5B, then classify test images with TIP-X, a training-free adapter that uses image-text similarity profiles to weight support labels and combines them with zero-shot logits. SOTA on 19 classification datasets (ICCV 2023).

## Goal-by-goal answers
### Goal: Is there in-domain precedent for synthesising a labelled support set at test time and reading it with a frozen encoder and a training-free head?
Yes, for categories. SuS is built "without such access" to target images, by prompting Stable Diffusion for N images per class name or retrieving top-N LAION images; TIP-X then uses frozen CLIP features of support and test images to compute attention weights over support labels, with no training [full text, Sec 3.1-3.3]. The labels are class names; no counts, lengths or other continuous/low-level quantities are addressed.

### Goal: What does it report about the synthetic-to-real gap?
Support-set size helps some datasets and hurts others, which the authors tie to the domain gap: "if the domain gap is large, it is inimical to provide a large support set" [full text, Sec 4.4, Fig 6]. Support sets "do not always capture the domain characteristics of the true distribution" (lighting, backgrounds, confounders) [full text, Sec 4.4]. It also relies on CLIP having seen the concept in pre-training [full text, Sec 4.5].
