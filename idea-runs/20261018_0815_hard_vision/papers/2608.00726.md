# Foveated Probes Recover Localized Binding Information in Vision Foundation Models

## What this paper does
Keeps SigLIP/SigLIP2/CLIP encoders frozen and varies only the readout over final patch tokens: global average pooling, the pretrained summary token, a learned single-query attention pool ("foveated", optionally with the query computed from the question's text embedding), and an oracle that pools tokens inside the annotated target box. Evaluates on synthetic colour-shape binding under clutter, crowded shape detection, and a GQA-derived paired colour-binding task, with a counterfactual nuisance-to-signal ratio explaining global-readout failures.

## Goal-by-goal answers
### Goal: How is the question-conditioned readout built, and is it trained per task?
The foveated readout scores each patch token by LN(x_i)^T q(Q)/T, softmax-pools tokens, and feeds the pooled vector (concatenated with t(Q)) to an MLP probe; for VQA q(Q)=W_q LN(t(Q)) with learned W_q and temperature [full text, Sec "Foveated Readout", "Probes"]. The query map and probe are trained jointly per task from the task loss (e.g. 6,000 training images for synthetic tasks; 50 epochs over GQA* with a fixed 10-class colour output) [full text, App "Training Protocols"]. So it is question-conditioned only within one trained task with a fixed label space; it is not task-general and is not connected to a generative VLM.

### Goal: What does it show about where low-level evidence is lost in frozen encoders?
Global readouts are near perfect when the target is alone but collapse under clutter, because pooling dilutes localized label-changing evidence while adding nuisance variation (nuisance-to-signal ratio) [full text, Abstract, Sec "Counterfactual Nuisance-to-Signal Ratio"]. On GQA*, question-only 2.3%, GAP 4.3%, foveated 17.0%, oracle 33.0% paired accuracy: foveation closes ~45% of the summary-to-oracle gap, and attends ~5.2 of 729 patches [full text, Sec "Question-Conditioned Foveation on Natural Images"]. The paper concludes apparent blindness can be an interface (readout) failure.
