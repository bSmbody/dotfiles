# Perception or Reasoning? Diagnosing and Tackling Reinforcement Learning Bottlenecks in VLMs

## What this paper does
Introduces PARA, which measures per model-benchmark pair how many current errors are recoverable by stronger perception (a frontier reference model's question-blind description given to the target) versus stronger reasoning (the target's own description given to a frontier reasoner). Finds RL gains shrink as perceptual headroom grows, shows reward/token-level signals reach visual attention only indirectly, and proposes GRAD, group-relative distillation of the best sibling rollout's visual attention into negative-advantage siblings.

## Goal-by-goal answers
### Goal: How does it attribute failures to perception, and what does the attribution assume?
Perceptual intervention: a stronger reference (Claude-Opus-4.8, GPT-5.6-Luna) writes a question-blind description; a failure counts as perception-recoverable if the target then answers correctly; reasoning headroom counts only items the reference also solves from the image [full text, Sec 3.1, Eqs 1-4]. So "perceptual headroom" is bounded by what the frontier references themselves perceive; failures where the reference is also blind are not attributable. Self-description accuracy tracks direct-image accuracy (slope >0.90, R^2=0.97) [full text, Sec 3.2]. MathVista shows more perceptual than reasoning headroom for all four models [full text, Sec 3.3].

### Goal: Does more reasoning-oriented training (RL) fix perceptual errors, and what limits GRAD?
RL gains decrease with perceptual headroom and increase with the reasoning-bottleneck index across algorithms and scales [full text, Sec 4.1, Fig 4]. GRAD picks b(g) = argmax reward sibling; weights w_i = max(-A_i, 0), so "groups with identical rewards are naturally excluded" — when every rollout of an image misperceives, no attention target exists [full text, Sec 5, Eqs 11-13]. It needs white-box attention and on-policy RL on the model being improved.
