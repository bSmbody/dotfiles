# VG-Refiner: Towards Tool-Refined Referring Grounded Reasoning via Agentic Reinforcement Learning

## What this paper does
Addresses tool-integrated visual reasoning models that are misled by wrong detector outputs on referring expression comprehension (REC). Qwen2.5-VL-7B first "thinks" and issues a tool call. A REC expert (EVF-SAM, or a weak GroundingDINO-T at test time) returns a box. The model then "rethinks" and outputs a final box, accepting or overriding the tool. It is trained with GRPO using a piecewise refinement reward: 0.5 when the tool and the final box are both correct, 1 when a wrong tool box is corrected. It introduces the PiTER protocol and the CCR and NSRI_w metrics for refinement ability.

## Goal-by-goal answers

### Goal: What mechanism decides whether to call a tool and whether to trust its output over the model's own reading?
The same VLM arbitrates: B_f = π²_m(I, P¹_CoT, B_t). "Through this reflective process, the refiner learns when to trust or override the expert model" [full text, Section 3.1, Eq 2]. The tool is always called; the arbitration is a second reasoning turn that compares the model's own first-pass hypothesis with the tool box [full text, Section 3.1].

### Goal: What signal (and at what granularity) is the trust/necessity decision based on, and does it require the VLM's weights or logits?
The training signal is instance-level ground-truth IoU of the tool box and of the final box (Eq 3). It is used only as an RL reward, so at inference the trust decision rests entirely on the VLM's own visual reading of the image, query and box. It requires RL on the VLM's weights (GRPO on Qwen2.5-VL-7B) [full text, Section 3.2].

### Goal: What limitation does it report or show on handling incorrect tool outputs or confidently wrong VLM readings?
The method rests on the base VLM already being competent at the task. The paper notes the baseline "can locate the true object" even when REVPT follows the wrong tool box [full text, Section 1]. The base Qwen2.5-VL-7B averages 86.6 Acc@0.5 on RefCOCO/+/g [full text, Table 1], and SFT cold start is skipped "as the baseline model already demonstrates strong refinement ability" [full text, Section 3.2]. Under weak tools the model refines outputs only "to reach performance comparable to its own grounding ability" [full text, Section 4.2]. So correction is capped by the VLM's own perception. The setting where the VLM's perception is the weak link, so that it cannot tell a correct tool output from a wrong one, is not addressed.
