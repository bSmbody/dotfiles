# Vision-as-Inverse-Graphics Agent via Interleaved Multimodal Reasoning (VIGA)

## What this paper does
A training-free, task-agnostic agent that reconstructs a reference image as an executable (mostly Blender) program through a code-render-inspect loop: a VLM writes code, the program is rendered, and the VLM (plus a separate verifier agent) visually compares render and target to produce edit suggestions, with a sliding-window multimodal memory and a semantic skill library. Evaluated on BlenderGym, SlideBench and a new BlenderBench.

## Goal-by-goal answers
### Goal: In this analysis-by-synthesis loop, what compares the synthesised render with the target, and at what call cost?
The comparator is the VLM itself: "the verification process relies only on the agent's ability to interpret discrepancies between renders and reference images", with no auxiliary predictors [full text, Sec 1]. After each render the agent inspects views and "rigorously compares this rendered outcome against the target", turning discrepancies into natural-language feedback; execute_code also triggers "a separate verifier agent" returning modification suggestions [full text, Sec 3.1, App 0.D]. The loop runs up to max_iterate_round=10 iterations, with best-of-N candidates per step selected by CLIP score [full text, App 0.A.1]. So each instance costs many frontier calls, and fine discrepancies are judged by the same VLM perception.
