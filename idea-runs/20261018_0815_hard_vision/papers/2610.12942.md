# In-Context Learning Can Help Vision-Language Models Overcome Training Priors

## What this paper does
Builds a controlled benchmark separating prior-consistent from prior-conflicting (counterfactual) images on counting, colour, shape, object direction and spatial relation, and uses label-balanced visual in-context demonstrations as a diagnostic and black-box remedy. Demonstrations give +27.2% (Qwen3-VL 235B) on counterfactual items while leaving prior-aligned items unchanged, with attention shifting from prior cues to grounding cues.

## Goal-by-goal answers
### Goal: Which perceptual failures can a test-time (prompt-side) intervention fix, and which not?
ICL fixes "training prior dominance", where the visual evidence is encoded but a learned expectation overrides it [full text, Sec 1, Sec 4.1-4.2]. It does not fix unreliable capabilities: gains weaken for 4-5-leg counts, and on 450 synthetic 2D-shape images with counts 8-16, gains vary and some counts (10, 15) fall below zero-shot [full text, Sec 4.3, Fig 7, Tab 2]. The authors' "capability-selection view": ICL "can redirect a reliable capability suppressed by a prior, but does not consistently strengthen an unreliable capability" [full text, Sec 4.3].

### Goal: What cost/limit does the method report?
32-shot interleaved multimodal context "consumes substantial context, increases memory use, and adds latency"; capability absence "still calls for changes to data, training, or architecture" [full text, Sec 5].
