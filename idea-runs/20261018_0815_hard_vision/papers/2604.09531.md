# VisionFoundry: Teaching VLMs Visual Perception with Synthetic Images

## What this paper does
An automated pipeline that, from a task name only, has GPT-5.2 generate question/answer/T2I-prompt triples with answer-determining facts written into the prompt, renders images with text-to-image models, and filters them with a multimodal verifier. It builds VisionFoundry-10K (10 perception tasks x 1k) and fine-tunes (SFT and GRPO) 3B-8B open VLMs, improving MMVP, CV-Bench and RealWorldQA.

## Goal-by-goal answers
### Goal: Is the LLM-synthesised data used at training time or test time, and for which tasks?
Training time only. The dataset is built once per task (1k verifier-accepted samples per task) and used to fine-tune open VLM weights by SFT or GRPO [full text, Sec 2-3, Sec 4.2]. Tasks are orientation, viewpoint, positional context, spatial relation, state, structure, colour, depth order, relative distance and real-world spatial understanding; counting and metric low-level measurement (lengths, intersections) are not among them [full text, Sec 3 "Task selection"]. Gains are reported for Qwen2.5-VL-3B (+6.7 MMVP-pair, +10.5 CV-Bench-3D) [full text, Abstract].

### Goal: What limits it as a remedy for a black-box frontier model?
It needs weight access to the target VLM (SFT/RL), so it cannot be applied to an API model. Images come from T2I models whose rendering of the answer-determining fact must be checked by a verifier VLM, so exact quantities rely on the generator and verifier perceiving them [full text, Sec 2.2-2.3]. Transfer is task-dependent (e.g. Depth Order helps spatial benchmarks but not ScreenSpot-Pro or MMMU) [full text, Sec 4.4 "Task-wise analysis"].
