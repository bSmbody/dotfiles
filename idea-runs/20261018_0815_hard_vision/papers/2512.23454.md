# Automated river gauge plate reading using a hybrid object detection and generative AI framework in the Limpopo River Basin

## What this paper does
A hybrid river-gauge-plate reader (Dec 2025): waterline detection, YOLOv8-pose extraction of the scale's gap geometry, and GPT-4o / Gemini 2.0 Flash reading the numeric level, with the geometric "scale gap" metadata supplied to the LLM in a second stage. Only the arXiv abstract page could be retrieved (lit.py fulltext returned the abs page, 189 lines, no body), so everything below is from the abstract and nothing about the mechanism is claimed beyond it.

## Goal-by-goal answers
### Goal: Does it hand locally measured scale geometry to a frontier model, and does that help?
Per the abstract only (body not retrieved): yes, "incorporating scale gap metadata substantially improved the predictive performance of LLMs", best Gemini Stage 2 at MAE 5.43 cm, RMSE 8.58 cm, R2 0.84 under optimal image conditions, with LLMs sensitive to image quality. The answer is still produced by the LLM reading the image plus metadata, which is the proposal's "better-views / hand-back" configuration rather than its local-interpolation answer; the setting is a single domain (river staff gauges), not a public benchmark. No abstention or labelling margin is mentioned in the abstract.
