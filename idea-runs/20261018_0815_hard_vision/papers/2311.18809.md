# FoundPose: Unseen Object Pose Estimation with Foundation Features

## What this paper does
Training-free 6D pose estimation of unseen objects from one RGB image, given the object's textured 3D model. It renders ~800 templates (black background, fixed light), extracts frozen DINOv2 ViT-L intermediate-layer patch descriptors, retrieves the 5 most similar templates for a real crop by bag-of-words over patch descriptors, matches crop patches to template patches by kNN, solves PnP-RANSAC, and refines by featuremetric alignment on the same frozen descriptors. Outperforms trained RGB methods (MegaPose, GenFlow, GigaPose coarse stages) on the seven real BOP datasets.

## Goal-by-goal answers
### Goal: What is the core mechanism, and why does it bridge the render-to-real gap without training?
Synthetic templates rendered from a model are compared to the real image only through frozen DINOv2 patch descriptors; "reliable correspondences can be established between a real query image and a synthetic template by a simple nearest-neighbor matching", whereas prior methods "train on large-scale, heavily randomized, and task-specific datasets to bridge the synthetic-to-real domain gap" [full text, Fig 1, Sec 1]. No BOP training images are used [full text, Sec 4.1]. Gains: +10/+14/+16 AR over coarse GigaPose/GenFlow/MegaPose [full text, Sec 4.2].

### Goal: Which feature properties matter for reading a geometric state (pose) from renders, and what fails?
Intermediate-layer (layer 18 of 23) descriptors carry positional as well as semantic information; this makes correspondences geometrically consistent on symmetric and texture-less objects, where last-layer descriptors (as in ZS6D) blend into one colour [full text, Sec 3.3 Fig 3, Sec 3.4, Sec 4.3 Tab 2]. DINOv2 beats SAM, CLIP, LoFTR, S2DNet and dense SIFT descriptors in the same pipeline [full text, Sec 4.3]. A global descriptor (the cls token) "contains limited information about the object pose" and retrieves much worse than patch-based bag-of-words, even with the background masked [full text, Sec 4.3, rows 8-9].

### Goal: What does it assume and where does it fail?
It assumes an exact texture-mapped 3D model and a segmentation mask of the instance; wrong CNOS masks are a main failure source (+6-19 AR with ground-truth masks) [full text, Sec 3.1, Sec 4.3]. Patch size 14 px limits precision, which is why featuremetric refinement on the same frozen features is added (+5 AR) [full text, Sec 3.5, Sec 4.2]. PCA is applied per object on valid template patches at 256 dims (128-1024 give marginal differences), not to a few dozen dims [full text, Sec 3.2, Sec 4.3].
