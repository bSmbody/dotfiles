# Seeing Is Not Measuring: Tool-Augmented Metric Spatial Reasoning for Vision-Language Models

## What this paper does
A training-free, predictor-agnostic tool framework in which a small VLM (Qwen3.5-4B) orchestrates 3D detection, projection into a shared world frame and deterministic solvers for distance, size and bearing on ReVSI-Bench multi-view video. It swaps detector backends (GT oracle, Cube R-CNN, OVMono3D, WildDet3D, Grounding DINO + Depth Pro) behind the same tools to decompose error into orchestration vs perception.

## Goal-by-goal answers
### Goal: Does it frame "move metric measurement out of the VLM into deterministic tools" as its thesis, and in which domain?
Yes, in metric 3D spatial reasoning, not instrument reading: "Moving metric computation out of the model's weights and into explicit solvers yields large gains" (abstract); conclusion "Encapsulating 3D geometry behind modular tools lets a small VLM perform multi-view metric spatial reasoning it cannot do from pixels alone" [full text, Sec 1, Sec 5]. Appending camera intrinsics as text lowers MRA (0.46 -> 0.17), i.e. verbalised geometry does not help [full text, Sec 1].
### Goal: How does it attribute error, and does it give any reliability / abstention signal?
It uses a GT-oracle backend and a VLM-free scripted "geometric ceiling" to split error: orchestration costs 0.03 MRA, the monocular detector is the binding constraint, and a weak detector is worse than no tool [full text, Sec 1 contributions, Sec 5]. No abstention or margin signal is proposed; limitations note GT-based frame selection and that part of the gain may come from framing rather than tools [full text, Sec 5 Limitations].
