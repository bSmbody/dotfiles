# DialBench: Towards Accurate Reading Recognition of Pointer Meter using Large Foundation Models

## What this paper does
Introduces RPM-10K (10,730 pointer-meter images with reflections, occlusions, oblique views and thin pointers overlapping scale marks) and MRLM, a trained VLM reader with "Physical Relation Injection": CLIP template features of canonical meter archetypes cross-attend to image features (Key Feature Mining), a mixture-of-experts models pointer–scale interactions, and language-labelled supervision regresses the numeric reading.

## Goal-by-goal answers
### Goal: How does MRLM inject pointer–scale geometry, and does it generalise to unseen meters?
Geometry is injected only as learned attention: templates of six meter archetypes are encoded by CLIP (early, mid and late layers concatenated) and used as queries over image features, then an MoE fuses component interactions; everything is trained end to end on RPM-10K [full text, Sec 4.1–4.3]. No explicit tick lattice, numeral anchoring or needle fit is computed. In the authors' limitation analysis, "the model struggles to predict well on meter images it has never seen before"; adding chain-of-thought traces from VLMs for SFT made numeric predictions worse, and they conclude the model works by reducing reading to image regression [full text, Sec 5.7]. Related work lists earlier pipelines that read scale text and polar-transform the scale region (Li et al., Sun et al.), all with trained components [full text, Sec 2.1].


### Goal: Is RPM-10K public, what is its test split and metric, and how diverse are its dial designs?
The paper states "Both the dataset and source code will be released on https://github.com/Event-AHU/DialBench" [full text, Abstract]; the repo page (checked 2026-10-18) gives Baidu Netdisk and Dropbox download links for the 10,730 images and says model weights were released 2026-07-21. The split is 8,730 train / 2,000 validation, with "no meter instance" shared across splits and the held-out split "reserved solely for final performance reporting" [full text, Sec 3.1-3.2]. Images are frames from meter-reading videos plus nearly 2,000 web images, manually cropped to the dial; six major dial types dominate (ranges 10/3/6, index values 0.1-0.2) [Sec 3.2, Tab 1], so design diversity is concentrated, though over 300 types are claimed overall. Metrics: Ref = |y - y*|/Range, Rel, and Accuracy-epsilon = share with Ref <= 0.01 [Sec 5.1].
