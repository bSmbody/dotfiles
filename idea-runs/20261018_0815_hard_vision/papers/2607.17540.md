# Program Synthesis for Simulation-Based Inference: Joint Model Selection and Parameter Estimation

## What this paper does
Combines LLM program synthesis with neural SBI. From a natural-language problem description an LLM proposes K candidate simulator programs with parameter priors; simulations from each feed pairwise neural ratio estimators (Bayes factors, used for SMC-style resampling and LLM mutation of programs over rounds) and per-model masked-autoregressive-flow NPEs, giving a joint posterior over model and parameters. Benchmarks: damped oscillator, SIR epidemics, and dark-matter subhalo populations from 64x64 gravitational-lensing images.

## Goal-by-goal answers
### Goal: Does prior work already combine an LLM that writes the simulator with simulation-based inference, and is the posterior estimator trained?
Yes. "an LLM proposes candidate simulator programs ... evaluated using neural density estimation" [full text, Abstract, Sec 3.1]. Programs are validated by execution on random draws [full text, Sec 3.1]. The estimators are trained per candidate: neural ratio estimators for evidence and MAF flows for p(theta|x,M) [full text, Sec 3.3-3.4]; the lensing benchmark retrains a ResNet-18 DeepSets set embedder at every SMC round [full text, Sec 4.4]. So LLM-written simulator + SBI exists, but with trained, not in-context, estimators, and in scientific modelling, not VLM perception.

### Goal: Does it handle image observations, and what does it report about counts read from images?
Yes, lensing images. For the lensing case the LLM only emits parameter configurations for a fixed simulator, not code [full text, Sec 3.1, Sec 4.4]. The subhalo count is "only weakly identified" at N=4 images; count posteriors regress toward the prior interior because sub-pixel subhalos leave residuals below noise; with N=20 images the bias disappears [full text, Sec 4.4, Fig 3-4]. Stated limits: LLM programs can pass validation yet implement wrong physics; all benchmarks are in-distribution for the LLM [full text, Sec 5].
