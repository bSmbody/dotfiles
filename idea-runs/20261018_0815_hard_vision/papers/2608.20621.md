# RECOUNT: Reference-guided Counting with Synthetic Visual Exemplars

## What this paper does
Image-guided zero-shot counting: a frozen class-agnostic counter proposes points; a frozen backbone plus a lightweight, category-agnostic residual projection head (trained once on a FLUX.2-generated dataset, SynthAlikes) decides which points belong to the target by nearest-exemplar matching against online-generated galleries of synthetic visual exemplars of the target and its look-alike distractors. Cuts MAE by 55% on LookAlikes and 21% on PairTally versus the best prior zero-shot counter.

## Goal-by-goal answers
### Goal: Does it synthesise query-specific labelled exemplars at test time and read them with a frozen encoder, and what quantity does the synthetic data carry?
Yes for category identity, not for the count. At inference the data engine generates, from one reference image, a positive gallery and distractor galleries; each candidate point is accepted if its nearest prototype is a target exemplar [full text, Sec 3.1.3, Sec 3.3, Eq 3]. The count itself comes from the frozen class-agnostic counter's localisation; the synthetic data only specifies "which" objects, not "how many" [full text, Sec 3, Fig 3]. The projection head is trained (InfoNCE), though once and category-agnostically [full text, Sec 3.2.1].

### Goal: What does it say about frozen-backbone features for dense, small instances?
A fixed 32x32 patch grid means "many instances occupy a single patch and cannot be meaningfully separated"; features blend in dense regions, which they fix with crop-and-reprocess at native resolution [full text, Sec 3.3.1, Fig 9]. Faint discriminative detail sits "beneath a dominant signal" in raw backbone features, so raw cosine similarity collapses look-alikes [full text, Sec 3.2].
