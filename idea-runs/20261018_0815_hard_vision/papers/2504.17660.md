# Effortless, Simulation-Efficient Bayesian Inference using Tabular Foundation Models

## What this paper does
Proposes NPE-PFN: simulation-based inference (SBI) in which the pretrained tabular foundation model TabPFN, used autoregressively over parameter dimensions, serves as a training-free conditional density estimator. A dataset of (parameter, simulated observation) pairs drawn from the prior and the simulator is passed as in-context data, and the posterior for a real observation is read out in a forward pass. Adds nearest-neighbour filtering of simulations to stretch context size, a sequential truncated variant, and tests on the SBI benchmark, a misspecification benchmark, and two neuroscience simulators fit to real recordings.

## Goal-by-goal answers
### Goal: What is the core mechanism, and does it require training on the specific simulator?
In standard NPE a density network q(θ|x) is trained on simulated pairs. NPE-PFN instead sets TabPFN's target y=θ and features x, places the simulation set D in context, and obtains p(θ|x_o) ≈ q_ψ(θ|x_o, D); multivariate posteriors are factorised autoregressively, one TabPFN call per parameter dimension [full text, Sec 2.1-2.2, Eq 1]. No network is trained or tuned per simulator; "this approach bypasses model fitting entirely" [full text, Sec 2.2]. TabPFN was pretrained on synthetic tabular tasks from random structural causal models, with soft limits d_x ≤ 500 features and ≤10^4 context rows [full text, Sec 2.1, Sec 4 Limitations].

### Goal: How simulation-efficient and well-calibrated is it?
With 10^2 simulations NPE-PFN substantially beats flow-based NPE and NLE on all but one SBI benchmark task, and is competitive at 10^3-10^4 [full text, Sec 3.1, Fig 2a]. Posteriors are reported well calibrated (Fig D-3), with slight overconfidence in one HH setting [full text, Sec 3.1, Sec 3.3, Fig 4d]. On the Hodgkin-Huxley model fit to real Allen recordings it matches TSNPE predictive quality with an order of magnitude fewer simulations; on the 31-parameter pyloric model it reaches ~99% valid simulations with <5·10^4 simulations vs 1.5·10^5-1.8·10^7 for prior work [full text, Sec 3.3-3.4].

### Goal: How does it behave when the simulator is misspecified relative to the real data, and how are observations near x_o exploited?
On a 2D Gaussian benchmark with prior and likelihood misspecification, both NPE and NPE-PFN degrade, but NPE-PFN keeps better C2ST over a broader range of misspecification [full text, Sec 3.2, Fig 3]; on real HH data (a potentially misspecified simulator) it still gives close posterior predictives [full text, Sec 3.3]. Filtering keeps only the N_filter simulations nearest x_o (standardised Euclidean distance); the authors show any non-negative weighting f_{x_o}(x) with f(x_o)>0 leaves the posterior unbiased, i.e. an ABC-like local context, and because inference is training-free this per-observation filtering stays amortised [full text, Sec 2.3, App B.2].

### Goal: What limits it for high-dimensional observations such as images?
Feature size is a stated limitation: high-dimensional observations need hand-crafted summaries or a separately pretrained embedding net [full text, Sec 2.3]. With a CNN infomax embedding (spatial SIR images), NPE-PFN works but usually does not beat end-to-end trained NPE; compression independent of the estimator "may discard critical information" [full text, App B.3, D.4]. Inference is slower than amortised flow NPE and cost grows with simulations and dimension [full text, Sec 4 Limitations].
