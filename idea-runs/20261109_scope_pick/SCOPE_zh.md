## 2. 推荐 scope：思考型 VLM 长推理的效率
**一句话**：图像和视频推理模型先吃进几千到几万个视觉 token，再写几千到上万个 token 的思维链。研究在这种负载下，视觉 KV 怎么存、怎么读、什么时候再看，才能让"每答对一题的成本"最低。

### 2.1 为什么选它
- **贴学长的方向**：本质还是 KV、注意力剪枝、变种注意力，只是对象换成了视觉 KV。
- **贴你的兴趣**：多模态和视频推理。
- **领域年轻**：文本 KV 压缩有几十个成熟方法；这个交叉点只有半年历史，baseline 少，空白还多。
- **之前积累的东西都能复用**：每题成本的指标、显存打满的评测条件、H200 上的 vLLM 流程。

### 2.2 已知事实（都来自已读的论文）
| 事实 | 出处 |
|---|---|
| 推理模型失败中 72–78% 是"看错" | 2506.07218 |
| RL 训练过的推理模型对视觉 token 的注意力更低，思维链越长越低 | 2505.21523 |
| 每一步真正用到的视觉 token 很少，而且这个集合随推理在变 | VisionPulse 2605.31457 |
| 多余的视觉上下文会把推理带偏、让它变长 | VisionPulse 2605.31457 |
| 解码阶段 query 的方差远大于 prefill，按 prefill 统计挑视觉 KV 不稳 | MM-ShiftKV 2607.22586 |
| 直接复用旧的视觉 KV 去"再看一眼"，会因为位置编码过期导致解码崩溃 | PRCR 2606.26631 |
| 把裁剪结果换成噪声，DeepEyes / Pixel Reasoner 答案几乎不变 | 2510.23482 |
| 感知失败时，思维链长度和答对时差不多，想得更久也修不好 | L2T 2610.15810 |

### 2.3 近邻（这些就是 baseline）
| 工作 | 做了什么 | 留下的空 |
|---|---|---|
| VisionPulse 2605.31457（ICML'26） | 推理时逐步只读 5% 的视觉 token，推理变短 | 关键集合会变，所以 KV 还得全留着：省了读取，没省显存 |
| MM-ShiftKV 2607.22586 | prefill 阶段挑视觉 KV，模拟解码时 query 的分布 | 只在 prefill 挑一次，长思维链中途不能调整 |
| PRCR 2606.26631 | 重绑定位置后复用视觉 KV，实现"再看一眼" | 重看的内容还是由启发式决定 |
| LoRe 2610.27341（NeurIPS'26） | 预测相关区域，增强对应的 KV，单轮内完成"看" | 需要 RL 训练 |
| RAPO 2605.09614 | 训练让视觉影响在长链里传得更远 | 目标是准确率，不是效率 |
| LPAVR 2611.02780 | 用 MTP 前瞻预测下一步要看哪里 | 交错式推理，测试时启发式 |

### 2.4 看起来还开放的问题（待验证）
1. **显存**：视觉 KV 在长思维链里一直占着显存，可每一步只用到一小部分，而且用到哪部分在变，所以不能直接淘汰。显存打满时，它到底吃掉了多少 batch？
   - 一个有利条件：**视觉 KV 只依赖图像和它前面的 prompt，可以随时从图像精确重算，也可以跨请求共享**；思维链的 KV 则做不到。这种不对称还没有被利用。
2. **视频**：上面这些工作基本在测图像。视频动辄几万个视觉 token，加上长思维链、显存打满，几乎没人测过。
3. **成本口径**：这些论文报的是准确率、单步延迟或"推理变短多少"，没有人报"每答对一题的成本"。

## 3. 前三周做什么（先测量，不急着出方法）
模型：Qwen3-VL-8B-Thinking（必要时加 Qwen3-VL-4B-Thinking）。数据：MathVista、MathVerse、V*、Video-MME、LVBench 各取一个子集。

1. **第 1 周：画出成本账。** 用 vLLM 跑完整推理，记录：
   - 视觉 token 数、思维链长度；
   - 视觉 KV 占显存的比例、占每步读取量的比例；
   - 显存打满时能开多大 batch。
2. **第 2 周：看注意力怎么用视觉 KV。** 每一步对视觉 token 的注意力质量随思维链怎么衰减；关键视觉 token 集合怎么变；答错的题和答对的题有什么区别。
3. **第 3 周：复现 2–3 个 baseline**（VisionPulse、MM-ShiftKV，再加一个通用的 SnapKV 类方法），在同一套评测下算每题成本，看它们是否让思维链变长、是否出现失控。

三周后根据数据决定方法。如果测出来视觉 KV 占比很小，或者 baseline 已经接近上限，就及早换方向。
