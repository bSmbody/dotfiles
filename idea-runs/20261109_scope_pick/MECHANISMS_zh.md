# 思考型 VLM 长推理：可能的机制创新（2026-11-09，只做了快速查新）

共同前提（来自已读论文）：
- 每一步真正用到的视觉 token 很少，而且集合在变（VisionPulse 2605.31457），所以不能简单淘汰；
- 思维链越长，模型对视觉的注意力越低（2505.21523）；
- 72–78% 的错误是看错（2506.07218）；
- 把裁剪结果换成噪声，答案几乎不变，说明模型并不真用"再看一眼"的结果（2510.23482）；
- 视觉 KV 只依赖图像和它之前的 prompt，和后面生成的思维链无关。

## M1 中央凹式原位细化：再看一眼，不加长上下文
- **现在的做法**：裁剪 → 重新编码 → 在上下文末尾追加几千个新 token。每看一次，上下文就变长一截；旧的低清视觉 token 也一直留着。
- **机制**：图像先以低分辨率进入上下文。模型要放大区域 R 时，把 R 按高分辨率编码，**原地替换** R 对应的那些低清 token 的 KV。新 token 用 M-RoPE 的二维坐标，落在同一块空间位置（子网格坐标）。视觉 KV 的总量固定，上下文不随看的次数增长。
- **原理**：视觉记忆始终是"一张图"，只是局部变清晰，和人眼的中央凹、扫视一样。显存上界是常数。
- **附带好处**：旧的低清视图被替换掉，模型没法再"无视裁剪结果、靠旧视图答题"。
- **近邻**：
  - Foveated Compression 2610.07729：prefill 时一次性选一块保留原分辨率，不在推理中细化。它的发现值得警惕：整体缩图是很强的 baseline。
  - PRCR 2606.26631：复用旧 KV 并重绑定位置，但仍然是追加。
  - DeepEyes、ZoomEye、ViCrop：追加裁剪图。
  - LoRe 2610.27341：增强已有 KV，不提供新像素。
- **难点**：
  - 新 token 的深层 KV 要在"图像位置"上补算，而它之后的思维链 KV 是基于旧视图算的，这和 PRCR 遇到的位置问题同类；
  - 同一张图里混合分辨率，对模型是分布外输入，可能需要轻量训练。
- **训练**：可能需要 LoRA。

## M2 视觉 KV 金字塔：粗的常驻显存，细的按需取
- **机制**：显存里常驻池化后的粗粒度视觉 KV（例如 4×4 池化，只剩 1/16）。每个粗 token 加上 log(区域 token 数) 的偏置，使它吸引的注意力质量近似等于整块区域。全分辨率 KV 放在 CPU 内存（或者需要时从图像重算）。每一步先读粗 token；注意力质量集中的区域，再取回对应的细 token 精算。
- **原理**：利用图像的二维空间局部性。关键集合虽然在变，但粗层始终覆盖整张图，所以不会出现淘汰后"再也找不回来"的问题。
- **近邻**：
  - VisionPulse：逐步稀疏读，但 KV 全在显存；
  - 文本上的 Quest（页摘要）、ShadowKV、InfiniGen、OasisKV（卸载 + 按需取回）；
  - VisMemo 2610.25136：跨请求近似复用。
  - 快速查新没找到"按空间金字塔做解码期视觉 KV 分层"的工作，但审稿人可能会说这是"图像版 Quest"。
- **难点**：满 batch 时 PCIe 带宽够不够；粗 token 的注意力质量近似在 RoPE 下准不准。
- **训练**：不需要。

## M3 视频 KV 的"I 帧 + P 帧"编码
- **机制**：借视频编码器的做法，关键帧存完整 KV；其余帧只存相对同一空间位置的低比特残差。读取时，q·k_I 对一组帧只算一次，再加上 q·Δk。
- **原理**：相邻帧高度冗余，这是视频编码的基本假设。
- **近邻**：
  - TempoKV 2610.15324：预测式 KV 量化，但做的是视频**生成**；
  - InfiniPot-V、MuKV、PureKV、StreamingVLM：淘汰、合并、稀疏注意力。
- **难点**：M-RoPE 的时间轴会让同一空间位置在不同帧的 key 发生旋转，残差要在 RoPE 之前算，读取时再旋转。
- **训练**：不需要。

## M4 并行推理共享"看"：一个样本放大，所有样本都能读
- **机制**：多样本推理（例如 16 条采样再投票）时，各样本本来就共享原图的 KV。把 M1 扩展一下：任何一条样本放大区域 R 得到的高清 KV，写入**共享视觉池**，其他样本的注意力也能读到。感知各自做，结果大家共享。
- **原理**：视觉 KV 和各样本的思维链无关，天然可以共享；这是 SwarmEvolve"传 KV 不传文字"在视觉上的版本。
- **近邻**：Hogwild!（文本上共享 KV）、Visual Para-Thinker++ 2606.09290。
- **难点**：样本读到不是自己要的区域，可能被带偏；位置怎么安排。
- **训练**：可能需要。

## 优先级与决定性测量
| 机制 | 机制味道 | 训练 | 风险 | 第 1–2 周测什么来决定 |
|---|---|---|---|---|
| M1 | 强 | 可能需要 LoRA | 中高 | 思考型模型在 V* 和 HR-Bench 上，低清加原地放大能否追平高清；混合分辨率直接塞进去会掉多少分 |
| M2 | 中 | 不需要 | 中 | 视觉 KV 占显存和读取的比例；每步注意力质量在空间上有多集中 |
| M3 | 中 | 不需要 | 中 | 相邻帧同位置 KV 残差的大小（分层、RoPE 前后各测一次） |
| M4 | 强 | 可能需要 | 高 | 先做出 M1 再说 |
