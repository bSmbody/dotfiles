
## Axis: Hardware-efficient training and inference algorithms for linear and sparse attention

### What has been done
- **Chunkwise-parallel linear attention.** Chunkwise forms split the sequence into chunks: a recurrent pass carries the state across chunks, and dense matmuls run inside each chunk. DeltaNet handles the delta rule's non-diagonal transition (I - beta k k^T) in two steps. It compresses products of Householder-like transitions into WY form, then gets the per-chunk W and U from a lower-triangular inverse (the UT transform), so most of the work runs on tensor cores [2406.06484]. Its state-to-state dependency still prevents tiling over the head dimension, so it trains slower than elementwise-gated GLA and its state size is capped [2406.06484]. TFLA adds a second level of sequence parallelism: it tiles inside each chunk, FlashAttention-2 style, and also parallelizes over the embedding dimension. This removes the SRAM cap on chunk size, but it only applies to recurrences that can be rewritten as H = (QK^T)V + Q C_{k-1}. For DeltaNet that means precomputed pseudo-values V* = U - W C_{k-1} [2503.14376]. MDN extends exact chunkwise training to stepwise momentum. Momentum is a second-order recurrence that is still linear in (S, M), and MDN stores corrected values Ṽ instead of recomputing both states in the backward pass [2605.05838]. DeltaTTT keeps a nonlinear two-layer memory trainable in parallel. It gives each layer its own linear reconstruction target, so each layer becomes a delta rule that reuses DeltaNet's chunk scan [2610.08553].
- **Trainable, hardware-aligned sparse attention.** NSA combines compressed, selected and sliding-window branches. Selection is by block and shared across each GQA group so memory access stays contiguous. The compressed branch's attention probabilities serve as the block scores, so selection gets no gradient of its own [2502.11089]. FSA swaps NSA's kernel loop order to KV-block-outer, query-inner, which removes the padding NSA needs when a GQA group has few query heads. The cost is extra kernels for online-softmax statistics and for reduction [2508.18224]. MSA uses a separate per-group dot-product indexer with top-k blocks. The indexer is trained by a detached KL loss to the Main Branch's attention, computed only over the selected tokens after a full-attention warmup [2606.13392]. DashAttention replaces top-k with alpha-entmax routing over chunk summaries. Routed weights bias the Stage-2 softmax, so the routed mass is differentiable end to end [2605.18753]. Exact top-k attention used during SFT through a masked FlashAttention kernel improves top-k decoding, but exact selection needs O(N^2) scores. The learned Lightning Indexer reaches about 60% precision against exact top-k [2512.03494]. In a controlled study, hard top-k gives the gate zero gradient, and soft gates trained jointly with the model barely beat random gates ("routing absorption") [2603.02227].

### Open gaps on this axis
- **Gap:** Hardware-efficient linear-attention training (WY/UT chunk scans, TFLA tiling, two-state momentum chunks) parallelizes a recurrence only when each token's write is affine in the previous state, with coefficients that depend on keys and gates alone. Memories whose write depends nonlinearly on the current state, such as a gradient step through a nonlinear fast-weight network, are left without an exact chunkwise-parallel training algorithm. They must give up either tokenwise causality or joint credit across memory layers.
  - **Near-miss methods and coverage:** [2406.06484] — the WY/UT chunk form is exact, but only because S_t = S_{t-1}(I - beta k k^T) + beta v k^T is affine in S. [2605.05838] — extends exact chunking to momentum, again only because the second-order recurrence stays linear in (S, M). It notes that nonlinear-memory methods (TTT, Titans/LMM, LaCT) fall back to blockwise updates with intra-block non-causality and a training–inference mismatch. [2610.08553] — for a nonlinear two-layer memory, serial chunkwise TTT is slow at small chunks and underperforms fixed-base parallel TTT (28.25 vs 37.87 single-needle). DeltaTTT recovers chunk parallelism only by replacing the joint loss ||B phi(Ak) - v||^2 with separate per-layer linear targets, so layer A never receives credit for layer B's error. [2503.14376] — TFLA tiling applies only to recurrences that reduce to H = (QK^T)V + Q C_{k-1}. Query trail: "gated delta rule parallel training", "nonlinear recurrence parallel training chunkwise", "nonlinear test-time training parallel chunk causal" (since 2025-10), "chunkwise linear attention kernel" (since 2025-10). None returned an exact tokenwise-causal parallel algorithm for a state-nonlinear write.
  - **Methodological deficiency:** Algorithmic limitation. Every exact chunkwise algorithm read here works by unrolling a product of state-independent linear transitions into a triangular solve plus matmuls ([2406.06484] Eq 4-11; [2605.05838] Eq 14-18). The DeltaTTT digest states this outright: "each delta update is affine in the preceding memory state, enabling efficient chunkwise parallel evaluation" [2610.08553, Section 3]. A state-dependent nonlinear write has no such closed-form transition product. The available workarounds therefore change the learning rule itself rather than only its implementation: gradients evaluated at chunk-start or initial states, or local per-layer targets.
  - **Why it matters:** The run's memory-matrix axis wants more expressive update rules to fix the recall loss of fixed-size states. Today any such rule must be co-designed to stay affine in the state, or else trained with a rule that differs from the one used at decoding. Closing this would show whether the weak single-pass fitting and the serial-versus-parallel inversion reported for nonlinear memories [2610.08553] come from the memory form itself or from the parallelization compromise.
  - **Evidence route:** For a state-nonlinear tokenwise write rule, show that a parallel training procedure reproduces the recurrent-form outputs and gradients (exactly, or within a stated numerical tolerance) at chunk sizes of 64-256. Its training throughput should be measured against GDN/DeltaNet kernels. At about 0.4B scale, compare it against serial chunk TTT, fixed-base parallel TTT and DeltaTTT on single- and multi-needle retrieval at 32K. Report whether the quality ordering changes once training matches tokenwise decoding.
- **Gap:** Trainable block-sparse attention kernels get their speed by never computing query-key scores for unselected blocks. The selector's training signal is confined to the blocks it already selected: zero gradient through hard top-k, a KL loss normalized over selected tokens only, or an entmax Jacobian that is zero off the support. So in sparse-only training a relevant block that the selector misses never receives a corrective signal.
  - **Near-miss methods and coverage:** [2502.11089] — NSA's selection scores are the compressed branch's probabilities, so the selection itself gets no gradient. The authors report that an auxiliary-loss selector degraded the loss and that Quest-style heuristic selection had low recall. [2606.13392] — MSA reports that with LM loss alone the indexer "receives little direct pressure to select relevant blocks" and retrieval is poor. Its fix is a KL loss whose teacher and student are both normalized over only the selected tokens after a full-attention warmup, and it lists the residual long-context retrieval gap as open. [2605.18753] — DashAttention makes the routed mass differentiable, but g_ij = 0 masks off-support chunks and the entmax Jacobian applies only within a fixed support. [2603.02227] — hard top-k gives the gate zero gradient (71.22 vs 71.24 ppl, learned vs random), and soft gates trained jointly are absorbed by Q/K/V co-adaptation. Routing works only when learned post-hoc against frozen dense attention. [2512.03494] — exact top-k training needs full O(N^2) scores, and the learned Lightning Indexer reaches about 60% precision against exact top-k.
  - **Methodological deficiency:** Credit-assignment flaw. In every method read, the gradient or loss that trains the selector is computed only over the support the selector chose: MSA "L_KL is computed over the top-k selected positions" [2606.13392, Section 3.2]; DashAttention's Jacobian exists only "within regions where the support remains fixed" [2605.18753, Appendix A]; dM/dG = 0 for hard top-k [2603.02227, Section 3.2]. False negatives (missed blocks) are therefore only corrected by dense phases (MSA warmup, post-hoc distillation on frozen dense Q/K/V), and those phases reintroduce the full-attention cost the kernel was built to avoid. Under joint sparse training the backbone adapts to the selector's mistakes instead (routing absorption).
  - **Why it matters:** The run's Challenge names this failure: a block that looks unimportant now is needed later in long chain-of-thought or multi-key retrieval. The selector's recall on such blocks is exactly what its current training cannot improve without dense compute. Closing the gap would make sparse attention trainable or adaptable from sparse-only compute, which matters for light fine-tuning or conversion of public ≤8B models on 24 GB GPUs where dense warmup at long context is expensive. It would also separate routing quality from backbone co-adaptation.
  - **Evidence route:** Under sparse-only training at a fixed per-query block budget, track selector recall against exact dense top-k on held-out sequences over training. Use RULER multi-key and multi-value retrieval at 32K and a long-CoT math subset where intermediate results are revisited. Compare against NSA-style, MSA-style KL-on-support and DashAttention-style routers, with a random-router control, and report the extra FLOPs over pure sparse attention. Closing the gap would show rising off-support recall without a dense warmup, and a larger learned-versus-random router gap than the 2.2% reported in [2603.02227].


## Axis: Hybrid architectures mixing full attention with linear or recurrent layers

### What has been done
- **Fixed-ratio interleaving (pretrain or convert).** A repeating r:1 block of linear and full layers, with the ratio picked by sweep. Over 72 small models, recall on RULER rises with more full layers and levels off near 3:1, while LM loss stays flat across ratios. A good standalone mixer does not predict a good hybrid mixer [2507.06457]. Opal keeps every fourth layer as full attention by a fixed rule and recovers long-CoT reasoning only through prolonged on-policy distillation of the weights [2609.31947].
- **Choosing layers when converting a pretrained Transformer.**
  - One-swap KL scoring: restore one layer to softmax in an all-linear student, briefly re-distill, then rank layers by the drop in teacher-forced KL on DCLM text [2512.20569].
  - Joint per-layer gates between the frozen full branch and an aligned linear branch, fit by hidden-state L2 at the passkey answer positions plus an L1 linearization penalty [2606.30562].
  - Differentiable search over {Full, Window, Linear} logits with teacher KL plus a relative-cost term, at 4K length [2605.20936].
  - Beam search over restored layers, scored by perplexity on AR / C-EVAL / FineWeb [2603.26556].
  - Leave-one-out MMLU drop, then 100-step KD-loss probes, for a 15B reasoning teacher [2511.02651].
  - In every one of these, the budget K or the ratio is still set by hand.
- **Distillation objective for the converted hybrid.** Perplexity and log-likelihood evaluation hide 5-21 pp generation gaps and can re-rank design choices [2603.26556]. Off-policy KL never trains the student on recurrent states that its own errors produce, so long rollouts drift. On-policy reverse KL with rollout-length doubling fixes this for weights [2609.31947].
- **Compressing the KV of the retained full-attention layers.**
  - GateSight: query-agnostic eviction after prefill. Per-head MLPs read the GDN write gate, decay and value-norm signals to predict a leave-one-out attention-output utility. Budgets follow the attention output gate [2610.14754].
  - HeadWiseKV: a static recency window per KV head, calibrated layer by layer on the cosine of the pre-gate attention output [2609.02029].
  - Oracle-guided sparse prefill: an indexer distilled from each layer's dense attention mass. It covers prefill only [2606.07703].
- **From-scratch hybrids with bounded exact caches.**
  - laLTE: a per-head learnable eviction CNN on the attention layer's own local KVs, next to GDN [2510.20787].
  - HOLA: an exact cache inside each delta-rule layer that keeps tokens with large committed residual beta*||e||, meaning the ones the state represents worst [2607.02303].

### Open gaps on this axis
- **Gap:** Prior Transformer-to-hybrid methods choose which layers keep full attention with signals computed on teacher-forced fixed text: one-swap KL on DCLM, passkey hidden-state alignment, KL+cost search at 4K, or perplexity beam search. But the failure that the retained layers must prevent in long-CoT reasoning comes from the student's own rollouts, where compounding recurrent-state drift happens. So the allocation is never chosen against that failure.
  - **Near-miss methods and coverage:**
    - [2512.20569] scores each layer by teacher-forced forward KL on generic text after a short distillation. It beats every selector baseline on RULER/SWDE but never evaluates reasoning, and 128K NIAH falls to 0.684.
    - [2606.30562] jointly optimizes per-layer gates, capturing inter-layer dependence, but supervises only hidden states at the passkey answer positions of a fixed prefilled document.
    - [2605.20936] searches operator logits with a teacher-forced KL at T=4096 on DCLM.
    - [2603.26556] uses perplexity beam search, and calls it a "cheap comparative proxy", while showing in the same paper that perplexity and generation disagree and re-rank choices.
    - [2511.02651] uses MMLU leave-one-out and short KD-loss probes for a reasoning model, and needs tens of billions of distillation tokens.
    - [2609.31947] is the one method that trains on the student's own long rollouts. It shows off-policy KL misses compounding drift (AIME'24 33.3 vs 17.1 off-policy), but it uses that signal only for weights and keeps a fixed every-fourth-layer allocation.
    - The repeated deficiency across all six: the placement criterion is computed off-policy, on prefixes the hybrid did not generate.
    - Query trail: "layer selection hybrid attention distillation", "which layers keep full attention hybrid model", "hybrid reasoning linear attention", "hybrid Mamba reasoning distillation" (recency, since 2025-06).
  - **Methodological deficiency:** Training-objective mismatch in the selection step. Every selector scores a layer's marginal value as a reduction in teacher-forced divergence (Eq 6 of [2512.20569]; Eqs 10-12 of [2606.30562]; Eq 13 of [2605.20936]). [2609.31947, Section 2] identifies the mechanism that dominates long-generation failure: a student error changes the prefix, which changes S_t for every later step. That mechanism shows up only under student-sampled trajectories. A layer that matters for keeping the student's own long trace self-consistent can therefore be ranked low, and nothing in these selectors can detect it.
  - **Why it matters:** People converting public reasoning models (≤8B) into hybrids for long-CoT serving cannot tell whether a given placement or ratio is right for reasoning, or merely right for teacher-forced recall. Without that, the budget K stays a hand-tuned knob and costly on-policy weight training has to make up for a possibly wrong allocation. If this is closed, we learn which layers carry long-horizon self-retrieval in reasoning models, and the hand-chosen ratio that problem.md names could be set from data.
  - **Evidence route:** At a matched full-attention budget and matched post-selection training, compare placements from teacher-forced selectors [2512.20569, 2606.30562, 2605.20936] against a placement chosen with on-policy rollout signals. Measure AIME/MATH-500 accuracy with thinking enabled as a function of generated length, plus student-teacher divergence along the student's own rollouts. A real closure shows (a) different selected layer sets and (b) a smaller accuracy drop on long traces at equal K. Short-context and RULER scores should not regress.
- **Gap:** KV compression for the retained full-attention layers of pretrained hybrids scores each cached entry by the distortion it causes in that attention layer's own output, with the recurrent layers held fixed or left untouched. This applies to GateSight's leave-one-out utility, HeadWiseKV's per-head output cosine and oracle sparse prefill's per-layer attention mass. None of these criteria can tell an evicted token whose content the co-resident GDN states still carry apart from one that is lost entirely, so the attention cache and the recurrent memory are budgeted as if they were independent.
  - **Near-miss methods and coverage:**
    - [2610.14754] is the closest. It reads GDN write/decay signals, but only as features to predict U(i), which is the exact leave-one-out change of one attention layer's output with "the rest of the forward pass held fixed". After eviction "the GDN states are left untouched". Its signal-utility correlations are modest (+0.09 to +0.33), and scoring happens once, after prefill.
    - [2609.02029] calibrates recency windows per KV head on pre-gate attention-output cosine while "preserving native recurrent paths", and admits it "cannot recover evicted evidence".
    - [2606.07703] keeps per-layer dense-attention-mass supports, for prefill only.
    - [2510.20787] learns eviction from the attention layer's own local KVs in a from-scratch hybrid.
    - [2607.02303] shows the complementary principle (keep exactly what the delta-rule state represents worst, via the residual beta*||e||) beats recency. But it builds the cache inside recurrent layers of a model trained from scratch, not for compressing the full-attention cache of an existing hybrid.
    - So three methods that apply to pretrained hybrids share the layer-local criterion, and the one complementary criterion exists only from scratch.
    - Query trail: "KV cache compression full attention layers hybrid model", "KV cache eviction hybrid model recurrent state", "evicted tokens recurrent memory", "hybrid model KV cache decoding".
  - **Methodological deficiency:** Missing mechanism / wrong objective for eviction in hybrids. The utility being optimized (Eq 2 of [2610.14754]; the SeqCalib cosine of [2609.02029]; the top-k mass of [2606.07703]) measures attention-layer-local reconstruction. It does not measure the end-to-end effect through a stack in which recurrent layers hold a lossy copy of the same history. The eviction rule therefore has no term for redundancy or complementarity with the recurrent state. [2607.02303] shows that such a term (residual against the state) matters for choosing what exact memory keeps. In none of the pretrained-hybrid methods is an evicted token's information routed to, or credited against, the recurrent state.
  - **Why it matters:** In production hybrids (Qwen3-Next/3.x-style, 1 full layer per 3 GDN layers), the attention KV is the only state that grows with length. It is 42x the GDN state at 100K tokens [2610.14754]. That makes it the binding memory cost for long-context and long-CoT serving on 24 GB GPUs. Resolving this would show whether the two memory systems in a hybrid can divide the history between them, so that the attention cache stores only what the recurrent state cannot. That bears directly on how small the full-attention budget can go.
  - **Evidence route:** On a public GDN hybrid (e.g., Qwen3-Next-class) at matched kept fractions, compare layer-local eviction [2610.14754, 2609.02029] with a criterion that accounts for the recurrent state. Measure (a) the end-to-end logit KL of the model with versus without each evicted set, (b) multi-key NIAH/RULER at 32K+, and (c) long-CoT accuracy where the cache also grows during decoding. A real closure keeps the same accuracy at a smaller kept fraction. It should also show that the entries it drops but layer-local methods keep are ones whose information the GDN states still retrieve, checked with a probe on GDN read-outs.
