# Gated KalmaNet: A Fading Memory Layer Through Test-Time Ridge Regression

## What this paper does
GKA is a linear-SSM layer that outputs the solution of a gated, ridge-regularised least-squares problem over all past key-value pairs, y_t = U_t (H_t + lambda_t I)^{-1} q_t, with H_t and U_t exponentially gated sums of k k^T and v k^T. The solve is done approximately by r Chebyshev iterations per token inside a chunkwise kernel, with backward by implicit differentiation. Stability comes from adaptive regularisation lambda_t = a ||H_t||_F. Trained at 2.8B on 100B tokens, then continued to 128K context, against Mamba2, DeltaNet, GDN, GLA and attention.

## Goal-by-goal answers
### Goal: How does GKA make exact ridge-regression memory parallel, and is the per-token solve exact or iterative?
Iterative. GKA notes the KF/RLS recursion is a low-rank-plus-identity Woodbury update but is sequential and loses precision through division [full text, Section 3.1-3.2]. It solves (H_t + lambda_t I) x = q_t with r Chebyshev iterations (CH), because an exact solver costs O(D^3) per t and would need every H_t materialised [Section 4.1]. The gated recurrence is H_t = gamma_t H_{t-1} + k_t k_t^T with a scalar gate gamma_t, plus the ridge lambda_t I added at read time [Eq CH]. Chunkwise kernels carry H at chunk starts and get matrix-vector products H_t xi without forming H_t [Section 4.2.1]. Throughput is "comparable to that of GDN at the same state size" [Section 5.2].

### Goal: What role does the regulariser play in stability, and what does it cost in memorisation capacity?
Section 3.2: the worst-case error of any solver is about epsilon * kappa, so in bf16 the problem "has to be regularized strongly". GKA sets lambda_t = a ||H_t||_F, which bounds kappa <= (a+1)/a [Eq 4]. Appendix I: a large lambda "reduces the memorization capacity". Long-context scores improve as a goes 0.1 -> 0.05, then fall again for 0.05 -> 0.02 -> 0.01 because the larger condition number lowers the quality of the CH solution [Appendix I, Fig 9-10]. With kappa = 51 (a = 0.02), the weight schedule needs up to about 20 iterations to converge at bf16 precision [Appendix B, Remark 1]. So the isotropic ridge is the only stability lever, and it trades directly against capacity.

### Goal: What does it report as limitations on long-context recall?
On RULER synthetic recall GKA is competitive only at 4K and "starts to fall behind afterwards", though it gains over 10% relative on RAG and LongQA [Section 5.3.2]. A gap to attention remains on recall tasks [Section 5.3.1]. Limitations: GKA is optimal only among linear memories; faster variants via sketching the normal equations into a low-dimensional subspace are left as preliminary [Section 7; Appendix J].
