# Dense Backpropagation Improves Training for Sparse Mixture-of-Experts

## What this paper does
Default MoE gives a top-K MoE router a dense gradient without activating more experts. For experts a token was not routed to, it substitutes a default output, an exponential moving average of that expert's outputs on the tokens that did activate it, into the backward pass, so the router receives signal for all experts. It beats standard TopK, SparseMixer and Loss-Free Balancing in MoE pretraining at negligible overhead (NeurIPS 2025).

## Goal-by-goal answers
### Goal: How does it give a sparse top-K router a training signal for the options it did not select, and what alternatives does it compare against?
Under top-K the router gradient term dy/dpi_i is E_i(x) for selected experts and 0 otherwise, so non-activated experts cannot influence the update [full text, Section 3 / Eq 6-7]. Default MoE replaces the missing E_i(x) with an EMA default vector Ê_i, a per-expert input-independent mean, making the missing-term error zero in expectation over x [Section 3.1-3.2 / Eq 8-11]. It compares against SparseMixer, which estimates the true router gradient without straight-through but adds noise and lags TopK early, and finds that much of prior routers' "free lunch" is absorbed by a globally reduced load-balancing loss [Section 4.4]. Structurally this is the MoE version of "selector trained only on its own support"; its fix is a mean-field default rather than sampled exact feedback with known propensities.
