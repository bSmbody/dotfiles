# One-shot Learning with Memory-Augmented Neural Networks

## What this paper does
Meta-learns one-shot classification (Omniglot) and regression with a Neural-Turing-Machine-style memory-augmented network (LSTM controller, content-addressed external memory). Its main architectural contribution is the Least Recently Used Access (LRUA) write module: a usage record that accumulates both reads and writes decides where new content goes, so new items overwrite the least-used slots and recently read memories are preserved. LRUA beats the standard NTM access module on the one-shot task.

## Goal-by-goal answers
### Goal: What is the LRUA mechanism and what signal decides which memory gets overwritten?
Each slot carries a usage weight updated every step as decayed previous usage plus the current read weights plus the current write weights, w^u_t = gamma w^u_{t-1} + w^r_t + w^w_t [full text, Section 3.2 / Eq 5]. The n least-used slots (n = number of reads) are marked by a hard threshold on usage [Section 3.2 / Eq 6-7]. Write weights are a learned sigmoid interpolation between the previous read weights (update the slot just read) and the least-used indicator (fill a rarely used slot) [Eq 8]. Before writing, the least-used slot is zeroed, so "the least used memories simply get erased" [Section 3.2 / Eq 9]. The key point: reads count toward usage, so a slot survives because it was retrieved, not only because it was recently written. The stated aim is to "preserve recent, and hence potentially useful memories" [Supplementary 6.1].
### Goal: Does read-informed usage measurably beat a write-order/location-based memory controller?
Yes on their task. On 15-class Omniglot episodes with an LSTM controller, MANN-LRUA reaches 62.6 / 79.3 / 86.6 / 88.7 / 95.3% at the 2nd/3rd/4th/5th/10th instance, against 35.4 / 61.2 / 71.7 / 77.7 / 88.4% for the same MANN with the standard NTM access module; "a MANN with a standard NTM access module was unable to reach comparable performance" [full text, Section 4.2 / Table 2]. When memory is not wiped between episodes, performance degrades from proactive interference [Section 4.2.1]. The authors list learning the addressing procedure itself by meta-learning as future work [Section 5].
### Goal: What assumption does LRUA rely on, and what is its cost structure?
It relies on temporal locality of reuse: a slot read recently is likely to be needed again, so read history is a usable proxy for future demand [Section 3.2]. Slots are discrete addressable rows with softmax content addressing; usage is a per-slot scalar recurrence that is a cheap running sum, and the least-used selection is a hard top-n threshold [Eq 5-7]. There is no claim about distributed (superposed) memories such as a linear-attention matrix; the transfer to key directions in a matrix state is not tested in this paper.
