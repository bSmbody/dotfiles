# Depth Memory

## What this paper does
Treats mixing of representations across Transformer depth as storing and retrieving information in a memory, and unifies PreLN, mHC and AttnRes as "streams". Proposes Linear Depth Memory (LDM): a linear associative memory carried across layers whose write is exact recursive least squares (Sherman-Morrison), with learnable per-layer exponential forgetting factors, per-token importance weights and a decaying ridge. This adds a dense inverse-covariance stream per group. A CuTe-DSL implementation uses state unwinding (reconstructing earlier states in backward) and windowed writes (reads inside a window of E layers computed from the window-start state plus rank-1 RLS terms).

## Goal-by-goal answers
### Goal: Does LDM run exact RLS along the sequence axis, or give a chunk-parallel exact RLS form?
No. RLS runs along depth only [full text, Section 3.2 / Eq 6-8]. The authors state that "for sequence mixing, efficient training and prefill motivate parallelizable (approximate) solvers", and that they can use exact Sherman-Morrison RLS only because layers are evaluated sequentially in depth anyway [Section 3.2; Appendix A.2]. Appendix A.2 calls the sequence-axis RLS recurrence of the MesaLayer "inherently sequential". The windowed write [Section 3.3 / Eq 10] defers state materialisation, but the gains kappa_l are still computed layer by layer; it is not a block-parallel solve.

### Goal: What forgetting rule does LDM use, and is it directional?
Uniform exponential forgetting with learnable per-layer (per-group) factors lambda_j, and a ridge that decays with the same factors, P_{-1} = alpha I [Section 3.2 / Eq 6-8]. P_l = (P_{l-1} - kappa k^T P_{l-1}) / lambda_l, so forgetting rescales the whole covariance. Nothing is directional or subspace-restricted.
