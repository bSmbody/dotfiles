# CARVE: Content-Aware Recurrent with Value Efficiency for Chunk-Parallel Linear Attention

## What this paper does
Revises Gated DeltaNet-2 so that the erase and write gates see the stored state. Once per chunk it folds a low-rank down-projection into the chunk-boundary state and reads it with each token's query, U(S_{c-1} q_t), adding that content signal to the token-computed gate logits. All gating is restricted to the key axis, which the paper proves is the condition for the WY-form chunk solver to stay exact, and a megakernel makes it train slightly faster than GDN-2. At 1.3B/100B tokens it improves perplexity and RULER S-NIAH / MK-NIAH up to 8K over GDN-2.

## Goal-by-goal answers
### Goal: What signal do CARVE's gates use, and is any record of past reads accumulated over time?
The gates are sigma(b_{x,t} + W_{U2} tanh(W_{U1} S_{c-1} q_t)): a per-token term from x_t plus a content term from the current token's query reading the previous chunk-boundary state [full text, Section 4.2 / Eq 7-8]. The decay is a key-axis gate from the current input [Section 4.3 / Eq 9]. The content signal is recomputed per token from the current query; nothing accumulates which stored associations earlier queries have retrieved, and there is no supervision about future reads. The motivation is "memory-blind gating": GDN-2 decides what to erase "without knowing whether slot k holds a high-value association" [Section 1, Three structural limitations]. So CARVE answers "what is stored where the current token points", not "what has been or will be read".
### Goal: How much does it help multi-key retrieval, and what does it leave open?
RULER at 1.3B: MK-NIAH-1 at 1K/2K/4K is 76.8/55.2/41.4 for CARVE against 72.6/51.4/37.8 for GDN-2 and 54.0/44.2/28.0 for KDA; S-NIAH-2 at 8K is 42.0 vs 39.2 (GDN-2) [Section 8.5 / Table 8]. Multi-key retrieval still collapses with length. Stated limitations: no content signal for sequences shorter than two chunks, extra memory/parameters for the content-aware write gate, and only pre-training is evaluated [Section 9].
### Goal: What kernel constraint does it establish for gated delta rules?
The WY-form triangular chunk solver is exact if and only if the intra-chunk coupling matrix is independent of the value index (Chunkability Boundary, Theorem 11); GDN-2's value-axis erase breaks this, key-axis gating keeps it [Section 1; Section 6.1]. Conditioning gates on the chunk-boundary state costs one small matmul per chunk and induces an O(1/sqrt(L)) gate perturbation (measured 0.18%) [Section 6.3 / Proposition 14].
