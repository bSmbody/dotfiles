# DashAttention: Differentiable and Adaptive Sparse Hierarchical Attention

## What this paper does
Hierarchical sparse attention that replaces hard top-k block routing with alpha-entmax routing over learned chunk summaries (Stage 0 local summarization, Stage 1 1.5-entmax over chunk logits giving an adaptive sparse support averaged within each GQA group, Stage 2 softmax over tokens of routed chunks with logits biased by a prior derived from the router weights). Three Triton kernels (AdaSplash-2 for entmax, masked FlashAttention for Stage 2); reports 3.36x over FlashAttention-3 and 1.35x over InfLLMv2 and better accuracy than NSA/InfLLMv2 in long-context continual pretraining.

## Goal-by-goal answers
### Goal: How does it give the router a gradient from the task loss, and where does that gradient vanish?
Stage 2 is p_ij ∝ g_ij exp(z_ij) with g derived from the entmax routing weights, so the output is differentiable in g and gradients flow back to Stage 1 and Stage 0 [full text, Section 3.3 / Eq 6-7]. But g_ij = 0 exactly where w_ij = 0, which masks those chunks; 1.5-entmax has a closed-form Jacobian only "within regions where the support remains fixed" and is piecewise differentiable at support changes, like sparsemax/ReLU [Appendix A, "Differentiability of DashAttention"]. So chunks outside the support get no task gradient. It contrasts NSA (gradient to the first stage only via compressed attention) and InfLLMv2 (first stage not trainable) [Appendix A].

### Goal: What hardware constraints does it keep?
The routed support is shared within each GQA group to keep NSA/InfLLMv2-like tiling; the support is stored as a bitpacked block mask reused in the backward pass thanks to the sparse entmax Jacobian [Section 3.2, Section 3.5]. Stated limitation: no integration with serving frameworks (vLLM, SGLang) yet [Section 7].
