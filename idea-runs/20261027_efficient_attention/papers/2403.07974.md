# LiveCodeBench: Holistic and Contamination Free Evaluation of Large Language Models for Code

## What this paper does
LiveCodeBench continuously collects competitive-programming problems from LeetCode, AtCoder and CodeForces, each tagged with its contest release date, and evaluates code generation, self-repair, code execution and test-output prediction with input-output tests. Because every problem carries a release date, a model can be scored only on problems released after its training cutoff ("scrolling through time"). The first release held about 400 problems from May 2023 to May 2024, split into easy, medium and hard.

## Goal-by-goal answers
### Goal: How does it avoid contamination, and is there evidence that it matters?
Each problem is stamped with its contest date D, and a model is evaluated on problems released after its cutoff [full text, Section 3.1 "Scrolling through time"]. DeepSeek-Instruct-33B shows "a stark drop" on LeetCode problems released after August 2023, just before its release, and GPT-4-O drops after its November cutoff, which the authors read as contamination of earlier problems [Section 5.1, Fig. 1].
### Goal: What does a code-generation instance consist of and how is it graded?
Each problem is a tuple of a natural-language statement, test cases and a ground-truth solution; problems with images or multiple valid answers are excluded, and code generation is graded by passing the tests (pass@1) [Section 3.1; Section 4.1].
