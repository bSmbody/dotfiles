# Jet-Nemotron: Efficient Language Model with Post Neural Architecture Search

## What this paper does
PostNAS starts from a pretrained full-attention model (Qwen2.5-1.5B/3B), freezes the MLPs and explores attention designs coarse-to-fine: (1) full-attention placement and elimination, (2) linear-attention block selection, (3) a new JetBlock with dynamic convolution, (4) hardware-aware hyperparameter search. Jet-Nemotron-2B keeps two full-attention layers (15, 20) and two SWA layers, and reports Qwen3-level accuracy with up to 53.6x decoding speedup at 256K.

## Goal-by-goal answers
### Goal: How does PostNAS choose which layers keep full attention, and is the criterion teacher-forced or generation-based?
A once-for-all super network adds linear-attention paths beside each pretrained full-attention layer; each training step samples an active path and trains with feature distillation. Afterwards beam search finds the placement under a given constraint (e.g., two full-attention layers). The search objective is task-dependent: for MMLU the lowest loss on the correct answer, "while for mathematical and retrieval tasks, we choose the one with the highest accuracy" [full text, Section 2.2]. Math accuracy (GSM8K/MATH style, 4-shot, lm-eval-harness [Section 3.1]) is an end-task score of the subnetwork's own output, so the placement objective is outcome-based rather than per-position teacher-forced KL. The final model uses the retrieval task to place full attention and MMLU to place SWA [Section 3.1]. The budget (number of full layers) is a given constraint, not chosen from data.

### Goal: Does it target long chain-of-thought or re-collect after each choice?
No. Base models are not long-CoT reasoners; math evaluation is short few-shot; the super network is trained once and the beam search scores configurations without re-training or re-sampling between picks [Section 2.2, Section 3.1].


### Goal: How does the once-for-all super network make arbitrary full/linear placements evaluable without per-placement re-training, and what does the placement search cost?
The pretrained model is augmented with alternative linear-attention paths beside each full-attention layer; "during training, we randomly sample an active path at each step, forming a subnetwork, which is trained using feature distillation loss" [full text, Section 2.2]. Any placement is then extracted from the super network and scored directly (the per-layer heatmap is built by setting one layer full and the rest linear) [Section 2.2, Figure 5a]. The placement stage costs 50B tokens and 808 H100 GPU-hours [Appendix A.2, Table 12]. Scoring each configuration is by whole-task loss or accuracy; nothing localizes which examples or positions a placement fixes.
