# Gumbel Counterfactual Generation From Language Models

## What this paper does
Recasts a language model as a structural equation model via the Gumbel-max trick, so that an observed string and its counterfactual under a model intervention share the same sampling noise. It gives hindsight Gumbel sampling to infer the noise of an observed string and uses it to generate the counterfactual string from an intervened model (MEMIT edits, steering, instruction tuning), measuring how far counterfactuals move on prompts unrelated to the intervention.

## Goal-by-goal answers
### Goal: Under shared Gumbel noise, how much does a small, targeted model intervention change the generated string?
On 500 Wikipedia prompts with continuations of at most 25 tokens, the normalized edit distance between original and counterfactual strings is smallest for MEMIT, "10-15% for the Louvre and Koalas concepts", and larger for steering and instruction tuning [full text, Section 4.1.1-4.1.2, Fig 2]. The authors conclude that even interventions "designed to be minimal ... still have considerable" side effects on unrelated text [Section 4.1.2]. So shared noise does not keep short continuations identical under even a rank-one edit of one fact; for intervention-related prompts counterfactuals are "not minimal" either [Section 4.2].
