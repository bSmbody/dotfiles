# Distill-then-Replace: Efficient Task-Specific Hybrid Attention Model Construction

## What this paper does
DtR converts a pretrained Transformer (Qwen2.5-1.5B, Llama-3.2-3B, Llama-3.1-8B) into a task-specific hybrid in two steps: blockwise local distillation of a linear-attention counterpart for every full-attention block (~100M general tokens), then a greedy layer-replacement search that swaps one block at a time while monitoring validation performance on the target task, with no retraining during search.

## Goal-by-goal answers
### Goal: What criterion does DtR's layer search optimize, and how is the number of full-attention layers decided?
Starting from the full model, each iteration tries replacing every remaining full block with its distilled linear counterpart, evaluates the task validation metric, and commits the replacement with the highest score P*; if P* falls below a tolerance P_min (e.g., 5% relative drop) the search stops [full text, Section 3.2, Algorithm 1; Section 4.2]. The metric is the task's official one via lm-eval-harness, including GSM8K 4-shot generation accuracy [Section 4.1]. So the number of retained full layers is read off data through a tolerance stop, and the score is the hybrid's own end-task output, not teacher-forced KL. Only forward passes are used; no re-fit between picks [Section 3.2].

### Goal: Does it show that static per-layer scores fail because of layer interactions?
Yes: an impact-score (probe-based) static ranking underperforms greedy validation-driven replacement at the same 10/28 budget, which the authors attribute to "layer interactions: replacing one layer alters the functional role of others" [Section 4.3, Table 4]. No long-generation or long-CoT task is evaluated.


### Goal: Why can DtR swap any subset of layers without re-fit, and what does its search see of each candidate?
Each linear counterpart is trained independently by blockwise local distillation, MSE between its output and the parent full-attention block's output on the same hidden-state input, ~100M general tokens, all blocks in parallel [full text, Section 3.1]. Because each linear block is a drop-in imitation of its own block, the greedy search can mix any subset with forward passes only [Section 3.2]. Each candidate is summarized by one task validation score on ~500 samples [Section 4.2, Table 3]. Greedy validation-driven replacement beats local-importance, uniform and random orders [Section 4.2, Fig 4], and static impact scores lose 3.5-3.8 pp at a 10/28 budget due to layer interactions [Section 4.3, Table 4]. SFT after search still improves the hybrid [Section 4.2, Fig 5].
