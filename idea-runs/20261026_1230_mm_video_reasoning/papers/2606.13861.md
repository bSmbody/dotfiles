# Temporal Backtracking Search for Test-time Generative Video Reasoning

## What this paper does
TBS is a test-time search for video-generation reasoning (Wan2.2-TI2V-5B LoRA). It finetunes the model with variable-K clean-prefix conditioning (per-frame timestep mask), then runs a generate-verify-restart loop: an external process verifier finds the first failure frame of each rollout, the valid prefix is cached as an anchor, and suffixes are resampled from the highest-priority anchor. Gains grow with horizon (2D Maze >40 steps: BoN-20 17.1% vs TBS-20 60.0%).

## Goal-by-goal answers
### Goal: Where along the trajectory do generative video reasoning failures occur, and can they be localized?
Defines transition validity phi and first-failure frame F(v), which splits a rollout into a valid prefix and invalid suffix [full text, Section 3.1, Eq 1-2]. "Reasoning errors cluster early in the temporal axis": 72.7% of failed BoN-20 2D-maze rollouts fail in the first 0-20% of the trajectory, 78.3% on Keys-and-Doors OOD; the rest of the trajectory is locally easy [full text, Section 4.3]. Searching over denoising steps cannot rescue flawed rollouts because trajectories commit early in diffusion [full text, Abstract].
### Goal: What does it leave open (training vs inference, verifier dependence)?
It is inference-only on top of SFT; it "depends on the base video model's local competence" and "does not change what the generator can locally produce" [full text, Sections 4.5, 5]. It relies on domain-specific external verifiers; future work: "internalize this supervision by training implicit video process reward models (PRMs)" [full text, Section 5]. Replacing the prefix with a single last frame collapses repair from 100% to 2.5%, so motion context in the prefix matters [full text, Section 3.3, 4.4].
