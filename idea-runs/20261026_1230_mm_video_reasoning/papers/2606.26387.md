# Staying VIGILant: Mitigating Visual Laziness via Counterfactual Visual Alignment in MLLMs

## What this paper does
VIGIL (ECCV 2026) frames hallucination as "visual laziness": models encode correct evidence but answer from language priors. It defines Visual Information Gain VIG = log pi(y|x_v,x_t) - log pi(y|x_v^blank,x_t), where the blind state zeroes text-to-visual attention in every layer, and adds a Counterfactual Visual Decoupling (CVD) loss, a DPO-style preference for the seeing state over the blind state for the same preferred response, plus self-generated hallucination hard negatives and a dynamic gate. Offline DPO training on preference data.

## Goal-by-goal answers
### Goal: What mechanism does it use to make the reasoning trace visually grounded/faithful?
Constrained objective max J_DPO s.t. E[VIG(y_w)] >= delta, relaxed with a Lagrange multiplier into L_CVD [full text, Sec 3.1 / Eq 3-6]; L_VIGIL = L_DPO(y_w, y_hard) + lambda * alpha * L_CVD with alpha = 1 - tanh(|VIG|) [Eq 7-8].
### Goal: Does its signal test whether the final answer causally depends on the trace's visual claims, or only claim truth / image sensitivity / attention?
Image sensitivity of the whole response likelihood only: it raises how much the preferred response's probability drops without vision. It neither checks the truth of individual claims nor whether an answer depends on intermediate trace content [Sec 3.1-3.2].
### Goal: What counterfactual/intervention operator does it use, and what limitation does it report?
Total removal of visual access via attention masking (blind state) [Sec 3.2 Step 1]. It argues GRPO does not naturally encode the counterfactual comparison, and extra blind trajectories per sample would add substantial compute, hence DPO [Sec 2.3].
