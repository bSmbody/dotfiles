# ResAdapt: Adaptive Resolution for Efficient Multimodal Reasoning

## What this paper does
ResAdapt adds a lightweight Allocator before the MLLM's visual encoder that predicts a per-frame resize scale from coarse frozen features and the query (Beta-distributed actions), so the backbone keeps its native token interface. Allocation is a contextual bandit trained with Cost-Aware Policy Optimization (a dynamic cost pivot on group advantages) and a temporal-similarity regularizer; the backbone can be co-trained. It improves low-budget operating points on video QA, temporal grounding and some image reasoning.

## Goal-by-goal answers

### Goal: What signal decides how much visual evidence an instance gets, and when is it decided?
The Allocator maps coarse visual features plus the query to per-frame scales once, before decoding; "Because the Allocator acts once before decoding, the outer problem is a Contextual Bandit" [full text, Section 2.2 / Eq 4-6]. Reward is answer quality minus lambda times visual cost, reshaped by CAPO [Section 3.1, 3.3].

### Goal: Can the visual budget respond to what the reasoning discovers?
No. "Because the policy is open-loop - budget decisions are committed before any backbone processing begins - it cannot revise allocations once reasoning starts" [Section 4.4.3]. Limitation (iv): "Open-loop allocation ignores reasoning state ... cannot revise a mistaken low-resolution choice once partial reasoning or uncertainty signals emerge"; the authors suggest early backbone states could trigger re-encoding or a secondary visual pass [Limitations and Future Work]. Limitation (ii): coarse features miss small text, subtle objects and transient cues [Limitations (ii), Fig. 20].

### Goal: Does it adapt reasoning length?
No; it controls only input pixels per frame; the reasoning trace is whatever the backbone produces [Sections 3.1-3.4].
