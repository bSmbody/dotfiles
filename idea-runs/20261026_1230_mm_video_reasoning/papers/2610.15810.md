# Adaptive Look, Flexible Thought: Learning How and How Long to Think in Multimodal Reasoning

## What this paper does
L2T turns tool-produced intermediate images (crops, zooms, transforms) into discrete VQ visual tokens added to the MLLM vocabulary, so the model can emit visual and textual reasoning tokens in one sequence. After SFT on converted tool trajectories and a stability RL stage, a third RL stage adds a modality-aware routing reward (based on visual/text token ratios against per-sample routing labels) and a difficulty-aware fast-slow pairwise advantage that favors shorter correct traces on high-pass-rate prompts and longer correct traces on low-pass-rate prompts.

## Goal-by-goal answers

### Goal: What signal decides how much compute an instance gets, and can it tell perception-limited from reasoning-limited instances?
Reasoning depth is set by group pass rate p_G with easy/hard thresholds; on hard prompts (p_G < tau_hard) longer successful traces get a bonus [full text, Section 3.3 Stage 3 / Eq 17-21]. Which modality to use comes from binary routing labels n_v, n_t that are "initialized based on dataset/task categories and further refined through keyword-based rules" [Stage 3, Modality-aware Routing / Eq 15], so the visual-versus-text choice is fixed per sample by its task type, not inferred from the model's own failure. The authors' failure analysis with GPT-5.5 over 8,230 responses finds perception failures have CoT lengths (mean 241.9) comparable to correct answers (277.3), arise early, and "cannot be effectively remedied by simply extending the reasoning process"; they conclude "using rollout pass rate alone as a proxy for task difficulty is insufficient for adaptive CoT allocation, as it may unnecessarily encourage longer reasoning on tasks that are unlikely to benefit" [Appendix A.4.4 / Table 8].

### Goal: Does the adaptation act on visual evidence, and can it fetch new visual information?
It generates discrete visual tokens that stand in for tool outputs, learned from tool trajectories [Sections 3.1-3.2]. Limitations: the codebook "inevitably sacrific[es] part of the fine-grained visual information", and visual tokens "cannot fundamentally correct perception errors caused by the limited representation capability of the underlying vision encoder ... once incorrect visual evidence is encoded, subsequent reasoning ... has limited ability to recover" [Appendix A.8]. Images only.
