# Addressing Overthinking in Large Vision-Language Models via Gated Perception-Reasoning Optimization

## What this paper does
GPRO (ACL 2026) inserts gated modules into alternating decoder FFN layers of Qwen2.5-VL. A 2-layer meta-controller reads the hidden state, next-token predictive entropy and global image features and picks, per token, a fast path (original FFN), a slow perception path (cross-attention from the hidden state over the visual features) or a slow reasoning path (a meta-transformer over recent context). The controller is trained with PPO on task reward, a path-cost penalty and a calibration reward, using about 30-40K curated samples whose failures were attributed by GPT-4 to perception or reasoning out of ~790K mined samples.

## Goal-by-goal answers

### Goal: What signal decides how much compute an instance gets, and can it tell perception-limited from reasoning-limited instances?
The controller state is s_t = [h_t; U_t; V_g], where U_t is next-token predictive entropy and V_g global image features [full text, Section 3.1.1]. The distinction between perceptual and reasoning failure is not computed by the model online; it is imported from offline GPT-4 failure attribution over mined errors [Section 3.3], and the calibration reward only aligns U_t with eventual correctness, not with failure source [Section 3.2 / Eq 6]. Limitations name dependence on GPT labels, "especially in cases where perception and reasoning errors are closely intertwined" [Section 6].

### Goal: Does the adaptation act on visual evidence, and can it fetch new visual information?
Partly. The slow perception path is Perc(h_t,V) = CrossAttn(h_t,V,V) over the already-encoded visual features V [Section 3.1.2 / Eq 2]; it re-reads the same tokens at the same resolution and cannot request a crop, higher resolution or new frames. Ablation: removing the perception path costs 3.4 (MathVision) and 4.4 (MathVerse) points versus 1.7 for the reasoning path, which the authors read as perception being the main bottleneck [Section 4.3 / Table 2]. Slow perception fires on 17% of tokens, mainly numbers in tables, coordinates and legend text [Section 4.3, Resource Allocation Dynamics].

### Goal: What limitations does it report?
GPT-based attribution quality, and a discrete routing scheme over a fixed set of paths; finer or continuous control is left to future work [Section 6]. Images only; no video.
