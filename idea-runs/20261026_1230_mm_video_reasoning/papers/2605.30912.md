# Attend to Evidence: Evidence-Anchored Spatial Attention Supervision for Multimodal RLVR

## What this paper does
EASE (EMNLP 2026) adds visual-evidence process supervision to DAPO/GRPO. Training examples get answer-relevant evidence boxes from an automated extract-localize-validate pipeline; boxes become a smoothed Gaussian-mixture target over visual tokens, and a KL loss pulls response-to-vision attention (layer floor(2L/3), head-averaged, 64 sampled tokens) toward the target, applied only to trajectories whose verifier reward passes a threshold. Inference uses only image and question.

## Goal-by-goal answers
### Goal: What mechanism does it use to make the reasoning trace visually grounded/faithful?
L_total = L_RL + lambda_attn * L_EASE, with L_attn = KL(P_model^t || P_target) averaged over reward-gated trajectories [full text, Sec 3.3-3.5 / Eq 1-9]. Motivation: attention-target KL is higher for hallucinated responses on HallusionBench [Sec 3.1].
### Goal: Does its signal test whether the final answer causally depends on the trace's visual claims, or only claim truth / image sensitivity / attention?
Attention location only. The authors state EASE "mainly supervises where response-to-vision attention is allocated ... rather than directly optimizing how much the generation depends on visual input" [Limitations]. Functional check: masking evidence pixels drops accuracy strongly, but suppressing attention to evidence tokens at the supervised layer changes accuracy little (evidence-specific gap 2.8 pts for DAPO, 6.1 for EASE) [Sec 4.4, Table 4], so the supervised attention is not the main channel of use. Failure cases: attends to the right boxes yet misreads a size illusion, or reasons wrongly after correct evidence acquisition [App H].
### Goal: What counterfactual/intervention operator does it use, and what limitation does it report?
Only at evaluation: evidence-region masking vs area-matched control, and attention suppression [Table 4]. Limitations: needs box annotations; box supervision suits localizable evidence, not holistic cues [Limitations].
