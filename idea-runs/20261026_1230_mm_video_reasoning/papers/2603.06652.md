# PaLMR: Towards Faithful Visual Reasoning via Multimodal Process Alignment

## What this paper does
PaLMR targets "process hallucinations" (right answer, misperceived visual evidence) in RL-tuned MLLMs. A data layer builds ~4.7K FineVision samples with Gemini-generated structured pseudo-ground-truth captions (objects, relations, attributes) and a Best-of-N reference trajectory. An optimization layer (V-GRPO) uses an LLM judge that compares the rollout against the reference trajectory, given the pseudo-GT facts, to produce a binary visual-fidelity score that multiplicatively gates the answer+format reward. Evaluated on Qwen2.5-VL-7B and other scales.

## Goal-by-goal answers
### Goal: What mechanism does it use to make the reasoning trace visually grounded/faithful?
A hierarchical reward R = S_vis * (alpha*S_ans + (1-alpha)*S_fmt) [full text, Sec 3.3 / Eq 3]. S_vis = 1[tau_target preferred over tau_ref], a pairwise LLM-as-judge preference "given the ground-truth facts" [Eq 2]. Pairwise replaced point-wise claim-vs-fact scoring because point-wise judging was biased and unreliable on partially correct traces; pairwise reaches >88% model-human agreement with Qwen3 judges [Sec 3.3, Fig 3]. A trajectory judged visually unfaithful gets zero reward regardless of answer correctness.
### Goal: Does its signal test whether the final answer causally depends on the trace's visual claims, or only claim truth / image sensitivity / attention?
Only claim truth relative to text pseudo-GT captions. The judge reads text (trace, reference trace, Gemini facts); no intervention on the image or on the trace is performed, and nothing checks whether the answer is computed from the stated facts [Sec 3.2-3.3].
### Goal: What counterfactual/intervention operator does it use, and what limitation does it report?
None. Reported limitations: exact-matching penalizes lexically different but valid descriptions ("blue" vs "cyan"), Geometry3k failures because pure text reasoning misses implicit geometric constraints, and an upper bound set by the base model's perception [Sec 4.5, 4.6].
