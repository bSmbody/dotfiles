# Bad Seeing or Bad Thinking? Rewarding Perception for Multimodal Reasoning

## What this paper does
The paper prompts the VLM to interleave <recognition> perception blocks and <think> reasoning blocks, then rewards perception with a "Blindfolded Reasoner" test: a text-only LLM (e.g. Qwen2.5-14B-Instruct) gets the question and only the recognition text and must reach the correct answer. Outcome is verified by an LLM executing a structured verification protocol. MoCA routes credit: in failed trajectories whose perception passed, perception tokens' penalty is dampened; where perception failed, it is amplified.

## Goal-by-goal answers
### Goal: How does it verify perception, and does the verifier see the image?
R_P = 1 if Proxy(Q, {a_p}) = Y_correct else 0, where the proxy is a text-only reasoner and the image is withheld [full text, Section 2.3]. It therefore tests sufficiency of the description for reaching the answer, not fidelity to the image: the authors frame it as an information-bottleneck proxy rewarding perception text "maximally informative about the answer". A recognition block that states a fabricated value that leads to the correct answer passes.

### Goal: How is perception credit routed to tokens?
Trajectory return R = R_O + lambda R_P; for failed trajectories (R_O = 0), perception-block tokens get A + alpha_protect |A| if R_P = 1 or A - alpha_punish |A| if R_P = 0 [full text, Section 2.5]. Routing is at block level (all perception tokens of a trajectory share one binary R_P) and the modification applies only to failed trajectories; successful trajectories are reinforced uniformly.

### Goal: What limitations or noise sources does it acknowledge?
The text-only oracle is fallible and can produce false negatives; they posit these are infrequent and run a human agreement study [full text, Section 2.3, Appendix E.2].
