# AdaThinkV: Adaptive Thinking for Token-Efficient Video Reasoning

## What this paper does
AdaThinkV trains a video MLLM to choose between an explicit-reasoning mode (THINK) and direct answering (ANSWER). During RL it forces a fraction of each rollout group into each mode, estimates ThinkGain = accuracy gain of THINK over ANSWER minus a length cost, converts it into a mode target with a dead zone, and trains the mode marker with a supervised loss. VRPO expands all-failed low-variance groups instead of discarding them. It reports 40.79 mean accuracy at 257 output tokens on video reasoning benchmarks, beating VideoAuto-R1 with fewer tokens.

## Goal-by-goal answers

### Goal: What signal decides how much reasoning compute an instance gets, and can that signal tell perception-limited from reasoning-limited instances?
The signal is the paired-rollout estimate Delta(x) = mean acc(THINK) - mean acc(ANSWER) - lambda * (length difference)/B [full text, Method, ThinkGain / Eq 1], thresholded into THINK / ANSWER / no-target [Eq 2]. The introduction argues confidence is a poor proxy because "high confidence can coexist with missed temporal evidence" [Introduction], but ThinkGain itself only measures whether extra text reasoning helps under the same visual input. If the answer fails because the needed frame was never sampled, both modes fail, Delta is about zero or negative, and the instance is routed to ANSWER (no extra compute) or given no target; VRPO then expands rollouts on such all-failed groups [Eq 5], i.e. more text samples on the same frames.

### Goal: Does the adaptation act on visual evidence (frames, resolution, re-inspection) or only on text length?
Only on whether to emit a text reasoning trace and its length. Evaluation uses a fixed pipeline of 2 to 256 frames at 2 FPS with a 4096-token visual budget for every question [Experimental Setup, line ~842]. The action space is {THINK, ANSWER}.

### Goal: What does it report about the limits of its adaptivity?
Automatic mode is 0.71 points below forced THINK with 62.9% fewer tokens; prompt-level reasoning length correlates only moderately with difficulty (rho=0.39) [Ablation Study, Inference modes]. Future work: extend utility estimation beyond scalar accuracy rewards [Conclusion].
