# ARES: Multimodal Adaptive Reasoning via Difficulty-Aware Token-Level Entropy Shaping

## What this paper does
ARES is an adaptive-reasoning recipe for multimodal reasoning models with two stages: an adaptive cold start whose SFT traces have length proportional to problem difficulty, and AEPO, an RL stage that uses sliding-window token entropy to decide where to branch extra rollouts and a difficulty-bucketed reward that penalizes too many high-entropy tokens on easy problems and too few on hard ones, plus a dynamic KL term. Difficulty buckets come from online pass@8.

## Goal-by-goal answers

### Goal: What signal decides how much reasoning compute an instance gets, and can that signal tell perception-limited from reasoning-limited instances?
Two signals. (1) Difficulty bucket from online pass@8: easy >=6, medium 3-5, hard <=2 correct [full text, Appendix G / Eq 10]. (2) Window-averaged token entropy; a segment whose window entropy exceeds the batch 95th-percentile threshold triggers extra branched rollouts [Section 3.2.1]. High-entropy tokens are counted only within a GPT-filtered vocabulary of reasoning triggers such as "but", "however", "therefore" [Appendix H, Semantic filtering; Fig. 2b word cloud: explain, assume, constraint, conclude]. So both the trigger and the budget target are defined over textual reasoning uncertainty; the hierarchical reward penalizes under-exploration on hard (low pass@8) problems by pushing for more high-entropy reasoning tokens [Section 3.2.2, g_d and R(x,y;d)], regardless of whether the failure is perceptual.

### Goal: Does the adaptation act on visual evidence or only on text?
Only text: exploration is extra text branches and longer chains; the paper shows response length grows roughly linearly with the number of high-entropy tokens [Section 2.2; Appendix J]. No mechanism changes the visual input.

### Goal: What method assumption limits it?
It assumes more high-entropy (reasoning-fork) tokens are what hard problems need ("hard problems inherently require sustained exploration ... probing multiple solution paths") [Section 2.2]. That assumption is stated for difficulty as measured by pass rate, without a perception/reasoning split.
