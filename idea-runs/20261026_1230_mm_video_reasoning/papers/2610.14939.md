# VC-OPD: Visual Counterfactual On-Policy Distillation for Grounded Vision-Language Reasoning

## What this paper does
On-policy distillation for VLM reasoning in which each student trajectory is scored by the teacher under the original image and under a counterfactual image with weakened instance evidence (default 60% patch dropout). The factual teacher-student log-ratio sets the update direction; the factual-minus-counterfactual teacher log-prob gap estimates token visual dependence and softly reweights the token loss with mass-preserving normalization. Evaluated across Qwen2.5-VL, Qwen3-VL and InternVL3.5 students.

## Goal-by-goal answers
### Goal: What mechanism does it use to make the reasoning trace visually grounded/faithful?
A_t^dir = log p_T^+(y_t) - log mu(y_t) [full text, Sec 3.3 / Eq 8]; Delta_t^vis = log p_T^+(y_t) - log p_T^-(y_t) [Eq 9]; w_t = sigmoid((Delta - tau)/T) [Eq 10]; mass-preserving normalization [Eq 11].
### Goal: Does its signal test whether the final answer causally depends on the trace's visual claims, or only claim truth / image sensitivity / attention?
Teacher-side image sensitivity of trace tokens only; the authors call it "a proxy for token-level visual dependence, not a rigorous causal estimate" [Sec 3.3]. No check of answer dependence on the trace.
### Goal: What counterfactual/intervention operator does it use, and what limitation does it report?
Removal/degradation: patch dropout (default), random dropout, Gaussian blur, contiguous region masking, object erasing, saliency-guided corruption all work similarly; a mismatched image hurts (-4.89%) [Sec 4.6, Table 5]. Limitations: visual dependence is not equivalent to reasoning importance; perturbations are not a perfect causal intervention [Sec 6].
