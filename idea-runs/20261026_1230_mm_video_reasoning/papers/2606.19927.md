# CARE: Competence-Aware Reward Shaping for Adaptive Reasoning Length in Video-MLLMs

## What this paper does
CARE is a GRPO reward-shaping scheme for video MLLMs (Qwen2.5-VL-7B, Video-R1 data) that changes the preferred reasoning length over training. It keeps an EMA of batch pass rate as a competence estimate, routes training into four stages (Novice to Master) that move from rewarding long traces to penalizing them, normalizes trace length against batch statistics, and amplifies rewards for groups that beat the competence baseline. The effort reward is gated by accuracy. It reports gains on VSI-Bench, VideoMMMU, Video-MME with shorter traces and an expand-then-compress length trajectory.

## Goal-by-goal answers

### Goal: What signal decides how much reasoning compute an instance gets, and can that signal tell perception-limited from reasoning-limited instances?
The only per-instance difficulty signal is the GRPO group pass rate P_g, which enters the length-preference coefficient as k_s = b_s + sgn(b_s)(alpha(1-P_g) + beta|P_b,t - a|) [full text, Section 3.3 / Eq 7]; the global stage comes from an EMA of batch pass rate (gamma=0.99) [Section 3.2 / Eq 4]. Effort is the token length of the reasoning chain normalized by batch statistics (mean length of correct responses, 75th-percentile length, floor T_floor=300) [Section 3.3 / Eq 6]. Nothing in the reward separates why a group fails: a low pass rate from missing visual evidence and a low pass rate from hard multi-step inference produce the same push toward longer text on hard instances (Fig. 7 left: harder instances keep longer responses).

### Goal: Does the adaptation act on visual evidence (frames, resolution, re-inspection) or only on text length?
Only text length. Training uses at most 16 frames at resolution up to 128x28x28; inference uses 256x28x28 and 16 to 64 frames, set globally, not per instance [Section 4.1]. The reward terms are R_acc, R_format, R_CARE (length), and an auxiliary temporal reward [Eq 14]; none changes which or how many frames the model sees. The conclusion lists as future work "finer-grained adaptive control signals beyond reasoning length alone" [Section 6].

### Goal: What limitations does it report?
The limitations section only says the absolute optimum may vary with model scale, data and controller coefficients [Section 5]; hyperparameter sensitivity to stage thresholds, tolerance omega and floor T_floor is shown in Section 4.7, with both directions of change lowering accuracy.
