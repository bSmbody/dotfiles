# IAPO: Input Attribution-Aware Policy Optimization for Tool Use in Small Multimodal Agents

## What this paper does
IAPO trains a small VLM agent (Qwen2.5-VL-3B) for visual tool calling with GRPO plus an attribution penalty: integrated-gradients-style scores (gradient × embedding) quantify how much each semantic input block (prompt, tool definitions, image, etc.) contributes to the generated tool call, and the KL divergence between the student's and a stronger teacher's block-attribution distributions is subtracted from the outcome reward. Reports ~3% average VQA gain over prior visual tool-use RL on six test sets.

## Goal-by-goal answers

### Goal: Does IAPO's attribution signal measure whether the returned tool observation is used by the answer, and at what granularity is credit applied?
No. The attribution target is s(E) = log π(y′|E), the log-probability of the generated tool-call sequence y′, with gradients taken w.r.t. input embeddings [full text, Section 3.2]. It thus measures which inputs drove the call, not whether the observation returned by the tool influenced the subsequent answer. The penalty P^A = KL(b̂‖â) against a teacher enters a trajectory reward R = R_out − λP^A, and "we broadcast A_i^IAPO to all response tokens" [Section 3.2], so credit is trajectory-level. It requires a stronger teacher model.

### Goal: What tool-use failure does it report for outcome-reward GRPO?
Multimodal small models "trained with vanilla GRPO continue to produce a substantial number of misused tool calls even in the later stages of training" [Section 1, case study Section 4.2]; existing tool rewards rely on exact matching to ground-truth trajectories, which is unsuitable when "multiple tool use paths may be valid" [Abstract, Section 1].
