# EventLens: Event-Structure Reinforcement Learning for Video Understanding

## What this paper does
EventLens argues caption-style post-training lets MLLMs rely on language shortcuts and fail to recover temporal structure. It builds a three-level temporal ontology and three verifiable proxy task families—hierarchical event segmentation, single-event progression discrimination, and multi-event relation reasoning (next-event, fill-in, clip reordering)—trains task-specialized GRPO teachers on Qwen3-VL-4B/8B, and consolidates them with multi-teacher on-policy distillation. Inputs are 256 frames at 256x256.

## Goal-by-goal answers
### Goal: What mechanism does it use to locate or re-inspect temporal evidence in long videos?
None: fixed 256-frame input [full text, Sec 4.1]. Multi-event tasks present candidate events as pre-cut visual clips with neutral identifiers [Sec 3.2].
### Goal: How does its RL reward assign credit to the evidence the model uses (outcome-only, IoU vs annotation, other)?
Deterministic rewards: exact match for next-event / fill-in, and a normalized permutation-displacement reward for clip reordering over a chronologically ordered window W = (e1..em) of neighboring events [full text, Sec 3.2, Eq 4]. These reward temporal relations, but only among clips the data pipeline has already segmented and handed to the model.
### Goal: What limitation or failure mode does it report on long-video temporal reasoning?
Confuses adjacent events with gradual state change; "visually similar repeated actions remain difficult"; it "does not solve all long-range narrative reasoning" [full text, Sec 4.4 Failure modes].
