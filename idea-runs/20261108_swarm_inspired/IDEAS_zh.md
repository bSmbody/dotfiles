## C1（L1 低比特 KV）：自适应精度细化——只把正在被读的片段重算回 FP8

**一句话**：整条推理一直用 INT2 存，另外维护一个小的 FP8 工作集，只覆盖当前 query 真正在读的片段。片段换了，工作集就跟着挪。

**机制：**
- 解码内核每一步本来就会算出注意力权重。用它定位"当前被重点读取的片段"，这个信息白拿。
- 把这些片段**单独重新 prefill**，读的是常驻的 INT2 缓存。代价只和片段长度成正比，可以塞进 GPU 的空闲算力里。
- 每隔几步重新划分一次工作集，类似计算物理里的自适应网格加密：大部分区域用粗网格，只在关键区域加密。

**借鉴来源**：自适应网格加密（AMReX [2009.12009]）；HPC 容错里的"选择性可靠"[1206.1390]。

**和主线的关系**：这就是我们之前讨论的"部分升级"的升级版。之前的设想要重算整个前缀，现在只重算被读的片段，代价低得多。

**最大风险**：片段是对着 INT2 的上下文重算的，误差已经混进上下文，算出来的值只是"近似恢复"，可能仍然拦不住失控。

## C2（L2 并行推理）：聚合群体——把粒子滤波的"缺陷"变成 KV 共享

**一句话**：一道题同时跑几百条推理分支，当作粒子滤波来做。在关键分叉点淘汰打转或不自信的分支，用存活分支的"写时复制"副本补位。

**最巧的地方**：统计学里，反复重采样会让各条分支的祖先迅速合并成一条主干，这叫"路径退化"，本来是粒子滤波的有名缺陷。这里反过来当作机制用：
- 所有分支共享这条主干的 KV，主干用 **FP8**，被所有分支同时读取（用树状共享注意力 [2402.05099]）；
- 每条分支只私有一小段最近的"枝尖"，枝尖用 **2 bit**；
- 显存约为"主干长度 + N log N 个块"，而不是"N × 推理长度"；
- 选择压力越大，主干越长、越省显存，相当于一个显存调节旋钮；
- 某页被引用的次数升高时，就把这页重算为 FP8。也就是按"有多少分支在读"来分配精度。

**分叉点和存活判断**："wait""however"这类高熵词是推理方向真正分开的地方。存活判断综合三种信号：打转检测、token 置信度、隐状态多样性过滤（直接借用 SwarmEvolve）。

**借鉴来源**：计算统计的粒子滤波和群体遗传学的溯祖理论（coalescent）[1307.3180, 1804.01811]。

**最大风险**：多样性坍缩。如果置信度在长推理上校准不好，选择会把所有分支都挤进同一条"很自信但错误"的主干，结果反而不如独立采样后投票。

## C3（L3 淘汰/剪枝）：重放 KV——放心地狠删，定期从 token 原样重建

**一句话**：把 KV 当成 token 的一个"可丢弃视图"，而不是必须保存的状态。解码时只留一个很小的常驻缓存，每隔几千个 token，后台逐层重新 prefill 整条推理，重建出精确的完整 KV，然后再删掉大部分。

**重建这一步会白送三样东西：**
1. 最新的 query 在**完整历史**上真正读了哪些位置，用来挑下一轮常驻哪些 token；
2. 自上次重建以来，每个写出的 token 在**完整上下文**下的概率，如果某一步明显"写错了"，就回滚；
3. 没有任何 token 被永久删除，淘汰带来的误差不会一直累积。

**借鉴来源**：数值线性代数中，流水线共轭梯度法会定期用真实值替换累积误差的残差 [1601.07068]；训练系统里的动态张量重算 DTR [2006.09616]。

**最大风险**：重建代价随长度变大。40K–60K token 时注意力是平方复杂度，每次重建要好几秒。如果几百个 token 就得重建一次，算力会把 batch 变大省下的收益吃掉。另外，temperature 0.6 下正常采样出的低概率 token 可能被误判而触发回滚。

## C4（L4 混合模型/记忆矩阵）：状态补丁——让混合模型也能像 git 一样分叉、合并

**一句话**：在 Gated DeltaNet 层里，一段 token 对记忆矩阵的全部影响，可以浓缩成一个**固定大小的"补丁"**：一个变换矩阵，加上一个写入矩阵。不管这段是 40 个还是 4000 个 token，补丁都约等于两个状态那么大。有了补丁，混合模型的推理分支就能像版本控制那样分叉、变基（rebase）、三方合并。

**机制：**
- **分叉**：直接复制状态，注意力层的前缀 KV 按引用共享，几乎零成本。
- **变基**：把一条分支的补丁应用到另一个基础状态上，不需要重新 prefill 它的文字。
- **三方合并**：从共同祖先出发，把各分支的擦除和写入各施加一次，共享的衰减也只施加一次。
- **免费的冲突信号**：两个分支补丁的"对易子"大小，一次小矩阵乘就能算出。接近 0 说明两条分支写入了不同的记忆方向，可以无损合并；很大说明它们在同一位置写了不同内容，即"冲突"。它同时可以作为分支间的分歧或多样性度量，相当于 SwarmEvolve 隐状态多样性过滤在混合模型上的对应物。
- 少数全注意力层仍按 SwarmEvolve 的方式，按引用拼接 KV。

**它解决什么**：SwarmEvolve 明确写到，混合模型因为状态没法合并，所以无法使用它的方法。C4 正面回答了这个问题。

**借鉴来源**：版本控制的补丁理论 [1311.3903]；量子模拟里的 Trotter 误差理论 [1912.08854]：几段演化"几乎对易"时，先后顺序几乎不影响结果，误差由对易子决定。

**最大风险**：合并出来的状态对后续层来说可能是"分布外"的，因为模型从没见过一个同时装着两条不同思路的记忆。最后效果可能还不如直接沿最好的那条分支往下写。

## C5（L5 变种注意力）：Verlet 皮层注意力——带有效期的页面清单

**一句话**：解码时相邻步的 query 漂移得很慢，而一次完整注意力本来就会算出每一页的精确最大 logit，只是算完就丢了。把它留下来，给每个 KV 页发一张"有效期证书"，写明 query 漂移多远之内这一页都不可能变重要。在证书过期之前，只读清单上的页。

**机制**：
- 借鉴分子动力学的 Verlet 邻居表：给每个粒子的邻居列表加一层"皮"，粒子移动不超过皮的厚度，就不用重建列表。
- 每一步只算 query 相对参考 query 漂了多少（按 RoPE 频带分开算，几百次浮点运算），用二分查找找出刚刚过期的少数页，重新读取。
- 在线 softmax 本来就维护着运行最大值和归一化项，可以借此给出"被跳过的注意力质量"的上界。上界超过阈值时，才做一次完整重建。

**借鉴来源**：分子动力学的 Verlet 邻居表；Lasso 的安全筛选（safe screening）规则。

**最大风险**：界可能太松。真实的 query 漂移分散在很多维度上，而这个界假设漂移最坏地对齐到每页最大的 key 上。如果每一步都有大量证书过期，机制就退化成每步扫描（类似 Quest），还多了一堆记账开销。

**一个横向发现**：C1、C3 和我们的主线都建立在同一个事实上——KV 只是 token 的一个可重算视图。这个事实已经有人公开过（KV-Direct 2603.19664），但把它当作"精度和淘汰的撤销键"系统地利用起来，可能足以构成一条统一的论文主线：KV 可重算 → 精度可撤销（主线）→ 局部可细化（C1）→ 淘汰可撤销（C3）。
