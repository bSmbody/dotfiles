# Fast RoPE Attention: Combining the Polynomial Method and Fast Fourier Transform

## What this paper does
A theory paper (Alman and Song) giving an n^{1+o(1)} algorithm for approximate RoPE softmax attention in the bounded-entry regime (B = o(sqrt(log n)), d = O(log n)), plus a matching SETH lower bound. The RoPE pre-softmax matrix is a sum of O(d) rescaled Toeplitz matrices diag(Q_{*,l1}) C diag(K_{*,l2}); a polynomial approximation of exp keeps a sum of few rescaled Toeplitz matrices, and each is applied to V with FFTs.

## Goal-by-goal answers
### Goal: Does prior work already use FFTs to exploit RoPE's relative-position structure in attention, and in what setting?
Yes, for full prefill (all n queries times all n keys). Linear RoPE attention is reduced to O(|S|) FFTs of O(n log n) each by writing A = sum over support pairs of diag(Q_{*,l1}) C^{l1,l2} diag(K_{*,l2}) with C Toeplitz [full text, Section 4, Definitions 4.5-4.7, Claims 4.6-4.9]; softmax is handled via the polynomial method [full text, Section 1, technique overview]. The FFT gain there comes from amortizing over n queries (Toeplitz matvec). No implementation or experiments; it does not treat low-rank key caches or single-query decoding.
