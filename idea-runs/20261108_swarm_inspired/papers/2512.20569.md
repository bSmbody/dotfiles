# Distilling to Hybrid Attention Models via KL-Guided Layer Selection

## What this paper does
Converts a pretrained softmax Transformer (Qwen2.5-3B/1.5B/7B-Instruct, Llama-3.2-3B-Instruct) into a hybrid with K softmax layers and the rest Gated DeltaNet, using the RADLADS pipeline (hidden-state alignment then KL distillation). Its contribution is layer selection (GA-S2): first distill an all-linear student, then for each layer restore just that layer to softmax, briefly re-distill, and score the layer by how much the teacher-student KL drops on generic DCLM text; keep the top-K. Beats uniform interleave, associative-recall probes, PPL/activation-MSE probes, SMART and PostNAS's released layer set on RULER and SWDE.

## Goal-by-goal answers
### Goal: What mechanism does it use to decide which layers keep full attention, and on what data/objective is that decision scored?
One-swap greedy addition: from an all-linear student, restore layer l to softmax, run Stage 1 (L2 hidden alignment, 100M tokens) and Stage 2 (temperature-scaled forward KL, 600M tokens) on DCLM generic text, and set importance I(l) = -E[KL] on a held-out DCLM slice; select top-K [full text, Section 3.2-3.3 / Eq 6, Algorithm 1]. The KL is teacher-forced on corpus prefixes (Eq 5), so the selection signal never involves the student's own generations. Ablation: KL-based (S2) scores beat MSE-based (S1) scores, and greedy addition beats greedy removal [full text, Section 5.1, Table 2]. Selection is per whole layer and the final ratio K is set by hand (1:8, 1:3, 1:2, 1:1) [Section 4.2].

### Goal: What does it report as its limitation on hybrids (recall, length, reasoning)?
Recall on RULER is highly sensitive to K while commonsense is flat [Section 4.1, Figure 2]. Long-context evaluation is mostly below 10K tokens and distillation uses short sequences; NIAH at 128K drops from 0.954 (teacher) to 0.684 (25% softmax student) [Appendix F, Table 13]. No long chain-of-thought / reasoning benchmark is evaluated. The conclusion names cheaper importance proxies and head-level hybridization as future work [Section 7]. The intro notes that test-time-compute scaling for distilled hybrids is where in-context retrieval is a key bottleneck, but the paper does not address it [Section 1].
