# Kalman Delta Networks: Uncertainty-aware Associative Memory

## What this paper does
Casts associative memory as a linear-Gaussian state-space model (latent map S~_t = D_t S~_{t-1} + W_t, observation v_t = S~_t^T k_t + e_t) and updates the memory with a Kalman filter, so write strength depends on tracked uncertainty of stored associations. Shows DeltaNet/GDN/KDA are fixed-gain Kalman filters with a token-predicted isotropic surrogate. Proposes Diagonal KDN (one uncertainty per key channel) and Isotropic KDN (one per head) that keep associative-scan / chunkwise training; pretrains 750M and 1.3B models.

## Goal-by-goal answers
### Goal: What memory update rule does it use and what determines the write/erase strength per token?
Section 3.1-3.3: process model D_t (=I for DeltaNet, alpha_t I for GDN, diag(alpha_t) for KDA), process noise Omega_t, observation noise r_t; gain kappa_t = (p^_t ⊙ k_t) / (r_t + sum_i p^_{t,i} k_{t,i}^2) (Eq. 11, Diagonal KDN). So write strength depends on accumulated per-channel uncertainty p_t plus token-predicted r_t, omega_t, alpha_t. The introduction states prior models "predict write strength from the current token representation, without explicitly tracking uncertainty in the stored memory".

### Goal: What approximation does it make to stay hardware-efficient, and what does it lose?
Section 4.1: the exact posterior covariance P*_t = (I - kappa_t k_t^T) P^_t "is generally dense", so it is projected each token onto a diagonal (mean-field) family. "Diagonal projection discards correlations that encode confidence in combinations of key channels. It can therefore overestimate uncertainty along an already observed key direction, causing repeated or similar keys to trigger overly strong writes" — patched by a heuristic information scale mu (Eq. 17). Conclusion [Section 7]: "Exact filtering maintains a dense key-space covariance and a state-dependent Riccati update, whereas the isotropic and diagonal approximations compress this covariance to preserve parallel training"; making richer transition + covariance updates scan-efficient "remains open".

### Goal: What does it report as its limitation on recall / memory capacity at long context?
Section 5.2: Diagonal KDN has the best recurrent-only RULER aggregate and real-world recall average, but "every hybrid model substantially outperforms its recurrent-only counterpart on these tasks". Uncertainty reflects how much evidence has been written, not whether an association will later be queried.
