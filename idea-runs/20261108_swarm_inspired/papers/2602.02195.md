# State Rank Dynamics in Linear Attention LLMs

## What this paper does
Studies effective-rank dynamics of the recurrent state in Qwen3-Next (Gated DeltaNet) and finds "State Rank Stratification": some heads stay near-zero effective rank, others saturate at the upper bound, and the split is identical across data domains. Proposes Joint Rank-Norm Pruning (JRNP), a training-free head-pruning rule that removes high-rank "saturated" heads, cutting KV-state memory by 38.9%.

## Goal-by-goal answers
### Goal: What mechanism selects which recurrent-state units are removed, and is the selection fixed or input-dependent?
Heads are scored by a saturation score S_h = alpha*mean_rank/d + (1-alpha)*mean_nuclear_norm/max, and top-k% heads are permanently pruned [full text, Section 5.2, Eq 14]. The choice is justified by "Data Independence": the set of high- vs low-rank heads is invariant across WikiText, GitHub and arXiv, so the method is data-free and fixed per model [full text, Section 3.3]. Under repetitive adversarial inputs the stratification pattern breaks (cyclic, contracted rank) [full text, Section 3.4], but pruning does not react to this.
### Goal: What does it report as its limitation on long-context recall under state pruning?
Removing the wrong group (low-rank heads) collapses NIAH 93.8->46.9; removing high-rank heads costs 93.8->90.6 NIAH and GSM8K 100->96.9 [full text, Sections 5.1, 5.3]. Analysis is only on Qwen3-Next; generalization to Mamba/RWKV/RetNet and a theory of the invariance are left open [full text, Section 8].
