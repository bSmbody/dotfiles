# GSRQ: Gain–Shape Residual Quantization for Sub-1-bit KV Cache

## What this paper does
Vector/residual quantization of K and V toward and below 1 bit per activation (ICML 2026). Argues that ℓ2 K-means centroids shrink in high dimension (mean cancellation), weakening angular fidelity. Replaces K-means with Gain–Shape K-means (separate magnitude and unit-direction updates) and a log-weighted variant inside a product×residual quantization pipeline (codebook K=256, subspace D, R residual stages; BPA = R·log2K/D). Calibrated offline on 128×2048 samples.

## Goal-by-goal answers
### Goal: What is the mechanism and bit accounting?
Law-of-cosines argument: ||x−μ||² = ||x||²+||μ||²−2||x|| ||μ|| cosθ, so small ||μ|| down-weights direction [full text, Sec 4, Eqs 1-2]. GSKM alternates assignment, shape (direction) update and gain (mean projection) update [Sec 5.2]; weighted GSKM [Sec 5.3]. Configs: 2/1/0.75 BPA use D=128, R=32/16/12; 0.375 BPA uses D=256, R=12 [Sec 6.2 "Configurations"].
### Goal: How does it do on reasoning at 1–2 bits?
Llama-3-8B-Instruct, 8K max length: GSM8K FP16 76.19; GSRQ 2-bit 65.73 (VQLLM 55.65); 1-bit 26.16 (VQLLM 2.27) [Table 4]. MATH-500 FP16 20.4; GSRQ 2-bit 19.0, KIVI-2 15.8; 1-bit GSRQ 14.2, KIVI-1 0.8; RULER 1-bit GSRQ 72.0 vs FP16 96.0 [Table 5]. LongBench 1-bit avg 33.54 vs VQLLM 11.34 [Abstract]. Baselines CQ, KIVI, VQLLM (AnTKV excluded). No long-CoT reasoning model or output length is evaluated; sub-1-bit still loses heavily on reasoning.
### Goal: Efficiency?
Custom PyTorch + Triton fused kernels (quantize/pack new KV; unpack+dequant+RoPE+attention); 1.59–3.40× per-token decode latency speedup over FP16 at long contexts at 0.75 BPA on Llama-3-8B; FP16 OOMs at 128K [App C, Tables 12-13]. Not in vLLM/SGLang.

# GSRQ: Gain-Shape Residual Quantization for Sub-1-bit KV Cache

## What this paper does
GSRQ is a residual vector quantizer for the KV cache (ICML 2026). It identifies "centroid shrinkage": in high dimension, Euclidean K-means centroids lose norm, which weakens angular alignment. It replaces K-means with Gain-Shape K-means (a separate unit-norm shape and a scalar gain, updated by mean projection), plus a gradient-weighted variant, inside a residual quantization pipeline with codebook size 256, subspace dimension D=128 and R residual stages. The rate is R·log2(K)/D bits per activation: 2, 1, 0.75 or 0.375. Codebooks are calibrated offline (128 samples × 2048 tokens).

## Goal-by-goal answers
### Goal: Headline numbers?
LongBench average on LLaMA-3-8B at 1 bit: 33.54 vs 11.34 for VQLLM (Abstract, Table 3). GSRQ at 0.75 bits beats VQLLM at 1 bit and KIVI-1. GSM8K (Table 4), LLaMA-3-8B-Instruct: FP16 76.19, GSRQ-2bit 65.73, GSRQ-1bit 26.16 (VQLLM-1bit 2.27). So 1-bit RQ still loses about 50 GSM8K points on short reasoning.
### Goal: Is it evaluated on long-CoT reasoning models?
No. It uses LLaMA-2/3, Mistral and Qwen3-8B few-shot tasks, LongBench, MATH-500 and RULER with an 8K maximum sequence length (Section 6.2, Tables 5, 7). No thinking-mode generation.
### Goal: Kernels/latency?
Custom Triton kernels fuse RQ encode/pack and unpack/dequant/RoPE/attention. Layer-wise per-token latency at 1K context is 2.3 / 3.9 / 7.9 ms (FP16) vs 1.2 / 1.7 / 2.3 ms (GSRQ) at batch 8 / 16 / 32 (App. C, Table 12). Encoding new tokens requires R sequential residual codebook searches.
