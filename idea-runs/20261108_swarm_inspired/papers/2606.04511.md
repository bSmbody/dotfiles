# SparDA: Sparse Decoupled Attention for Efficient Long-Context LLM Inference

## What this paper does
Adds a fourth per-layer projection, the Forecast F_l, alongside Q, K and V (<0.5% extra parameters, a trained indexer). F_l scores the compressed keys of layer l+1 and selects that layer's top-k blocks one layer ahead, so the CPU-to-GPU prefetch of the selected KV overlaps with the current layer. Built on InfLLM-V2 sparse attention, with evaluation on long-context and reasoning (MATH-500, AIME).

## Goal-by-goal answers
### Goal: Does the lookahead change what attention computes, or only which blocks are fetched?
Only which blocks are fetched. The selected set B_{l+1} = init ∪ local ∪ topk(F_l K~_{l+1}^T). The sparse attention itself still uses the fresh Q_{l+1} [full text, Section 4.1, Eqs 3-5]. Its accuracy is "bounded by the quality of the base sparse attention method" [Section 6].
