# Learning What Matters: Causal Evidence Sets for Global Context Pruning

## What this paper does
Tests whether attention shows which context a model's answer depends on, using synthetic key-value retrieval tasks (single-record, multi-hop, latest-write) where evidence is known, and frozen Qwen2.5 models on natural-language variants. Context blocks are masked at every layer and the answer change is measured. Attention and causal dependence disagree; a block-selection router trained on causal evidence sets (labels verified by masking) routes far more reliably than one distilled from attention, and transfers to pretrained models up to 32B.

## Goal-by-goal answers
### Goal: How are the causal labels defined and obtained, and what do they beat?
Masking a block adds −1e4 to its attention logits at every layer for every query outside it, with positions unchanged; a set is sufficient if restricting attention to it preserves the answer, a block necessary if masking it changes the answer [full text, Sections 2.2, 2.3]. Redundancy breaks necessity, so the measured set includes every block that alone suffices [Section 2.3]. A router trained on these causal evidence sets routes multi-hop at 0.99-1.00, against 0.36-0.98 for one distilled from answer-position attention across four teachers [Section 1, Section 5]. On frozen Qwen2.5-3B/7B, a causal record router matches the dense model and holds at doubled record count, while the attention-imitation router falls to its random control [Section 7].

### Goal: What is its scope: architecture, phase (prefill vs decode), and limits?
Pure Transformers only (10.7M synthetic teachers, Qwen2.5 and Llama up to 32B); the selection is a one-shot global routing of the context before or at query time (KV eviction / prompt compression protocol), not decode-time eviction of generated tokens [Sections 1, 7, Appendix M]. Labels are behavioral and the annotation-free estimator handles redundancy or chains but not both; no router recovers the pretrained multi-hop task; natural-text selector reaches two thirds of the annotated-evidence reference [Section 10].
