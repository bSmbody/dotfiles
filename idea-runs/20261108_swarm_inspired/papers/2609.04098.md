# Why Gated DeltaNet Survives 4-Bit Quantization: NVFP4 W4A4 for the Recurrent Half of a Hybrid 27B LLM

## What this paper does
Builds an NVFP4 W4A4 checkpoint of Qwen3.8-27B (48 GDN + 16 attention layers) with all linear layers including GDN quantized, matching BF16 within seed noise on MMLU-Pro, GSM8K, AIME'25, GPQA, LiveCodeBench and RULER to 64K, and runs a mechanism study of why the GDN recurrence does not accumulate the injected error. Also studies FP8 KV for the attention layers.

## Goal-by-goal answers
### Goal: What error-persistence model does its allocation use, and does it include delta-rule erasure and cross-step error correlation?
No allocation; it measures persistence. With quantization noise injected every step, state error plateaus (12.96% at token 256, 12.31% at 32,768). A one-off 1% state impulse falls to 1/e within 80-1,382 steps and to 1/10 within ~2,200-2,900, "while the decay-implied horizons 1/(1-alpha) of the same layers reach 44K-62K tokens"; the extra erasure "is the delta rule itself ... old errors are deleted key by key as new tokens arrive, not merely decayed" [full text, Section 5.3, Figure 1]. Caveat: this is weight/activation noise (largely incoherent), not state-storage rounding.
### Goal: How does it treat the attention-layer KV cache versus the recurrent state, and is the byte budget shared between them?
Separately. Weight-quantization cost falls with position (+0.081 nats first half, +0.011 second half), while the FP8-KV cost "is small, rises with position", i.e. the two error sources have opposite position dependence [Section 5.4, Figure 2]. KV is set to FP8 with static per-tensor calibrated scales as an independent recipe step [Section 7]. Scope: one model, 32K PPL, 64K retrieval [Section 9].
