# Transformer-VQ: Linear-Time Transformers via Vector Quantization

## What this paper does
Decoder-only Transformer whose keys are vector-quantized to a learned codebook of S codes. Because the attention-score matrix then has at most S distinct columns, softmax attention over the quantized keys is computed exactly in linear time: a block recurrence keeps, per code, a running count and value sum (compressive cache), plus exact attention to the current and previous block. Trained from scratch; competitive on Enwik8, PG-19, ImageNet64, >3x faster than quadratic attention at 8K and >12x at 32K.

## Goal-by-goal answers
### Goal: How does Transformer-VQ compute softmax attention over quantized keys without a per-token scan?
Theorem 3.5: W = Diag(exp(Q C^T) Delta 1)^{-1} exp(Q C^T) Delta with Delta_{s,t} = delta(s, z_t), so the query only needs the S code scores and the grouped sums Delta V and counts Delta 1 [full text, Section 3.2, Eq 21]. Theorem 3.7 gives the causal block recurrence U(n) = U(n-1) + Delta V (value sums per code) and L(n) = L(n-1) + Delta 1 (counts per code), read as exp(Q C^T) U(n-2) and exp(Q C^T) L(n-2), plus exact terms for the last two blocks [Section 3.3, Eq 26-34]. Cost O(T(S+2L)(D_k+D_v)) [Remark 3.8]; implemented with running means and log-counts for stability [Remark 3.9].

### Goal: Does it use product / multi-codebook quantization, and what codebook sizes?
It uses a single codebook (no product structure); codebook-size ablation S = 256 / 512 / 1024 with BPB 1.010 / 1.005 / 1.000 and rising latency; S=512 in main experiments [Section 5.1.1, Table 1; Section 5.2]. No product-code joint table, hence no need for tensor compression.
