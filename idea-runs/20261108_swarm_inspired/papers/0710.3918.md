# Dependable k-coverage algorithms for sensor networks

## What this paper does
Studies sleep scheduling in dense, redundant wireless sensor networks where every region must stay covered by at least k awake sensors (k-coverage), and extra coverage beyond k buys nothing. Models coverage as a sensor–region bipartite graph, defines a per-region coverage ratio (positive when over-covered, negative when at or below k) and a per-sensor "drowsiness factor" built from the regions it covers. A centralized greedy scheduler and a distributed Controlled Greedy Sleep (CGS) variant put sensors to sleep one by one only while every region they cover stays k-covered. In simulation CGS keeps full 3-coverage at the lifetime where Randomized Independent Sleeping covers only ~90%, and degrades far more gently.

## Goal-by-goal answers

### Goal: What is the core sleep-scheduling mechanism, and why does it beat independent random sleeping?
The sensing assignment is a bipartite graph between regions R and sensors S; the k-coverage problem is to find a subset S' such that every region has degree ≥ k, and the minimal version asks for a non-redundant such subset [full text, Section III.A]. Each region r gets a coverage ratio Φ_r = 1/(c_r − K) if c_r > K (over-covered) and −1 otherwise (Eq 3). A sensor's drowsiness D_s is (energy term) × Σ_r Φ_r over the regions it covers if all those regions are over-covered, and −1 otherwise: "Negative drowsiness indicates that the sensor is not allowed to sleep" (Eq 1-2). The centralized scheduler repeatedly sends the most drowsy node to sleep and recomputes, until no node has positive drowsiness (Section III.C, steps 3-5). Sensors covering only slightly over-covered regions get larger drowsiness, so the scheduler reasons about the whole coverage state rather than any sensor's own merit. The distributed CGS version lets a node sleep only "if the k-coverage problem can be solved using only nodes present in the LAN [awake list] and nodes with STD larger than STD_s" (Section III.D, step 7). The baseline Randomized Independent Sleeping lets each node sleep with probability p independently: simple, no communication, but "there is no guarantee for coverage" (Section II).

### Goal: What does it report versus random, and what assumptions does the mechanism rely on?
On a 100-node grid with required coverage 3 (Section IV.B, Fig 5-6): with p_sleep = 0.4 the random scheduler reaches about the same lifetime as CGS but its 3-coverage ratio is only ~90%, while CGS keeps the required coverage; with p_sleep = 0.25 random reaches ~95% coverage but keeps many more sensors awake and collapses abruptly (all coverage lost at t = 34, when CGS still has Θ3 = 81%, Θ2 = 86%, Θ1 = 95%). Assumptions: the sensor–region incidence must be known or approximated (each node approximates its sensing disk by a set of square regions, a deliberately pessimistic approximation that may over-cover; Section III.D Note 1, Eq 4); value is a threshold — "larger coverage does not provide higher performance" once k is met (Section I); decisions are greedy and order-dependent, not optimal.
