# Selective and Hybrid-State Communication for Latent Multi-Agent Systems

## What this paper does
NeurIPS 2026 workshop paper with two independent methods: SelectKV (boundary-aware selection of which KV positions to pass between latent agents, ~10% payload reduction) and HyLaMAS, which extends LatentMAS-style latent collaboration to Qwen3.5 hybrids by handing the full-attention KV and the GDN recurrent + causal-conv states from one agent to the next through a shared workspace. HyLaMAS cuts decoded tokens 53-80% and gives 1.16-2.78x speedups vs text-based multi-agent systems.

## Goal-by-goal answers
### Goal: Does HyLaMAS merge recurrent states of several parallel agents, or hand one state along a chain?
A chain: the shared hybrid state H_i = {(K,V) for FA layers} U {(C,S) for GDN layers} at agent boundary i, and "the next agent continues computation from that state", H_{i+1} = F_{i+1}(H_i, x_{i+1}); the Judger decodes from the final accumulated state [full text, Section 3.2, Eqs 7-11]. No parallel agents' GDN states are combined.
### Goal: How much does the GDN-state channel contribute to accuracy?
Channel ablation on MedQA: 88% with KV + GDN state, 87% KV only, 84% GDN state only, 90% with neither; none significant (McNemar p = 1.000/0.344/0.754). Keeping GDN state shortens responses (825 vs 983 decoded tokens with KV present) — "an output-length benefit without a demonstrated accuracy advantage" [Appendix A.1, Fig 3]. Only 100 examples per benchmark [Section 6].
