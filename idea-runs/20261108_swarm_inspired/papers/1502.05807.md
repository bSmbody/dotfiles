# Noise-shaping Quantization Methods for Frame-based and Compressive Sampling Systems

## What this paper does
Survey chapter (SAMPTA 2013 book) on noise-shaping quantization. When a signal is represented redundantly (oversampled time samples, frame coefficients, compressive measurements) and then reconstructed by a linear operator, the right goal is not to make each quantized coefficient close to its true value (memoryless scalar quantization, MSQ/PCM) but to push the vector of quantization errors into the kernel of the reconstruction operator. Sigma-Delta modulation does this with a causal feedback recursion that carries each step's rounding error into the next step's input; the paper generalises it to arbitrary noise-shaping transfer operators, frame duals (Sobolev, beta, V-duals) and compressive sampling.

## Goal-by-goal answers
### Goal: What is the core noise-shaping mechanism, and what guarantees does it give?
Quantization error is forced to satisfy y - q = H u with a bounded state u, where H is lower-triangular with unit diagonal; first-order Sigma-Delta is H = D (first difference), so y_n - q_n = u_n - u_{n-1} and every partial sum of errors telescopes to a difference of two bounded states [full text, Section 2 Eq 6-9, Section 3.1 Eq 12-13]. The greedy rule q_n = round(y_n + carried state) is stable (|u_n| <= delta, half the level spacing) as long as the alphabet is not overloaded: number of levels L must satisfy ||H~|| + mu/delta <= L, i.e. for first order the quantizer range must cover the input plus one step [Proposition 3.1]. A stable r-th order scheme gives reconstruction error ~ lambda^(-r) in the oversampling ratio [Eq 10-11]; MSQ's error for any frame decays at best linearly in the number of measurements [Section 3.3.1, citing [20]]. Even 1-bit and 3-level alphabets admit stable schemes with exponentially decaying error [Section 2].

### Goal: How does the reconstruction (dual) operator determine the gain, and does the ordering of samples matter?
The error is Psi H u, so it depends on how the reconstruction coefficients interact with H. For first order, ||x - Psi q|| <= ||u||_inf * sum_j ||psi_j - psi_{j+1}||, the "frame variation" of the reconstruction vectors taken in the order the quantizer visits them [Section 3.2 Eq 15-16]. Frames with low variation, e.g. obtained by sampling a smooth curve ("frame paths"), give better bounds, so the visiting order is a design variable; frame-variation bounds do not give higher-order accuracy unless the path terminates smoothly [Section 3.2]. Alternatively the decoder can be adapted to the quantizer (Sobolev duals, Eq 22-25), which is a decoder-side choice.

### Goal: What does the mechanism rely on?
(i) Redundancy: many samples per degree of freedom, so the reconstruction operator has a large kernel of high-pass / high-variation error patterns [Section 2 Eq 5]; (ii) a reconstruction that is smooth along the visiting order (low frame variation) [Section 3.2]; (iii) a non-overloaded quantizer so the carried state stays bounded [Proposition 3.1]; (iv) causality: the rule is a recursion with a tiny state, implementable in real time [Section 2].
