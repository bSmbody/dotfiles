# Not All Bits Are Equal: Scale-Dependent Memory Optimization Strategies for Reasoning Models

## What this paper does
An empirical study (more than 1,700 configurations, Qwen3 family, AIME25 and GPQA-Diamond) of how to spend a fixed memory budget for reasoning models: weight precision vs model size vs generation length vs parallel scaling, and KV eviction (R-KV at 2k/4k/8k) vs KV quantization (symmetric per-channel 2/4/8-bit, group 64, 128-token FP residual), with budget forcing to trace memory-accuracy curves.

## Goal-by-goal answers
### Goal: How does the precision-vs-token-count trade-off for KV depend on the model (relevant to seed 2's per-request precision and to precision-count trade-offs)?
Scale-dependent. Below an effective size of an "8-bit 8B" model, eviction gives the best memory-accuracy trade-off and 4-bit KV quantization causes a significant accuracy drop; above it, quantization becomes competitive with eviction, but 2-bit KV still loses significant accuracy [full text, Sec 5]. Both strategies push the Pareto frontier beyond no compression for 4/8/16-bit weights [Sec 5, Fig 8]. Precision choices are global per configuration; nothing per request or per difficulty.

### Goal: Limitations?
Only Qwen3, two benchmarks, one quantizer and one eviction method; no comparison of PTQ or eviction algorithms [Sec 8]. No wall-clock serving at memory saturation.

# Not All Bits Are Equal: Scale-Dependent Memory Optimization Strategies for Reasoning Models

## What this paper does
An empirical study over about 1,700 inference configurations of the Qwen3 family (AIME25, GPQA-Diamond). Weight precision (GPTQ 4/8/16 bit), generation budget (budget forcing), parallel scaling (majority vote) and KV compression (R-KV eviction at 2k/4k/8k tokens; symmetric per-channel KV quantization at 2/4/8 bits, group 64, 128-token full-precision residual) are traded against total memory (weights + KV).

## Goal-by-goal answers
### Goal: When does KV quantization beat eviction for reasoning?
Both advance the memory-accuracy Pareto frontier at every model size and weight precision (Section 5, Fig. 8). Below an effective size of an 8-bit 8B model, eviction (R-KV 8k) dominates and 4-bit KV causes a significant accuracy drop. Above that, 4-bit KV becomes competitive with eviction. 2-bit KV (plain symmetric per-channel) still loses significant accuracy even for large models (Section 5).
### Goal: Memory allocation finding?
Below an effective size of an 8-bit 4B model, memory is better spent on weights than on longer generation. For larger models, memory is better spent on generation length (KV). For math, 8/16-bit weights are more memory-efficient than 4-bit (Section 4, Fig. 1).
### Goal: Limitations?
Only one simple KV quantizer (no rotation or VQ) and one eviction method. Qwen3 only. Memory is accounted per request, not as throughput or cost per correct answer under batched serving (Section 8).
