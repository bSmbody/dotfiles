# Error Feedback Fixes SignSGD and other Gradient Compression Schemes

## What this paper does
ICML 2019. Shows that biased gradient compressors such as sign compression (signSGD) can fail to converge even on simple convex problems because the compressor forgets magnitude and direction. The fix, error feedback (EF), stores the residual between the intended update and its compressed version locally and adds it to the next update before compressing. For any delta-approximate compressor, EF-SGD provably converges at the rate of uncompressed SGD, approaches the span of past gradients (so it generalises like SGD), and matches SGD on CIFAR with ~64x less communication.

## Goal-by-goal answers
### Goal: What is the error-feedback mechanism and why does it repair a biased compressor?
Algorithm 2: p_t = gamma g_t + e_t; Delta_t = C(p_t); x_{t+1} = x_t - Delta_t; e_{t+1} = p_t - Delta_t [full text, Section 4, Algorithm 2]. The residual is never discarded, so "eventually, all the gradient information is transmitted -- albeit with a delay"; the error-corrected iterate x~_t = x_t - e_t follows exact SGD, and the method behaves like a delayed-gradient method [Section 4, proof sketch of Theorem II]. Lemma 3: the stored residual stays bounded, E||e_t||^2 <= 4(1-delta) gamma^2 sigma^2 / delta^2, uniformly in t, so errors do not accumulate. Without EF, the bias of sign compression accumulates and the algorithm can converge to a wrong point or not at all [Sections 1, 3].

### Goal: What does EF require, and does it work for compressors other than sign?
Only Assumption A: ||C(x) - x||^2 <= (1-delta)||x||^2, which covers sign, top-k, low-rank (k-PCA) and randomized compressors [Section 4, Assumption A]. EF adds no hyperparameters and one stored residual vector of the same size as the update [Section 1]. The guarantee is about the running SUM of compressed updates (the iterate), which is exactly the quantity the downstream computation consumes; individual compressed updates can be far from their targets.
