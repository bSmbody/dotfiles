# What Attention Recalls and Recurrence Controls in Hybrid Language Models

## What this paper does
Two cache-level interventions on hybrids (Qwen3.5-4B with GDN, Falcon-H1-3B with Mamba): split-prefill keeps only the attention KV or only the recurrent state from a prefilled context before answering a query; state-swap pairs the KV of one context with the recurrent state of another. Exact retrieval survives only via attention KV; output language and persona survive only via the recurrent state. Four causal case studies (mixed memories, recall-not-control, associative false recall, conjunction trap) support "attention provides a lookup over what was said; the recurrent state shapes how the model says it next". Findings of EMNLP 2026.

## Goal-by-goal answers
### Goal: Which kinds of context information can the recurrent (GDN) state alone carry into generation, and which only the attention KV?
Table 1 (Qwen3.5-4B full/rec-only/kv-only): KV retrieve 1.00/0.00/0.89; list indexing 1.00/0.00/0.98; language following 0.97/0.70/0.01; persona 0.69/0.49/0.14 [full text, Section 4, Table 1]. The recall collapse under rec-only "persists in minimal versions of the task (short dictionaries, short lists), ruling out a state-too-small explanation" [Section 4]. Rec-only keeps the "semantic field" of seen words (false recall of associated absent words; conjunction errors) but not item identity/binding [Sections 5.3-5.4].
### Goal: When the KV of one context is paired with the recurrent state of another, what does the output take from each?
Case study 1: K(c_A) + R(c_B) yields the dictionary value from c_A and the answer language from c_B, jointly correct on >=99% of items in both models; same-source controls match full [Section 5.1, Appendix E]. Case study 2: kv-only can name the requested language but does not answer in it; rec-only reverses this [Section 5.2].
### Goal: What limits the generality of these results?
Small synthetic isolated tasks chosen to separate capabilities, not long-CoT reasoning [Section 4, "Why small, isolated tasks"]; results describe what each channel causally drives, not what it statically stores [Limitations, "Functional, not static, content"]; split-prefill produces a partly out-of-distribution cache combination, which state-swap mitigates [Limitations, "Nature of the intervention"].
